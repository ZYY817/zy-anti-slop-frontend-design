# V1 · 光影与阴影效果

> 光影是让界面从"平"到"有质感"的第一步。每个效果都有名字、气质、场景、prompt 措辞和坑。

---

## 一、阴影类（Shadows）

### 投影 (Drop Shadow)
- **感觉**:元素"浮"起来,有层次
- **场景**:卡片、按钮、下拉菜单、Modal
- **prompt 措辞**:"卡片带柔和投影,hover 时加深"
- **实现**:`box-shadow: 0 4px 6px rgba(0,0,0,0.1)`
- **坑**:阴影太重(模糊小、透明度高)= 廉价。要大范围、低透明度才高级
- **谁在用**:Material Design 全线

### 分层阴影 (Layered / Multi Shadow) ★高级
- **感觉**:真实、柔和、有深度(模拟真实光的多重散射)
- **场景**:高质感卡片、浮层
- **prompt 措辞**:"用多层叠加阴影模拟真实光影,更柔和自然"
- **实现**:
```css
box-shadow:
  0 1px 2px rgba(0,0,0,0.04),
  0 2px 4px rgba(0,0,0,0.04),
  0 4px 8px rgba(0,0,0,0.04),
  0 8px 16px rgba(0,0,0,0.04);
```
- **坑**:层数别太多(4-5 层够),否则性能下降
- **谁在用**:Stripe、Vercel(这是"高级阴影"的秘密)

### 长阴影 (Long Shadow)
- **感觉**:扁平时代的深度感、复古
- **场景**:图标、扁平插画
- **实现**:一连串同色阴影堆叠成"斜长条"
- **坑**:现在略过时,慎用

### 硬阴影 / 偏移阴影 (Hard Shadow / Offset Shadow)
- **感觉**:大胆、有活力、手工感
- **场景**:新粗野主义(Neo-brutalism)、年轻化品牌
- **prompt 措辞**:"新粗野风格,硬阴影不模糊,偏移 4px,黑色实边"
- **实现**:`box-shadow: 4px 4px 0 #000`(无模糊)
- **谁在用**:Gumroad、创意工具

### 彩色阴影 (Colored Shadow)
- **感觉**:活泼、现代、有品牌感
- **场景**:彩色按钮、产品卡片
- **prompt 措辞**:"按钮阴影用主色的半透明版本,而非黑色"
- **实现**:`box-shadow: 0 8px 24px rgba(59,130,246,0.4)`(主色阴影)
- **坑**:饱和度要低,否则脏
- **谁在用**:很多现代 SaaS 的 CTA

### 接触阴影 (Contact Shadow) ★真实感关键
- **感觉**:元素真正"贴"在表面上
- **实现**:一层很紧很浅的阴影(模拟接触点)+ 一层大范围软阴影
```css
box-shadow:
  0 1px 1px rgba(0,0,0,0.08),      /* 接触阴影,紧 */
  0 8px 24px rgba(0,0,0,0.08);     /* 环境阴影,散 */
```

### 内阴影 (Inset Shadow)
- **感觉**:凹陷、嵌入、按下
- **场景**:输入框内壁、按下状态、新拟物
- **实现**:`box-shadow: inset 0 2px 4px rgba(0,0,0,0.06)`

### 环境光遮蔽 (Ambient Occlusion)
- **感觉**:物理真实(角落自然变暗)
- **场景**:拟真 3D UI
- **实现**:元素交界/凹陷处加深色渐变

## 二、发光类（Glow）

### 外发光 (Outer Glow)
- **感觉**:发光、聚焦、科技、能量
- **场景**:深色界面的 CTA、focus 态、霓虹风
- **prompt 措辞**:"深色背景,按钮带柔和外发光"
- **实现**:`box-shadow: 0 0 20px rgba(59,130,246,0.6)`
- **坑**:浅色背景上发光看不出来,发光效果主要用于深色

### 内发光 (Inner Glow)
- **感觉**:内部照亮、通透
- **实现**:`box-shadow: inset 0 0 20px rgba(255,255,255,0.2)`

### 泛光 (Bloom)
- **感觉**:强光溢出、梦幻、影视感
- **场景**:hero 背景光源、高光溢出
- **实现**:亮色元素 + 大范围模糊 blur 光晕叠加

### 光晕 (Halation)
- **感觉**:柔和光环、胶片感、温暖
- **场景**:文字/图标周围柔光
- **实现**:多层 text-shadow / drop-shadow 递增模糊

### 霓虹光 (Neon Glow)
- **感觉**:赛博、夜生活、张扬
- **场景**:游戏、音乐、赛博朋克
- **prompt 措辞**:"霓虹管效果,文字带多层发光,粉蓝配色"
- **实现**:
```css
text-shadow:
  0 0 5px #fff,
  0 0 10px currentColor,
  0 0 20px currentColor,
  0 0 40px currentColor;
```

### 边缘光 / 轮廓光 (Rim Light)
- **感觉**:立体、被背光照亮、高级摄影感
- **场景**:产品图、3D 元素、暗色卡片
- **实现**:元素边缘一侧加亮色细边(`border` 或 `box-shadow` 一侧偏移)

### 逆光 (Backlight)
- **感觉**:戏剧性、神秘、氛围
- **场景**:hero 主视觉、产品展示
- **实现**:元素后方放置模糊光源

---

## 三、光斑与光线类（Light Rays）

### 镜头光斑 (Lens Flare)
- **感觉**:阳光、影视、真实相机
- **场景**:hero 背景、产品照
- **实现**:装饰性光斑图形/SVG 叠加

### 上帝光 / 丁达尔 (God Rays / Volumetric Light)
- **感觉**:神圣、通透、氛围
- **场景**:hero 背景、宗教/自然主题
- **实现**:锥形渐变 + 模糊,或 WebGL

### 聚光灯 (Spotlight)
- **感觉**:聚焦、舞台感、引导注意
- **场景**:光标跟随聚光、hero 焦点
- **prompt 措辞**:"深色背景,鼠标位置有径向聚光跟随"
- **实现**:`radial-gradient` 跟随鼠标位置(需 JS 更新 CSS 变量)

### 高光 (Specular Highlight)
- **感觉**:光泽、反光点、材质真实
- **场景**:玻璃、金属、按钮顶部反光
- **实现**:顶部一道白色半透明渐变

## 四、暗色模式的光影特殊处理 ★重要

**核心问题**:深色背景下,阴影(黑色)看不见。

### 解决方案
1. **微光边框 (Luminous Border)** 代替阴影表达层级
```css
border: 1px solid rgba(255,255,255,0.08);
```

2. **表面提亮** 代替阴影:越"高"的层用越亮的背景色
```
base:      #0A0A0A
surface 1: #141414   /* 卡片 */
surface 2: #1C1C1C   /* 浮层 */
surface 3: #262626   /* 弹窗 */
```

3. **外发光** 代替阴影表达焦点/悬浮
```css
box-shadow: 0 0 0 1px rgba(255,255,255,0.1),
            0 8px 24px rgba(0,0,0,0.4);
```

**prompt 措辞**:
> "深色模式下不用黑色阴影,改用:微光边框(white/8)+ 表面分层提亮 + 焦点态外发光"

## 五、光影的"高级感"规律

| 廉价 | 高级 |
|---|---|
| 单层重阴影(模糊小/黑) | 多层柔和阴影(大范围/低透明度) |
| 纯黑阴影 | 带一点主色的阴影 |
| 阴影到处都有 | 只有浮层有阴影,其余用边框 |
| 硬边缘阴影(非故意) | 柔和过渡阴影 |
| 深色下还用黑阴影 | 深色下用发光/边框/提亮 |

**核心口诀**:
- 阴影要"大而淡",不要"小而重"
- 光源方向要统一(通常从上方)
- 深色模式忘掉阴影,用光和边框

## 六、Prompt 模板

### 浅色高质感
```
【光影】
- 卡片:多层柔和阴影(4 层叠加,每层 rgba 0.04),而非单层重阴影
- 光源方向统一从上方
- hover:阴影从 shadow-sm 过渡到 shadow-lg,200ms
- CTA 按钮:主色的彩色阴影 rgba(主色, 0.3)
- 输入框:极淡 inset 内阴影表达"可输入"
- 禁止:重黑阴影、多处滥用阴影
```

### 深色发光
```
【光影】
- 深色基底 #0A0A0A,表面分 3 层提亮(#141414/#1C1C1C/#262626)
- 卡片用微光边框 white/8 代替阴影
- CTA/focus 态:柔和外发光 rgba(主色, 0.5) blur 20px
- hero 背景:模糊光球 + 逆光氛围
- 玻璃面板顶部一道 specular 高光
```

## 七、检验清单

- [ ] 阴影是"大而淡"而非"小而重"
- [ ] 光源方向统一
- [ ] 只有浮层有阴影,平铺内容用边框
- [ ] 深色模式用发光/边框/提亮,不用黑阴影
- [ ] CTA 阴影带主色而非纯黑
- [ ] hover 阴影过渡平滑
- [ ] 高质感场景用了多层阴影
