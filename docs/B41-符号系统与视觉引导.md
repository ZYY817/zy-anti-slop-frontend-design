# B41 · 符号系统与视觉引导

> 界面上除了图标,还有大量"小符号"——箭头、分隔符、标记、徽点。
> 这些最容易随手用,但顶级产品每一个都有规范。

---

## 一、箭头系统(Arrow System)

### 箭头的语义分类

| 箭头 | 语义 | 用途 |
|---|---|---|
| **→ 右箭头** | 前进、下一步、查看更多 | CTA、链接、面包屑 |
| **← 左箭头** | 返回、上一步 | 返回按钮、轮播 |
| **↑ 上箭头** | 增长、上传、回顶部、收起 | 数据趋势、Back to top |
| **↓ 下箭头** | 下降、下载、展开、滚动提示 | 展开、下载、滚动暗示 |
| **↗ 斜右上** | 外链、新窗口、增长趋势 | 外部链接标识 |
| **↘ 斜右下** | 下降趋势 | 数据下跌 |
| **⌄ V 形** | 展开(轻量) | 下拉菜单、手风琴 |
| **› 单尖括号** | 层级/导航 | 面包屑分隔、列表项 |
| **» 双尖括号** | 快进、更多 | 分页跳转 |
| **↻ 循环** | 刷新、重试、重新生成 | 刷新按钮 |
| **⇄ 双向** | 交换、同步、对比 | 切换、排序 |

### 箭头的视觉规范
```
线宽:      跟随图标系统(1.5px)
尺寸:      跟随文字(16px 文字配 16px 箭头)
线端:      round(友好)或 butt(精确)
与文字间距: 4-8px
垂直对齐:  与文字视觉中心对齐(不是基线)
```

### 箭头的动效
```css
/* 链接 hover 箭头右移(邀请感) */
.link:hover .arrow { transform: translateX(4px); }

/* 展开箭头旋转 */
.accordion[open] .chevron { transform: rotate(180deg); }

/* 外链箭头斜移 */
.external:hover .arrow { transform: translate(2px, -2px); }
```

### 常见错误
- ❌ 用 `>` 字符代替箭头图标(视觉不精确)
- ❌ 箭头方向与语义不符(展开用 → 而不是 ⌄)
- ❌ 箭头尺寸与文字不匹配
- ❌ RTL 语言下箭头未镜像

## 二、分隔符系统(Separator System)

### 内联分隔符

| 符号 | 名称 | 用途 | 示例 |
|---|---|---|---|
| **·** | 中点(interpunct) | 元信息分隔 | `作者 · 5 分钟阅读 · 2 天前` |
| **•** | 项目符号(bullet) | 列表 / 元信息 | `标签 • 分类` |
| **/** | 斜杠(slash) | 分类层级 / 选项 | `设计 / 开发` |
| **|** | 竖线(pipe) | 导航分隔 | `首页 | 产品 | 定价` |
| **›** | 单尖括号 | 面包屑 | `首页 › 产品 › 详情` |
| **—** | 长破折号 | 引用作者 | `—— Steve Jobs` |
| **–** | 短破折号 | 范围 | `2020–2026` |

### 分隔符使用规范
```
✅ 中点 · 最常用于元信息(前后加空格)
✅ 竖线 | 用于导航(前后加更多空格或用留白)
✅ 面包屑用 › 而不是 >
❌ 不要混用多种分隔符
```

**CSS 实现(自动分隔)**:
```css
.meta > *:not(:last-child)::after {
  content: '·';
  margin: 0 8px;
  color: var(--text-muted);
}
```

### 块级分隔

| 方式 | 视觉 | 何时用 |
|---|---|---|
| **留白** | 无线条 | ★首选,最干净 |
| **1px 线** | 极淡横线 | 需要明确边界时 |
| **色块背景** | Section 背景变色 | 大区块切换 |
| **形状分隔** | 波浪/斜切 SVG | 品牌感/柔和过渡 |
| **带文字的线** | ───── 或 ───── | 表单"或"分隔 |

**带文字分隔线实现**:
```css
.divider-text {
  display: flex;
  align-items: center;
  gap: 16px;
}
.divider-text::before,
.divider-text::after {
  content: '';
  flex: 1;
  height: 1px;
  background: var(--border);
}
```

## 三、标记与徽点(Markers & Indicators)

### 状态点(Status Dot)
```
● 6-8px 圆点
绿 = 在线/正常  黄 = 忙碌/警告  红 = 离线/错误  灰 = 未知
```
**规范**:必须配文字,不能只用颜色(色盲)。

### 未读点(Unread Dot)
```
● 8px 实心圆,主色或红色
位置:列表项左侧,或标题旁
```

### 数字徽标(Badge)
```
< 10:   单数字,圆形
10-99:  两数字,圆角矩形
≥ 100:  "99+"
0:      不显示(或显示灰点)
```

### 必填标记(Required)
```
✅ 标签后加 * (红色)
✅ 或标签后加 "(必填)"
❌ 不要只用红色(色盲)
```

### 新功能标记(New/Beta)
```
[NEW]  小 pill,主色底白字,10-11px,大写
[BETA] 同上,灰底或黄底
```
**规范**:一段时间后自动消失(不要永久 NEW)。

### 星标/收藏(Star)
```
☆ 空心 = 未收藏
★ 实心 = 已收藏
颜色:金色 #F59E0B
动效:点击时 scale 弹跳
```

## 四、视觉引导手段完整表

引导用户视线到目标(如主 CTA)的所有手段:

### 1. 尺寸引导
最大的元素先被看到。

### 2. 颜色引导
唯一的强调色 = 唯一的焦点。

### 3. 对比引导
高对比元素跳出。

### 4. 空间引导(隔离)
周围留白最多的元素显得最重要。

### 5. 位置引导
Z 型/F 型动线的关键节点。

### 6. 方向引导
- 箭头明确指向
- 线条引导视线
- 渐变方向暗示流动
- 人物视线方向(模特看向 CTA)

### 7. 动效引导
- 动的东西先被注意(共同命运原则)
- CTA 微妙 pulse
- 入场动画最后出现的元素

### 8. 序号引导
1 → 2 → 3 明确顺序。

### 9. 高亮/暗化引导
聚焦目标,暗化其余(staging)。

### 10. 重复引导
同一元素重复出现建立认知,最后一次出现时用户已熟悉。

### 11. 中断引导
规律中的突然打破 = 吸引注意。

### 12. 深度引导
浮起的元素(阴影/z轴)先被注意。

**顶级做法**:主 CTA 至少用 **3 种引导手段叠加**(尺寸 + 唯一色 + 空间隔离)。

## 五、Emoji 在 UI 的规范

### 可以用的场景
- 空态插图替代(轻量)
- 分类标识(视觉化)
- 微文案点缀(轻松语境)
- 庆祝/成功反馈

### 不该用的场景
- 主要功能图标(跨平台渲染不一致)
- 严肃/专业界面
- 需要精确对齐的地方(emoji 尺寸不统一)
- 品牌视觉核心

### 规范
```html
<!-- 装饰性 emoji -->
<span aria-hidden="true">🎉</span>

<!-- 有意义的 emoji -->
<span role="img" aria-label="庆祝">🎉</span>
```
- 加 `aria-label` 或 `aria-hidden`
- 注意跨平台渲染差异(Apple/Google/Windows 长得不一样)
- 不超过 1-2 个(过多显廉价)

## 六、数学与特殊符号

| 符号 | Unicode | 用途 | 常见错误 |
|---|---|---|---|
| **×** | U+00D7 | 乘号/尺寸 | 用字母 x |
| **÷** | U+00F7 | 除号 | 用 / |
| **±** | U+00B1 | 正负 | 用 +/- |
| **≈** | U+2248 | 约等于 | 用 ~ |
| **≥ ≤** | U+2265/2264 | 大于等于 | 用 >= |
| **→** | U+2192 | 箭头 | 用 -> |
| **…** | U+2026 | 省略号 | 用 ... |
| **—** | U+2014 | 长破折号 | 用 -- |
| **–** | U+2013 | 短破折号 | 用 - |
| **©®™** | — | 版权商标 | 用 (c)(r)(tm) |
| **°** | U+00B0 | 度 | 用 o |
| **′″** | U+2032/2033 | 分秒/英尺英寸 | 用 '" |
| **№** | U+2116 | 编号 | 用 No. |

**规律**:用真正的 Unicode 符号,不用 ASCII 近似 —— 这是精致度的细节。

## 七、Prompt 模板

```
【符号系统】

箭头:
- 前进/查看更多:→(hover 时 translateX(4px))
- 返回:←
- 展开/收起:⌄ / ⌃(旋转 180deg 动画)
- 外链:↗(hover translate(2px, -2px))
- 刷新:↻
- 线宽 1.5px,尺寸跟随文字,round 线端
- RTL 时方向性箭头镜像

分隔符:
- 元信息用中点 ·(前后 8px 间距)
- 面包屑用 ›
- 范围用短破折号 –(2020–2026)
- 引用作者用长破折号 ——
- 块级分隔优先用留白,必要时 1px rgba(0,0,0,0.06)

标记:
- 状态点:8px 圆 + 文字(不只用颜色)
- 未读:8px 主色实心圆
- 数字徽标:<10 圆形,≥100 显示 99+
- 必填:标签后 * 红色 + aria-required
- NEW/BETA:pill 标签,11px 大写,一段时间后消失

视觉引导(主 CTA):
- 至少 3 种手段叠加:最大尺寸 + 唯一强调色 + 周围最多留白
- 可选:箭头指向 / 微妙 pulse / 入场最后出现

特殊符号:
- 用真 Unicode:× 不是 x,… 不是 ...,— 不是 --
- 引号用 "" 不是 ""

Emoji:
- 仅用于空态/庆祝/轻松语境
- 加 aria-label 或 aria-hidden
- 不超过 1-2 个
```
