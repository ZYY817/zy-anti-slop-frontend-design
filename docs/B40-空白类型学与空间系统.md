# B40 · 空白类型学与空间系统

> 留白讲了很多次,但从没**分类**过。
> 不同的空白有不同的名字、语义和用法——搞清这层,间距系统才真正成立。

---

## 一、空白的技术类型学

### 六种基本空白

| 名称 | 位置 | 作用 | CSS |
|---|---|---|---|
| **Margin 外边距** | 元素外部 | 元素与元素之间的距离 | `margin` |
| **Padding 内边距** | 元素内部 | 内容与边框之间的空隙 | `padding` |
| **Gap 间隙** | 布局子元素之间 | Flex/Grid 子元素间距 | `gap` |
| **Gutter 装订线** | 栅格列之间 | 栅格系统的列间距 | `column-gap` |
| **Inset 内嵌** | 定位偏移 | 绝对定位的四边偏移 | `inset` |
| **Offset 偏移** | 位置调整 | 元素相对原位的位移 | `transform` / `top/left` |

### 现代最佳实践
```
✅ 优先用 gap(Flex/Grid)
   - 不会有 margin collapse 问题
   - 不会有"最后一项多余 margin"问题
   - 语义更清晰

⚠️ margin 用于组件之间的关系
✅ padding 用于组件内部呼吸
```

## 二、空白的尺度层级(Scale of Space)

### 五个层级

| 层级 | 名称 | 数值范围 | 作用 |
|---|---|---|---|
| **微空白** | Micro | 2-4px | 图标与文字、内联元素 |
| **元素空白** | Element | 8-16px | 相关元素之间 |
| **组件空白** | Component | 16-24px | 组件内部 padding、组件之间 |
| **区块空白** | Section | 32-64px | 内容区块之间 |
| **画布空白** | Canvas | 64-200px | 页面级留白、首屏呼吸 |

### 具体应用
```
微空白 (4px):
  图标 ↔ 文字
  标签 ↔ 数值

元素空白 (8px):
  Label ↔ Input
  标题 ↔ 描述
  按钮 ↔ 按钮

组件空白 (24px):
  卡片内 padding
  卡片 ↔ 卡片

区块空白 (48px):
  Section 内的组之间

画布空白 (96-128px):
  Section ↔ Section(桌面)
  首屏上下 padding
```

## 三、主动留白 vs 被动留白 ★概念区分

### 被动留白(Passive Whitespace)
- 功能性的、必要的空隙
- 例:行高、字距、元素间距、padding
- 目的:可读性、分组、呼吸
- **用户不会注意到,但缺了就难受**

### 主动留白(Active Whitespace)
- 有意为之的、大面积的空
- 例:首屏 60% 留空、单个元素周围的巨大空间
- 目的:**制造焦点、传达高级感、创造张力**
- **用户会感觉到"这个设计很大方/自信"**

**关键洞察**:
> 被动留白是**及格线**(不做就难受)
> 主动留白是**高级感来源**(敢做才显贵)

**Prompt 措辞**:
> "首屏使用大量主动留白(70%):单个巨型标题浮在空间中央,周围至少 200px 空白。这个留白不是'没内容',是主动传达'从容与自信'。"

## 四、空白的语义功能

### 1. 分组(Grouping)★格式塔接近性
```
标题
 ↕ 8px    ← 近 = 一组
描述
 ↕ 32px   ← 远 = 分组
下一个标题
```
**用空白分组比用边框分组更干净**(Tufte 数据墨水比)。

### 2. 层级(Hierarchy)
元素周围留白越多 = 越重要。
```
[巨大留白] 主标题 [巨大留白]   ← 最重要
[中等留白] 副标题 [中等留白]
[小留白] 正文 [小留白]         ← 次要
```

### 3. 引导(Guidance)
用空白创造"通道",引导视线流动。

### 4. 呼吸(Breathing)
长内容之间的休息点,避免视觉疲劳。

### 5. 停顿(Pause)★
Section 之间的大留白 = 音乐的休止符。
- 告知"话题切换"
- 让前面的信息沉淀
- 制造期待

### 6. 叙事(Narrative)
留白本身传达信息:
- 大量留白 = 从容、高级、自信
- 极少留白 = 紧凑、高效、信息型
- 突然的大留白 = 强调、惊叹

## 五、间距系统的建立

### 基准单位选择
| 基准 | 阶梯 | 特点 |
|---|---|---|
| **4pt** | 4,8,12,16,20,24,32,40,48,64,80,96,128 | 精细,选择多 |
| **8pt** | 8,16,24,32,40,48,64,80,96,128,160 | 简洁,不易乱 |
| **斐波那契** | 8,13,21,34,55,89 | 自然比例,略难对齐 |

**推荐**:4pt 基准(兼顾精细与规整)。

### 语义化间距 Tokens
```
space-3xs:  2px    图标微调
space-2xs:  4px    图标↔文字
space-xs:   8px    紧密相关元素
space-sm:   12px   按钮之间
space-md:   16px   标准间距
space-lg:   24px   卡片 padding / 卡片间
space-xl:   32px   小区块间
space-2xl:  48px   区块间(移动)
space-3xl:  64px   区块间
space-4xl:  96px   大区块间(桌面 section)
space-5xl:  128px  首屏 padding
space-6xl:  160px  极致留白
```

### 流体间距(响应式)
```css
--space-section: clamp(48px, 8vw, 128px);
--space-container: clamp(16px, 4vw, 32px);
```
自动在移动端收缩,桌面端舒展。

## 六、空白的常见错误

### 1. 等距陷阱(Equal Spacing Trap)
```
❌ 所有间距都 16px → 无法分组,层级不清
✅ 组内 8px,组间 32px → 清晰分组
```

### 2. 双倍留白(Double Space)
```
❌ 上元素 margin-bottom: 24px + 下元素 margin-top: 24px = 48px
✅ 用 gap 或统一方向的 margin
```

### 3. 最后一项多余间距
```
❌ 每项 margin-bottom → 最后一项底部多余空隙
✅ 用 gap,或 :not(:last-child)
```

### 4. 移动端间距不缩
```
❌ 桌面 96px 直接用于移动 → 一屏只能看到一点
✅ clamp() 或断点缩到 48px
```

### 5. 内容贴边
```
❌ 移动端 padding: 0 → 文字贴屏幕边缘
✅ 最少 16px container padding
```

### 6. 随手值
```
❌ padding: 15px 22px
✅ padding: 16px 24px(4 的倍数)
```

## 七、留白的量化(版面率)

```
版面率 = 有内容的面积 / 总面积

< 40%      极空旷 — 奢侈品/艺术/品牌页
40-55%     空旷   — 高端落地页
55-70%     舒适   — 标准网站 ★推荐
70-85%     密集   — 内容平台/仪表盘
> 85%      极密集 — 金融终端/专业工具
```

**规律**:想显高级 → **降版面率**(多留白)。

## 八、留白的节奏(Rhythm of Space)

长页面的留白不应均匀,要有节奏:

```
Hero:        画布留白(128-200px)  ← 深呼吸
Social Proof: 区块留白(32px)      ← 紧凑
Features:     区块留白(64px)      ← 中等
Big Visual:   画布留白(128px)     ← 深呼吸
Pricing:      组件留白(24px)      ← 密集
CTA:          画布留白(160px)     ← 极致呼吸
```

**密-疏-密-疏交替 = 视觉节奏。**

## 九、Prompt 模板

```
【空间系统】

间距基准:4pt 系统
Tokens:
- 2px  图标微调
- 4px  图标↔文字
- 8px  紧密相关(label↔input / 标题↔描述)
- 12px 按钮之间
- 16px 标准 / 移动端 container padding
- 24px 卡片 padding / 卡片间距 / 桌面 container padding
- 32px 小区块间
- 48px section 间距(移动端)
- 64px section 内组间
- 96px section 间距(桌面)
- 128px 首屏上下 padding

流体间距:
- --space-section: clamp(48px, 8vw, 128px)
- --space-container: clamp(16px, 4vw, 32px)

分组原则(格式塔):
- 组内间距 8px < 组间间距 32px(4 倍差)
- 优先用留白分组,不用边框/分隔线

主动留白:
- 首屏 70% 留空,单一焦点浮在空间中
- 版面率控制 55-60%(舒适偏空旷)
- Section 之间大留白作为"视觉停顿"

留白节奏:
- Hero 画布留白 → Features 区块留白 → 大图画布留白 → Pricing 组件留白 → CTA 极致留白
- 密疏交替,不均匀铺开

技术规范:
- 优先用 gap(不用 margin)避免 collapse 和末项多余
- 所有间距是 4 的倍数,无随手值(禁止 15px/22px)
- 移动端 container padding ≥16px(不贴边)
```

## 十、检验清单

- [ ] 间距全部是 4(或 8)的倍数
- [ ] 无随手值(15px / 22px / 37px)
- [ ] 组内间距 < 组间间距(至少 2-4 倍差)
- [ ] 优先用 gap 而非 margin
- [ ] 没有双倍留白(margin 相加)
- [ ] 最后一项无多余间距
- [ ] 移动端间距缩小(不是桌面值直接用)
- [ ] container 有 padding(移动 ≥16px)
- [ ] 有主动留白(不只是被动够用)
- [ ] 版面率 55-70%(或有意选择其他档)
- [ ] 长页面留白有节奏(密疏交替)
- [ ] 首屏留白最大(呼吸最深)
- [ ] 分组优先用留白不用边框
