# F7 · 视觉提示词速查库

> 定位：B82（反 AI 味五维度引导）与 Z1（全量生成器）之间的"**即取即用层**"。F2 是通用高杠杆词，本文件是视觉专用的 prompt 模板库——复制、填空、粘贴。
> 2026 共识：**给 AI 一个标签，不如给一份 brief**（Superdesign）。意图与执行分离（explainx）：否则得到 wallpaper。
> 与 F2(词典)、Z1(全量)、B82(引导)、B16(风格词)、B85(参考演化) 衔接。

---

## 一、四要素结构（任何视觉 prompt 的地基）

| 要素 | 回答什么 | 示例 |
|---|---|---|
| Context | 做什么类型的设计 | SaaS 仪表盘 / 移动 onboarding / 落地页 hero |
| Purpose | 给谁、达成什么 | 面向 CMO 的营销分析工具 |
| Style | 视觉方向与气质 | 极简、深色、像 Stripe |
| Details | 具体元素 | 侧边栏、指标卡、图表区、CTA |

> 每一类越具体，结果越好（Komposo）。**意图（audience/brand 约束）与执行（layout/style tokens）分开写**，混在一起模型就自由发挥。

---

## 二、视觉规则块模板（frontend_aesthetics 型，可整体粘贴）

来源：Claude Cookbook 对照实验验证——无此块时模型默认白底紫渐变，有此块时输出多样且有趣：

```
<frontend_aesthetics>
过度使用的字体：Inter、Roboto、Arial、系统默认 —— 禁用
陈词滥调的配色：白底紫渐变、千篇一律的"蓝 #4F46E5 主按钮" —— 禁用
可预测的布局与组件模式：三张圆角卡片、居中 Hero —— 禁用
要求：为上下文做真正有主见的选择，可辩护的美学风险。
注意：你会收敛到常见选择（如 Space Grotesk）——必须跳出框框。
</frontend_aesthetics>
```

> 陷阱：只列"禁用"不够，还要点名"你会收敛到哪"（Space Grotesk 效应）——模型需要被告知它自己的盲区。

## 三、五维度引导模板（B82 精简版）

```
逐维度给我选择，并先陈述理由再写代码：
1. 字体：[Display 一个 + Body 一个 + Mono 可选]，禁 Inter/Roboto/系统默认
2. 色彩：一句话定调性（"奶油纸感+陶土橙强调"），主色+锐利强调，CSS 变量
3. 动效：一个精心编排的时刻 > 散落的微交互；有 reduced-motion 降级
4. 背景/氛围：[渐变?/纹理?/网格?/纯色?] 与主内容的关系
5. 布局：网格逻辑、留白比例（对标 B18：50% 留白、1-2 英雄元素）
```

## 五、参考杂交模板（B85 三段式，直接填空）

```
[拆解] 参考 A（给图/描述），只学它的【排版节奏】；
        参考 B，只学它的【配色逻辑】；
        参考 C，只学它的【动效哲学】。
[杂交] 三者组合，互不冲突。
[变异] 移除所有 AI 默认元素（禁 Inter/紫渐变/三卡片）；
        加入真实约束：{一句业务约束}；
        把【某维度】极端化（字号×3 / 留白×5 / 对比拉满）。
```

## 六、页面型模板（可复制的骨架）

| 场景 | 模板骨架 |
|---|---|
| 落地页 hero | 标题区+副标题+主 CTA+右侧产品图/插画；形容词×2 + 充足留白（Komposo 式） |
| SaaS 仪表盘 | 侧边导航+顶部指标卡+中部图表+浅/深主题；指定行业变量 |
| 移动 onboarding | 3-4 屏；插画+占位文案+进度指示+突出 CTA；跨屏一致性要求 |
| 组件变体 | "生成 primary/secondary/disabled 按钮：hover/active/focus 态，Tailwind 类" |
| 主题变体 | "转成暗色版，同布局同组件，给 CSS/主题定义" |
| UI 套件 | "生成按钮/卡片/输入/警示/弹窗成套组件：一致风格（色彩/字体），给 CSS 定义，再出深色/强调色替代方案" |

## 七、提示库管理（自己攒库的方法）

| 要点 | 说明 |
|---|---|
| 为什么攒库 | 一致性（默认值编码一次，每屏继承同一品味）+ 速度（思考被复用，不只词） |
| 长度 | 3-7 句，超过 ~200 词就是过度指定；其余靠迭代增量补 |
| 组织方式 | 按 screen 或按 style 二选一，别混 |
| 具体 > 形容词 | "深海军蓝主色+电光蓝强调+浅灰底" > "make it blue" |
| 变量即契约 | 跳过变量=模型自由发挥；填 30 秒约束 > 90% 只换形容词的 prompt |
| 迭代 | 首轮只定方向，细节通过 follow-up 增量（"再出一版暗色""hover 动效建议"） |

## 八、防翻车清单

- [ ] 意图与执行分开写（否则 wallpaper）
- [ ] 禁字清单在场（Inter/Roboto/紫渐变/三卡片）
- [ ] 防收敛点名在场（"你会收敛到 Space Grotesk，跳出框框"）
- [ ] 风格有名字或参考图（不是抽象形容词堆砌）
- [ ] 有真实约束（业务一句话）
- [ ] 写代码前先陈述字体/色彩/布局选择（M1 铁律）
- [ ] 生成后跑 B82 症状清单 + B85 三问
