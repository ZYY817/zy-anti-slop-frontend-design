# B9 · 界面感知与视觉心智

> 用户不是在"看"界面,是在"感知"界面。这些术语描述的是人与界面之间那层肉眼看不见但大脑能感知的东西。
> 从"排列元素"升级到"操控感知"——这是顶级设计师的思维层。

---

## 一、感知性能（Perceived Performance）

> 真实性能和"感觉快"是两回事。后者对用户体验的影响更大。

| 术语 | 含义 |
|---|---|
| 感知性能 | perceived performance,体感速度 > 实际速度 |
| 乐观 UI | optimistic UI,先假定成功立即反馈,后台再真正处理 |
| 骨架占位 | skeleton screen,用形状预示内容,减少"白屏焦虑" |
| 渐进加载 | progressive loading,先模糊后清晰 / 先骨架后真实 |
| 即时反馈 | instant feedback,点击后 <50ms 有视觉响应 |
| 预加载 | prefetch / preload,提前加载即将需要的资源 |
| 首字节时间 | TTFB,服务器响应速度(用户看不见但影响体感) |
| 首次内容绘制 | FCP,第一个像素出现 |
| 最大内容绘制 | LCP,主内容出现(用户"觉得加载完了") |
| 累积布局偏移 | CLS,内容跳动(令人沮丧) |
| 交互响应延迟 | INP,点了到有反应的间隔 |
| 视觉稳定 | visual stability,内容不跳 |
| 渐进式呈现 | progressive rendering,边加载边显示 |

**口诀**:快不重要,"感觉快"才重要。乐观 UI + 骨架屏 + 即时反馈三件套。

**prompt 片段**:
> "所有操作给即时反馈(<50ms 视觉响应)。异步操作用乐观 UI 先渲染预期结果。加载用骨架屏 + shimmer,不用 spinner 白屏。图片 blur-up 占位防 CLS。"

## 二、视觉可用信号（Visual Affordance & Signifiers）

| 术语 | 含义 |
|---|---|
| 可供性 | affordance,物体暗示的"能怎么用" |
| 信号 | signifier,视觉线索提示可供性 |
| 假可供性 | false affordance,看着能点实际不能 |
| 隐藏可供性 | hidden affordance,能点但看不出来 |
| 视觉可点性 | clickability cue,暗示元素可交互 |
| 状态标示 | state indicator,告诉用户当前状态 |
| 模式指示 | mode indicator,当前在什么模式 |
| 交互预期 | interaction expectation,用户预判这东西能做什么 |
| 反馈回路 | feedback loop,操作→系统→响应→用户确认 |
| 操作可见 | visibility of action,可做的操作看得到 |

**口诀**:能点的必须"看着能点";不能点的不能"看着能点"。

## 三、注意力经济学（Attention Economy）

| 术语 | 含义 |
|---|---|
| 注意力资本 | 用户注意力是稀缺资源 |
| 注意力成本 | 每个元素都在消耗用户注意力预算 |
| 注意力竞争 | 多个元素争夺同一注意力 |
| 视觉优先权 | 哪个元素先被注意到 |
| 注意力衰减 | 滚动越深注意力越低 |
| 注意力恢复 | 留白/变化让注意力重新集中 |
| 单焦点原则 | 一屏只该有一个抢注意力的元素 |
| 认知预算 | 用户在一个页面愿意花的脑力总量 |
| 信息气味 | information scent,链接/CTA 是否暗示了目的地 |
| 视觉入场费 | 用户为了理解一个 section 要花的认知成本 |

**prompt 片段**:
> "遵循单焦点原则:每个 section 只有一个视觉最强点。注意力成本控制:去掉一切不服务于转化目标的装饰。利用注意力恢复:section 之间用大留白让眼睛'换气'。"

## 五、视觉舒适度（Visual Comfort）

| 术语 | 含义 |
|---|---|
| 视觉疲劳 | 长时间看高对比/高密度后的不适 |
| 阅读舒适度 | readability + legibility 综合 |
| 字号舒适区 | 正文 16-18px / 长文 18-20px |
| 行宽舒适区 | 正文 45-75 字符(中文 25-40) |
| 行高舒适区 | 正文 1.4-1.6 |
| 对比度舒适区 | 足够但不刺眼(避免纯黑纯白) |
| 亮度适应 | 暗色模式为什么要用深灰不用纯黑 |
| 闪烁敏感 | 避免高频闪烁(诱发光敏癫痫) |
| 前庭敏感 | 大幅位移/视差/旋转可能引发眩晕 |
| 色彩疲劳 | 高饱和长时间看会不适 |
| 视觉"安全"感 | 留白足/对比适中/无跳动=安心 |

**prompt 片段**:
> "追求视觉舒适:正文 16px/行高 1.6/行宽 65ch。不使用纯黑(用 #1a1a1a),不使用纯白(用 #fafafa)。暗色模式主色饱和度降 10%。尊重 prefers-reduced-motion(去大幅视差)。"

## 六、微观精度术语（Micro Precision）

| 术语 | 含义 |
|---|---|
| 像素完美 | pixel-perfect,严格对齐到像素网格 |
| 亚像素渲染 | subpixel rendering,字体平滑技术 |
| 视觉校准 | optical adjustment,视觉对齐 > 几何对齐 |
| 半像素偏移 | 边框/分割线出现模糊——奇数定位导致 |
| 网格贴合 | grid snap,元素紧贴基准网格 |
| 基线对齐 | baseline alignment,多列文字的字底对齐 |
| 光学居中 | optical center vs geometric center |
| 设计负债 | design debt,累积的不一致/临时方案 |
| 打磨 | polish / pixel-pushing,最后阶段的微调 |
| 手术刀级精度 | surgical precision |

## 七、视觉情绪操控（Visual Mood Control）

> 本节原为情绪形容词表，已被 B61（情绪→Oklch 色度/圆角/字重/间距/动效全参数矩阵）取代——情绪词请直接用 B61 的参数化版本，本表只留感知层要点：

- 情绪由**参数组合**传达而非形容词：调性 = 对比度×明度×密度×圆角×动效的协奏
- 冷 ≠ 冷漠：低对比柔和 + 局部高对比 CTA 的反差结构（详见 B70 五档温度）
- 检查工具：六维一致性审计见 B61；温度审计见 B70

## 九、前端视觉特有词组

| 术语 | 这个词什么时候用 |
|---|---|
| 首屏 above the fold | 描述首次可见区域 |
| 折叠线 the fold | 分析用户是否需要滚动 |
| 可滚动暗示 | scroll hint,告诉用户下面有内容 |
| 视口 viewport | 当前可见区域 |
| 安全区 safe-area | 避开刘海/底部 bar |
| 视觉稳定 no CLS | 内容不跳 |
| 字体闪烁 FOUT/FOIT | 字体加载前的替代显示 |
| 图片占位 LQIP | 模糊先显再清晰 |
| 懒加载 lazy-load | 滚到才加载 |
| 首次有意义绘制 FMP | 主内容首次出现 |
| 可交互时间 TTI | 用户可以开始操作 |
| 惰性渲染 content-visibility | 屏幕外不渲染 |
| 渐进式图片 progressive JPEG | 先糊后清 |
| 响应式图片 srcset/sizes | 按设备给合适尺寸 |
| blur-up 占位 | 小图放大模糊 → 真图替换 |
| 累积布局偏移 CLS | 内容加载后位置变了 |
| 预渲染 pre-rendering | 提前准备好页面 |
| 流式渲染 streaming | 边生成边发给用户 |

## 十、检验:这些高阶维度都考虑到了吗

- [ ] 版面率/跳跃率/信噪比有意识设定
- [ ] 首屏 3 秒法则 + 动线 + 单焦点
- [ ] 感知性能:骨架屏/乐观UI/即时反馈
- [ ] 视觉层级叠加 ≥2 种手段
- [ ] 注意力控制:单焦点/注意力恢复/衰减应对
- [ ] 质感方向明确(哑光/颗粒/通透)
- [ ] 视觉舒适:字号/行高/行宽/对比度在舒适区
- [ ] 情绪控制:明度/对比/圆角/动效协调
- [ ] 有叙事弧和节奏起伏
- [ ] 有视觉签名/记忆点
