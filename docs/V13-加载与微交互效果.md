# V13 · 加载与微交互效果

> 微交互是界面"活着"的证据。每个细小反馈都在对用户说"我收到了你的操作"。

---

## 一、加载效果（Loading）

### Shimmer 光带 ★骨架屏标配
- **感觉**:正在加载、有进度
- **场景**:内容加载占位
- **实现**:骨架块 + 一道光带从左到右循环
```css
background: linear-gradient(90deg, #f0f0f0 25%, #e0e0e0 50%, #f0f0f0 75%);
background-size: 200% 100%;
animation: shimmer 1.5s infinite;
@keyframes shimmer { to { background-position: -200% 0; } }
```

### Pulse 脉冲
- **感觉**:静候中、有生命
- **场景**:通知点、状态指示、等待
- **实现**:`opacity 0.5 → 1 → 0.5` 循环,或 `scale(0.95→1.05→0.95)`

### Spinner 旋转
- **感觉**:传统加载
- **场景**:短操作(1-3 秒)
- **变体**:圆环 / 三点 / 双环 / 品牌 Logo 旋转
- **坑**:大面积用 spinner 显得廉价 → 中长加载用骨架屏

### 进度条 (Progress Bar)
- **场景**:上传、下载、长任务
- **分类**:确定进度(有百分比)/ 不确定(来回)
- **实现**:
```css
/* 不确定进度 */
.bar { animation: indeterminate 2s infinite; }
@keyframes indeterminate {
  0%   { transform: translateX(-100%); }
  100% { transform: translateX(200%); }
}
```

### 数字滚动 (Counter Tween)
- **感觉**:有力、数据感
- **场景**:统计数字从 0 增长到目标值
- **实现**:requestAnimationFrame 递增 / CSS `@property` counter
- **时长**:1-2 秒,ease-out

### 打字指示器 (Typing Indicator)
- **感觉**:对方正在输入、AI 思考中
- **场景**:Chat、AI 等待
- **实现**:三个圆点依次跳动
```css
.dot { animation: bounce 1.4s infinite; }
.dot:nth-child(2) { animation-delay: 0.2s; }
.dot:nth-child(3) { animation-delay: 0.4s; }
```

### 光标闪烁 (Cursor Blink)
- **场景**:AI 流式输出末尾
- **实现**:
```css
.cursor { animation: blink 1s step-end infinite; }
@keyframes blink { 50% { opacity: 0; } }
```

## 二、成功/错误反馈

### 勾号路径绘制 (Checkmark Draw) ★
- **感觉**:完成、确认
- **场景**:表单提交成功、步骤完成
- **实现**:SVG path + stroke-dasharray → stroke-dashoffset 动画
- **时长**:300-500ms

### 红色闪烁 + 抖动 (Error Flash + Shake)
- **感觉**:出错了!
- **场景**:校验失败、操作错误
- **实现**:
```css
@keyframes shake {
  0%, 100% { transform: translateX(0); }
  25% { transform: translateX(-4px); }
  75% { transform: translateX(4px); }
}
```
- **时长**:300ms,2-3 次震动

### 绿色闪光 (Success Flash)
- 整个区域短暂绿色闪烁(200ms)

## 三、按钮微交互

### 按下缩小 (Press Scale)
```css
&:active { transform: scale(0.96); }
```
最基础但最有效的"点击感"。

### 涟漪 (Ripple)
Material 风格,从点击位置扩散圆形。

### Loading 态
按钮文字 → spinner → 成功 ✓ 的完整状态流:
```
[提交] → [⏳] → [✓ 已发送]
```
- **实现**:状态切换 + 宽度保持(不要按钮跳动)

### 计数变化
数字变化时旧数字滑上去、新数字从下滑入。
- **场景**:点赞数、购物车数量

## 四、Toggle / Switch 微交互

### 基础
滑块从左到右 + 背景色变化。

### 高级
- 滑块形状变化(圆→椭圆挤压→圆)
- 图标切换(☀️ ↔ 🌙)
- 背景渐变过渡
- 弹性过冲(spring)

## 五、点赞 / 收藏

### 心跳 (Heart Beat)
点击时心❤️ scale(0→1.2→1) + 颜色填充:
```css
@keyframes heartbeat {
  0%   { transform: scale(0.8); }
  50%  { transform: scale(1.2); }
  100% { transform: scale(1); }
}
```
- **进阶**:发射小粒子/小心形

### 星星填充
从空心 ☆ 到实心 ★ 的 path 动画。

## 六、输入框微交互

### 浮动标签 (Floating Label)
focus 时 label 缩小浮到上方:
```css
&:focus + label { transform: translateY(-20px) scale(0.75); }
```

### 焦点边框动画
边框从透明 → 主色,可以从中间向两侧展开。

### 校验实时反馈
输入满足条件时右侧出现 ✓(绿色 fade-in)。

### 字符计数动画
快接近上限时数字变红 + 轻微 shake。

---

## 七、复选框 / 单选

### 勾号绘制
勾选时 ✓ 用 SVG stroke 路径绘制(而非直接出现)。

### 选中弹跳
整个复选框 scale(0.9→1.1→1) spring 弹。

---

## 八、通知 / Toast 微交互

### 入场
从右侧或顶部滑入 + fade:
```css
@keyframes slide-in { from { transform: translateX(100%); opacity: 0; } }
```

### 退场
倒放,或向右滑出。

### 进度条
Toast 下方有倒计时条(5s → 0 消失)。

### 堆叠
多个 Toast 堆叠时,后面的缩小并叠在下面。

---

## 九、页面级微交互

### 滚动到顶 (Back to Top)
滚动超过一屏后右下角出现 ↑ 按钮(fade-in + translateY)。

### 导航栏变体
滚动后导航栏背景从透明变毛玻璃 + 缩小 logo + 阴影出现。

### 主题切换
Light → Dark 的 transition(全局色彩过渡 300ms)。

### 页面过渡
页面切换时 crossfade / slide / shared element。

---

## 十、微交互的原则

| 原则 | 说明 |
|---|---|
| **有目的** | 每个微交互必须传达信息,不纯粹装饰 |
| **即时** | 反馈 <100ms,让人觉得"响应" |
| **克制** | 不是每个操作都要动,只有关键交互 |
| **一致** | 同类操作同样反馈(所有按钮 press scale 一致) |
| **可逆** | 有入场就有退场(对称) |
| **物理** | 遵循物理(弹簧/惯性),不突兀 |
| **安静** | 不抢内容焦点 |

## 十一、Prompt 模板

### SaaS 全站微交互
```
【微交互系统】
加载:
- 骨架屏 shimmer 1.5s 循环,形状匹配真实内容
- 短操作(<1s)无 loading;中操作用 inline spinner;长操作进度百分比
- 骨架→内容 crossfade 200ms

按钮:
- hover: bg 加深 + scale(1.02),150ms
- active: scale(0.96),50ms(立即)
- loading: 文字→spinner→完成 ✓ 全流程,宽度不变
- disabled: opacity 0.5, cursor not-allowed

表单:
- focus: 边框主色 + 浮动标签升起,200ms
- 校验通过:右侧 ✓ fade-in(绿)
- 校验失败:红边框 + shake 300ms + 内联错误消息
- 字符计数接近上限:数字变红

反馈:
- 成功:Toast 从右侧滑入 + 下方进度条 5s 倒计时
- 错误:Toast 红色 + shake
- 保存:内联"已保存"fade-in 2s 后 fade-out

庆祝:
- 里程碑完成(注册/首次发布):confetti 3s
- 日常完成:绿色 ✓ 路径绘制 + 轻微 scale

页面:
- 导航栏:滚动后透明→毛玻璃,200ms
- Back to top:滚动超 2 屏后右下出现,fade-in
- 主题切换:全局色彩 transition 300ms
```

### AI Chat
```
【微交互】
- 发送:按钮 scale(0.9→1) + 消息从底部 slide-in
- 等待:三点跳动 typing indicator
- 流式输出:逐字追加 + 光标闪烁
- 完成:光标消失 + 反馈按钮 fade-in
- 复制代码:按钮 → "已复制 ✓" 2 秒后恢复
- 重新生成:旧内容 fade-out + 新内容 fade-in
```

## 十二、检验清单

- [ ] 每个按钮有 hover + active 态
- [ ] 加载不是白屏(有骨架/spinner/进度)
- [ ] 表单有即时校验反馈
- [ ] Toast 有入场 + 退场 + 自动消失
- [ ] 成功有正面反馈(✓/confetti)
- [ ] 错误有 shake + 红色提示
- [ ] 微交互时长正确(反馈<100ms,动画200-400ms)
- [ ] 所有微交互对称(有入有出)
- [ ] 不过度(不是每次点击都有庆祝)
- [ ] prefers-reduced-motion 时简化
