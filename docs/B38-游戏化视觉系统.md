# B38 · 游戏化视觉系统

> 游戏化(Gamification)不只是"加个积分",是一整套视觉和心理系统。
> 用对场景 = 上瘾机制;用错场景 = 幼稚/烦人。

---

## 一、游戏化元素全表

| 元素 | 视觉形式 | 心理机制 |
|---|---|---|
| **积分(Points)** | 数字 + counter 动画 | 即时反馈 / 量化进步 |
| **等级(Levels)** | 段位图标 / 进度条到下一级 | 成长感 / 身份认同 |
| **徽章(Badges)** | 图标+标题+描述,集合展示 | 收集欲 / 成就感 |
| **排行榜(Leaderboard)** | 列表 + 排名 + 头像 + 分数 | 竞争 / 社会证明 |
| **连续(Streak)** | 火焰🔥 + 天数 + 日历 | 损失厌恶 / 习惯养成 |
| **进度条(Progress)** | 线性/环形/步骤 | 目标梯度(越近越努力) |
| **成就(Achievement)** | 弹窗 + 图标 + 庆祝动效 | 里程碑 / 多巴胺 |
| **任务/挑战(Quest)** | Checklist + 奖励预览 | 目标导向 / 好奇心 |
| **奖励(Reward)** | 宝箱/转盘/惊喜 | 可变奖励(赌博心理) |
| **头像/自定义** | 个性化外观 | 自我表达 / 归属 |
| **称号(Title)** | 文字标签显示在个人资料 | 身份认同 / 炫耀 |
| **虚拟货币** | 金币/钻石图标 + 余额 | 价值存储 / 目标 |
| **限时事件** | 倒计时 + 特殊 UI | 稀缺 / 紧迫 |
| **社交操作** | 点赞/分享/关注/挑战 | 社交认同 / 互惠 |

## 二、积分与数字的视觉处理

```
┌─────────────────────────┐
│  +50 XP ★              │  ← 获得积分 toast
│  Level 12 ▓▓▓▓▓▓░░░░   │  ← 等级 + 进度条
│  68/100 to Level 13     │  ← 距离下一级
└─────────────────────────┘
```

**动效**:
- 数字增加:counter tween(从旧值滚到新值)
- 积分获得:数字从操作位置"飞"到总数位置
- 升级:进度条满 → 等级数字 +1 弹跳 + 彩色闪光

## 三、徽章系统设计

### 视觉层次
```
未解锁:  灰色 + 锁图标 + 低对比
已解锁:  彩色 + 光效 + 完整图标
稀有等级: 普通(铜) / 稀有(银) / 史诗(金) / 传说(全息/动态)
```

### 徽章展示
- 网格展示(集合墙)
- 最近获得的高亮/大号
- 总数统计:"已解锁 24/50"

### 解锁瞬间动效
```
1. 灰色徽章震动(anticipation)
2. 爆发光效 + 颜色填充(从灰→彩)
3. scale(0.5→1.2→1) spring 弹出
4. confetti / sparkles 环绕
5. 描述文字 fade in("恭喜!你完成了...")
```

## 四、进度条的游戏化设计

### 基础进度
```css
.progress-bar {
  height: 8px;
  background: var(--surface);
  border-radius: 4px;
  overflow: hidden;
}
.progress-fill {
  height: 100%;
  background: linear-gradient(90deg, var(--primary), var(--accent));
  border-radius: 4px;
  transition: width 600ms cubic-bezier(0.16, 1, 0.3, 1);
}
```

### 高级进度
- **多色渐变**(随进度从蓝→绿→金)
- **发光效果**(进度条发光,越满越亮)
- **里程碑标记**(25%/50%/75% 有小钻石标记)
- **动效**:到达里程碑时 pulse + sparkle
- **数字标签**:88% 或 "22/25"

### XP 到下一级
```
Level 12                         Level 13
  ▓▓▓▓▓▓▓▓▓▓▓▓▓░░░░░░░
  68 / 100 XP
```

## 五、连续(Streak)★Duolingo 核心机制

### 视觉
- 火焰🔥图标 + 天数
- 日历热力图(连续天用主色,断裂用灰)
- "你已经连续 14 天!"

### 心理
- **损失厌恶**:断了会"失去"连续天数(比获得更痛)
- **沉没成本**:连续越长越不想断

### 视觉状态
```
活跃:  🔥 火焰亮,数字大
将断:  🔥 火焰减弱/变小(制造紧迫)
已断:  💔 心碎/灰色(损失感)
恢复:  💎 "使用冻结卡恢复"
```

### 伦理注意
- 不要让 streak 成为焦虑来源
- 提供"休息卡"/冻结机制
- 断了后不要过度惩罚(鼓励恢复)

## 六、排行榜设计

```
#  用户       分数    趋势
1  🥇 Alice   12,450  ↑2
2  🥈 Bob     11,890  ↓1
3  🥉 Carol   11,200  ↑5
---你的位置---
47 ★ You     3,450   ↑12
```

**设计要点**:
- 自己的位置始终可见(即使不在前列)
- 趋势箭头(↑↓)显示变化
- 时间段切换(本周/本月/全部)
- 好友排行 vs 全局排行
- 匿名/化名选项(隐私)

**伦理**:
- 排行榜对"中间"用户有激励
- 对底部用户可能有挫败感 → 考虑只显示前 N + 自己位置

## 七、成就解锁的完整动效流

```
触发 → 停顿 100ms(预备)
  → 遮罩出现(暗化背景,staging)
  → 成就图标 scale(0→1.2→1) + 发光(400ms spring)
  → confetti 从两侧喷出(500ms)
  → 标题淡入("成就解锁!")
  → 描述淡入(delay 200ms)
  → CTA("继续" / "分享")淡入(delay 400ms)
  → 3s 后可关闭,或点击 CTA
```

**关键**:这是**罕见的场景,允许华丽**——日常操作克制,成就解锁可以放纵。

## 八、游戏化的配色

| 元素 | 颜色 | 感觉 |
|---|---|---|
| 经验值/XP | 主色(蓝/紫) | 进步 |
| 金币 | 金色(#FFD700) | 价值 |
| 钻石 | 冰蓝(#00BCD4) | 稀有 |
| 连续火焰 | 橙红渐变 | 热情/紧迫 |
| 成功/完成 | 绿色 | 正向 |
| 稀有 | 紫色 | 神秘/珍贵 |
| 传说 | 金色 + 全息 | 极致 |

### 稀有度渐变
```
普通:  纯色(灰/绿)
稀有:  渐变(蓝)
史诗:  渐变(紫)+ 微光
传说:  全息彩虹 + 动态光效 + 粒子
```

## 九、适合游戏化的场景

| ✅ 适合 | ❌ 不适合 |
|---|---|
| 学习/教育(Duolingo) | 医疗/健康(可能焦虑) |
| 健身/运动 | 金融/银行(不严肃) |
| 社交/社区 | 企业内部(除培训) |
| 产品 onboarding | 结账/支付流程 |
| 任务管理/习惯养成 | 严肃内容(新闻/法律) |
| 客户忠诚度 | 简单工具(计算器) |

**判断标准**:游戏化应该让任务"更愿意做",不是让严肃的事"变幼稚"。

## 十、Prompt 模板

```
【游戏化视觉系统】

核心元素:
- XP 积分:右上角常驻,获得时 counter tween + 飞入动画
- 等级:头像旁显示,进度条到下一级
- 连续:火焰🔥 + 天数,日历热力图展示
- 成就:解锁时全屏庆祝(scale spring + confetti + 暗化背景)

视觉:
- 进度条:渐变填充(主色→强调色),里程碑有标记
- 稀有度:普通纯色 → 稀有渐变 → 史诗紫光 → 传说全息
- 解锁灰→彩:从 grayscale + opacity 0.5 → 彩色 + 全亮
- 排行榜:金银铜🥇🥈🥉 + 自己位置始终可见

动效:
- 积分获得:数字从操作位飞到总数位
- 进度满:pulse + sparkles
- 升级:数字 +1 弹跳 + 全屏光效
- 成就解锁:scale spring + confetti + 背景暗化
- 连续:火焰 pulse 呼吸(活跃时)

克制:
- 日常操作不触发庆祝(只有里程碑)
- 不让 streak 成为焦虑(有冻结机制)
- 排行榜不羞辱底部用户
- 提供关闭游戏化元素的选项
```

## 十一、检验清单

- [ ] 游戏化与产品场景匹配(不幼稚)

- [ ] 进度条有视觉反馈(不只是填色)
- [ ] 数字变化有 counter 动效
- [ ] 成就解锁有完整编排(不是突然弹出)
- [ ] 稀有度有视觉递进
- [ ] 自己的排名始终可见
- [ ] 有"冻结"/休息机制(反焦虑)

- [ ] 配色与主题一致(不突兀)
