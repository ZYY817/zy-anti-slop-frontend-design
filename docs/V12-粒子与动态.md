# V12 · 粒子与动态效果

> 粒子和物理动态是"这个网站活着"的信号。用对场景=高级;用错场景=廉价。

---

## 一、粒子系统（Particle System）

### 星尘 / 漂浮微粒 (Floating Particles)
- **感觉**:宇宙、深度、科技
- **场景**:深色 hero、AI/科技产品
- **prompt 措辞**:"深色背景漂浮微粒,稀疏(30-50 个),低透明度,缓慢漂浮"
- **实现**:Canvas / tsParticles
- **关键**:粒子要**稀疏**(30-60 个)、**小**(1-3px)、**慢**(移动极慢)、**淡**(opacity 0.2-0.5)

### 连线粒子 (Connected Particles / Constellation)
- **感觉**:网络、连接、数据、科技
- **场景**:技术产品、网络可视化
- **实现**:粒子之间距离 < 阈值时画连线
- **坑**:很容易显得 2015(太多老网站用过)→ 慎用,除非确实匹配

### 鼠标交互粒子
- 鼠标接近时粒子逃开/吸引
- 鼠标移动拖出拖尾粒子
- 鼠标点击时爆炸

### 上升气泡 / 萤火虫
- **感觉**:梦幻、有机、温暖
- **场景**:品牌氛围、夜间主题

## 二、庆祝效果（Celebration）

### Confetti 彩带 ★最常用庆祝
- **感觉**:成功、喜悦、里程碑
- **场景**:任务完成、付款成功、成就解锁
- **prompt 措辞**:"完成注册后全屏 confetti 庆祝动画,3 秒后淡出"
- **库**:canvas-confetti / react-confetti
- **关键**:只在真正的里程碑使用,不滥用

### 烟花 (Fireworks)
- 比 confetti 更隆重
- 场景:特别成就、新年

### 星星/闪光 (Sparkles)
- **感觉**:亮眼、魔法、惊喜
- **场景**:hover 特效、关键文字点缀
- **实现**:CSS 或小 Canvas 生成随机闪烁小星星
- **库**:react-sparkle

---

## 三、流体效果（Fluid / Liquid）

### Metaball / 液态球
- **感觉**:有机、流动、高级
- **场景**:品牌 hero、创意站
- **实现**:SVG blur + contrast 技巧(让圆球相遇时融合)
```css
.container { filter: blur(10px) contrast(20); }
```
- **进阶**:WebGL shader 做真实流体

### 液态形变 (Liquid Morph)
- blob 形状缓慢变形
- **实现**:SVG animate 或 CSS border-radius 动画
```css
@keyframes morph {
  0%   { border-radius: 40% 60% 60% 40% / 60% 30% 70% 40%; }
  50%  { border-radius: 60% 40% 40% 60% / 40% 60% 30% 60%; }
  100% { border-radius: 40% 60% 60% 40% / 60% 30% 70% 40%; }
}
```

## 四、物理动画（Physics-based）

### 弹簧 (Spring)
- **感觉**:自然、有生命、iOS 感
- **场景**:所有需要"自然"感的动效
- **库**:Framer Motion `spring` / react-spring

### 重力 (Gravity)
- 元素落下 + 弹跳
- **场景**:庆祝(confetti 落下)、游戏化

### 惯性 (Inertia / Momentum)
- 拖拽松手后继续滑行
- **场景**:轮播、列表滚动

### 弹力 (Elastic / Bounce)
- 到达终点后回弹
- **场景**:拖拽边界、下拉刷新

### 布料模拟 (Cloth)
- **感觉**:柔软、物理真实
- **场景**:旗帜动画、窗帘效果
- **实现**:WebGL / Three.js

## 五、噪声与生成（Noise & Generative）

### Perlin 噪声 / Simplex 噪声
- **感觉**:有机、自然、不规则
- **场景**:背景流动变形、地形生成、粒子运动路径
- **实现**:Canvas + noise 函数

### 噪声场 (Flow Field)
- 粒子沿着噪声场方向流动,形成有机曲线
- **感觉**:高级、生成艺术
- **谁在用**:大量数字艺术/创意站 hero

### 生成图案 (Generative Pattern)
- 每次随机不同但规则约束下的图案
- **感觉**:独特、艺术
- **实现**:p5.js / Canvas

---

## 六、涟漪与波纹（Ripple）

### 点击涟漪 (Click Ripple)
- **感觉**:触感反馈、Material
- **场景**:按钮、列表项
- **实现**:点击位置生成圆形扩散 → 淡出

### 水波 (Water Ripple)
- **感觉**:液态、平静、互动
- **场景**:创意背景、hover 互动
- **实现**:WebGL shader / Canvas

## 七、粒子的"高级 vs 廉价"

| 廉价 | 高级 |
|---|---|
| 粒子太多(100+) | 稀疏(30-60) |
| 粒子太大 | 极小(1-3px) |
| 运动太快 | 极慢 |
| 连线太密 | 稀疏或不连线 |
| 颜色杂乱 | 统一色调(单色/主色) |
| 占满全屏 | 只在局部(hero/角落) |
| 与品牌无关 | 配合品牌色和质感 |
| 粒子是唯一视觉 | 粒子是辅助装饰 |

**核心口诀**:粒子是"氛围调味料",不是"主菜"。少 = 高级。

## 八、Prompt 模板

### AI 产品 hero
```
【动态背景】
- 深色底 + 稀疏微粒(40 个,1-2px,white opacity 0.3)
- 缓慢随机漂浮(30s 循环)
- 无连线,纯漂浮
- 鼠标微微影响附近粒子(轻微排斥,最大 20px)
- 不影响性能:Canvas 实现,移动端减半(20 个)
```

### 任务完成庆祝
```
【庆祝效果】
- 触发:注册完成 / 支付成功 / 成就解锁
- 效果:全屏 confetti 从顶部下落
- 持续:2-3 秒后自然停止
- 颜色:主色 + 辅色 + 金(3 色)
- 库:canvas-confetti
- 克制:只在真正里程碑使用
```

### 创意站(流体)
```
【流体效果】
- Hero 区:2-3 个 metaball 缓慢漂浮融合
- 颜色:品牌渐变
- 速度:极慢(15-25s 变形循环)
- 实现:SVG filter blur+contrast 技巧
- 移动端:改为静态 blur blob(不动画)
```

## 九、检验清单

- [ ] 粒子稀疏(≤60 个)
- [ ] 粒子极小(1-3px)
- [ ] 运动极慢
- [ ] 颜色与品牌统一
- [ ] 移动端有性能降级
- [ ] confetti 只在里程碑用
- [ ] 流体动画极慢(≥15s)
- [ ] 不在 scroll 事件中大量计算
- [ ] 60fps 无卡顿
- [ ] 粒子是装饰不是主角
