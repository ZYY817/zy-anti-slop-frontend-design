# B87 · 结构与内容展示词库（骨）

> 定位：B86 管"皮"（表达层十二维：排版/色彩/构图/纵深/空间/动效/人性/气质轴/色板库/材质光/母题/年代锚），本文档管"骨"（**说什么、按什么顺序说、拿什么证明**）。
> 收录标准同 B86：**用了这个词，AI 会做出不同的决定**——每个词背后挂着结构规则或验收句。
> 证据：case04 二轮裸跑 V0 信息设计维唯一胜、case05 裸跑 W0 结构胜（用户终审）——三案证明一件事：**表现层全部答对、结构层即兴，照样输**。"质感赢不了骨架"（用户原话方向）。
> 用法：生成前先过"结构卡"（Z1 第 0 层 / Z2 §二点五），卡上的空位到这里挑词填；审计时到 K10 维度 2 拿检查句。
> 反模式：把这些词当标签贴（"本页是论证型"）而不做对应的区块删减与排序。

---

## 一、页面类型（先定种类——不同种类的结构基因不同）

| 词 | 是什么 → 改什么决策 | prompt 用法 |
|---|---|---|
| **论证页 Argument page** | 全页只为说服一个主张，区块=论证链节点 → 区块顺序按论证逻辑排，不按"想展示什么"排 | `本页是论证页：区块按论证链排序` |
| **货架页 Shelf page** | 陈列供人自选 → 均权网格合法，比较的便利性优先于叙事 | `货架页：卡片均权，比价/参数并列` |
| **工具页 Tool page** | 即用即走 → 功能前置，装饰最少，首屏即操作区 | `工具页：hero 直接是可用输入框` |
| **舞台页 Stage page** | 展示/表演为主 → 叙事性滚动、表演配额放宽 | `舞台页：叙事滚动，expressive 配额 +1` |
| **信函页 Letter** | 一对一说话感（创始人信/编辑手记）→ 无卡片无网格，纯排印+落款 | `信函页：通栏排印，落款签名，零卡片` |

> 判定：同一产品不同页型不同——落地页多为论证页，定价页多为货架页，仪表盘是工具页。选错页型=骨架先天错位（把论证页做成货架=特性均摆无说服力；把货架页做成论证页=选品过程被叙事绑架）。

## 二、叙事结构（全页区块的顺序逻辑）

| 词 | 是什么 → 改什么决策 | prompt 用法 |
|---|---|---|
| **论证链 Claim chain** | 勾住→定向→证明→深化→排疑→收口，六站不缺站不颠倒 → 区块清单按这六站填 | `区块=勾住/定向/证明/深化/排疑/收口各一` |
| **PAS** | problem→agitate→solve：先戳痛再放大再给解 → 痛点产品用，痛点句要具体到场景 | `PAS 结构：痛点场景段→代价放大段→解法` |
| **BAB** | before→after→bridge：前后对照+桥梁 → 有强烈对比素材时用 | `BAB：现状截图→用后截图→怎么到达` |
| **提问链 Question chain** | 每屏回答上一屏留下的问题 → 区块标题写成"对上一屏疑问的回答" | `区块按访客提问链排：是什么→凭什么→多少钱` |
| **五幕压缩 Five-act** | 开端/发展/高潮/回落/收束 → 舞台页/品牌页可用，说服力弱于论证链 | `五幕叙事滚动` |
| **特性轮转 Feature parade** | 三大特性均摆——**最弱结构**，仅货架页/短页可用，论证页禁用 | `（仅货架页）特性均摆` |

> 判定：论证页默认走论证链或提问链；特性轮转是"没想清楚区块顺序"的默认产物——三个特性为什么是这个顺序？答不出就是轮转。

---

## 三、区块职责（每块报岗——说不出岗的区块=赘肉，删）

| 岗 | 干什么 → 典型形态 |
|---|---|
| **勾住 Hook** | 让人停下滑动 → 主张句/冲突/反直觉数字，3 秒决定走留 |
| **定向 Orient** | 这是什么/给谁/为什么和我有关 → 一句话定位+人群点名 |
| **证明 Prove** | 上证据（见§五） → 产品实证/样张/数字/引语 |
| **深化 Deepen** | 已经信了，展开机制与细节 → 原理图/步骤/参数 |
| **排疑 Objection** | 处理"但是……" → FAQ/对比表/承诺与退款 |
| **收口 Ask** | 要求行动 → CTA+最后一次主张复述 |
| **信任 Trust** | 他者背书 → logo 墙/用户引语/数据 |
| **换气 Rest** | 职责也可以是"什么都不说" → 结构喘息位，纯留白或一句短句（形态 → B86§五 休止符/呼吸词族） |

> 规则：**一个区块一岗**；两岗合一区=读者要分心两次（如"证明+收口"挤一屏）。报不出岗的区块删掉——它比空着更糟，空着是留白，赘肉是噪音。
> **例外**：首屏天然复合岗（勾住+定向，还可叠加证明——首屏四问即复合职责）；收口区块允许"收口+信任"复岗。一岗规则管的是 hero 以下的内容区块。

## 四、首屏（hero 的职责清单——全页最贵的一屏）

| 词 | 是什么 → 改什么决策 |
|---|---|
| **首屏四问** | 是什么 / 给谁 / 为什么在意 / 下一步干嘛——答出 ≥3 才合格；答不出"下一步"的 hero 只有美感没有方向 |
| **首屏主手段** | hero 靠什么撑，**选一个主导**：巨型字/产品实证/3D/生成艺术/摄影大图/插画/数据可视化/视频/纯排版——多手段并列=没有主张（并入自 B15 首屏主手段） |
| **主张句 Claim line** | 可证伪的句子（"打开即写""3 秒同步"）→ 比氛围句更敢写，后面必须配证据件 |
| **氛围句 Vibe line** | 不可证伪（"与灵感不期而遇""重新定义创作"）→ 单用 = 广告腔；要配主张句副题托底 |
| **首屏证据件** | hero 里放不放产品实证 → **放了实证的 hero 几乎总赢**（case05：W0 大而真的窗口样张 vs W1 缩成装饰件）；装饰窗口要能被当证据读 |
| **承诺式标题 vs 描述式标题** | "少做 80% 重复劳动"（承诺，可测）vs "智能工作台"（描述，模糊）→ 论证页首选承诺式 |

## 五、证据件（show 的器材——每个主张至少配一件，否则是自称）

| 件 | 强度 | 用法 |
|---|---|---|
| **产品实证** | ★★★ | 真界面样张/录屏帧——要像真截图不像插画 |
| **真实内容样张** | ★★★ | 一段真实文字/真数据/真对话（衔接 C6 真实内容系统） |
| **演示件** | ★★☆ | 可交互 demo——最强但成本最高，只放一个 |
| **数字证据** | ★★☆ | 可核验的量化（"2.1MB""37ms"），禁编造感（"提升 300%"） |
| **引语/社证** | ★☆☆ | 他者背书，单独用弱，配合数字用 |
| **反模式：tell-only** | — | 全自称零证据（"只做三件事""极致体验"）——广告腔的来源 |

> 配比规则：**主张→证据交替**（claim 后必接 show）；一页 tell-only 区块 ≤1。

## 六、图文关系（每张图报岗——和区块职责同规则）

| 关系 | 是什么 → 判定 |
|---|---|
| **复述 Duplicate** | 图=文：说的和画的一样 → 弱，只能出现在给小孩/纯新手的页 |
| **延伸 Extend** | 图补文未尽：文字说功能，图给手感 → 良 |
| **证据 Evidence** | 图为文作证：文字主张，图来证明 → 最强，论证页默认 |
| **装饰 Decor** | 纯气氛 → 限量，受 K18 装饰配额管；装饰图占比 ≥50% 就要砍 |

## 七、信息层级与主张排序

| 词 | 是什么 → 改什么决策 |
|---|---|
| **单主张屏** | 一屏只推进一个主张 → 屏内出现第二个主张就拆或降级 |
| **主主张唯一** | 全页只有一个主主张，其余都是它的支撑 → 写码前一句话说出主主张，说不出=没想清楚 |
| **渐进披露** | 先结论后机制 → 结论先行，参数细节殿后（金字塔原则） |
| **降级法** | 次级主张视觉权重明确低一档——**不是同级小字号**，是层级系统里低一级（如 h2→mono kicker）。从属五手段：变小/变灰/变透明/退后/去阴影（B22§6 并入） |
| **跳读论证** | 只看各级标题+每段首行能复述全页主张 → **验收句**，做不到就重写标题 |

## 八、内容节奏（论证的呼吸——和视觉密度节奏是两回事）

| 词 | 是什么 → 改什么决策 |
|---|---|
| **主张→证据交替** | claim 屏后必接 show 屏 → 连续两个 tell 屏=说教疲劳 |
| **排疑前置** | 最大疑虑（通常是价格/迁移成本/隐私）越早处理越好 → 别藏 FAQ 在页尾 |
| **阅读坡度** | 易读先行深入殿后 → 专业密度递增，不许首屏上参数表 |
| **减区决策** | 每个区块必须挣得它的滚动位置 → B85 三问的区块版：这区块删了，论证断吗？不断=删 |
| **内容密度 ≠ 视觉密度** | K18 密度节奏管视觉档位；本节管"每屏的信息量"——L1.5 视觉呼吸峰可以仍含一个强主张 |

## 九、CTA 与承诺阶梯

| 词 | 是什么 → 改什么决策 |
|---|---|
| **承诺阶梯** | 承诺从低到高排：看演示→试用→下载→付费 → 不许第一屏就要最高承诺（"立即购买"出现在证据前=赶客） |
| **主 CTA 唯一** | 一页一个主诉求 → 两个同权 CTA=没有主张 |
| **回扣原则** | 主 CTA 在页尾必须重复出现 → 收口区块回到 hero 的主张句+同一 CTA |
| **次级出口** | 不给主 CTA 也要给路 → "先看看文档"这类低承诺退路必须存在 |
| **CTA 文案** | 写"用户得到什么"不写"用户做什么" → "免费下载" 优于 "提交" |

## 十、读者旅程与扫描

| 词 | 是什么 → 改什么决策 |
|---|---|
| **疑虑序列** | 访客问题链：这是什么→和我有关吗→凭什么信→怎么用→多少钱 → 区块顺序尽量贴这条链 |
| **首读点** | 视线路径的第一个落点 → 放主张句不是放装饰 |
| **跳读友好** | 标题自成论证（见§七跳读论证） |
| **回程动线** | 滚到底的人往哪去 → 页尾不是墓地，是第二收口位 |

## 十一、构件与密度型补充词

| 词 | 是什么 → 改什么决策 |
|---|---|
| **页面密度型** | 长卷 continuous（叙事滚动，论证页默认）/ 分屏 snap（一屏一岗，舞台页可用）/ 混合（snap hero+长卷正文）——决定滚动节奏 |
| **列表岗** | 排比（均权列举）/ 主从（一大多小，主项即主主张）/ 瀑布（时间线，进度感）/ 台账（格线高密度，数据感） |
| **集合展示** | 货架网格（均权比较）/ 焦点单件（一次只证一件事）/ 全宽陈列带（横向扫视）——轮播慎用（证据弱+第2帧到达率差） |
| **导航岗** | 定向（我在哪）/ 捷径（跳排疑/跳收口）/ 进度（还剩几站）——导航不是链接表是读者扶手 |
| **页脚岗** | 收口候补（最后 CTA）+ 信任清单 + 次级出口集合——页脚不是链接墓地 |
| **空态岗** | 换气+引导（给出第一动作建议+为什么值得开始）——"暂无数据"不是空态是失职 |
| **加载岗** | 骨架=定向维持（让用户知道来的是什么形状）/ 进度=照管感（报真实进度不装死） |
| **移动端重组岗** | 窄屏不是缩小版：区块岗不变，形态重排（双列→单列、边注→行内、导航→横滑/抽屉）——岗丢了才是 P0 |
| **分组容器岗** | 卡片分组（一块一容器，组间边界强——设置/表单等块化任务的合法默认）/ 分隔线分组（台账连续感，行同构且密集才成立）/ 编号节（长卷导览，混合内容）——**按"同屏需要几组"选**：设置页一次看一组=卡片最优；通篇长滚台账只在行级同构数据多时赢。禁忌：把 B82"三卡片"误用成"禁用一切卡片容器"——那张禁忌只管营销页均权网格（case07 实证：设置页禁卡改台账，用户盲判视觉反输卡片分组） |
| **名目层数岗** | 一个区块允许挂几层名目：页题/区题/EN 标注/卡组头/行标签——**工具页单区 ≤2 层**（区题+行标签，卡组头与 EN 标注二取一）；名目层比行数还多 = chrome 比内容重（case07 实证：3 行设置区挂 4 层名目被终审为"乱"）。判定：每删一层名目问"内容是否更难认"，不是就删 |
| **工具页 hero 禁令** | "呼吸峰"是营销页语境——**工具页没有 hero，首屏即操作区**；peak 式大标题+引言块在工具页=把第一屏让给名目（与 B82 过修正边界同族：概念对语境错）。工具页的"安静区"在区头不在页头（case07 实证：peak 块把 3 行设置压到半屏以下） |
| **同屏内容量** | 单区聚焦时短区会留下大段死空间——对策三选一：①全区滚动但每区成卡（中间态：密度由卡内行控不由连续面控）；②单区+右侧情境栏（预览/提示/相关项填空）；③区内容纵向居中不贴顶。判据：**首屏有效内容占比 <40% 即判死空间**（case07 实证：单区聚焦 3 行设置占一屏被圈空判"不行"） |

## 十二、与既有层的关系（防混淆）

| 层 | 管什么 | 文档 |
|---|---|---|
| **结构层（本文档）** | 说什么/顺序/证据 | B87 + Z1 结构卡 + K10 维度2 |
| 表达层 | 怎么长/什么气质 | B86 + Z1 方向卡 + K18 |
| 行为层 | 怎么动/怎么响应 | K 词条 + K10 维度5/6 |
| IA 层（多页） | 全站归类导航 | C1（本文档只管单页内结构） |
| 蓝图层 | 结构转规格 | D5（重型，多屏产品用） |

> 一次实证注解（case05）：W1 方向卡七维全对、动效双轨合规、印章母题三现——**皮全对，骨输了**：hero 把产品实证缩成装饰件，特性区是 tell-only 轮转。所以规则写成：**结构卡先于方向卡，骨架输了质感白搭**。
