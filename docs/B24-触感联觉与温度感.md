# B24 · 触感联觉与温度感

> 顶级界面让人"摸得到"、"感觉到冷暖"。这是最难描述但最能拉开档次的维度。
> 视觉刺激唤起触觉/温度/重量的感知 = 联觉(Synesthesia)。

---

## 一、触感的五个维度

### 1. 粗糙度(Roughness)

| 感觉 | 视觉手段 | 词汇 |
|---|---|---|
| 丝绸般顺滑 | 平滑渐变 + 零噪点 + 大圆角 | silky, smooth, sleek |
| 磨砂 | 2-4% 噪点 + backdrop-blur | frosted, matte, brushed |
| 粗粝 | 8-15% 粗噪点 + 硬边 | gritty, coarse, raw |
| 颗粒 | 细密噪点 + 胶片 grain | grainy, textured, filmic |
| 抛光 | 高光反射 + 平滑 | polished, glossy, lacquered |
| 织物 | 布纹纹理叠加 | woven, fabric, canvas |
| 纸质 | 纸纹 + 暖白 + 微噪 | papery, uncoated, tactile |

**Prompt 措辞**:
> "整体触感:磨砂铝——2% 细噪点叠加,哑光无高光,边缘 crisp 不柔化。不要塑料的顺滑感。"

---

### 2. 硬度(Hardness)

| 感觉 | 视觉手段 |
|---|---|
| 坚硬 | 直角 / 硬边 / 高对比 / 无阴影模糊 |
| 柔软 | 大圆角 / 柔和阴影 / 低对比 / 渐变边缘 |
| 有弹性 | spring 动效 / 挤压变形 / 回弹 |
| 脆 | 极细线条 / 玻璃质感 / 锐利高光 |
| 韧 | 中等圆角 + 缓慢变形动效 |

**Prompt 措辞**:
> "按钮质感:有弹性——按下时 scale(0.95) 带轻微挤压(scaleY 0.93/scaleX 0.97),松开 spring 回弹。给人'橡胶按键'的手感。"

---

### 3. 温度(Temperature)

| 感觉 | 视觉手段 | 温度词 |
|---|---|---|
| 灼热 | 高饱和红橙 + 强发光 | scorching, blazing |
| 温暖 | 暖调米/焦糖/胡桃 + 柔光 | warm, cozy, golden |
| 室温 | 中性灰 + 平衡对比 | neutral, ambient |
| 清凉 | 淡蓝绿 + 高明度 | cool, crisp, fresh |
| 冰冷 | 深蓝灰 + 高对比 + 锐边 | cold, icy, frigid |
| 冷峻 | 蓝灰 + Mono + 无暖色 | clinical, sterile |

**顶级技巧**:**大面积冷 + 一点暖 = 有温度的科技感**(比全冷更高级)

**Prompt 措辞**:
> "温度感:整体清凉(冷灰 slate 系 + 淡蓝强调),但 CTA 用一点焦糖暖色,像冷房间里的一盏暖灯。"

---

### 4. 重量(Weight)

| 感觉 | 视觉手段 |
|---|---|
| 失重/漂浮 | 浅色 + 细字重 + 无阴影 + 大留白 + 缓慢浮动 |
| 轻盈 | 高明度 + 低饱和 + 细线条 |
| 适中 | 中明度 + 400-500 字重 |
| 沉稳 | 深色 + 600-700 字重 + 明确阴影 |
| 沉重 | 极深色 + 900 字重 + 大面积 + 密集 |
| 纪念碑感 | 巨大尺寸 + 深色 + 无动效(静止如石) |

**Prompt 措辞**:
> "视觉重量:失重感。所有元素浅色 + 300 字重 + 零阴影,配 20s 极慢浮动动画,像在水中漂浮。"

---

### 5. 湿度(Moisture)

| 感觉 | 视觉手段 |
|---|---|
| 干燥 | 哑光 + 粉质纹理 + 暖中性 + 无光泽 |
| 湿润 | 高光 + 反射 + 渐变 + 液态形态 |
| 液态 | metaball / 流体变形 / 反射折射 |
| 冰霜 | 磨砂玻璃 + 冷白高光 + 结晶纹理 |

**关键洞察**:
- **哑光 = 干 = 高级**(奢侈品/苹果)
- **高光 = 湿 = 廉价**(除非刻意做液态效果)

## 二、材质联觉词库

### 高级材质(用了显贵)
| 材质 | 视觉配方 |
|---|---|
| **哑光铝** | 冷灰 + 2%噪点 + 极细高光边 + 无强反射 |
| **磨砂玻璃** | 半透明 + backdrop-blur + 白边 white/15 |
| **绸缎** | 柔和渐变 + 微光泽扫过 + 暖白 |
| **陶瓷** | 纯净白 + 极柔阴影 + 微光滑 |
| **石材** | 暖灰 + 粗噪点 + 无光泽 + 硬边 |
| **胡桃木** | 暖棕 + 木纹纹理 + 哑光 |
| **牛皮纸** | 米黄 + 纸纹 + 完全哑光 |
| **黄铜/香槟金** | 暖金渐变 + 拉丝纹 + 柔和高光 |
| **炭黑石墨** | 极深灰 + 细噪点 + 哑光 |
| **亚麻布** | 暖白 + 织物纹 + 柔和 |

### 廉价材质(要避免)
| 材质 | 为什么廉价 |
|---|---|
| 亮面塑料 | 强高光 + 高饱和 + 无纹理 |
| 镀铬(除 Y2K) | 过度反射 + 刺眼 |
| 廉价渐变 | 高饱和撞色 + 有色带 |
| 假 3D | 生硬阴影 + 无环境光 |

## 三、组件的触感设计

### 按钮
```
硬按键(机械键盘感):
- 直角/小圆角 4px
- 硬阴影 offset 0 3px 0 深色(模拟厚度)
- 按下:translateY(3px) + 阴影消失(像真的按下去)

软按键(橡胶感):
- 大圆角 12px
- 柔和阴影
- 按下:scale(0.96) + spring 回弹

玻璃按键:
- 半透明 + backdrop-blur
- 顶部 1px 白色高光
- 按下:亮度提升(像被按亮)
```

### 卡片
```
纸片感:
- 纯白/米白 + 极淡阴影 + 4px 圆角
- hover:轻微上浮 2px(像纸被吹起)

石板感:
- 暖灰 + 粗噪点 + 直角 + 无阴影
- hover:几乎不动(重)

玻璃板感:
- 半透明 + blur + 白边
- hover:透明度略增(更通透)
```

### 输入框
```
凹陷感(嵌入):
- inset 阴影 + 稍深背景
- 像刻进表面

浮起感:
- 白底 + 极淡外阴影
- 像贴在表面上

线条感(极简):
- 只有底部 1px 线
- focus 时线变粗变色
```

## 四、温度的空间分布

高级界面的温度不是均匀的:

```
背景:室温/清凉(中性灰或冷灰)
    ↓
卡片:略暖于背景(白色 = 视觉上更暖)
    ↓
CTA:明确暖(唯一的暖色 = 视觉热源)
    ↓
文字:冷(深灰蓝)
```

**"视觉热源"概念**:整个界面只有一个"热点"(通常是主 CTA),其余都冷。这样热点就自然吸引注意。

## 五、联觉的高级组合

### "冷房间里的暖灯"
- 大面积冷灰 + 一个焦糖色 CTA
- 感觉:理性中的温度、专业但不冷漠
- 适合:B2B SaaS 想显得有人性

### "冰面下的水流"
- 磨砂玻璃层 + 后方彩色流动渐变
- 感觉:通透、有生命、克制的活力
- 适合:AI 产品

### "石头上的水滴"
- 粗糙哑光底 + 一个光泽元素
- 感觉:质感对比、精致点缀
- 适合:高端品牌

### "纸上的墨"
- 暖白纸质底 + 深墨黑字
- 感觉:传统、可信、编辑感
- 适合:内容平台

### "太空舱内壁"
- 深色哑光 + 微光边框 + 冷光数据
- 感觉:精密、封闭、专注
- 适合:开发者工具/仪表盘

## 六、Prompt 模板

### 高级哑光科技
```
【触感与温度】
- 触感:哑光铝质——全站 2% 细噪点,零高光反射
- 硬度:偏硬——8px 圆角(不太软),crisp 边缘
- 温度:清凉基调(冷灰 slate)+ CTA 一点暖(焦糖 #B45309)作为唯一"热源"
- 重量:适中偏轻——500 字重,极淡阴影(rgba 0.04)
- 湿度:干燥——完全哑光,无光泽,无液态效果
- 联觉隐喻:"冷房间里的一盏暖灯"
```

### 温暖手工感
```
【触感与温度】
- 触感:纸质 + 亚麻——纸纹纹理 3%,暖白底 #FDFCF8
- 硬度:柔软——12-16px 圆角,柔和阴影
- 温度:温暖——暖中性色(Taupe 系)+ 胡桃棕 + 焦糖
- 重量:轻盈扎实——不飘但也不重
- 湿度:干燥——哑光,像未涂布纸张
- 联觉隐喻:"纸上的墨"——传统、可信、有手感
```

### 通透未来
```
【触感与温度】
- 触感:磨砂玻璃——backdrop-blur 16px + 白边 white/12
- 硬度:脆——细线条,锐利高光
- 温度:冰冷——深蓝灰 + 冷白高光
- 重量:失重——元素浮空,20s 极慢漂浮
- 湿度:冰霜——磨砂 + 冷白结晶感高光
- 联觉隐喻:"冰面下的水流"——玻璃后有彩色流动
```

## 七、检验清单

- [ ] 能说出这个界面"摸起来"什么感觉
- [ ] 能说出温度感(冷/暖/室温)
- [ ] 有明确的材质倾向(不是"就是网页")
- [ ] 有"视觉热源"(唯一的暖点吸引注意)
- [ ] 哑光而非高光(除刻意的液态效果)
- [ ] 加了噪点/纹理制造质感
- [ ] 按钮/卡片/输入框有一致的触感语言
- [ ] 能用一个联觉隐喻概括整体感觉
