# B52 · 空状态设计大全

> 空状态是**留存的关键节点**——用户第一次进来看到的往往就是空的。
> 做得好 = 引导用户上手;做得差 = 用户不知道该干什么然后离开。

---

## 一、空状态的八种类型

| 类型 | 场景 | 情感目标 | 核心策略 |
|---|---|---|---|
| **首次使用** | 新用户,还没创建任何数据 | 期待 → 行动 | 引导创建 + 展示价值 |
| **搜索无结果** | 关键词无匹配 | 不挫败 | 建议替代 + 放宽条件 |
| **筛选无结果** | 筛选条件太严 | 好修正 | 提示放宽 + 一键重置 |
| **已清空** | 用户主动清完(收件箱清空) | 成就感 | 庆祝 + 温暖文案 |
| **权限不足** | 无权访问 | 不困惑 | 说明原因 + 申请入口 |
| **加载失败** | 网络/服务错误 | 不焦虑 | 说明 + 重试按钮 |
| **不支持** | 浏览器/设备不支持 | 有出路 | 说明 + 替代方案 |
| **等待中** | 数据正在生成 | 有预期 | 进度 + 预计时长 |

---

## 二、空状态的标准结构

```
┌────────────────────────────────┐
│                                │
│         [插图/图标]             │  视觉锚点
│                                │
│         标题(状态说明)          │  一句话说清
│                                │
│     描述(为什么空+能做什么)     │  1-2 行
│                                │
│        [主要 CTA]               │  明确下一步
│      [次要操作(可选)]           │  替代路径
│                                │
└────────────────────────────────┘
```

### 视觉规格
```css
.empty-state {
  display: flex;
  flex-direction: column;
  align-items: center;
  text-align: center;
  padding: 64px 24px;      /* 大量留白 */
  max-width: 400px;        /* 文字不要太宽 */
  margin: 0 auto;
}

.empty-illustration {
  width: 120px;            /* 插图 96-160px */
  height: 120px;
  margin-bottom: 24px;
  opacity: 0.9;            /* 略微降低,不抢 CTA */
}

.empty-title {
  font-size: 18px;
  font-weight: 600;
  margin-bottom: 8px;
}

.empty-description {
  font-size: 14px;
  color: var(--text-muted);
  line-height: 1.6;
  margin-bottom: 24px;
}
```

## 三、各类型的文案与设计

### 1. 首次使用(最重要)★

```
📁 (插图)

还没有项目

创建你的第一个项目,几秒钟就好。
所有内容都会自动保存。

[+ 创建项目]     [查看示例]
```

**关键策略**:
- 标题**不带负面词**("还没有" > "空的" > "无数据")
- 描述强调**容易**("几秒钟就好")
- 消除顾虑("自动保存")
- 提供**示例数据入口**(降低"从零开始"的恐惧)
- 可选:短视频/GIF 演示

**进阶做法**:
```
不显示空态,而是显示"预填示例"
用户看到"填好后长什么样"→ 更容易开始
如 Notion 新页面有模板,Figma 有示例文件
```

### 2. 搜索无结果

```
🔍 (图标)

没找到"设计系统"相关内容

试试其他关键词,或者浏览全部内容。

[清除搜索]     [浏览全部]

你可能想找:
· 设计规范
· 组件库
· Design Tokens
```

**关键策略**:
- **回显搜索词**(让用户确认没打错)
- 提供**相近建议**(拼写纠错/同义词)
- 一键清除搜索
- 浏览全部的退路

### 3. 筛选无结果

```
🎯 (图标)

当前筛选条件下没有结果

已选条件:[价格 <100 ✕] [品牌 Apple ✕] [有货 ✕]

试试移除部分条件

[重置所有筛选]
```

**关键策略**:
- **显示当前筛选条件**(可逐个移除)
- 提示"哪个条件最可能造成无结果"
- 一键重置

### 4. 已清空(正面场景)

```
✨ (插图)

收件箱已清空

干得漂亮!今天没有待处理的消息了。

[查看已归档]
```

**关键策略**:
- **庆祝语气**(这是好事!)
- 可以有小动效(sparkle)
- 提供"回看"入口

### 5. 权限不足

```
🔒 (图标)

你没有权限查看此内容

这个项目仅对团队成员可见。
联系管理员申请访问权限。

[申请访问]     [返回]
```

**关键策略**:
- 说明**为什么**没权限
- 提供**申请路径**(不是死胡同)
- 有返回出路

### 6. 加载失败

```
⚠️ (图标)

加载失败

网络连接似乎有问题。请检查网络后重试。

[重试]     [返回首页]
```

**关键策略**:
- **不用技术错误码**做标题
- 说明可能原因
- **重试按钮**(最重要)
- 有其他出路

### 7. 不支持

```
🌐 (图标)

你的浏览器不支持此功能

请使用 Chrome、Edge 或 Safari 最新版本访问。

[下载 Chrome]     [了解更多]
```

### 8. 等待中(数据生成)

```
⏳ (动画图标)

正在生成报告...

这通常需要 30 秒左右。
你可以离开此页面,完成后我们会通知你。

[后台运行]

▓▓▓▓▓▓░░░░ 62%
```

**关键策略**:
- **预期时长**(减少焦虑)
- 可以离开(不困住用户)
- 通知机制
- 进度可见

## 四、插图 vs 图标 vs 无视觉

| 方式 | 适合 | 优缺点 |
|---|---|---|
| **定制插画** | 品牌重要的产品 | 最有品牌感,但成本高 |
| **图标(大号)** | 通用/工具类 | 简洁,成本低,不失专业 |
| **Emoji** | 轻量/趣味产品 | 最快,但跨平台不一致 |
| **纯文字** | 极简/专业工具 | 最克制,但可能显冷淡 |
| **示例数据** | 编辑类产品 | 最佳(直接展示价值) |

**推荐**:
- 首次使用 → 插画/示例数据(需要吸引力)
- 搜索/筛选无结果 → 图标(功能性)
- 错误 → 图标(不要太可爱,会显得不严肃)

### 插图的视觉规范
```
尺寸:96-160px
风格:与产品插画系统一致
颜色:用品牌色但降低饱和(不抢 CTA)
不要:免费素材站的通用插画(一眼廉价)
```

## 五、空状态的文案禁忌

| ❌ 不要 | ✅ 要 |
|---|---|
| "暂无数据" | "还没有项目" |
| "无结果" | "没找到「xxx」相关内容" |
| "列表为空" | "你的收藏夹还是空的" |
| "Error 404" | "找不到这个页面" |
| "操作失败" | "保存失败,请检查网络后重试" |
| "空空如也~~~" | (过度卖萌,专业场景不适合) |
| 只有标题没有 CTA | 一定要有明确的下一步 |

**核心原则**:
1. **不用负面/技术词汇**
2. **说清状态 + 给出出路**
3. **语气与产品调性一致**
4. **永远有下一步**

## 六、空状态的进阶技巧

### 1. 上下文相关的引导
不同入口进来的空态,引导不同:
```
从"团队"页面进来的空态 → "邀请团队成员"
从"项目"页面进来的空态 → "创建项目"
```

### 2. 渐进式空态
```
0 个项目  → 大插图 + 强引导 + 示例
1-2 个项目 → 小提示 + "创建更多"
3+ 个项目 → 不再显示引导
```

### 3. 骨架 → 空态的正确过渡
```
❌ 白屏 → 直接显示空态(用户以为出错了)
✅ 骨架屏 → 确认无数据 → crossfade 到空态
```

### 4. 空态与错误态必须区分
```
❌ 加载失败也显示"暂无数据"(用户以为真的没数据)
✅ 空态:"还没有项目" + [创建]
✅ 错误:"加载失败" + [重试]
```
**这是最常见的实现错误。**

### 5. 表格/列表的空态
```
保留表头,内容区显示空态:
┌──────┬──────┬──────┐
│ 名称  │ 状态  │ 时间  │  ← 表头保留(让用户知道结构)
├──────┴──────┴──────┤
│                     │
│    还没有记录        │
│    [+ 添加记录]      │
│                     │
└─────────────────────┘
```

### 6. 卡片网格的空态
```
方式 A:整个区域一个空态
方式 B:显示一个"虚线占位卡片"+ 加号(引导创建)
```

## 七、移动端空状态

```
- 插图缩小到 80-120px
- padding 减到 40px 24px
- CTA 全宽按钮
- 文字更简短(移动端阅读耐心低)
- 考虑键盘遮挡(如果空态有输入)
```

## 八、空状态的动效

```
入场:
- 插图 fade + scale(0.9→1),400ms
- 标题 fade + translateY(8px),delay 100ms
- 描述 delay 150ms
- CTA delay 200ms
(stagger 50ms 依次出现)

已清空的正面空态:
- 可加 sparkle 粒子效果
- ✓ 图标路径绘制

等待中的空态:
- 图标持续动画(旋转/脉冲)
- 进度条动画
```

## 九、Prompt 模板

```
【空状态设计】

标准结构(所有空态):
- 插图/图标 120px(移动 96px)
- 标题 18px/600(状态说明,无负面词)
- 描述 14px/400 灰色(为什么空+能做什么,1-2 行)
- 主 CTA(明确下一步)
- 次要操作(可选替代路径)
- padding 64px 24px(移动 40px 24px)
- max-width 400px 居中

八种类型分别设计:
1. 首次使用:插画 + "还没有 X" + 强调容易 + [创建] + [查看示例]
2. 搜索无结果:图标 + 回显搜索词 + 相近建议 + [清除搜索] + [浏览全部]
3. 筛选无结果:图标 + 显示已选条件(可逐个移除) + [重置筛选]
4. 已清空:插图 + 庆祝语气 + sparkle 动效 + [查看已归档]
5. 权限不足:锁图标 + 说明原因 + [申请访问] + [返回]
6. 加载失败:警告图标 + 人性化说明 + [重试] + [返回首页]
7. 不支持:说明 + [替代方案]
8. 等待中:动画图标 + 预期时长 + 进度条 + [后台运行]

关键要求:
- 空态和错误态必须视觉+文案区分(不能都显示"暂无数据")
- 骨架屏 → 空态 crossfade(不是白屏直接跳)
- 表格空态保留表头
- 文案不用"暂无数据"/"无结果"/技术错误码
- 永远有明确的下一步 CTA
- 插图用品牌插画系统(不用免费素材通用图)

动效:
- stagger 50ms 依次入场(插图→标题→描述→CTA)
- 正面空态可加 sparkle
```
