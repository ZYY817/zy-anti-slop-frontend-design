## 三、氛围情绪词(定"感觉")

> 本节原为 6 系 ~60 个情绪形容词穷举，词堆已删——与 B7 气质词库、B86 人格词大量重叠，且**情绪的参数化版本在 B61**（情绪→Oklch 色度/圆角/字重/间距/动效全参数矩阵），温度维度在 B70。
> 本节的正确用法只剩一句：风格定完后用 §四 手法词 + §五 字体气质 + §六 色彩组合把"感觉"落成参数，别停在形容词层。

## 四、"惊艳"的视觉手法词(制造 WOW)

> 格栅/空间/光影/密度向手法词已归 B86§三/四/五/十（破格/出血分级/悬挑/被困留白/chiaroscuro/Ken Burns）；本节只留主手段与特效向词。

| 手法词 | 效果 |
|---|---|
| 巨型排版 oversized typography | 一个大字撑满屏,气场全开（首屏主手段 → B87§四） |
| 文字裁切 clipped type | 巨字被视口切掉一半 |
| 撞色狂欢 color clash | 高饱和撞色(粗野风)——全场撞色非单色点 |
| 3D 深度 z-depth | 真实空间纵深 |
| 生成律动 generative motion | 算法驱动的呼吸感 |
| 流体变形 liquid morph | 有机流动形态 |
| 数据即美学 data as art | 图表本身是视觉 |

## 七、风格叠加公式(惊艳=极致组合)

**规律**:惊艳作品 = 2-3 个维度拉到极致 + 一个反差。

经典惊艳组合:
```
巨型衬线 + 极简留白 + 黑白           = 高级编辑(Lumina)
暗色 + 3D 线框 + 等宽字             = 科技实验室(TERRAIN)
生成点阵 + 衬线大字 + 深色           = 艺术科技(Breathing Dots)
撞色 + 重叠巨字 + 系统崩坏文案       = 新粗野狂欢(REBEL)
瑞士栅格 + 粉彩 + 超大无衬线         = 现代编辑(INNO)
深色 + 极光渐变 + 发光字             = AI 未来(GYMMASTER)
纸白 + 竖排 + 极细字 + 70%留白       = 日式禅意
液态流体 + 蓝调 + 大字               = 数字物性(CRAFTING)
```

**反差制造惊艳**:
- 极简排版 + 一个大胆动效
- 严肃数据 + 意外的色彩
- 经典衬线 + 前卫布局
- 冷科技 + 一抹暖色

## 八、把风格词转成 prompt

### 示例:想要"暗黑科技实验室"感
```
【风格】暗黑数据实验室(参考 Observatory/TERRAIN)
- 气质:冷峻 / 精密 / 未来
- 配色:曜石黑 #0A0A0A + 电光蓝强调 + 荧光绿数据点
- 字体:等宽 JetBrains Mono(数据)+ 无衬线(标题)
- 版式:高信息密度,严格栅格,数据可视化主导
- 质感:微光边框 white/8,极淡网格背景
- 动效:数据流动,数字 counter,极慢
- 惊艳点:3D 线框地形 / 实时数据律动
```

### 示例:想要"高级编辑感"
```
【风格】优雅衬线编辑(参考 Lumina IV)
- 气质:隽永 / 克制 / 精工
- 配色:奶油白 #FAFAF7 + 墨黑 + 一点香槟金
- 字体:Playfair Display 巨型衬线标题 + Inter 正文
- 版式:极简留白 60%+,高跳跃率,严格对齐
- 细节:首字下沉,悬挂标点,负字距
- 动效:极克制,逐词浮现入场
- 惊艳点:巨型衬线数字 + 大量呼吸空间
```

### 示例:想要"炸裂新粗野"
```
【风格】新粗野狂欢(参考 REBEL 2026)
- 气质:叛逆 / 生猛 / 张扬
- 配色:荧光黄 #FDE047 + 纯黑 + 品红撞色
- 字体:Druk/Archivo Black 超粗展示体,巨型重叠
- 版式:打破网格,元素重叠错位,满幅出血
- 装饰:滚动跑马灯文字带("NO RULES NO LIMITS")
- 质感:硬阴影 offset,粗黑边框
- 动效:故障 glitch,快速切换
- 惊艳点:重叠巨字 + 撞色 + 系统崩坏感文案
```
