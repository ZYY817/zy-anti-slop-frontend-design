# B69 · 按钮设计完全指南

> 按钮是界面里被点击最多的东西,也是最能体现"手感"的元素。
> 一个好按钮:一眼知道能点、点了有反馈、点完知道结果。
> 从层级到尺寸,从状态矩阵到加载态,从图标位置到特殊变体——按钮的每个决策都影响转化。
> 这份文档拆的是:按钮的完整体系,让每一个按钮都"想被点击"。

## 二、按钮层级系统

### 2.1 四级层级

```
Primary(主):    实色填充,最醒目 —— 一屏最多 1 个
Secondary(次):  描边/浅底,中等 —— 可多个
Tertiary(三级): 文字/幽灵,最弱 —— 辅助操作
Destructive(危险): 红色系,警示 —— 删除等
```

```css
/* 主按钮 */
.btn-primary {
  background: var(--brand);
  color: white;
  border: none;
}

/* 次按钮:描边 */
.btn-secondary {
  background: transparent;
  color: var(--text-primary);
  border: 1px solid var(--border);
}

/* 次按钮:浅底(另一种风格) */
.btn-secondary-filled {
  background: var(--brand-alpha-10);
  color: var(--brand);
  border: none;
}

/* 三级:文字 */
.btn-tertiary {
  background: transparent;
  color: var(--text-secondary);
  border: none;
}
.btn-tertiary:hover {
  background: oklch(0% 0 0 / 0.04);
}

/* 危险 */
.btn-destructive {
  background: var(--error);
  color: white;
}
.btn-destructive-ghost {
  background: transparent;
  color: var(--error);
  border: 1px solid var(--error-alpha-30);
}
```

### 2.2 层级铁律

```
✅ 一个操作区只有 1 个 primary(主次分明)
✅ "确认"用 primary,"取消"用 tertiary/secondary
✅ 危险操作(删除)用 destructive,且通常需二次确认
❌ 两个 primary 并排(用户不知点哪个)
❌ 所有按钮都实色(失去层级)
```

## 三、按钮尺寸系统

### 3.1 尺寸档位

```css
:root {
  /* 高度档位 */
  --btn-h-sm: 32px;
  --btn-h-md: 40px;
  --btn-h-lg: 48px;
  --btn-h-xl: 56px;
}

.btn-sm { height: 32px; padding: 0 12px; font-size: 13px; border-radius: 6px; }
.btn-md { height: 40px; padding: 0 16px; font-size: 14px; border-radius: 8px; }
.btn-lg { height: 48px; padding: 0 24px; font-size: 16px; border-radius: 10px; }
.btn-xl { height: 56px; padding: 0 32px; font-size: 17px; border-radius: 12px; }
```

### 3.2 padding 比例规律

```
水平 padding ≈ 垂直 padding × 2-2.5

例: 高度 40px(上下各约 12px)→ 左右 padding 约 24px
经验: 文字左右的空间要比上下多,视觉才舒展
```

### 3.3 触控目标

```css
/* 视觉高度可以小,但点击区必须 ≥ 44px */
.btn-sm {
  height: 32px;
  /* 用透明 padding 或 min-height 扩大点击区 */
  position: relative;
}
.btn-sm::before {
  content: "";
  position: absolute;
  inset: -6px;  /* 上下各扩 6px,总点击区 44px */
}

/* 移动端所有按钮 ≥ 44px */
@media (pointer: coarse) {
  .btn { min-height: 44px; }
}
```

## 四、按钮状态矩阵

### 4.1 完整状态

```
default(默认) → hover(悬停) → active(按下) → focus(聚焦)
                                             → loading(加载)
                                             → disabled(禁用)
```

### 4.2 状态视觉规范

```css
.btn-primary {
  background: var(--brand);
  color: white;
  transition: background 150ms, transform 100ms, box-shadow 150ms;
}

/* hover:变亮/变暗 + 微浮起 */
.btn-primary:hover {
  background: oklch(from var(--brand) calc(l + 0.05) c h);
  box-shadow: 0 4px 12px oklch(from var(--brand) l c h / 0.3);
}

/* active:按下变暗 + 下沉 */
.btn-primary:active {
  background: oklch(from var(--brand) calc(l - 0.05) c h);
  transform: translateY(1px);
  box-shadow: none;
  transition-duration: 50ms;
}

/* focus:键盘聚焦环 */
.btn-primary:focus-visible {
  outline: none;
  box-shadow: 0 0 0 3px oklch(from var(--brand) l c h / 0.4);
}

/* disabled:降透明 + 禁用光标 */
.btn-primary:disabled {
  opacity: 0.4;
  cursor: not-allowed;
  pointer-events: none;
}
```

### 4.3 状态对比表

| 状态 | 背景 | 位移 | 阴影 | 光标 |
|---|---|---|---|---|
| default | 主色 | 0 | 无 | pointer |
| hover | 主色 +5% 亮 | 0 | 浮起 | pointer |
| active | 主色 -5% 暗 | +1px | 无 | pointer |
| focus | 主色 | 0 | focus ring | pointer |
| loading | 主色 | 0 | 无 | wait |
| disabled | 40% 透明 | 0 | 无 | not-allowed |

## 五、加载态设计

### 5.1 保持尺寸的加载态

```css
/* ❌ 错误:加载时文字换成 spinner,按钮宽度跳变 */

/* ✅ 正确:保持按钮宽度,内部切换 */
.btn {
  position: relative;
  min-width: 120px;  /* 固定最小宽度 */
}

.btn .btn-text {
  transition: opacity 200ms;
}
.btn.loading .btn-text {
  opacity: 0;   /* 文字隐藏但仍占位 */
}

.btn .spinner {
  position: absolute;
  inset: 0;
  margin: auto;
  opacity: 0;
  transition: opacity 200ms;
}
.btn.loading .spinner {
  opacity: 1;
}
```

### 5.2 Spinner

```css
.spinner {
  width: 16px;
  height: 16px;
  border: 2px solid oklch(100% 0 0 / 0.3);
  border-top-color: white;
  border-radius: 50%;
  animation: spin 700ms linear infinite;
}

@keyframes spin {
  to { transform: rotate(360deg); }
}
```

### 5.3 加载态防重复提交

```javascript
async function handleSubmit(btn) {
  if (btn.classList.contains('loading')) return;  // 防重复

  btn.classList.add('loading');
  btn.disabled = true;

  try {
    await submitForm();
    // 成功态
    btn.classList.remove('loading');
    btn.classList.add('success');
  } catch {
    btn.classList.remove('loading');
    btn.disabled = false;
  }
}
```

### 5.4 加载 → 成功的形变

```css
/* 加载完成变成对勾 */
.btn.success {
  background: var(--success);
  min-width: 44px;
  border-radius: 22px;   /* 变圆 */
}
.btn.success .btn-text,
.btn.success .spinner { display: none; }
.btn.success .check {
  display: block;
  animation: check-draw 400ms ease;
}
```

## 八、按钮文案

### 8.1 文案规范

```
✅ 好文案:
- 动词开头("保存更改" 而非 "更改")
- 具体("创建项目" 而非 "提交")
- 第一人称有时更好("开始我的免费试用")

❌ 差文案:
- "确定" / "提交"(太笼统)
- "点击这里"(废话)
- 过长(按钮文字 ≤ 4 个词)
```

### 8.2 按钮文案对照

```
场景          ❌ 差            ✅ 好
表单提交      提交            创建账号
删除确认      确定            删除这 3 个文件
下载          点击            下载 PDF(2.4MB)
免费试用      提交            开始免费试用
危险操作      确定            我明白,永久删除
```

## 十、踩坑指南

### 坑1:两个 primary 并排
**症状**:"保存" 和 "发布" 都是实色,用户不知点哪。
**解法**:一个 primary,另一个降为 secondary。

### 坑2:加载时按钮宽度跳变
**症状**:文字换 spinner,按钮突然变窄。
**解法**:固定 min-width,文字 opacity 0 占位。

### 坑3:没有防重复提交
**症状**:用户狂点,提交了 5 次。
**解法**:loading 时 return + disabled。

### 坑4:disabled 没有视觉区分
**症状**:禁用按钮和正常按钮看起来一样。
**解法**:opacity 0.4 + cursor not-allowed。

### 坑5:focus 没有键盘可见
**症状**:Tab 到按钮看不出选中。
**解法**:`:focus-visible` 加 focus ring。

### 坑6:触控目标太小
**症状**:32px 小按钮在手机上难点。
**解法**:透明 padding 扩到 44px。

### 坑7:文案笼统
**症状**:满屏"确定""提交"。
**解法**:动词 + 具体宾语。

### 坑8:危险操作太容易点
**症状**:删除按钮和普通按钮一样,误删。
**解法**:destructive 样式 + 二次确认。

### 坑9:hover 效果在移动端粘住
**症状**:手机点完按钮保持 hover 态。
**解法**:hover 包在 `@media (hover: hover)`。

### 坑10:FAB 被虚拟键盘/安全区遮挡
**解法**:`bottom: calc(24px + env(safe-area-inset-bottom))`。

## 检验清单

- [ ] 一个操作区只有 1 个 primary
- [ ] 层级清晰(primary/secondary/tertiary 视觉区分明显)
- [ ] 危险操作用 destructive 样式 + 二次确认
- [ ] 尺寸档位统一,padding 比例合理(水平≈垂直×2)
- [ ] 触控目标 ≥ 44px(移动端)
- [ ] 五种状态都有设计(default/hover/active/focus/disabled)
- [ ] focus-visible 有键盘可见的 focus ring
- [ ] 加载态保持按钮宽度(不跳变)
- [ ] 加载态防重复提交
- [ ] disabled 有明显视觉区分 + not-allowed 光标
- [ ] hover 效果包在 @media (hover: hover)
- [ ] 图标按钮有 aria-label
- [ ] 图标位置符合语义(左动作/右方向)
- [ ] 文案动词开头 + 具体 + ≤ 4 词
- [ ] FAB 加 safe-area-inset
