# G7 · 行业视觉规则速查

> G1-G6 按"平台类型"分（落地页/后台/移动/电商/内容/AI）。
> 本文件按"**行业**"分：同一类页面，金融和游戏必须长不一样。
> 用途：AI 生成任何界面时，先对号入座本行业的配色/密度/语气/禁忌。

## 快速对号入座表

| 行业 | 配色基调 | 密度 | 语气 | 核心禁忌 | 信任要素 |
|---|---|---|---|---|---|
| 金融/Fintech | 深蓝/墨绿/中性 + 单一强调 | 中高 | 沉稳、专业、保守 | 花哨渐变、嬉皮插画、俏皮文案 | 数字对齐、安全徽章、合规标注 |
| 医疗/健康 | 白/浅青/暖中性 + 高可读 | 高（信息量大） | 可信、同理、不恐吓 | 血红色调滥用、卡通化、晦涩术语 | 认证、免责声明、清晰流程 |
| 教育/学习 | 明快但不高饱和 | 中 | 鼓励、清晰、循序渐进 | 过载动画、幼稚化（区分 K12/成人） | 进度可见、成果反馈 |
| 游戏/泛娱乐 | 高饱和、戏剧性、暗底可用 | 中低 | 兴奋、沉浸、奖励感 | 克制错用（该热闹时冷清） | 稀有度、成就、即时反馈 |
| B2B/SaaS | 中性 + 功能色明确 | 中高 | 直接、价值导向 | 过度装饰、隐藏价格/限制 | 规格透明、试用路径短 |
| 电商 | 产品图主导、CTA 强对比 | 中 | 促成行动、减少犹豫 | 页面噪音淹没商品、信息不全 | 评价、退换政策、库存真实 |

## 2026 趋势 × 行业适用矩阵（哪些趋势能用在哪些行业）

| 趋势 | 适用行业 | 会失败的地方 |
|---|---|---|
| Modern minimalism | B2B、Fintech、Healthtech、SaaS、法律 | 需要表达能量/创造力的品牌 |
| Glassmorphism | Fintech、科技、生产力工具 | 数据密集后台（可读性受损） |
| Bento grids | SaaS 功能展示、产品页 | 叙事型/情感型页面 |
| Gamified UI | SaaS、AI 工具、教育 | 严肃金融/医疗（钱与健康不游戏化） |
| Anti-design / Neubrutalism | 创意工作室、时尚、机构（参考 Toggl） | **金融服务、医疗、企业 B2B——会被读成"不可信"** |
| Retro / Y2K | 年轻品牌、娱乐、文化 | 企业服务、高信任行业 |
| Kinetic typography | 任何要大胆的品牌 | 正文可读性受损时 |
| 3D | 汽车、科技、高端产品 | 移动端/性能敏感场景（会毁 CWV） |
| Scroll storytelling | 品牌战役、新品发布、高端产品 | 功能型/结账型页面 |

> 判断公式：**趋势 × 信任门槛**。信任门槛高的行业（金融/医疗/企业）只吃"清晰感"趋势；门槛低的行业（娱乐/时尚/教育 K12）才能吃"表现力"趋势。

## 各行业精讲

### 金融 / Fintech
- 信任是第一视觉资产：数字用等宽 `tabular-nums` 对齐、统一单位格式
- 强调色小面积用在关键动作（转账/投资），不用全屏渐变
- 安全相关（验证、加密）有明确符号 + 文案说明
- 多语言金额/日期格式正确（见 B31）；避免"游戏化"气质（钱要严肃）
- 反模式：卡片乱飞动效、emoji 表达金融结果、亮黄大喇叭"稳赚"
- **2026 trust UX 升级**：用户要的是"安全"不是"被惊艳"——安静、清晰、快速（calm/clear/quick）；"设计即合规"，合规文案变成核心设计元素；用 **micro-confidence**（小处反馈累积可信）替代大场面背书；AI 定位是"伙伴不是神谕"（AI 可协助但决策权在用户）
- 可访问性 = 信任乘数：正文 ≥16px、行高 1.5、对比度 ≥4.5:1、始终可见 focus 指示
- 长表单改 **wizard 分步**（每步一个主题 + 进度指示）；内联校验即时反馈（"密码强度：强"）
- 设计系统内嵌行业规则（WCAG/合规文案），省 30-50% 设计时间、~30% 开发时间
- 反模式（2026 常见）：直接套 SaaS 模板不调信任要素、动效过度拖垮 CWV、把合规披露藏起来、把重设计当美学项目而非结构工程

### 医疗 / 健康
- 可读性第一：大字号、高对比、清晰层级
- 情绪克制：非紧急信息不用红色/警报视觉，避免制造焦虑
- 数据可视化准确（见 B29），单位/参考范围明确
- 隐私与免责显著但柔和
- 反模式：把"疗效"当营销词堆砌、图标不统一造成误读

### 教育 / 学习
- 进度可视化（目标梯度，见 H2）驱动持续学习
- 正向反馈（正确→激励视觉，见 B38 游戏化）；错误→温和、可重试
- 区分受众：K12 可活泼，成人/职业培训要效率优先
- 反模式：信息过载首页、激励浮夸空洞

### 游戏 / 泛娱乐
- 允许戏剧性：暗底、高饱和、辉光、粒子（V12）
- 奖励/解锁有"庆祝时刻"（B47 Aha 分级）
- 稀有度用明确色彩层级（灰/蓝/紫/金，见 B38）
- 反模式：克制审美的套用到娱乐场景、奖励无差异

### B2B / SaaS
- 价值主张极简明确，功能截图/规格透明
- 三表结构（对比/定价/FAQ）帮决策（见 B75）
- 状态明确：权限、试用剩余、计费规则可见
- 反模式：营销文案掩盖技术事实、隐藏限制条款

### 电商
- 产品图是主角：统一底/构图/调色（见 B32），缩略图一致
- CTA 与价格层级最高对比
- 信任位置：评价、退换、物流信息靠近购买按钮（见 H3 信任架构）
- 反模式：促销标签泛滥、库存虚假紧迫、图片加载慢

## 用法（AI 生成 prompt 时）

```
行业：[金融]
- 基调：深中性 + 单一强调色，专业沉稳
- 密度：中高，数据密集但有序
- 语气：保守可信，避免俏皮
- 禁忌：不花哨渐变、不嬉皮插画、数字等宽对齐
- 信任：安全徽章、合规标注、金额格式统一
```

## Typography 行业基线（2026，全行业通用下限）

- 正文 ≥ **16px**；行高 ≥ 1.5；对比度 ≥ 4.5:1（见 C7）
- 用相对单位 **rem/em**（用户缩放浏览器字体时布局不破）；文字可缩放到 200% 不丢功能
- 严肃行业（法律/金融/学术）serif 传递传统与权威；科技/消费 sans-serif 传递现代与效率
- 字体即信任信号：字体管理混乱的站会被读成"业余"（见 B5/B6 字体专题）

## 检查清单（行业适配自查）

- [ ] 配色符合该行业信任/情绪预期？
- [ ] 密度匹配行业信息复杂度？
- [ ] 语气无行业禁忌（金融不俏皮、医疗不恐吓、教育不幼稚）？
- [ ] 信任要素齐全（金融安全、电商评价、B2B 透明）？
- [ ] 反模式清单过一遍？
- [ ] 数据展示格式正确（数字/金额/日期）？
