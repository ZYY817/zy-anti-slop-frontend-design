# K17 · 图表与检视器手感

> 覆盖 3 个决策对象：图表交互手感、图像检视器（灯箱/缩放）、选中态视觉。
> B29 是图表的"静态工艺档"（选图/Tufte/色彩），但交互层（tooltip 跟手、图例交互、响应式重组）接近零覆盖；lightbox 全库仅 G4 两行功能列表——"视觉版吸附"级空白。本文件补交互决策。

---

## K·图表交互手感（Chart Interaction）

- **领域**：数据可视化/交互 · **成本**：中
- **定义**：图表在用户指针下的行为——tooltip 触发与定位、crosshair、图例交互、轴标签碰撞、空态。
- **症状**：tooltip 贴近右边缘时被裁掉一半；悬停某点看不出对应图例哪条系列；窄屏轴标签全部叠在一起不可读；图表无数据时一个空白矩形；tooltip 内容挡住数据点本身。
- **适用**：一切数据图表（仪表盘/报表/趋势）｜ **不适用**：纯装饰性 sparkline（无交互）。
- **决策点**：
  ① **tooltip 触发**——hover（桌面）/ click 或 tap（触屏）/ 最近点吸附？数据点稀疏时吸附最近 x 值；tooltip 定位防出界（边界翻转）
  ② **crosshair**——多系列图表要不要指示线+联动 tooltip？（多系列对比必须，单系列可选）
  ③ **图例交互**——图例 click toggle 系列显隐、hover 高亮对应系列（其他淡出）？系列数 >7 时图例换行或分页
  ④ **轴标签碰撞**——密度超限时的降级链：缩写（1.2k）→ 旋转 45° → 抽样显示（隔一显一）→ 换图表类型；窄屏重组成横条图
  ⑤ **空/加载/错误态**——空图表显示"无数据"说明+原因（区别于 B52 通用空态：图表要保留坐标轴骨架作为期待框架）；加载骨架用图表形状不是灰块
- **实现**：
  - tooltip：`position` 计算 + 边界 flip（右侧不足翻左）；`pointer-events: none` 防拦截
  - 图例 toggle：更新 series visibility 而非移除数据（保留颜色槽位，再点恢复）
  - 响应式：容器查询驱动轴标签降级链；<400px 建议换条形图或摘要卡
  - 时间轴：brush/zoom 衔接 K8·语义缩放（层级导航）与 K1·吸附（刻度对齐）
- **验收**：tooltip 不出视口、不遮数据点；图例可 toggle 且状态可恢复；窄屏轴标不叠字；空态有轴骨架+说明；多系列有 crosshair 或同步高亮。
- **衔接**：B29（选图/色彩/Tufte/仪表盘静态档）、B60（数字对齐）、K8·语义缩放、G2（后台数据可视化）、F3（图表渲染成本）、C4（图表的 a11y 表格回退）

## K·图像检视器（Lightbox / Zoom Viewer）

- **领域**：媒体/交互 · **成本**：中
- **定义**：图片/媒体点开后的全屏检视行为——进入过渡、缩放档位、pan 边界、关闭路径。
- **症状**：点击缩略图直接跳转新页面丢失上下文；放大后拖拽图片直接飞出边界；Esc 关不掉灯箱；移动端双指缩放和滑动切换手势互相打架；灯箱遮罩浅得看不清图。
- **适用**：画廊/电商详情/图片附件/作品展示 ｜ **不适用**：装饰性图片（无需检视）。
- **决策点**：
  ① **进入过渡**——缩略图 morph 到全屏（共享元素，衔接 B58 FLIP）还是直接淡入？（morph 建立"这张图放大"的空间感，默认做）
  ② **缩放档位**——fit 屏幕 / 100% 实际像素 / 双击在两者间切换；滚轮缩放以指针为中心（非容器中心）；最大倍率限制（2-4x）
  ③ **pan 边界**——缩放后拖拽带边界阻尼（橡皮筋，衔接 K1·几何约束/R12）；到边后松手弹回
  ④ **关闭路径**——Esc / 点击遮罩 / 下滑手势（移动端）/ ×按钮，至少两条；关闭 morph 回缩略图
  ⑤ **backdrop 与预载**——遮罩浓度 0.85-0.95（比 modal 更深，图是主角）；相邻图预载实现秒切
- **实现**：
  - morph：FLIP 记录缩略图 rect → 全屏 rect 反向播放（B58 模式）
  - 缩放：`transform: scale(s) translate()`，变换原点跟随指针位置；双指用 `touch-action: none` + 手势中心计算
  - pan 阻尼：越界量 × 0.3 橡皮筋（R12 参数族）；松手 spring 回边
  - 滑动切换与缩放的仲裁：scale>1 时手势归 pan、scale=1 时归切换（衔接 K16·方向锁定）
- **验收**：缩略图→全屏有 morph 连续感；双击在 fit/100% 间切换；pan 到边有阻尼非硬停；Esc/遮罩/下滑均能关；移动端缩放与切换不冲突。
- **衔接**：B58（共享元素/FLIP）、K1·几何约束（pan 边界）、K4·惯性（拖拽抛掷）、K16·手势仲裁、G4:79-84（电商灯箱规格）、R12（阻尼参数）

## K·选中态视觉（Selected State Visual）

- **领域**：交互/视觉 · **成本**：低
- **定义**：元素被选中后的视觉表达——用什么手段、如何避免布局跳变、如何与 hover 区分。
- **症状**：选中行加 border 整行跳 1px；选中态和 hover 态长得一样分不清当前是真选中还是只悬停；多选和单选用同一视觉没有数量感。
- **适用**：可选列表/表格/卡片/标签组 ｜ **不适用**：无选择交互的展示内容。
- **决策点**：
  ① **表达手段**——描边(outline)/底色/勾选标/图标填充切换（outline→filled），四种手段按组件选：列表行=底色+勾选、卡片=描边+勾选、标签=填充切换
  ② **防布局跳**——选中用 `outline`（不占盒模型）或 `box-shadow`；必须 border 时用 `padding-1px` 补偿（B65 技巧）或预设透明 border
  ③ **与 hover 区分**——hover 是"可能"（轻、瞬态），selected 是"是"（强、持稳）：选中态饱和度/权重高于 hover；hover 到已选中项视觉不降级
  ④ **多选感**——多选时给数量指示（选中条/chips 区）；批量操作入口随选中数显现
- **实现**：
  - `.item.selected { outline: 2px solid accent; outline-offset: -2px; }` 零布局成本
  - 或 `.item { border: 2px solid transparent; } .item.selected { border-color: accent; }`（预占空间）
  - hover 态 `background: hover-bg`、selected 态 `background: selected-bg`（更深）+ outline
- **验收**：选中不产生任何位移/跳动；选中与 hover 一眼可区分；多选有数量反馈；选中态在 hover 经过时不被覆盖。
- **衔接**：B65:483-489（防跳技巧源头）、B62:279-284（selected 行）、B68:138-155（outline/filled 切换）、D4（selected 态矩阵）、K13·行选择模型、K14·徽标
