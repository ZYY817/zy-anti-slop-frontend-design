# R7 · 风格化与媒介模拟（提示词库 E 组）

> 定位：不追求"真实"，而追求**有身份的假**——让画面像版画、像 CRT、像水彩、像 8bit，而不是像照片。
> 覆盖层：L3 肉 + L5 髓（少量 L0 意）。
> 条目卡格式：`名称（英文术语）· L层级 · 档位（基础/进阶/电影级）· 成本（低/中/高）`，卡内含视觉收益、强度档位/关键约束、同族拓展、可直接抄用的提示词片段。
> 来源：融合自外部「视觉提示词库 E 组：风格化与媒介模拟」（v1.x，2026-08-16），交叉引用已改写为本库 R 编号体系。
> **关键判断（原库铁律）：E 组只能选一个主媒介。** 同时用 halftone + CRT + 水彩 = 灾难。

---

## 使用说明

写实向的 R3–R6 组（`R3` 几何与光线 / `R4` 体积与介质 / `R5` 光照与色彩管线 / `R6` 后期与镜头）目标是"像真的"。R7 的目标是**"像某种东西"**。

**R7 是绕过"技术不够"的捷径**：写实渲染做不到 90 分会很难看，但风格化做到 70 分就已经很有辨识度。同时 R7 也是打破"AI 默认干净数字感"最有效的一组手段——任何媒介模拟都能立刻打破它。相关的反 AI 味清单见 `B82`（反AI味与差异化系统）与 `B44`（反面词典与视觉禁忌）；这两份是**参考清单，不是硬性铁律，按项目自行取舍**。

铁律：**E 组只能选一个主媒介**。

```
E1 非真实渲染 NPR        E4 像素与低保真
E2 印刷媒介模拟          E5 手工痕迹与不完美
E3 屏幕媒介模拟          E6 光学现象与自然奇观
```

## E1 非真实渲染（NPR / Stylized Rendering）

把三维渲染成"画"而不是"照片"。

- **描边（Outline / Contour）** · L3 · 基础 · 成本:低
  - 视觉收益：卡通/技术插画感的第一要素。轮廓被强调，形体立刻清晰
  - 强度档位：细 1px / 中 2–3px / 粗 5px+（漫画感）
  - 实现路径对比：
    - `法线-深度边缘检测`（后期 Sobel）：最通用，能画内部结构线
    - `背面外扩`（inverted hull）：便宜，只有外轮廓
    - `Fresnel 阈值`：最便宜，但线宽不均
  - 同族拓展：Sobel/Scharr edge detect、inverted hull、depth discontinuity、变宽描边（随距离/曲率）
  - 提示词片段：`描边用法线+深度双通道 Sobel 检测，线宽 2px 且随距离衰减；线条颜色不用纯黑，用主色暗化 80%`

- **色阶化 / 卡通着色（Cel Shading / Posterize）** · L3 · 基础 · 成本:低
  - 视觉收益：连续光照被切成 2–4 个色阶，动画片质感
  - 强度档位：2 阶（极简）/ 3 阶（标准）/ 5 阶（半写实）
  - 同族拓展：ramp texture（用一条渐变条映射光照）、hard shadow terminator、rim 高光单独一阶
  - 提示词片段：`光照量化为 3 阶，阶间用 fwidth 抗锯齿软化；阴影色不是主色变暗而是偏冷的另一个色相`

- **交叉排线（Hatching / Cross-Hatching）** · L3 · 进阶 · 成本:中
  - 视觉收益：素描/铜版画质感，用线的密度表达明暗
  - 同族拓展：TAM（tonal art maps）、多层排线（明度越低层数越多）、屏幕空间 vs 物体空间排线
  - 提示词片段：`用 4 层屏幕空间排线按明度叠加；线条方向随曲率变化避免机械感`

- **水彩与湿介质（Watercolor / Wet Media）** · L3 · 电影级 · 成本:中
  - 视觉收益：边缘沉积（edge darkening）、颜料扩散、纸纹渗透——最难被认作 AI 的风格之一
  - 关键取胜点：**边缘要比中心深**（颜料沉积），这是水彩的物理签名
  - 同族拓展：edge darkening、pigment granulation、wet-in-wet diffusion、paper bleed、alpha 抖动边界
  - 提示词片段：`水彩：色块边缘加深 15%、内部轻微不均、边界用噪声抖动破碎、叠加纸纹 multiply`

- **油画与笔触（Oil Paint / Brush Stroke）** · L3 · 电影级 · 成本:高
  - 视觉收益：可见笔触方向、颜料厚度（impasto）、笔触沿形体走
  - 同族拓展：Kuwahara filter（保边平滑，最经典的油画滤镜）、anisotropic Kuwahara、flow-based stroke、颜料高光（法线扰动）
  - 提示词片段：`用各向异性 Kuwahara 滤镜（半径 6，8 个扇区）产生笔触块；笔触方向沿结构张量`

- **半调渐变与色彩偏移（Stylized Color Ramp）** · L3 · 进阶 · 成本:低
  - 视觉收益：把亮度直接映射到一条艺术家定义的渐变，跳过物理正确
  - 同族拓展：gradient map、duotone/tritone、false color、见 `R5·C7`
  - 提示词片段：`把明度映射到 3 色渐变（暗=深靛 / 中=品红 / 亮=米黄），完全放弃物理色`

- **描线抖动（Line Jitter / Sketchy Lines）** · L5 · 进阶 · 成本:低
  - 视觉收益：线条不完美，像手画的。**极强的"非默认输出"信号**（对照 `B82` / `B44` 的参考清单，按项目取舍）
  - 同族拓展：wobble、squigglevision、每帧重抖（会呼吸）、见 `R7·E5`
  - 提示词片段：`描边路径加低频噪声抖动 ±1.5px；抖动种子每 200ms 更新一次（不是每帧，避免闪烁）`

## E2 印刷媒介模拟（Print Media）

把数字画面伪装成"印出来的"。**性价比极高的高级感来源**。

- **半调网点（Halftone / Dot Screen）** · L3 · 进阶 · 成本:低
  - 视觉收益：用点的大小表达明暗，报纸/丝网印刷质感
  - 强度档位：网点尺寸 2px（细腻）/ 4px（标准）/ 8px+（波普艺术）
  - 关键约束：网点必须**有角度**（经典 CMYK 各 15°/75°/0°/45°），正交网点很廉价
  - 同族拓展：AM halftone（点大小变化）、FM halftone（点密度变化）、line screen（线网）、crosshatch screen、moiré 控制
  - 提示词片段：`半调网点：网格 4px，旋转 15°，点半径由明度驱动，边缘用 fwidth 抗锯齿`

- **CMYK 分色与错版（CMYK Separation & Misregistration）** · L3 · 电影级 · 成本:低
  - 视觉收益：四色套印，各版轻微错位露出彩边——**最强的"真印刷品"信号**
  - 强度档位：微 0.5px / 中 1.5px / 强 4px（故意的复古错版）
  - 同族拓展：registration error、trapping、rich black、见 `R6·D3` 色散（不同概念：这里是每个色版整体位移）
  - 提示词片段：`分 CMYK 四版各自半调，各版偏移 1px 不同方向并各自旋转不同角度；叠印用 multiply`

- **Riso / 丝网印刷（Risograph / Screen Print）** · L3 · 电影级 · 成本:低
  - 视觉收益：2–3 个高饱和专色叠印、油墨不均、纸张吸墨、边缘不实
  - 关键取胜点：**限定 2–3 个专色**（不是 CMYK），叠加处产生第三色
  - 同族拓展：spot color、ink texture、overprint multiply、Riso 专色板（荧光粉/亮蓝/黄）
  - 提示词片段：`Riso 风：仅 2 个专色（荧光品红 + 亮蓝），各自半调后 multiply 叠印，加油墨不均噪声 8%`

- **纸张纹理（Paper Texture）** · L3 · 基础 · 成本:低
  - 视觉收益：底层纸纹让画面"有物质感"，不再悬浮在数字空间
  - 同族拓展：程序化纸纹（低频噪声 + 纤维方向）、牛皮纸/水彩纸/新闻纸、纸张边缘毛边
  - 提示词片段：`底层加程序化纸纹（各向异性低频噪声，对比 6%），overlay 混合`

- **油墨溢出与吸收（Ink Bleed）** · L3 · 进阶 · 成本:低
  - 视觉收益：色块边缘轻微向外渗，文字边缘略糊
  - 同族拓展：dot gain（网点扩大）、feathering、blur+threshold 循环
  - 提示词片段：`色块边缘做 dot gain：先轻模糊再阈值化，产生油墨渗出 0.5px`

- **烫金与压凹（Foil & Emboss）** · L3 · 电影级 · 成本:中
  - 视觉收益：局部金属反光随视角变化、压凹的高光暗边——高端印刷品的奢华感
  - 同族拓展：holographic foil（虹彩，见 `R5·C3` 薄膜干涉）、letterpress deboss、spot UV
  - 提示词片段：`标题做烫金：局部用各向异性金属反射，反射方向随鼠标位置轻微变化`

## E3 屏幕媒介模拟（Screen Media）

把画面伪装成"从某种屏幕上拍下来的"。

- **CRT 显像管（CRT）** · L3 · 进阶 · 成本:中
  - 视觉收益：曲面畸变 + 扫描线 + 荫罩孔 + 泛光 + 边缘失焦，怀旧感极强
  - 组成清单（做全才像）：桶形畸变 / 扫描线 / 荫罩(aperture grille RGB 条纹) / 光晕泛光 / 四角失焦 / 轻微色散 / 亮度闪烁 / 玻璃反光
  - 同族拓展：shadow mask、aperture grille、slot mask、phosphor persistence（余晖拖影）
  - 提示词片段：`CRT：桶形畸变 k=0.06、扫描线周期 3px 强度 0.15、RGB 荫罩条纹、四角失焦、余晖拖影 0.85`

- **扫描线（Scanlines）** · L3 · 基础 · 成本:低
  - 视觉收益：最便宜的"屏幕感"，一行代码
  - 强度档位：微 0.05 / 中 0.15 / 强 0.35（明显条纹）
  - 关键约束：周期要与实际像素对齐，否则出 moiré
  - 提示词片段：`扫描线周期锁定为 devicePixelRatio×2 px，强度 0.12，避免 moiré`

- **VHS / 模拟信号（VHS / Analog Artifacts）** · L3 · 进阶 · 成本:中
  - 视觉收益：色度带宽损失、行同步抖动、磁带噪纹、色彩渗出
  - 同族拓展：chroma subsampling（色度模糊而亮度清晰）、head switching noise（底部噪带）、time base error（行位移）、tracking error、dropout
  - 提示词片段：`VHS：色度通道横向模糊 8px 而亮度保持、随机行水平位移 ±3px、底部 12px 噪带、轻微色彩渗出`

- **Glitch / 数据损坏（Glitch / Datamosh）** · L3 · 进阶 · 成本:低
  - 视觉收益：块位移、RGB 通道分离、行错位、压缩块
  - 关键约束：**必须是偶发的、短促的**（80–200ms）。常态 glitch 极其廉价
  - 同族拓展：block displacement、channel shift、DCT block artifact、pixel sorting、datamosh
  - 提示词片段：`glitch 仅在事件触发时出现，持续 120ms：随机 4 条水平带位移 + RGB 分离 6px；禁止常态开启`

- **液晶与子像素（LCD Subpixel / Dot Matrix）** · L3 · 进阶 · 成本:低
  - 视觉收益：可见的 RGB 子像素栅格，像放大看屏幕
  - 同族拓展：subpixel layout（RGB stripe / pentile）、dot matrix、LED 点阵、pixel grid gap
  - 提示词片段：`每个逻辑像素画成 RGB 三条子像素 + 1px 黑缝，模拟 LCD 放大`

- **摩尔纹（Moiré）** · L5 · 进阶 · 成本:低
  - 视觉收益：两个规则栅格叠加产生的干涉波纹，可以是缺陷也可以是风格
  - 双面性：**不想要时**必须避免（网点角度错开、抗锯齿）；**想要时**是极强的视觉张力
  - 同族拓展：interference pattern、aliasing pattern、rosette pattern（印刷玫瑰斑）
  - 提示词片段：`刻意制造 moiré：两层同心圆栅格，角度差 3°，周期比 1.02`

- **屏幕反光与眩光（Screen Glare）** · L3 · 进阶 · 成本:低
  - 视觉收益：玻璃面板的环境反光，让"屏幕"有实体
  - 同族拓展：Fresnel 玻璃层、指纹污渍、见 `R6·D3` 脏镜头
  - 提示词片段：`叠加一层低强度玻璃反光（斜向渐变 + 轻微指纹噪声），强度 0.08`

## E4 像素与低保真（Pixel & Lo-Fi）

**约束即风格。** 主动限制分辨率与色数，反而产生强烈风格。

- **像素化（Pixelation / Downsample）** · L3 · 基础 · 成本:低
  - 视觉收益：块状化，复古游戏感
  - 关键约束：必须用 **nearest 采样**，否则糊；且像素网格要与屏幕像素整数对齐
  - 同族拓展：nearest-neighbor、pixel-perfect scaling、integer scale only
  - 提示词片段：`渲染到 320×180 RT 后用 nearest 整数倍放大；禁止非整数缩放`

- **限定色板（Limited Palette / Color Quantization）** · L3 · 进阶 · 成本:低
  - 视觉收益：只用 4/8/16 色，色彩关系被迫精炼，风格极强
  - 强度档位：2 色（单色）/ 4 色（GameBoy）/ 16 色（EGA）/ 32 色
  - 同族拓展：palette LUT、nearest color in OKLab（不是 RGB！）、经典色板（NES/CGA/PICO-8/GameBoy 绿）
  - 提示词片段：`量化到 8 色自定义色板，最近色搜索在 OKLab 空间进行（RGB 空间会选错色）`

- **抖动艺术（Ordered / Error-Diffusion Dithering）** · L3 · 进阶 · 成本:低
  - 视觉收益：用抖动图案表达中间色，Bayer 网格是标志性的复古纹理
  - 同族拓展：Bayer 2×2/4×4/8×8、Floyd-Steinberg（误差扩散，需串行，shader 难做）、blue-noise dither（现代感）、Atkinson dither
  - 提示词片段：`用 8×8 Bayer 有序抖动 + 4 色量化；抖动图案锁定屏幕像素不随内容移动`

- **ASCII / 字符画（ASCII Art）** · L3 · 进阶 · 成本:中
  - 视觉收益：把画面转成字符矩阵，极客感与文本美学
  - 同族拓展：字符按明度排序的 ramp（` .:-=+*#%@`）、边缘方向字符（`/\|-`）、SDF 字符图集
  - 提示词片段：`8×12 网格转 ASCII：明度映射到 10 级字符 ramp，边缘处改用方向字符 /\\|-`

- **低帧率（Reduced Frame Rate / Stop Motion）** · L5 · 进阶 · 成本:低
  - 视觉收益：刻意的 12fps 或 8fps，定格动画/手绘动画的节奏感
  - 关键约束：必须是**刻意且稳定的**（时间量化），不是掉帧
  - 同族拓展：time quantization、on-twos/on-threes（动画术语）、frame hold
  - 提示词片段：`把时间量化为 12fps 步进（floor(t*12)/12）产生定格动画感；相机运动不量化保持顺滑`

- **单色与双色调（Monochrome / Duotone）** · L3 · 基础 · 成本:低
  - 视觉收益：去掉色彩变量，形与光成为唯一主角，最稳的高级感捷径
  - 同族拓展：duotone、tritone、gradient map、见 `R5·C7`
  - 提示词片段：`双色调：暗部映射到深靛蓝、亮部映射到暖米白，中间在 OKLab 插值`

## E5 手工痕迹与不完美（Handmade Imperfection）

**最直接的"去机器味"手段**。默认生成的画面永远太整齐，这一节专门破它。可与 `B82` / `B44` 的清单对照使用——那是参考清单，不是硬性铁律，按项目自行取舍。

- **有意的不对齐（Intentional Misalignment）** · L5 · 进阶 · 成本:低
  - 视觉收益：一处刻意打破网格，画面立刻有"人做的"痕迹
  - 关键约束：**只破一处**，其余严格对齐。全乱 = 没设计
  - 同族拓展：off-grid element、asymmetric bias、rule-breaking accent
  - 提示词片段：`全局严格对齐网格，但选一个元素偏移 12px 且轻微旋转 1.5°`

- **非均匀间距（Non-Uniform Rhythm）** · L5 · 进阶 · 成本:低
  - 视觉收益：等距排列是机器味的第一 signature。让间距有节奏（疏-密-疏）
  - 同族拓展：rhythmic spacing、Fibonacci spacing、tension-release
  - 提示词片段：`列表间距不等距，按 1:1.6:1:2.6 的节奏变化`

- **手绘抖动（Hand-Drawn Wobble）** · L5 · 进阶 · 成本:低
  - 视觉收益：直线不直、圆不圆，见 `R7·E1` 描线抖动
  - 同族拓展：rough.js 风格、squiggle、每次渲染重新随机
  - 提示词片段：`所有分隔线用两段轻微不直的路径（中点偏移 ±1px）`

- **材质瑕疵（Material Blemish）** · L3 · 进阶 · 成本:低
  - 视觉收益：划痕、指纹、灰尘、水渍、磨损边角——干掉"全新出厂"的塑料感
  - 同族拓展：scratch mask、wear on edges（曲率驱动磨损）、dust accumulation（朝上面积多）、smudge
  - 提示词片段：`表面加曲率驱动的边缘磨损 + 极细划痕（各向异性噪声）+ 朝上面轻微积灰`

- **色彩不均（Color Inconsistency）** · L3 · 进阶 · 成本:低
  - 视觉收益：纯色块内部有极轻微的色相/明度变化，像颜料而非填充
  - 同族拓展：subtle hue variance、per-element random tint、ink unevenness
  - 提示词片段：`每个色块内部加 ±2% 明度与 ±3° 色相的低频变化`

- **人的签名（Human Signature）** · L0 · 进阶 · 成本:低
  - 视觉收益：一处只有人会做的选择——一句冷笑话、一个手写注释、一个彩蛋、一个不合规的细节
  - 同族拓展：easter egg、handwritten note、personal aside、参考 `B82` 与 `B44` 中关于"人味细节"的条目（参考清单，不是硬性铁律，按项目自行取舍）
  - 提示词片段：`加一处"只有人会做"的细节：例如一行手写体旁注、一个需要探索才发现的彩蛋`
  - 适用提示：作品集与个人展示类页面尤其要做这一条

## E6 光学现象与自然奇观（Optical Phenomena）

真实世界里稀有但极美的光学效应。**用一个就能撑起整个画面**。

- **焦散（Caustics）** · L4 · 电影级 · 成本:高
  - 视觉收益：水面/玻璃聚焦阳光投在池底的游动光网——极高辨识度
  - 实现路径：真实光子映射（太贵）/ **程序化伪造**（推荐：多层扭曲噪声取 pow 后叠加）
  - 同族拓展：photon mapping、caustic map、pool caustics、Voronoi-based caustics
  - 提示词片段：`焦散用双层反向流动的 Voronoi 边缘取 pow(4) 叠加，颜色略偏青，随时间缓慢流动`

- **虹彩与薄膜干涉（Iridescence / Thin-Film）** · L4 · 电影级 · 成本:中
  - 视觉收益：肥皂泡、油膜、甲虫壳、CD 面——颜色随视角连续变化
  - 同族拓展：thin-film interference、structural color、pearlescence、见 `R5·C3` 光谱渲染
  - 提示词片段：`加薄膜干涉：膜厚 200–600nm 随位置变化，按视角计算干涉色，6 波长采样`

- **色散棱镜（Prism Dispersion）** · L4 · 电影级 · 成本:中
  - 视觉收益：白光被分解成光谱带，水晶/棱镜的"火彩"
  - 同族拓展：见 `R3·A6` 色散、spectral refraction、rainbow caustics
  - 提示词片段：`折射按波长分 8 段采样，产生连续光谱色散而非仅 RGB 三通道`

- **大气光学（Halo / Rainbow / Glory）** · L4 · 电影级 · 成本:中
  - 视觉收益：日晕 22° 环、幻日、彩虹、宝光——罕见到"一看就记住"
  - 同族拓展：22° halo、sun dog、circumzenithal arc、fogbow、Alexander's band
  - 提示词片段：`加 22° 日晕环 + 幻日双点，强度 0.3，仅在太阳可见时出现`

- **水面（Water Surface）** · L4 · 电影级 · 成本:高
  - 视觉收益：反射 + 折射 + Fresnel + 焦散 + 波纹 + 深度衰减，六项齐全才像水
  - 同族拓展：Gerstner waves（尖顶波，比正弦真实）、FFT ocean（Tessendorf）、foam（泡沫，曲率驱动）、subsurface 散射
  - 提示词片段：`水面用 4 层 Gerstner 波（不同方向波长）；Fresnel 混反射折射；波峰加泡沫；水下加深度色衰减 + 焦散`

- **辉光与光学眩光（Glory / Corona）** · L4 · 进阶 · 成本:低
  - 视觉收益：光源周围的同心彩环（雾中/云中），神秘感
  - 同族拓展：corona、Mie 前向散射（见 `R4·B4`）、diffraction ring
  - 提示词片段：`雾中光源加同心彩环（3 圈，色相递变），强度随雾密度提升`

- **极光（Aurora）** · L4 · 电影级 · 成本:中
  - 视觉收益：垂直光幕、下端亮上端淡、青绿到品红渐变、缓慢波动
  - 关键取胜点：**纯加性发光不遮挡**（加性混合，不参与遮挡与深度排序），且垂直方向要有条纹（磁场线）
  - 同族拓展：见 `R4·B3` domain warping、`R4·B5` 慢速流场
  - 提示词片段：`极光：垂直方向亮度从下(青绿)到上(品红透明)衰减，水平用 domain-warped 噪声，垂直加细条纹，纯加性混合`

- **热辐射与蜃景（Heat Shimmer / Mirage）** · L2 · 进阶 · 成本:低
  - 视觉收益：地平线附近的抖动扭曲，酷热或引擎尾焰
  - 同族拓展：见 `R3·A5` 折射热浪、inferior mirage、屏幕空间 UV 扰动
  - 提示词片段：`地平线上方 15% 区域加垂直向上的 UV 抖动（幅度随高度衰减）`

**常见坑**：
- 网点很廉价 → `R7·E2` 网点没旋转角度，或没抗锯齿
- 像素画很糊 → `R7·E4` 用了 linear 采样或非整数缩放
- 限定色板选色很脏 → `R7·E4` 最近色搜索要在 OKLab 而非 RGB
- CRT 不像 → `R7·E3` 少了荫罩条纹和四角失焦（只有扫描线远远不够）
- glitch 很烦人 → `R7·E3` 常态开启了，必须改成偶发短促
- 水彩不像水彩 → `R7·E1` 缺"边缘比中心深"这个物理签名
- 水面像塑料膜 → `R7·E6` 六项要素缺项（尤其缺焦散与泡沫）
- 风格很乱 → E 组用了 2 个以上主媒介，只能留一个
- 手工感变成"做坏了" → `R7·E5` 破规矩只能破一处，其余必须严格

> **风格化与写实的取舍**：如果 R3–R6 组能做到 85 分以上，走写实；如果只能做到 60 分，果断转 R7 风格化——**风格化的 70 分比写实的 60 分好看得多**。
