# K0 · 词条总索引与检索

> K 板块定位：**决策对象层**。A/B/V/F 是原理与规范层，R 是视觉效果提示词条目层，K 是"一个交互/视觉概念需要设计哪几个决策点"的条目层。
> K 词条不重复 B/R/V 已深覆盖的内容——每条只聚合"症状→决策点→实现→验收"，深度原理用 `衔接` 字段指回原档。
> 词条 ID 形如 `K·吸附`，纯词条寻址，不用字母小节号（避免与 R 板块内部编号混淆）。

---

## 一、什么时候用 K

| 场景 | 用法 |
|---|---|
| 生成界面 | Z2 检索时若命中具体决策对象（如"这个面板要能拖动"），先取对应 K 词条的决策点清单，再按衔接字段取 B/R 深文档 |
| 升级/优化已有界面 | 先按 K10 九维框架扫症状 → 命中词条 → 按词条决策点逐项给答案 → 按验收字段自检 |
| 审计 | Z3 五轮审计时，K 词条提供"行为细节"维度的检查项 |
| 查词 | K0 本文件：先定分类 → 词条级需求进 K1-K9，原理级需求走指针去 B/R/V |

**铁律**：K 词条只回答"要决定什么"，不替项目做决定——具体取值由产品上下文定，词条给的是参数域和取舍依据。
