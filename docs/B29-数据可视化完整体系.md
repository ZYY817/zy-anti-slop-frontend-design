# B29 · 数据可视化完整体系

> 数据可视化是"信息设计"最难的部分。做好 = 让复杂变清晰,做差 = 让简单变混乱。
> 从选图表到工艺细节到叙事,全套系统。

---

## 一、选图表:先想清楚要表达什么

**核心问题**:你要让用户对比什么、发现什么?

### 意图 → 图表映射表

| 想表达什么 | 首选图表 | 备选 |
|---|---|---|
| **数量对比** | 柱状图 Bar | 条形图 / 点图 |
| **趋势变化** | 折线图 Line | 面积图 |
| **累积/份额** | 面积图 Area | 堆叠柱 |
| **组成比例** | 环形图 Donut | 堆叠柱(不用饼图!) |
| **两变量关系** | 散点图 Scatter | 气泡图 |
| **分布密度** | 直方图/热力图 | 密度图 |
| **层级占比** | 树图 Treemap | 旭日图 Sunburst |
| **流向/转化** | 桑基图 Sankey | 弦图 Chord |
| **多维对比** | 雷达图 Radar | 平行坐标 |
| **地理数据** | 地图 Choropleth | 点图/热力图 |
| **单指标+趋势** | 大数字 + Sparkline | Bullet Chart |
| **目标进度** | Bullet Chart | Progress Ring |
| **相关矩阵** | 相关矩阵热图 | 散点矩阵 |
| **时间序列多类** | 小倍数 Small Multiples | 高亮当前系列 |

### 避免的图表

- ❌ **3D 图表** — 视觉扭曲数据,精确度差(Tufte 明确反对)
- ❌ **饼图有 >5 片** — 角度难比,改环形+数字
- ❌ **双 Y 轴** — 容易误导,除非有充分理由
- ❌ **雷达图有 >7 维** — 混乱不可读

## 二、Tufte 五大金律(应用版)

**1. 展示数据(Show the data)**
数据本身是主角,其他都是配角。
→ 去掉边框/背景/装饰/3D

**2. 最大化数据墨水比(Maximize data-ink ratio)**
每一像素都该表达数据。
→ 网格线减到最少,坐标轴细化,标签必要时才加

**3. 消除图表垃圾(Erase chartjunk)**
无意义的装饰、渐变、阴影全部删除。
→ 图表就是几何图形+数据,不需要"美化"

**4. 使用小倍数(Small multiples)**
对比多个类别时,不要塞一个复杂大图,用一排小图。
→ 每个类别一张小图,并排放

**5. 高数据密度(High data density)**
好图表在小尺寸也能读出上千个数据点。
→ Sparkline 是极致

## 三、图表工艺细节

### 坐标轴
- **去除框架** — 只保留必要的一条 X 轴基线
- **淡化次要网格** — 用极淡灰(#F0F0F0),不用黑线
- **主要刻度** — 只在关键值(0/50/100)
- **标签直接标数据旁** > 单独图例框

### 颜色
- **单色渐变**(数据有序时):浅→深表达小→大
- **分类色**(数据无序):3-5 色即可,超过难分辨
- **色盲友好**:红绿不同时用,配合形状/图案
- **强调色**:高亮当前系列,其他置灰

### 数字标签
- **只标关键点**(最高/最低/当前),不是每个数据都标
- **单位在轴上一次说明**(不重复)
- **千分位分隔**(1,234,567)
- **大数缩写**(1.2M)

### 悬浮提示(Tooltip)
- **显示精确值**(轴上只标近似)
- **多维数据同时显示**(x, y, category)
- **跟随鼠标位置** + 智能避开视口边缘

### 图表标题
- **描述结论,不是描述内容**
- ❌ "月度销售数据"
- ✅ "Q3 销售同比增长 42%"

## 四、颜色系统(数据可视化专用)

### Sequential(有序,单色渐变)
```
适合:数值大小(温度/人口/密度)
方向:浅 → 深
不要:多色相跳变
例子:蓝色系 #DBEAFE → #1E3A8A
```

### Diverging(分歧,双色对比)
```
适合:有中心点的数据(盈亏/温差/相对基准)
方向:红 ← 白 → 蓝
不要:红绿(色盲不友好)
例子:红蓝(RdBu)/ 棕蓝(BrBG)
```

### Qualitative(分类,无序多色)
```
适合:类别(部门/产品/地区)
限制:≤7 种(超过难分辨)
不要:高饱和撞色
推荐:Tableau 20 / D3 category10
```

### 推荐色板资源
- **ColorBrewer** — 专为数据设计的科学色板
- **Viridis** — 感知均匀,色盲友好
- **Tailwind Color System** — 现代 UI 友好

## 五、仪表盘(Dashboard)布局

### 布局原则

**F 型布局**:
```
[━━ 大标题/摘要 ━━━━━━━━━━━━]
[大指标] [大指标] [大指标] [大指标]  ← 关键 KPI
[━ 主图表 ━━━━━━━━━━━━━━━━]
[小图]  [小图]  [小图]           ← 详细分解
```

**优先级**:
- **左上**:最重要的 1-3 个 KPI(F 型第一停留点)
- **中央**:主要趋势图
- **底部/右侧**:详细分解

### 网格规则
- **12 列栅格**,大 KPI 占 3-4 列,主图占 8-12 列
- **卡片间距 16-24px**
- **卡片内 padding 24px**
- 数据表格用**紧凑行高**(32-40px)

### 密度控制
- **稀疏仪表盘**(高管用)—— 少而精,每个卡片一个关键数
- **密集仪表盘**(分析师用)—— 高信息密度,多变量并排

## 六、数据叙事(Data Storytelling)

### 叙事结构

```
1. 场景 Context     数据在说什么背景下
2. 冲突 Conflict    发生了什么值得关注的
3. 洞察 Insight     从数据中看出了什么
4. 行动 Action      基于洞察该做什么
```

### 视觉叙事技巧

**高亮关键点**:
- 用色标记异常/关键值
- 数据标注箭头指向重点
- 图例只标当前关注的,其他置灰

**渐进披露**:
- 先总数,再分解,再明细
- 点击 KPI → 展开对应详细图

**故事年份/期间**:
- 时间序列图用竖线标记重大事件
- "疫情开始"、"产品发布" 等标注

**对比基准**:
- 加参考线(平均值/目标/去年同期)
- 目标线一定要清晰(通常虚线)

## 七、专用图表深度

### Sparkline(迷你图)★ Tufte 发明
词大小的图表,嵌入表格/文字中。
```
用户增长: 120 ▁▂▃▅▇▇▆▅ 132
收入:     $2M ▂▃▂▅▇▇█ $4M
```
- 尺寸:高 20-30px,宽 60-120px
- 无坐标轴、无标签(主图旁的辅助)
- 只显示形状,不显示精确值
- 表格里每行一个

### Bullet Chart(子弹图)
一维空间显示当前值 + 目标 + 分级:
```
0━━━━40━━━━80━━━━100
▓▓▓▓▓▓▓░░░░ ▮
差   一般   好    目标(▮)当前(▓)
```
比仪表盘图省 90% 空间。

### Small Multiples(小倍数)
```
┌─2020─┐ ┌─2021─┐ ┌─2022─┐ ┌─2023─┐
│  ▂▅▇ │ │ ▂▃▇█│ │▂▅▇▇█│ │▃▅▇██│
└──────┘ └──────┘ └──────┘ └──────┘
```
每个小图坐标系相同,方便对比。

### Heatmap(热力图)
- 一维:日历热力图(GitHub 贡献图)
- 二维:x 轴时间 + y 轴类别
- 用单色渐变编码强度
- 单元格间隙 2-4px(不要贴太紧)

## 八、可视化的技术栈

### JavaScript 库
- **D3.js** — 底层最强,学习曲线陡
- **Recharts** — React 首选,简单
- **Nivo** — React,组件多
- **Visx** — Airbnb,底层+组件
- **Observable Plot** — Tufte 精神,极简
- **ECharts** — 中文文档最全,功能强
- **Chart.js** — 简单场景

### 高级/特殊
- **Deck.gl** — 大数据集/地理
- **Three.js** — 3D 可视化
- **Sigma.js** — 网络图专用

### 推荐组合
- **一般 SaaS Dashboard** → Recharts / Nivo
- **数据密集应用** → D3 / ECharts
- **极简/Tufte 风** → Observable Plot
- **大数据/地理** → Deck.gl

## 九、无障碍数据可视化

- **不能只用颜色区分** — 加图案/形状/直接标签
- **提供数据表格备选** — 屏幕阅读器可读
- **对比度达标** — 数据点与背景 ≥3:1
- **文字描述关键洞察** — 图表附文字总结
- **键盘可导航** — 数据点可 Tab
- **动画可跳过** — 数据加载动画尊重 reduced-motion

## 十、Prompt 模板

### 仪表盘
```
【数据可视化系统】

图表选择原则:
- 数量对比:柱状图(不用饼图)
- 趋势:折线图
- 组成:环形图 <5 片,否则堆叠柱
- 单指标:大数字 + Sparkline

Tufte 五律遵循:
- 展示数据(去装饰)
- 最大化数据墨水比(去除边框/多余网格)
- 消除 chartjunk(无 3D/无渐变/无阴影)
- 使用小倍数对比多类别
- 高数据密度(Sparkline)

工艺细节:
- 坐标轴:只保留一条基线,极淡网格
- 颜色:分类用 ≤5 色,数值用单色渐变
- 数字:tabular-nums,千分位,大数缩写
- Tooltip:悬浮显示精确值
- 标题:描述结论不是内容

布局(仪表盘):
- 左上 3 个大 KPI(F 型入口)
- 中央主趋势图
- 底部详细分解
- 12 列栅格,卡片间距 24px

无障碍:
- 不只用颜色区分
- 数据点对比度 ≥3:1
- 图表有文字总结
- 支持键盘导航

技术栈:Recharts + Nivo(React)/ ECharts(密集场景)
```
