# B10 · 色彩描述词库

> 从"蓝色"升级到"忧郁蓝 / 磨砂黑 / 黎明粉"。
> 色彩描述精度 = AI 出图精度。这是最容易立刻见效的升级。

---

> **定位**：色彩"词牌"+hex 弹药库——B86§二/§九 的散装选色层。机制性色彩决策（色岗/来源色板/chroma taper）在 B86；本文只管"把单个颜色说准"。时段色板与五槽选色语法已并入 B86。

## 为什么这个词库最重要

说"用蓝色"→ AI 可能给你 #0000FF(廉价刺眼)
说"用忧郁的午夜蓝,低饱和,带一点灰调"→ AI 给你 #1E293B(高级沉稳)

**同一个色相,描述精度不同,结果差一个档次。**

### ★关键规则:冷暖不混
```
✅ 全套冷灰 (Slate 系) — 科技、专业、冷静
✅ 全套暖灰 (Taupe 系) — 温暖、高级、生活
❌ 冷灰 + 暖灰混用 — 看起来"脏"、不专业
```

**这一条是区分专业与业余的最快检验方法。**

### ★工具页 accent 的彩度铁律（case07 实证）

出现在功能表面（按钮/开关/分段/focus 环）的 accent 不是装饰色——全页几十处反复出现，**饱和度必须往灰靠**：HSL S ≲20% 或 RGB 通道极差 ≲30。实证：`#3f4a56`（S≈15%，"带蓝倾向的灰"）满屏用不吵；`#3d6b4f`（S≈27% 松绿）同面积就显"花"。**高彩度色只配当签名点**（印章/logo/徽标，面积 <1%）。想象把这个色涂满十个开关：吵 = 降彩换灰。判据与治理见 `K18`·视觉职责分工①b。
