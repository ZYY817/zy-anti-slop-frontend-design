# K21 · 概念提炼与叙事骨架（Concept Extraction / Narrative Skeleton）

> 一个链式决策对象：素材盘点 → 隐喻候选 → 骨架当选 → 时刻落位 → 撞车应对。
> **这是"页面凭什么是一个整体"的入口词条。** K19 管"什么该先被看到"（层级），本词管"页面结构本身从哪来"（概念）。case08 实证：两个独立 agent（裸跑/武装）面对同一份品牌 brief **各自提炼出同一骨架**——"整页=一条下山路，海拔 2000m→0m"——证明这个能力可复现、可写成决策对象；同时也证明强 brief 素材下**骨架撞车是预期现象**，胜负在执行与时刻设计。

---

## K·叙事骨架（决策点逐项作答，跳步=没用）

- **领域**：视觉/信息架构/概念层 · **成本**：零（纯决策）
- **定义**：从 brief 的具体素材中提炼一个**能映射全部区块的结构隐喻**，让它同时承担排序逻辑、空间系统与 signature 装置——骨架是结构不是装饰。"整页=一条下山路"是骨架；"hero 上画一座山"只是装饰。
- **症状**：每个区块各自成立但互相不认识（模板脸的终极形态）；signature 装置悬在半空——很炫但拿掉不影响页面；概念只活在 hero，往下滚立刻回到通用组件流；提炼不出骨架于是堆三种叙事碎片（海拔+经纬度+实验室编号 各说各话）。
- **适用**：视觉表达为主表达的页面（品牌页/落地页/作品集/活动页）｜ **不适用**：工具页——工具页的骨架是任务流不是隐喻，强行上概念=呼吸峰错配（case07 hero 禁令同因）。**brief 无结构性素材时不许硬编骨架**——退回常规信息架构（C1），强拧的隐喻比没有更廉价。
- **决策点**（链式，按序作答）：
  ① **素材盘点**——列出 brief 里全部**具体名词/数字/动词**（"海拔 2000 米/三款香型/蒸馏"是素材；"高端/清新/东方"是形容词，不算素材——形容词给气质不给结构）。素材 <3 个=骨架材料不足，回到不适用分支
  ② **隐喻候选**——每个具体素材问"它能**成为**什么结构"：数字能当轴（海拔→纵轴/里程→进度）、集合能当序列（三香型→三海拔带）、工艺能当路径（蒸馏→冷凝管流程）。一个素材常出 2-3 个候选
  ③ **骨架当选**——只选一个隐喻，判据=**它能映射全部区块**（测试：每个 section 必须得到骨架**上**的位置而不是骨架**旁**的位置——冷杉在 2000m 带是"上"；冷杉卡片加一行小字"海拔 2000m"是"旁"）。当选骨架同时交出三样东西：区块排序逻辑 + 空间/刻度系统 + signature 装置的栖身位
  ④ **时刻落位**——**一个** signature 时刻必须落在骨架上（case08：裸跑的"雾间"按住吞字时刻在下山路中段；武装的海拔计轨全程随行）。骨架无时刻=只有脚手架；时刻不在骨架上=悬浮特效
  ⑤ **撞车应对**——brief 素材强→骨架撞车是**预期**不是失败（case08 双撞海拔）。此时**不许为求异换弱骨架**——差异化责任移交给：时刻设计（雾间 vs 海拔计）、执行工艺（CSS 瓶画 vs 台账版式）、文案声部。判断问句："这个骨架是素材自然长出来的，还是我为躲撞车硬编的？"后者必输
- **实现**：
  - 设计计划强制项：Pass1 输出一行骨架陈述——"整页=______"（case08 两版均可一句答出；答不出或需要两个句子=骨架未立）
  - 骨架三产自查：排序逻辑（区块为什么是这顺序）/空间系统（刻度·进度·位置从哪来）/装置位（signature 挂哪）——三缺一直接返工
  - 提取练习：把 brief 每句话标"素材/气质/噪音"，素材词不足 3 个时向需求方要具体物，不要自己造
- **验收**：骨架陈述一句成句；每个 section 能答出自己在骨架上的位置；signature 时刻 ∈ 骨架；无第二种隐喻混入（经纬度/编号/等高线只能是同一骨架的不同刻度，不是新骨架）；裸骨架测试——删掉全部装饰只留结构，仍能复述"这是什么路"。
- **衔接**：K19（骨架定区块序，层级链定区块内眼球序——先骨架后层级）、K·视觉配额（时刻配额≤1-2 的预算源）、B80（叙事弧类型清单——本词管"提炼"，B80 管"选哪种弧"）、R20·L1 骨层、R21（方向确定）、B85（骨架可源于参考拆解，但映射规则须自证）
