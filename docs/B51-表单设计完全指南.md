# B51 · 表单设计完全指南

> 表单是最高频、最容易做烂的界面。用户在这里最容易放弃。
> 从布局到校验到状态,全套视觉规范。

---

## 一、表单布局

### 单列 vs 多列
```
✅ 单列(推荐)      — 视线路径清晰,移动友好,完成率最高
⚠️ 双列            — 仅用于短相关字段(名/姓、城市/邮编)
❌ 三列以上        — 视线混乱,完成率下降
```

**研究结论**:单列表单完成速度比多列快 15.4%(Baymard Institute)。

### 标签位置
| 位置 | 优点 | 缺点 | 推荐度 |
|---|---|---|---|
| **上方(Top)** | 移动友好/可读性好/长标签不受限 | 占垂直空间 | ★★★★★ |
| **左侧(Left)** | 紧凑/桌面扫读快 | 移动端难处理/长标签麻烦 | ★★★ |
| **内嵌(Inline)** | 省空间 | focus 后消失(记不住) | ★★ |
| **浮动(Floating)** | 省空间+不消失 | 实现复杂/小字难读 | ★★★★ |

**默认选择**:标签在上方。

### 字段宽度暗示长度
```
邮编:     短输入框(80px)
手机号:   中输入框(160px)
邮箱/地址: 全宽
```
**宽度是视觉提示**——告诉用户"这里该输入多长"。

## 二、表单的视觉规格

```
标签
 ↕ 6px
┌──────────────────────────┐
│ ←12px→ 输入文字           │  height 40-44px
└──────────────────────────┘
 ↕ 6px
帮助文字 / 错误提示

字段之间: ↕ 20-24px
字段组之间: ↕ 32-40px
```

### 详细参数
```css
/* 标签 */
label {
  font-size: 14px;
  font-weight: 500;
  color: var(--text-primary);
  margin-bottom: 6px;
  display: block;
}

/* 输入框 */
input {
  height: 40px;           /* 移动端 48px */
  padding: 0 12px;
  font-size: 16px;        /* 移动端必须 ≥16px 防 iOS 缩放! */
  border: 1px solid var(--border);
  border-radius: 8px;
  background: var(--surface);
  transition: border-color 200ms, box-shadow 200ms;
}

/* focus */
input:focus-visible {
  border-color: var(--primary);
  box-shadow: 0 0 0 3px var(--primary-alpha-20);
  outline: none;
}

/* 帮助文字 */
.help {
  font-size: 13px;
  color: var(--text-muted);
  margin-top: 6px;
}
```

### iOS 缩放陷阱 ★
```
input 字号 <16px → iOS Safari 会自动放大页面
✅ 移动端 input font-size: 16px(至少)
```

## 三、必填与选填标记

```
✅ 推荐:标记必填(如果大多数是选填)
   邮箱 *
   
✅ 或标记选填(如果大多数是必填)
   电话(选填)

❌ 不要只用红色 *(色盲看不出)
✅ * + aria-required="true" + 表单顶部说明"* 为必填项"
```

**规律**:标记少数派。全必填的表单只在顶部说明一次。

## 四、校验时机 ★最关键

### 三种时机

| 时机 | 何时触发 | 适合 |
|---|---|---|
| **实时(onChange)** | 每次输入 | ❌ 太烦(打第一个字就报错) |
| **失焦(onBlur)** | 离开字段 | ✅ **推荐**(格式类) |
| **提交(onSubmit)** | 点提交 | ✅ 业务类(用户名重复) |

### 最佳实践:混合策略
```
1. 用户输入中     → 不校验(不打扰)
2. 用户离开字段   → 校验格式(邮箱/手机号)
3. 校验失败后重新输入 → 实时校验(帮用户修正,实时消除错误)
4. 提交时         → 全部校验 + 业务校验
```

**关键**:**失败后才开启实时校验**,这样用户能立即看到"改对了"。

### 密码强度(特例)
密码是唯一适合实时反馈的:
```
输入中实时显示:
□ 至少 8 位
□ 包含数字
□ 包含大写字母
(满足的打勾变绿)
```

## 五、错误提示设计

### 位置
```
✅ 字段下方(最近,最好找)
⚠️ 字段右侧(空间不足时)
❌ 表单顶部汇总(还要滚回去找)
✅ 顶部汇总 + 字段下方(长表单最佳)
```

### 视觉
```css
.field-error input {
  border-color: var(--danger);
  /* 可选:淡红背景 */
  background: var(--danger-alpha-5);
}
.error-message {
  color: var(--danger);
  font-size: 13px;
  margin-top: 6px;
  display: flex;
  align-items: center;
  gap: 4px;
}
/* 加图标(不只用颜色) */
.error-message::before {
  content: '⚠';  /* 或 SVG 图标 */
}
```

### 文案(三要素)
```
❌ "输入无效"
❌ "格式错误"
✅ "请输入有效的邮箱地址,例如 name@example.com"
✅ "密码至少需要 8 个字符(当前 5 个)"
✅ "这个用户名已被占用,试试 zhangsan_2026?"
```

**要素**:什么错了 + 为什么 + 怎么改。

### 动效
```css
@keyframes shake {
  0%, 100% { transform: translateX(0); }
  25% { transform: translateX(-4px); }
  75% { transform: translateX(4px); }
}
.field-error { animation: shake 300ms; }
```
提交失败时,第一个错误字段 shake + 自动聚焦 + 滚动到可见。

```
输入正确后:

⚠️ 不要每个字段都显示(视觉噪音)
✅ 只在"容易出错"的字段显示(邮箱/密码/用户名可用性)
```

## 七、表单状态完整覆盖

```
字段状态:
□ empty(空,显示 placeholder)
□ filled(有内容)
□ focus(聚焦,边框+ring)
□ error(错误,红边框+提示+图标)
□ success(通过,绿✓)可选
□ disabled(禁用,灰底+cursor not-allowed)
□ readonly(只读,无边框或淡边框)
□ loading(异步校验中,右侧 spinner)

表单状态:
□ pristine(未修改)
□ dirty(已修改,提交按钮激活)
□ submitting(提交中,按钮 loading,字段禁用)
□ success(成功,显示成功页或 Toast)
□ error(失败,顶部错误横幅)
```

## 八、提交按钮设计

```
✅ 全宽(移动端)或右对齐(桌面)
✅ 主色实心,最醒目
✅ 文案具体("创建账号" 不是 "提交")
✅ 有 loading 态(spinner + 禁用)
✅ 宽度不变(loading 时不跳动)

❌ 默认禁用直到全部填完(用户不知道为什么点不了)
✅ 始终可点,点击后显示所有错误
```

### 按钮状态流
```
[创建账号] → [⟳ 创建中...] → [✓ 已创建]
   ↑ 宽度保持一致(min-width 固定)
```

### 取消按钮
```
✅ 次要样式(ghost/link),放在主按钮左侧
❌ 与主按钮同等醒目(用户会误点)
```

## 九、长表单的处理

### 分步(Multi-step)
```
[1 基本信息] → [2 详细资料] → [3 确认]
  ●━━━━━━━━━━━━○━━━━━━━━━━━━○

- 步骤条显示进度(蔡格尼克效应驱动完成)
- 每步 3-7 个字段
- 可返回上一步(数据保留)
- 最后一步是"确认"页(可编辑)
```

### 分组(Fieldset)
```
━━ 账号信息 ━━━━━━━━━━━
邮箱
密码

━━ 个人资料 ━━━━━━━━━━━
姓名
生日
```
用标题 + 分隔线 + 大间距(32-40px)分组。

### 自动保存
```
长表单必须自动保存草稿:
- 每 30 秒或字段失焦时保存
- 显示"已保存"提示(微妙,不打扰)
- 刷新/意外关闭后恢复
```

## 十、特殊输入类型

### 密码
```
- 默认隐藏,右侧眼睛图标切换显示
- 强度指示器(实时)
- 不要禁止粘贴(密码管理器需要)
- autocomplete="new-password" / "current-password"
```

### 手机号
```
- 国际化:国家代码选择器 + 号码
- 自动格式化(138 0000 8888)
- inputmode="tel"(移动端数字键盘)
```

### 验证码(OTP)
```
- 分离的方格输入(4-6 个)
- 自动跳到下一格
- 支持粘贴(自动分配)
- 自动提交(填满后)
- inputmode="numeric" autocomplete="one-time-code"
```

### 日期
```
- 优先原生 <input type="date">(移动端体验最好)
- 桌面可用自定义日历
- 显示格式提示(YYYY-MM-DD)
```

### 文件上传
```
- 拖拽区 + 点击选择
- 虚线边框(暗示"可放这里")
- 拖拽悬停时高亮
- 上传中:进度条 + 文件名 + 取消
- 完成:缩略图/文件 chip + ✕ 移除
- 显示限制("最大 10MB,支持 JPG/PNG")
```

### 搜索
```
- 左侧放大镜图标
- 右侧清除 ✕(有内容时显示)
- 实时搜索 + debounce 300ms
- 加载时右侧 spinner
- type="search" + inputmode="search"
```

## 十一、移动端表单优化

```
✅ input font-size ≥16px(防 iOS 缩放)
✅ height 48px(触控友好)
✅ 正确的 inputmode(数字/邮箱/电话/URL)
✅ 正确的 autocomplete(浏览器自动填充)
✅ 提交按钮全宽 + 固定底部(可选)
✅ 键盘弹出不遮挡当前字段(scroll into view)
✅ 单列布局
✅ 减少字段(能自动获取的不要问)
```

### inputmode 完整表
```html
<input inputmode="text">      普通键盘
<input inputmode="numeric">   数字键盘(无小数点)
<input inputmode="decimal">   数字+小数点
<input inputmode="tel">       电话键盘
<input inputmode="email">     邮箱键盘(有 @)
<input inputmode="url">       URL 键盘
<input inputmode="search">    搜索键盘(有"搜索"键)
```

### autocomplete 常用值
```html
name / given-name / family-name
email / tel / url
street-address / postal-code / country
username / current-password / new-password
cc-number / cc-exp / cc-csc
one-time-code
```

## 十二、表单的无障碍

```html
<div>
  <label for="email">
    邮箱地址
    <span aria-hidden="true">*</span>
  </label>
  <input
    id="email"
    type="email"
    inputmode="email"
    autocomplete="email"
    required
    aria-required="true"
    aria-invalid="true"
    aria-describedby="email-help email-error"
  />
  <p id="email-help">我们不会分享你的邮箱</p>
  <p id="email-error" role="alert">请输入有效的邮箱地址</p>
</div>
```

**要点**:
- `label` 用 `for` 关联 `id`
- 错误用 `aria-describedby` 关联
- 错误消息用 `role="alert"`(立即播报)
- `aria-invalid` 标记错误状态
- 不用 placeholder 代替 label

## 十三、减少表单摩擦的 10 招

1. **减少字段** — 每个字段都问"真的需要吗?"
2. **智能默认** — 国家/时区自动检测
3. **自动填充** — 正确的 autocomplete
4. **社交登录** — 一键代替填表
5. **分步** — 长表单拆成小步
6. **自动保存** — 不怕丢
7. **合并字段** — 全名一个字段(不拆名/姓)
8. **允许多格式** — 手机号带空格/横线都接受(Postel's Law)
9. **进度可见** — 知道还剩多少
10. **明确价值** — 说明为什么需要这个信息

## 十四、Prompt 模板

```
【表单设计】

布局:
- 单列布局(完成率最高)
- 标签在输入框上方,间距 6px
- 字段之间 24px,字段组之间 40px
- 字段宽度暗示内容长度(邮编短/邮箱全宽)

视觉:
- 输入框 height 40px(桌面)/ 48px(移动)
- font-size 16px(移动端必须,防 iOS 缩放)
- padding 0 12px,border 1px,radius 8px
- focus: 主色边框 + 3px ring(主色 20% 透明)

必填:
- 标记少数派(多数选填就标必填)
- * + aria-required + 顶部说明

校验时机:
- 输入中不校验
- 失焦校验格式
- 失败后开启实时校验(帮用户看到改对了)
- 提交时全量校验 + 业务校验
- 密码例外:实时显示强度清单

错误:
- 位置:字段下方
- 视觉:红边框 + 图标 + 红字(不只用颜色)
- 文案三要素:什么错+为什么+怎么改
- 提交失败:第一个错误字段 shake + 聚焦 + 滚动到可见

状态全覆盖:
- 字段:empty/filled/focus/error/success/disabled/readonly/loading
- 表单:pristine/dirty/submitting/success/error

提交按钮:
- 移动全宽/桌面右对齐
- 文案具体("创建账号"不是"提交")
- loading 时宽度不变(min-width 固定)
- 始终可点(点击后显示所有错误,不预先禁用)
- 取消用 ghost 样式在左侧

长表单:
- 分步 + 步骤条进度
- 每步 3-7 字段
- 自动保存草稿(30s 或失焦)
- 分组用标题+分隔线+40px 间距

特殊输入:
- 密码:眼睛切换 + 强度清单 + 不禁止粘贴
- OTP:分离方格 + 自动跳格 + 支持粘贴 + 填满自动提交
- 文件:拖拽区虚线边框 + 进度 + 缩略图
- 搜索:左放大镜 + 右清除 + debounce 300ms

移动端:
- inputmode 正确(numeric/tel/email/url/search)
- autocomplete 正确
- 键盘弹出时字段 scrollIntoView

无障碍:
- label for + id 关联
- 错误 aria-describedby + role="alert"
- aria-invalid / aria-required
- 不用 placeholder 代替 label
```
