# D3 · 设计令牌（Design Tokens）

> Tokens 是设计的原子。让设计与代码共享一套"变量"。

---

## 一、什么是设计令牌

**Design Tokens** — 命名的设计决策，以键值对存储。

例：
```
color.primary.500 = #3B82F6
space.md = 16px
motion.duration.fast = 150ms
```

**优势**：
- 单一数据源（改一处全局生效）
- 跨平台复用（Web/iOS/Android/Figma）
- 支持主题切换（Light/Dark/Brand）
- 便于版本化、变更追踪

---

## 二、三层架构

### 1. Primitive（原始/底层）
无语义的原始值。
```
color.blue.500     = #3B82F6
color.slate.900    = #0F172A
space.4            = 16px
font.size.24       = 24px
radius.md          = 8px
duration.200       = 200ms
```

### 2. Semantic（语义/中层）
有语义，引用 Primitive。
```
color.brand.primary        = {color.blue.500}
color.text.primary         = {color.slate.900}
color.background.default   = {color.white}
color.border.subtle        = {color.slate.200}
color.feedback.success     = {color.green.500}
color.feedback.error       = {color.red.500}

space.component.padding    = {space.4}
space.section.gap          = {space.16}

text.heading.lg.size       = {font.size.30}
text.heading.lg.weight     = 600
text.heading.lg.line       = 1.2

motion.enter.duration      = {duration.200}
motion.enter.easing        = cubic-bezier(0, 0, 0.2, 1)
```

### 3. Component（组件专属/底层）
组件专属，引用 Semantic 或 Primitive。
```
button.primary.bg               = {color.brand.primary}
button.primary.bg.hover         = {color.blue.600}
button.primary.bg.pressed       = {color.blue.700}
button.primary.text             = {color.white}
button.primary.padding.x        = {space.4}
button.primary.padding.y        = {space.2}
button.primary.radius           = {radius.md}
```

## 三、命名规范

### 结构
```
[category].[property].[variant].[state].[modifier]

例：
color.button.primary.bg.hover
space.card.padding.md
text.heading.h1.size
```

### 类别
- `color` — 颜色
- `space` — 间距
- `size` — 尺寸
- `font` — 字体属性
- `text` — 排版组合
- `radius` — 圆角
- `border` — 边框
- `shadow` — 阴影
- `opacity` — 透明度
- `motion` — 动画
- `z` — 层级
- `breakpoint` — 断点

### 状态修饰
- `.default` — 默认
- `.hover` — 悬停
- `.active` / `.pressed` — 按下
- `.focus` — 焦点
- `.disabled` — 禁用
- `.selected` — 选中

### 尺寸修饰
- `.xs` `.sm` `.md` `.lg` `.xl` `.2xl` `.3xl`

## 五、主题化（Theming）

### 双主题（Light + Dark）
每个 semantic token 对应两个 primitive：
```
Light:
  color.background.default = color.white
  color.text.primary = color.slate.900

Dark:
  color.background.default = color.slate.950
  color.text.primary = color.slate.50
```

### 多品牌
每个品牌一套 primitive，semantic 相同：
```
Brand A:
  color.brand.primary = #3B82F6 (蓝)

Brand B:
  color.brand.primary = #10B981 (绿)
```

### 密度主题
- Cozy / Comfortable / Compact
- 调整 space 与 font 阶梯

## 六、实现方式

### CSS Variables（推荐）
```css
:root {
  --color-primary: 59 130 246;
  --color-text: 15 23 42;
  --space-md: 16px;
  --radius-md: 8px;
}

[data-theme="dark"] {
  --color-primary: 96 165 250;
  --color-text: 248 250 252;
}

.button {
  background: rgb(var(--color-primary));
  color: white;
  padding: var(--space-md);
  border-radius: var(--radius-md);
}
```

### Tailwind Config
```js
// tailwind.config.js
export default {
  theme: {
    colors: {
      primary: 'rgb(var(--color-primary) / <alpha-value>)',
      // ...
    },
    spacing: {
      md: 'var(--space-md)',
    }
  }
}
```

### JavaScript Tokens
```ts
export const tokens = {
  color: {
    brand: { primary: 'rgb(59 130 246)' }
  },
  space: { md: '16px' }
}
```

## 七、DTCG 标准格式（2026 行业事实标准）

> **W3C DTCG Design Tokens Format Module 2025.10**（2025-10-28 发布首个稳定版）。
> 由 20+ 组织共建（Adobe/Google/Meta/Microsoft/Amazon/Figma/Salesforce/Shopify…），
> 让 tokens 不再锁死单一工具：一个文件同时驱动设计与代码。采用率 84% 产品团队（2026，↑56%）。

### 格式要点

```json
{
  "color": {
    "brand": {
      "primary": { "$value": "#3B82F6", "$type": "color", "$description": "品牌主色" }
    }
  },
  "space": {
    "md": { "$value": "16px", "$type": "dimension" }
  }
}
```

- 键：`$value` / `$type` / `$description`（DTCG 规范）；文件扩展名 `.tokens` 或 `.tokens.json`
- 名称规则：不能以 `$` 开头，不能含 `{` `}` `.`
- 引用（别名/继承）：`{color.brand.primary}`，点分隔路径
- `$type` 体系覆盖：color / dimension / fontFamily / fontSize / fontWeight / duration / cubicBezier / strokeStyle / typography / shadow / gradient / border / spacing 等
- 支持现代色彩空间：**OKLCH、Display P3**、多主题、多品牌（Extended Collections：子品牌继承根集合，只重定义差异）

### 标准管道（design-system-as-code）

```
Figma Variables / Tokens Studio（设计端）
        │ 导出 DTCG JSON
        ▼
仓库内 tokens.json（单一事实源）
        │ Style Dictionary v4+ / Terrazzo 构建
        ▼
CSS 变量(Web) / Swift(iOS) / XML(Android) / Flutter
        │ CI 每次变更自动重建 + PR
        ▼
全平台同步
```

### 工具生态（10+ 已支持/实现）

| 类型 | 工具 |
|---|---|
| 设计工具 | Figma（2025 底原生支持导入导出）、Penpot（原生格式）、Sketch、Framer |
| Token 管理 | Tokens Studio、Knapsack、Supernova、zeroheight |
| 构建工具 | **Style Dictionary v4+**（Amazon，DTCG 一等支持）、**Terrazzo**（新锐） |
| 迁移 | Style Dictionary v3 JSON → DTCG 转换工具 |

> 注意：2025.10 格式在 Style Dictionary 需 v5（WIP）才完整支持；40% 团队仍手动同步（没有真管道）。

## 九、命名反例

```
❌ 太具体
color.button-hover-bg = ...

❌ 太抽象
color.1 = ...

❌ 混合层级
color.primary-500 = #3B82F6
color.brand = color.primary-500  # 应统一层级

❌ 不一致大小写
color.Primary_500
colorPrimary500

✅ 一致的命名
color.brand.primary
color.brand.primary.hover
```

## 十、Tokens 变更管理

- Primitive 层不轻易改（改了影响所有引用）
- Semantic 层可以调整映射（换个引用）
- 破坏性变更：主版本 + 迁移指南
- 弃用先标记，后移除
- 使用 codemod 自动迁移

## 十一、Prompt 表达模板

```
【Design Tokens】：
- 三层架构：primitive → semantic → component
- 存储方式：CSS variables + Tailwind config
- 主题：Light / Dark 双主题，data-theme 切换
- 命名规范：{category}.{property}.{variant}.{state}
- 颜色：10 阶色板 × Light/Dark 两套语义映射
- 间距：4pt 基础，space.0 到 space.32
- 字体：字号 xs-5xl，字重 400/500/600/700
- 圆角：sm/md/lg/xl/full
- 阴影：xs/sm/md/lg/xl，Dark 模式改用 border
- 动效：duration + easing 独立 tokens
- 实施：所有硬编码值必须来自 tokens
```
