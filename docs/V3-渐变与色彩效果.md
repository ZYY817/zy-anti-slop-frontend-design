# V3 · 渐变与色彩效果

> 渐变用好了是"高级",用坏了是"廉价"。差别全在细节。

---

## 一、渐变类型（Gradient Types）

### 线性渐变 (Linear Gradient)
- **感觉**:方向感、过渡
- **场景**:背景、按钮、遮罩
- **实现**:`linear-gradient(135deg, #667eea, #764ba2)`
- **角度**:135deg(左上到右下)最常用、最自然

### 径向渐变 (Radial Gradient)
- **感觉**:聚焦、光源感、发散
- **场景**:光晕、聚光、背景光源
- **实现**:`radial-gradient(circle at top, #fff, #f0f0f0)`

### 锥形渐变 (Conic Gradient)
- **感觉**:旋转、色轮、独特
- **场景**:饼图、加载动画、装饰
- **实现**:`conic-gradient(from 0deg, red, yellow, green, blue, red)`

### 网格渐变 (Mesh Gradient) ★现代热门
- **感觉**:柔和、梦幻、高级、AI 感
- **场景**:hero 背景、品牌页、AI 产品
- **prompt 措辞**:"背景用 mesh gradient,多个柔和色点融合,紫蓝粉过渡"
- **实现**:多个 radial-gradient 叠加,或用工具/图片
```css
background:
  radial-gradient(at 20% 30%, #667eea 0px, transparent 50%),
  radial-gradient(at 80% 20%, #764ba2 0px, transparent 50%),
  radial-gradient(at 40% 80%, #f093fb 0px, transparent 50%);
```
- **谁在用**:Stripe、Linear、大量 AI 产品

### 极光渐变 (Aurora Gradient)
- **感觉**:流动、梦幻、科技
- **场景**:AI 产品、深色 hero
- **实现**:mesh gradient + 缓慢动画 + 模糊

### 颗粒渐变 (Grainy Gradient) ★高级秘诀
- **感觉**:高级、有质感、消除"数字塑料感"
- **prompt 措辞**:"渐变叠加细微噪点(grain),增加质感,消除色带"
- **实现**:渐变 + SVG noise 叠加(`feTurbulence`)+ 低透明度
- **谁在用**:高端品牌页、独立设计师作品

## 二、渐变的应用（Gradient Applications）

### 渐变文字 (Gradient Text)
- **感觉**:亮眼、现代、品牌感
- **场景**:标题关键词、logo 文字
- **实现**:
```css
background: linear-gradient(135deg, #667eea, #764ba2);
-webkit-background-clip: text;
background-clip: text;
color: transparent;
```
- **坑**:整段用会影响可读性,只用于短标题/关键词

### 渐变边框 (Gradient Border)
- **感觉**:精致、科技、有边界感
- **实现**:
```css
border: 2px solid transparent;
background:
  linear-gradient(white, white) padding-box,
  linear-gradient(135deg, #667eea, #764ba2) border-box;
```
或用 `border-image`

### 渐变遮罩 (Gradient Mask)
- **感觉**:优雅渐隐
- **场景**:图片边缘淡出、内容底部渐隐、滚动提示
- **实现**:
```css
mask-image: linear-gradient(to bottom, black 60%, transparent);
```

### 渐变描边动画 (Animated Gradient Border)
- **感觉**:流光、高科技、吸睛
- **场景**:AI 输入框、特殊 CTA、卡片高亮
- **prompt 措辞**:"卡片边框流光动画,渐变沿边框旋转"
- **实现**:conic-gradient + 旋转动画 + mask

### 渐变阴影 (Gradient Glow)
- **感觉**:彩色发光
- **实现**:多层不同色 box-shadow,或滤镜

## 三、色彩滤镜效果（Color Effects）

### 双色调 (Duotone)
- **感觉**:时尚、统一、有设计感
- **场景**:图片处理、品牌化照片
- **prompt 措辞**:"图片处理成双色调,阴影用深蓝,高光用粉"
- **实现**:`filter` + `mix-blend-mode`,或 SVG filter

### 三色调 (Tritone)
- 双色调进阶,用三色映射明暗

### 色相偏移 (Hue Shift / Rotate)
- **实现**:`filter: hue-rotate(90deg)`
- **场景**:主题变体、hover 变色

### 色彩偏差 / 色差 (Chromatic Aberration)
- **感觉**:故障感、复古、3D、赛博
- **场景**:glitch 风格、特殊标题
- **实现**:RGB 三通道错位偏移

### 反相 (Invert)
- **实现**:`filter: invert(1)`
- **场景**:暗色模式快速反转、特效

### 复古 (Sepia)
- **实现**:`filter: sepia(0.5)`
- **场景**:怀旧、老照片感

### 饱和度调整
```css
filter: saturate(1.5);   /* 更鲜艳 */
filter: saturate(0.5);   /* 更灰 */
filter: grayscale(1);    /* 完全灰(hover 恢复彩色是常见手法) */
```

## 四、渐变的"高级 vs 廉价" ★核心

| 廉价 | 高级 |
|---|---|
| 高饱和撞色渐变(红→蓝) | 邻近色柔和渐变(蓝→紫) |
| 生硬两色跳变 | 多色平滑过渡 |
| 有明显色带(banding) | 加噪点消除色带 |
| 纯色无质感 | 颗粒渐变有质感 |
| 到处都是渐变 | 克制,只在关键处 |
| 经过灰色的脏渐变 | 走 HSL/OKLCH 短路径 |

### 三个高级秘诀
1. **邻近色渐变**:色相相差 10-40 度内,过渡柔和
2. **加噪点**:消除色带,增加质感
3. **用 OKLCH 插值**:避免中间变灰变脏
```css
background: linear-gradient(in oklch, #667eea, #f093fb);
```

## 五、常见技术坑

### 色带 (Banding)
- **问题**:渐变出现一条条明显的色阶
- **原因**:8bit 色深不够 / 渐变距离长颜色接近
- **解决**:叠加 1-2% 噪点打散色带

### 渐变经过灰色
- **问题**:红→蓝的渐变中间发灰发脏
- **原因**:RGB 直线插值经过低饱和区
- **解决**:用 `in oklch` / `in hsl` 插值,或加中间色

### 渐变文字不显示
- **原因**:忘了 `color: transparent`
- **解决**:三件套齐全(background-clip: text + color: transparent + 前缀)

## 六、Prompt 模板

### AI 产品 hero(极光渐变)
```
【背景渐变】
- Aurora mesh gradient:多个 radial-gradient 柔和融合
- 色点:靛蓝 #4F46E5 / 紫 #7C3AED / 粉 #EC4899,深色底
- 叠加 2% 噪点(grain)消除色带、增质感
- 缓慢流动动画(20s 循环,极慢)
- 标题关键词用渐变文字(靛蓝→粉)
```

### 高级品牌页
```
【渐变使用】
- 主背景:极淡的邻近色渐变(米白→浅暖灰)
- 用 in oklch 插值,过渡干净不发灰
- 叠加细微 grain 质感
- CTA:主色渐变 + 彩色阴影
- 克制原则:渐变只用于 hero 背景和 CTA,其余用纯色
```

### 特殊 CTA(流光边框)
```
【流光边框】
- 卡片边框:conic-gradient 渐变沿边框旋转
- 动画:边框流光 3s 循环
- 内部:深色实底
- 场景:AI 输入框 / 重点 CTA
```
