# G4 · 电商场景 Prompt 库

> 电商界面的每一个像素都和转化率挂钩。这里的"设计好"有可量化的标准。
> 本文件给出电商全流程各页面的完整 prompt + 转化率相关的关键细节。

## 一、商品列表 / 分类页

```
【页面】商品列表（分类/搜索结果）

【布局】
- 桌面：筛选侧栏（240px）+ 商品网格（auto-fit minmax(260px, 1fr)）
- 移动：顶部筛选按钮（打开 bottom sheet）+ 2 列网格
- 排序：右上下拉（推荐/价格升降/销量/新品/评分）

【商品卡片】
┌─────────────────┐
│  [商品图]         │  ← aspect-ratio 1:1 或 3:4
│  ♡（右上收藏）    │
│  [标签: 新品/折扣] │  ← 左上角
├─────────────────┤
│ 品牌名（小灰）     │
│ 商品名（2行截断）  │
│ ¥299  ~~¥399~~   │  ← 现价大+品牌色，原价小+删除线
│ ★4.8 (128)       │
│ [加入购物车]（hover出现）│
└─────────────────┘

【卡片细节（影响转化）】
- 图片 hover：切换到第二张图（或 scale 1.04）
- 价格：现价字号最大、最醒目；折扣率标注（"-25%"）
- 库存紧张：显示"仅剩 3 件"（稀缺性）
- 快速预览：hover 显示"快速查看"按钮（打开 Modal 不离开列表）
- 加购动效：按钮变勾 + 购物车图标数字 +1 弹跳

【筛选器】
- 分类（树形/复选）、价格区间（双滑块）、品牌（搜索+复选）、
  评分（星级）、属性（颜色色块/尺码）
- 已选筛选显示为可删除 chip（"价格: ¥100-300 ×"）
- 每个选项显示商品数（"红色 (24)"）
- 移动端：bottom sheet，底部固定"查看 128 件商品"按钮

【状态】
- 加载：商品卡骨架屏（保持网格结构）
- 空结果："没有找到匹配商品" + 清除筛选 + 推荐商品
- 加载更多：按钮 或 无限滚动（保持滚动位置）

【性能】
- 图片 srcset + lazy（首屏 4-6 张 eager）
- 网格用 content-visibility: auto
```

## 二、商品详情页（PDP）

```
【页面】商品详情（转化关键页）

【布局（桌面）】
┌──────────────┬──────────────┐
│              │ 品牌            │
│  图集         │ 商品名           │
│  （主图+缩略）  │ ★4.8 (128评价)  │
│              │ ¥299 ~~¥399~~   │
│              │ ─────────       │
│              │ 颜色: ● ● ●      │
│              │ 尺码: S M L XL   │
│              │ 数量: [- 1 +]    │
│              │ [加入购物车]      │
│              │ [立即购买]        │
│              │ ✓ 免运费 ✓ 7天退  │
└──────────────┴──────────────┘
  ↓
详情描述 / 规格参数 / 评价 / 推荐

【图集】
- 主图 + 左侧或下方缩略图
- 点击放大（lightbox）+ 滚轮/双指缩放
- hover 局部放大镜（桌面）
- 移动端：横向 swipe + 页码指示（1/6）
- 支持视频/360° 展示

【价格区（最关键）】
- 现价：最大字号（32-40px）+ 品牌色或红色
- 原价：小 + 灰 + 删除线
- 折扣：badge "省 ¥100" 或 "-25%"
- 分期："或 ¥100 × 3 期免息"
- 会员价：单独标注

【规格选择】
- 颜色：色块（选中有边框 + 勾）+ 名称显示
- 尺码：方块按钮，缺货款划线+禁用（不是隐藏）
- 选择后主图切换到对应颜色
- 未选必选项时点加购：高亮提示未选项（不是 alert）
- 尺码表链接（打开 Modal）

【CTA 区】
- 主按钮"加入购物车"：全宽/大，品牌色
- 次按钮"立即购买"：outline 或次色
- Sticky：滚动到详情区时，顶部或底部出现 sticky 购买条
  （缩略图 + 商品名 + 价格 + [加购]）
- 加购成功：不跳转，显示 Toast/侧滑购物车预览

【信任信号（提升转化）】
- ✓ 免运费 / ✓ 7 天无理由 / ✓ 正品保证 / ✓ 顺丰发货
- 库存："仅剩 3 件"（稀缺）
- 社会证明："238 人正在浏览" / "本周售出 1.2k"
- 支付方式图标（支付宝/微信/银联/Apple Pay）

【评价区】
- 总分 + 星级分布柱状图
- 筛选：有图/最新/好评/差评
- 单条：头像 + 昵称 + 星级 + 日期 + 规格（"颜色:黑 尺码:L"）+ 内容 + 图片
- 有用投票（"12 人觉得有用"）
- 商家回复

【推荐】
- "搭配购买"（组合套装 + 优惠）
- "相似商品"
- "看了又看"

【无障碍】
- 图集有 alt 描述
- 颜色选择不只靠色块（有名称）
- 星级有文字（"4.8 分，共 128 条评价"）
```

## 三、购物车

```
【页面】购物车

【布局】
┌────────────────────┬──────────┐
│ □ 全选              │ 订单摘要   │
│ ┌────────────────┐ │ 商品 ¥598 │
│ │□ [图] 商品名     │ │ 运费 ¥0   │
│ │  规格: 黑/L      │ │ 优惠 -¥50 │
│ │  ¥299 [- 2 +] 🗑 │ │ ─────    │
│ └────────────────┘ │ 合计 ¥548 │
│ [更多商品...]        │ [去结算]   │
└────────────────────┴──────────┘

【商品行】
- 复选框（选择结算）
- 缩略图（80px，点击进详情）
- 商品名 + 规格（可点击修改规格）
- 单价 + 数量步进器 + 小计
- 删除（垃圾桶）+ 移入收藏
- 库存不足/失效：置灰 + 标注 + "找相似"

【数量修改】
- 步进器 [- n +]，可直接输入
- 修改后价格实时更新（数字动画）
- 减到 0：询问是否删除
- 超库存：提示"库存仅 3 件"

【摘要区（sticky）】
- 商品总额、运费、优惠、税费、合计
- 合计最大最醒目
- 优惠券输入框 + "使用优惠券"
- 满减进度："再买 ¥52 免运费"（进度条）← 提升客单价
- [去结算] 大按钮，显示已选数量

【空购物车】
- 插画 + "购物车还是空的"
- [去逛逛] + 推荐商品/最近浏览

【删除保护】
- 删除后 Toast 带"撤销"（5 秒）
- 批量删除二次确认

【移动端】
- 商品行左滑显示删除/收藏
- 底部固定：合计 + [去结算]（含 safe-area）
```

## 四、结算 / 支付

```
【页面】结算（转化漏斗最后一步，任何摩擦都是流失）

【核心原则】
- 步骤越少越好（1 页最佳，最多 3 步）
- 显示进度（"步骤 2/3"）
- 支持游客结算（不强制注册）
- 全程显示订单摘要（不让用户忘记买什么）

【单页结算布局】
┌────────────────────┬──────────┐
│ 1. 收货地址          │ 订单摘要   │
│   [已保存地址选择]     │ [商品列表] │
│   或 [新增地址]       │ 小计       │
│ ─────────────      │ 运费       │
│ 2. 配送方式          │ 优惠       │
│   ○ 标准 免费 3-5天  │ ────      │
│   ○ 加急 ¥15 次日达  │ 合计       │
│ ─────────────      │           │
│ 3. 支付方式          │ [提交订单] │
│   ○ 支付宝           │           │
│   ○ 微信支付         │           │
│   ○ 信用卡           │           │
│ [提交订单]            │           │
└────────────────────┴──────────┘

【地址表单】
- 自动填充（autocomplete="shipping street-address" 等）
- 省市区三级联动（或地址智能识别粘贴）
- 手机号 inputmode="tel"
- 邮编 inputmode="numeric"
- 保存为默认地址 checkbox

【支付方式】
- 图标 + 名称，选中有明显标识
- 信用卡：卡号 inputmode="numeric" + autocomplete="cc-number"
  · 卡号自动分组显示（4-4-4-4）
  · 自动识别卡种并显示图标
  · CVV 有帮助提示
- 移动端优先展示 Apple Pay / 微信支付

【减少摩擦的细节】
- 不要求注册（游客结算 + 结算后可选注册）
- 表单字段最少化（不问不必要的信息）
- 实时校验（blur 时，不是提交时才报错）
- 错误定位：滚动到第一个错误字段 + 高亮
- 显示安全标识（SSL 锁图标 + "支付信息加密"）
- 不在结算页放导航/促销（避免分散注意力）

【提交按钮】
- 文案明确："提交订单 · ¥548"（含金额）
- 提交中：禁用 + spinner + "处理中，请勿关闭"
- 防重复提交

【成功页】
- ✓ 大勾号动画 + "下单成功"
- 订单号（可复制）
- 预计送达时间
- [查看订单] [继续购物]
- 可选：邀请注册/关注公众号
```

## 五、促销与营销组件

```
【促销组件库】

【限时倒计时】
- 天:时:分:秒，数字用 tabular-nums 防跳动
- 结束时切换为"活动已结束"
- 不要虚假倒计时（重置骗人）

【优惠券】
- 卡券形态（左侧金额 + 右侧条件，中间齿轮缺口）
- 状态：可用（亮）/ 已用（灰）/ 过期（灰+印章）
- [立即使用] 按钮
- 齿轮缺口 CSS：radial-gradient 或 mask

【满减进度条】
- "再买 ¥52 享免运费" + 进度条
- 达成时：进度条变绿 + ✓ "已享免运费"
- 提升客单价的最有效组件

【秒杀 / 限量】
- 库存进度条（"已售 82%"）
- "仅剩 3 件"红色文字
- 抢购按钮：倒计时结束前禁用（"即将开始"）

【价格标签体系】
- 折扣 badge：右上角三角/圆形，"-25%" 或 "省¥100"
- 新品 badge：左上角
- 会员专享：金色边框
- 预售：蓝色 badge + 发货时间

【推荐位】
- "猜你喜欢"（横向滑动卡片）
- "搭配购买"（组合套装 + 组合价 + 一键加购）
- "最近浏览"（横向）
```

## 六、避免的电商反模式

| ❌ 反模式 | 为什么坏 |
|---|---|
| 强制注册才能结算 | 直接流失 30%+ |
| 隐藏运费到最后一步 | 弃单率飙升 |
| 虚假倒计时（刷新重置） | 失信 + 违法风险 |
| 缺货款隐藏而非划线 | 用户以为没这个尺码 |
| 加购后强制跳转购物车 | 打断继续购物 |
| 结算页放促销/导航 | 分散注意力，降低转化 |
| 提交时才校验表单 | 用户反复挫败 |
| 只用颜色区分选中状态 | 色盲用户无法识别 |
| 价格不明确（税/运费另计但不说） | 信任崩塌 |
| 无删除撤销 | 误删无法恢复 |

## 七、Prompt 模板（快速版）

```
生成一个电商 {商品详情页}，React + Tailwind + shadcn。

【布局】左图集右信息（桌面 50:50），移动端上下堆叠
【图集】主图 + 缩略图，点击 lightbox 放大，移动端 swipe + 页码
【价格】现价 32px 品牌色最醒目 + 原价小灰删除线 + 折扣 badge "-25%"
【规格】颜色用色块（带名称，选中有勾）+ 尺码方块（缺货划线禁用不隐藏）
       选颜色时主图跟着切换
【CTA】"加入购物车"全宽主按钮 + "立即购买"次按钮
       滚动到详情区时出现 sticky 购买条（缩略图+名+价+加购）
       加购成功不跳转，显示侧滑购物车预览 + 图标数字+1弹跳
【信任】✓免运费 ✓7天退 ✓正品保证 + "仅剩3件" + "本周售出1.2k"
【评价】总分+星级分布柱状图 + 筛选（有图/最新/好评差评）+ 单条含规格
【推荐】搭配购买（组合价）+ 相似商品
【状态】图集/价格/评价各自骨架屏；库存不足置灰标注
【无障碍】图有 alt；颜色不只靠色块（有名称）；星级有文字描述
【性能】图片 srcset+lazy（主图 eager + fetchpriority=high），
       aspect-ratio 占位防 CLS
```

## 八、检验清单

- [ ] 价格层级明确（现价最大最醒目）
- [ ] 折扣有 badge 且标注省了多少
- [ ] 缺货规格是划线禁用，不是隐藏
- [ ] 选规格后主图跟着切换
- [ ] 有 sticky 购买条（长页面）
- [ ] 加购不跳转，有明确反馈（Toast/侧滑车）
- [ ] 有信任信号（免运费/退货/正品/支付图标）
- [ ] 有稀缺/社会证明（仅剩 N 件 / 售出 N 件）
- [ ] 评价有星级分布 + 筛选 + 规格标注
- [ ] 购物车有满减进度条
- [ ] 删除有撤销
- [ ] 结算支持游客（不强制注册）
- [ ] 运费在早期就明示（不藏到最后）
- [ ] 表单 autocomplete + inputmode 正确
- [ ] 表单 blur 时校验，不是提交时
- [ ] 结算页无促销/导航干扰
- [ ] 提交按钮含金额（"提交订单 · ¥548"）
- [ ] 防重复提交
- [ ] 空购物车有引导 + 推荐
- [ ] 所有状态覆盖（加载骨架/空/错误/缺货）
- [ ] 颜色不是唯一信息载体
