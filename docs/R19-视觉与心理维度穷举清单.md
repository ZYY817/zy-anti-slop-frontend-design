# R19 · 视觉与心理维度穷举清单（覆盖度检查表）

> **本文是"覆盖度检查表"，不是技法库。** 它只回答一个问题：**动手做之前，有哪些维度不能漏。**
> **与 B/V/R 板块的分工**：目标库已有 B 板块（85 篇视觉专题）讲"怎么做视觉"、V 板块（14 篇特效）讲"具体效果怎么实现"、`R0`–`R18`（可粘贴提示词库）给"能直接用的视觉词条"、`R20`（AI 前端视觉总纲）给方法论总纲、`R21`（视觉风格与技法目录）给风格与招式目录。本文**不复制任何技法实现细节**，只保留"可勾选的维度条目名 + 指向已有文档的引用"。只有别处没有的**维度枚举**（元维度、情绪轮、冷门跨界、概念视角、决策树）才在此展开。
> **使用纪律（重要）**：这是一份 600+ 条的穷举清单，**不要全做**。选 **20–30 个核心维度**深挖，其中至少 **3–5 个签名维度**（"只有你会想"的细节），再加 1–2 个**反 AI 味维度**（刻意打破默认）和 1 个**冷门维度**。全做等于平均化，等于 AI 味。
> **来源说明**：本文由三份外部维度清单三合一去重融合而成（`99-穷举式维度清单` / `世界级前端视觉作品·讨论维度清单 v0.2` / `终极版完整维度清单 v3.0`），条目与术语来自这三份原始整理，未新增未经验证的数据。姊妹篇 `R22`（工程·风险·商业维度补白）承接了性能 / 边缘情况 / 风险合规 / 商业营销 / 团队协作这五块，本文不再展开。

## 0. 本文定位与用法

### 0.1 这是什么 / 不是什么

- **是**：一张"开工前的维度盘点表"。逐项扫一遍，勾出这次项目要认真做的维度，避免"该想到的没想到"。
- **是**：`B15`（惊艳视觉全维度考虑清单）的**扩展深化版**——`B15` 是主文档，本文把维度枚举做到更细，并补齐了 `B15` 没有的情绪轮、概念视角、冷门跨界。
- **不是**：技法教程。任何一条维度"怎么实现"都在 B/V/R 板块，本文只给条目名 + 引用。
- **不是**：验收门槛。勾多少、深挖哪几个，**取舍由项目自行决定**；只有无障碍与闪烁安全属于安全项，不建议省（见 `C4`/`C7`/`B43`）。

### 0.2 推荐用法路径

1. **先读** `00-总索引.md`，确定这次要检索的板块。
2. 用**本文（R19）**做维度盘点：过一遍第 1–8 章，勾出 20–30 个核心维度 + 3–5 个签名维度。
3. 进 **`Z2`**（Prompt 检索与组合编排），按检索协议选 5–12 个相关专题文档，**不要把所有维度塞进一个 prompt**。
4. 需要可直接粘贴的视觉提示词时进 **`R0`**，按 L0–L5 分层挑 `R1`–`R18` 的条目组合。
5. 用本文第 9 章"决策入口"走一遍决策树，锁定风格 / 配色 / 字体 / 动效密度 / 3D 与否。
6. 生成后按 **`Z3`** 五轮审计（视觉 / UX / 内容 / 工程 / 原创性）闭环，P0/P1 实际修复。

### 0.3 三条使用铁律

1. **不要全做** —— 600+ 条是"备选池"，不是"待办清单"。全做 = 平均化 = AI 味。
2. **要有签名维度** —— 至少 3–5 个"只有你会想到"的维度，这是拉开差距的护城河。
3. **要有反 AI 维度** —— 至少 1–2 个刻意"打破默认值"的维度；反 AI 味清单见 `B82` + `B44`，**当参考清单看，不是硬性铁律，按项目自行取舍**。

> 作品集与个人展示类页面尤其要做"签名维度"和"反 AI 维度"——第一眼的记忆点往往就来自这里。

## 8. 概念性设计视角 44 条（本文重点 · 全保留）

> 来源：终极版「32 主动思考补遗」，44 条**一条不删**。
> **为什么不与 R 板块重复**：`R0`–`R18` 收的是"视觉词条"（能直接粘进 prompt 的画面描述），这 44 条是"**概念策略**"——它们决定作品的立意与姿态，不描述画面。适合在概念锁定阶段挑 1–3 条当作品的"主张"。

| # | 视角 | 一句话要点 |
|---|---|---|
| 1 | 反向设计 Inverse | 不问"用户能做什么"，问"用户不能做什么"；限制本身即设计 |
| 2 | 退化设计 Degenerate | 不是让东西更好，而是故意变差：故意慢 / 糊 / 错位 |
| 3 | 沉默设计 Silence | 用空白 / 静止 / 静音表达，不是没设计，是减到极致 |
| 4 | 噪音设计 Noise | 故意引入视觉 / 听觉噪音，但要有节奏，不是乱 |
| 5 | 拼贴设计 Collage | 多风格 / 时代 / 媒介叠加，不追求统一而追求"对话" |
| 6 | 致敬设计 Homage | 明显致敬某位艺术家 / 作品，让懂的人会心一笑 |
| 7 | 仪式感设计 Ritual | 进入 / 切换 / 离开都有仪式，不只是动效，是"过程" |
| 8 | 矛盾设计 Contradiction | 故意相反的元素：严肃 + 戏谑 / 极简 + 满铺 / 静 + 动 |
| 9 | 自我指涉 Self-referential | 页面在说自己；错误页是宇宙；加载是作品；形式即内容 |
| 10 | 时间尺度 Time Scale | 毫秒到世纪的尺度对比，让用户感受时间 |
| 11 | 空间尺度 Space Scale | 原子到宇宙的尺度对比，微距 / 巨视 |
| 12 | 触觉转译 Tactile Translation | 用视觉传达重量 / 温度 / 硬度，不只是看，是"摸到" |
| 13 | 文化密码 Cultural Code | 只有特定文化能读懂的符号，是反 AI 味的"暗号" |
| 14 | 个人历史 Personal History | 把自己的人生节点融入视觉，最有"人味" |
| 15 | 第二层含义 Double-layer | 表面 + 深层双层，深入后才发现隐藏层 |
| 16 | 慢设计 Slow | 故意慢节奏，让用户停下来，与即时满足对抗 |
| 17 | 不规则设计 Asymmetric | 不是对称的优雅，是不对称的张力 |
| 18 | 不完整设计 Incomplete | 故意留"未完成"，让用户参与想象 |
| 19 | 倒退设计 Retrogressive | 故意用旧技术：像 90s 网站 / 像 2000s flash |
| 20 | 透明设计 Transparent | 让一切可见：加载过程可见、思考过程可见，反"魔术"的诚实 |
| 21 | 对话设计 Dialogue | 页面与用户对话，不是单向展示 |
| 22 | 故事设计 Story | 整个作品是一个故事，有起承转合，不是"陈列" |
| 23 | 角色设计 Character | 给作品一个"角色"，第一人称叙事，让它有人格 |
| 24 | 节奏设计 Rhythm | 整个作品是"一首曲子"，有快慢停爆，不是平均分布 |
| 25 | 温度设计 Temperature | 视觉传达冷 / 暖（配色 + 动效 + 字体） |
| 26 | 重量设计 Weight | 视觉传达重 / 轻（字重 + 动效速度 + 留白） |
| 27 | 距离设计 Distance | 视觉传达远 / 近（模糊 / 缩放 / 透明度） |
| 28 | 速度设计 Speed | 视觉传达快 / 慢（时长 + 节奏 + 缓动），个人签名缓动 |
| 29 | 矛盾空间 Impossible Space | 埃舍尔式不可能图形 / 莫比乌斯环 / 彭罗斯三角 |
| 30 | 时间错乱 Time Distortion | 慢动作 / 快进 / 倒放 / 时间切片 / 多时间线 |
| 31 | 元数据可见 Metadata Visible | 开发者工具里能看到注释，在源码里写诗 |
| 32 | 屏幕外的设计 Beyond Screen | 想象屏幕外还有东西，滚动条暗示"无限" |
| 33 | 边缘设计 Edge | 边框 / 角落 / 隐藏细节，鼠标移到边缘有惊喜 |
| 34 | 历史感 Historical feel | 让作品有年代感：颗粒 / 噪点 / 失真，像老电影 |
| 35 | 未来感 Futuristic feel | 全息 / 透明 / 漂浮，像科幻电影 |
| 36 | 自然感 Natural feel | 有机 / 流动 / 不规则，像植物 / 像水 / 像风 |
| 37 | 工业感 Industrial feel | 钢铁 / 机械 / 齿轮，像工厂 / 像钟表 |
| 38 | 原始感 Primitive feel | 黏土 / 石器 / 洞穴壁画，像远古 |
| 39 | 数字感 Digital feel | 像素 / 网格 / 二进制，像屏幕 / 像代码 |
| 40 | 模拟感 Analog feel | 胶片 / 磁带 / 印刷，反数字的温暖 |
| 41 | 视觉音乐 Visual Music | 让作品"听得到"，视觉与音乐同构，像 VJ / 像 MV |
| 42 | 嗅觉视觉 Olfactory Visual | 让作品"闻得到"：食物 / 花香 / 烟 |
| 43 | 味觉视觉 Gustatory Visual | 让作品"尝得到"：甜 / 苦 / 酸 / 辣 |
| 44 | 触觉视觉 Tactile Visual | 让作品"摸得到"：软 / 硬 / 粗糙 / 光滑 |

> **用法**：44 条不是清单式勾选，而是**选题式取用**。挑 1–3 条作为作品主张写进概念文档，再回到第 2–7 章找对应的视觉维度落地。质感落地 → `B24`/`B64`；视觉修辞 → `B7`；从参考到原创 → `B85`。

### 9.2 视觉决策树（动手前的最后一步，来源 终极版 23.2）

5. **动效密度**：每个交互都有反馈，还是只在关键节点？（→ `B5`/`B71`）

### 9.3 风格决策辅助四问（来源 终极版 23.3）

1. 你想让人**惊叹**还是**平静**？
2. 你想让人**想起未来**还是**回到过去**？
3. 你想让人**感到人类**还是**感到超人类**？
4. 你想让人**看懂**还是**看不懂但震撼**？

### 9.4 字体选择决策树（来源 终极版 05.4）

1. **中文为主 vs 英文为主** → 中文优先时先定中文字体
2. **正式 vs 创意** → 正式选宋体 / 衬线，创意选几何 / 装饰
3. **技术感 vs 人文感** → 技术选等宽，人文选衬线
4. **小字 vs 大字** → 小字选人文无衬线，大字选装饰 / 衬线
5. **现代 vs 复古** → 现代选几何，复古选衬线 / 装饰
