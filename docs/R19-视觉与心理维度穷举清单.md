# R19 · 签名维度与概念层

> **本文管"只有你会想到的那一层"。** B86/B87 给骨架和皮的常规词，本文给你拉开差距的**签名维度**：情绪轮、状态对立、多感官、冷门跨界（化学/天文/神话/音乐）、真实感痕迹、35 条概念视角。
> **分工**：常规维度词 → `B86`/`B87`；预算与量 → `K18`；可粘贴词条 → `R0`→`R1`–`R18`；招式目录 → `R21`；工程商业维度 → `R22`。本文只管别处没有的枚举。
> **三条铁律**：① 不要全做——这是备选池不是待办清单，全做=平均化=AI 味；② 要有签名维度——挑 3–5 个"只有你会想到"的；③ 要有反 AI 维度——1–2 个刻意打破默认值（禁槽清单 → `B82`，排雷 → `B44`）。
> **用法**：概念锁定阶段从第 2–6 章挑签名维度 + 第 7 章挑 1–3 条概念视角，写进 Z1 方向卡，再回 B86 找落地参数。

## 一、情绪轮（四族，挑 1–3 个目标情绪）

> 比笼统说"做得高级"精确得多。情绪的参数化落地 → `B61` 视觉情绪工程、`B47` 情感设计；温度词梯 → `B86§八`。

| 族 | 情绪 | 典型界面用法 |
|---|---|---|
| 正向激活 | 喜悦 / 兴奋 / 渴望 / 成就感 / 骄傲 | 消费、创作、游戏化场景 |
| 正向平静 | 平静 / 放松 / 满足 / 安全感 / 归属感 / 自由感 | 阅读、冥想、金融、医疗 |
| 负向（慎用） | 愤怒 / 悲伤 / 恐惧 / 紧张 / 羞耻 | 公益警示、叙事张力；产品界面只做"共情承接"不做唤起 |
| 元情绪 | 共情 / 控制感 / 价值感 / 存在感 | 品牌人格与社区产品的情绪结构 |

> ⚠️ 负向族是设计"承接负面情绪的容器"（错误态、卸载页的文案与温度），不是让用户难受。

## 二、状态对立（签名维度高产区）

刻意选"右列"一侧，往往就是反 AI 味的来源：

`一致↔矛盾` `和谐↔冲突` `平衡↔失衡` `完整↔碎片` `完美↔不完美`

## 三、多感官选项

- **声音**：开启音 / 悬停反馈 / 章节切换音 / 加载完成音 / 滚动环境音 / 频率段分工 / 节拍同步动效
- **触觉**：移动端震动 / 触屏物理反馈 / 桌面端视觉代震
- **味觉化排印**：字体作味道隐喻（粗黑=黑咖啡 / 细衬线=清茶 / 手写=甜点 / 装饰字=香槟）
- 落地 → `B36`/`R16`（声音）、`B24`（联觉）

## 四、冷门跨界池（稀有维度，按产品挑）

- **数学之美**：分形/拓扑/贝塞尔/概率/傅里叶/洛伦兹吸引子/元胞自动机；驱动视觉：流场/反应扩散/粒子/Boids —— 实现 → `R8`
- **化学/分子**：分子三维结构 / 元素周期表视觉化 / 化学反应动画 / 晶体 / 球棍模型
- **天文/宇宙**：星图 / 星系 / 黑洞光线弯曲 / 星云 / 引力波可视化 —— 3D → `R13`
- **神话/符号系统**：炼金术符号 / 塔罗 / 占星 / 卡巴拉 / 符文 / 神圣几何 / 曼荼罗；配 Gothic Academia / Esoteric 美学 —— 符号落地 → `B41`
- **生成式设计**（本库此前的空白区）：**生命模拟**（康威生命游戏/元胞自动机）、**生长系统**（L-system 分形树/珊瑚/根系蔓延）、**物理模拟**（流体/布料/弹簧群）、**算法构图**（打包算法/沃罗诺伊/递归分割）—— 实现 → `R8`/`V` 板块
- **梦境/潜意识**：不可能图形（埃舍尔）/ 失重漂浮 / 时间错乱 / 镜像倒影 / 拼贴重组 / 巨大化缩小化；Jung 12 原型 → 已迁 `B86§七`（人格原型速选）
- **历史流派/跨文化**：已迁 `B86§十二` 年代文化锚（包豪斯/侘寂/Art Deco/民国美术字等 14 锚）

## 五、音乐→气质映射（选调性用）

`Lo-fi`(慢/温暖/咖啡馆) · `Ambient`(环境/无旋律) · `Glitch`(故障/碎片) · `IDM`(智能舞曲) · `Classical`(古典) · `Synthwave`(80s 合成器) · `Vaporwave`(紫粉复古) · `Post-rock`(缓慢爆发) · `黑金属`(极端压迫) · `爵士`(自由即兴)

> 用法：给作品选个"配乐流派"当气质锚——Synthwave 配色 + Post-rock 节奏是两个可执行决策。听觉落地 → `B36`/`R16`。

## 六、真实感痕迹（签名维度另一高产区）

- **口味**：个人怪癖 / 年代偏好 / 个人哲学 / 个人节奏（极慢 vs 极快）
- **痕迹**：不完美的留白 / 刻意卡顿 / 故意慢一点的滚动 / 非整数字号 / 像素级瑕疵 / 偶发可控小故障 / 个人化符号
- **元层**：页面自指 / 错误即艺术 / 加载即作品 / 空白即主角 / 源码注释写诗 —— 技法 → `R17`

## 七、概念性设计视角 35 条（本文重点）

> 不是清单式勾选，是**选题式取用**——挑 1–3 条当作品的"主张"写进概念卡。这些决定立意与姿态，不描述画面。

| # | 视角 | 一句话要点 |
|---|---|---|
| 1 | 反向设计 | 问"用户不能做什么"，限制本身即设计 |
| 2 | 退化设计 | 故意变差：慢/糊/错位 |
| 3 | 沉默设计 | 空白/静止/静音，减到极致 |
| 4 | 噪音设计 | 故意引入噪音，但要有节奏 |
| 5 | 拼贴设计 | 多风格/时代/媒介叠加，追求"对话"非统一 |
| 6 | 致敬设计 | 明显致敬某艺术家，懂的人会心一笑 |
| 7 | 仪式感设计 | 进入/切换/离开都有仪式，是"过程" |
| 8 | 矛盾设计 | 严肃+戏谑 / 极简+满铺 / 静+动 |
| 9 | 自我指涉 | 页面在说自己；形式即内容 |
| 10 | 时间尺度 | 毫秒到世纪的尺度对比 |
| 11 | 空间尺度 | 原子到宇宙的尺度对比 |
| 12 | 触觉转译 | 用视觉传达重量/温度/硬度 → 参数在 `B24` |
| 13 | 文化密码 | 只有特定文化读懂的符号=反 AI 暗号 |
| 14 | 个人历史 | 人生节点融入视觉，最有"人味" |
| 15 | 第二层含义 | 表面+深层，深入才发现隐藏层 |
| 16 | 慢设计 | 与即时满足对抗 |
| 17 | 不规则设计 | 不对称的张力 |
| 18 | 不完整设计 | 留"未完成"，让用户参与想象 |
| 19 | 倒退设计 | 故意用旧技术：90s 网站 / 2000s flash |
| 20 | 透明设计 | 加载过程可见、思考过程可见，诚实反"魔术" |
| 21 | 对话设计 | 页面与用户对话，非单向展示 |
| 22 | 故事设计 | 整个作品是一个故事，有起承转合 |
| 23 | 角色设计 | 作品第一人称叙事，有人格 → 原型在 `B86§七` |
| 24 | 节奏设计 | 作品是一首曲子，有快慢停爆 → `B23` |
| 25 | 温度设计 | 冷/暖（配色+动效+字体）→ `B86§八` |
| 26 | 重量设计 | 重/轻（字重+动效速度+留白） |
| 27 | 距离设计 | 远/近（模糊/缩放/透明度） |
| 28 | 速度设计 | 快/慢（时长+节奏+缓动），个人签名缓动 |
| 29 | 矛盾空间 | 埃舍尔/莫比乌斯/彭罗斯三角 |
| 30 | 时间错乱 | 慢动作/快进/倒放/时间切片/多时间线 |
| 31 | 元数据可见 | 源码里写诗，devtools 可见 |
| 32 | 屏幕外的设计 | 滚动条暗示"无限" → `B86` 出血分级 |
| 33 | 边缘设计 | 边框/角落藏细节，移到边缘有惊喜 |
| 34 | 时代质感族 | 历史感(颗粒)·未来感(全息)·自然感(有机)·工业感(钢铁)·原始感(黏土)·数字感(像素)·模拟感(胶片)。**选一个时代锚，不混** → `B86§十二` |
| 35 | 通感视觉族 | 听得到/闻得到/尝得到/摸得到 → 联觉参数在 `B24` |
