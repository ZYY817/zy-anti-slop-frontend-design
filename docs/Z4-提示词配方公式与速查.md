# Z4 · 提示词配方公式（一页速查·人用入口）

> **这是全库给人用的入口**：不用读 194 篇文档——按公式填槽，每槽的词单就在下面。填完就是一份能打的好 prompt。
> AI 编码助手请走 AGENTS.md（那是给 AI 的检索协议）；本文档面向手写 prompt / 想拿参考 / 找灵感的人。
> 词想深挖再回源文档：骨→B87，皮→B86+B16，量→K18，禁→B82，效果→R20/R21。

---

## 〇、一句话公式

```text
好提示词 = 【骨】说什么、按什么顺序、拿什么证明
         +【皮】什么气质、什么色、什么字、什么节奏、什么动法
         +【量】每种手法给多少
         +【禁】不许长成什么样
```

四个槽缺一个都会塌：没骨=皮对骨输（W1 实证）；没皮=正确但冷（V1 实证）；没量=笃定但满（V1b 实证）；没禁=AI 默认脸。

## 一、最小配方（5 分钟填完，覆盖 90% 任务）

```markdown
【项目】{什么页面 / 给谁}
【骨】页面类型{论证/货架/工具/舞台}；区块岗{hero=勾住+定向，2=证明，3=深化，尾=收口}；
     首屏证据件{放什么实证}；主 CTA{一个}
【皮】气质{三词}；色板{取自×××}；字{标题__+正文__+数据mono}；
     密度{基准档→唯一呼吸峰→收紧}；母题{一个重复 3-5 次的形状}
【禁】不用 Inter/紫蓝渐变/三圆角卡/均匀中密/01-02-03编号/emoji图标
```

## 二、完整配方（视觉重活 / 重要项目）

= 结构卡 6 项 + 方向卡 7 项 + 配额 + 反面清单 + 验证句。
结构卡六项（词在骨槽）：页面类型 / 叙事结构 / 区块逐块报岗 / 首屏四问+证据件 / show-tell 配比 / 承诺阶梯。
方向卡七项（词在皮槽）：气质三词 / 案名+判词 / 来源色板+剂量 / 字岗 / 密度节奏+呼吸峰 / 母题 / 动效性格 / （可选）人性词 0-2 个。

## 三、全词速查（按槽取词——全库决策词一览）

### 骨槽 · 结构与内容（源 B87）

| 槽 | 词单 |
|---|---|
| 页面类型 | **论证页**（说服一主张）/ 货架页（陈列自选）/ 工具页（即用）/ 舞台页（表演）/ 信函页（一对一） |
| 叙事结构 | **论证链**：勾住→定向→证明→深化→排疑→收口｜PAS 痛→放大→解｜BAB 前后对照｜提问链｜五幕｜特性轮转（最弱，仅货架） |
| 区块岗 | 勾住 / 定向 / 证明 / 深化 / 排疑 / 收口 / 信任 / **换气**（岗也可以是"什么都不说"）——报不出岗的块删掉 |
| 首屏 | 四问：是什么/给谁/为什么在意/下一步（答≥3）｜主张句（可测）优于氛围句（要托底）｜**首屏放实证**——大而真的产品窗口当证据，不当装饰 |
| 证据件 | 产品实证★★★ / 真实内容样张★★★ / 演示件★★ / 数字证据★★ / 引语社证★——每个主张配一件，连续两个 tell 屏=说教 |
| 图文关系 | 复述（弱）/ 延伸 / **证据**（强，论证页默认）/ 装饰（限量） |
| 主张排序 | 单主张屏 / 主主张唯一 / 渐进披露（先结论后机制）/ **降级法**（次级主张低一级非小字号；从属五手段：变小/变灰/变透明/退后/去阴影）/ 跳读论证（只看标题+首行能复述全页） |
| CTA | 承诺阶梯：看演示→试用→下载→付费，低承诺先行｜主 CTA 唯一｜终屏回扣首屏主张｜留次级出口｜文案写"得到什么"不写"做什么" |
| 构件岗 | （B87§十一）页面密度型（长卷/snap/混合）｜列表岗（排比/主从/瀑布/台账）｜导航岗（定向/捷径/进度）｜页脚岗（收口候补+信任清单+次级出口）｜空态岗（换气+引导第一动作）｜加载岗（骨架=定向维持）｜移动端重组岗（岗不变形态重排） |

|---|---|

| 材质光 | 材质（B86§十）：哑光纸/铜版纸/牛皮纸/描图纸/拉丝金属/混凝土/胶片颗粒——毛玻璃是AI味高发慎用；光：光位全页同一光源/影的色温非纯黑/辉光仅峰值一处 |
| 形状母题 | 角（直角工程/小圆角友好/切角机能）+线（发丝精密/粗描海报/虚线图纸）+母题（B86§十一）：印章/邮戳/方钉/刻度线/缝线/折角/照亮的一块——按产品域选，重复3-5次带变奏 |

### 量槽 · 配额（源 K18）

```
装饰手法 ≤2 种 ｜ 强调色 ≤5 处 ｜ 签名峰值 1 个（母题才可重复 3-5 次且带变奏）
连续动效 1 处 ｜ 每色/每元素一岗 ｜ 密度档至少两档对比，禁全域同档
```

### 禁槽 · 反面清单（源 B82，AI 默认指纹点名）

```
字体: Inter/Roboto/系统默认
配色: 紫蓝渐变+白底 / 渐变点缀 hero
布局: 三张圆角卡片 / 居中 hero 三件套 / 均匀中密铺满全页
装饰: 01/02/03 编号 / 大数字+小标签统计带 / 单词变色标点
图标: emoji 当功能图标
文案: "暂无数据"式占位 / lorem ipsum / "重新定义××"氛围句无托底
组合指纹 → B44§十"廉价感致命组合"（单条无错组合必廉价）
```

## 四、实证过的配方（抄了改直接用）

### 例 1 · 落地页「深夜书房 NIGHT DESK」（case05·W2，盲审 79 分胜裸跑 15 分）

```text
【骨】论证页；论证链六岗：hero=勾住+定向+证明(大编辑器实证窗,图注"不是插画")
     ※该配方早于气质轴法——气质三词今按轴法报轴名
     →特性×3=证明(0.8s启动时间线/截稿搜索3命中18ms/反链图谱)
     →引语=信任→5问FAQ=排疑→收口回扣"稿纸还亮着"；每主张配show，tell-only=0
【皮】气质:深夜/专注/被款待；色板:墨夜#16120D+钨丝灯#D9A24B(动作专色≤5处)+稿纸#F2EDDF；
     字岗:宋体display/sans正文/mono数据；母题"被照亮的一块"重复3次带变奏；
     动效双轨:productive 150ms,expressive仅hero点灯1.4s,签名缓动一条
【禁】紫蓝渐变/居中三件套/均匀中密/死链href="#"
```

### 例 2 · 通知面板「午夜海×灯塔光」（case04·V1c，盲审 79.5 胜 65.5）

```text
【骨】工具页；面板内岗位:未读分组=定向/条目=证明/空态=换气/底栏=收口
【皮】气质:安静/精确/有秩序「海港值守日志」；色岗:海军墨=信息层/琥珀=信号层(专司未读@提及)
     方钉=形状母题；"海平线"装饰仅1种；L3→L1.5呼吸峰(值守摘要)→L4
【禁】均匀中密=第一禁忌；toast只给@提及/指派；6s撤销窗
```

### 例 3 · 对照教训「案上墨」（case05·W1，皮 80 分但骨输用户终审）

```text
皮全对(案名/色板/字岗/母题/双轨全落地)，但：hero 把产品窗口缩成斜放装饰件(该当证据)，
特性区"只做三件事"是 tell-only 轮转 → 用户判输给裸跑。教训:先填骨槽再填皮槽。
```

## 五、万能选择程序（输入上下文 → 输出配方，AI 可自行执行）

```text
① 定类   读任务 → 页面类型(论证/货架/工具/舞台/信函) + 行业 + 品牌已有约束
② 答骨   结构卡六项照 B87 填：叙事结构→区块逐块报岗→首屏证据件→show-tell配比→承诺阶梯
③ 定气质 轴法：先定 1 根主轴(产品最想要的性格)取端 → 再选 2 根辅轴取端
         → 得气质三词(如"动静轴·安静 + 秩序轴·精确 + 轻重轴·笃定")
④ 取色板 按③的轴+行业从 B86§九 挑 1 板 → 派生色岗(底/信息/动作/信号各是哪个色)
⑤ 选母题 按产品域从 B86§十一 挑 1 个(文档→纸工/数据→刻度/契约→印记/创作→照亮草稿)
⑥ 定材质光 B86§十 挑 1 材质+1 光位 → 影的色温随之定
⑦ 填量禁 K18 配额默认 + 本页特调；反面清单默认+B16 系禁项+本页特禁
⑧ 验证句 产出前自检：区块报得出岗？三词报了轴？色板说了来源？母题有变奏？
```

**行业速配表**（第一步拿不准时的默认锚，G7 详表）：

| 行业/产品 | 主轴建议 | 色板源 | 母题 |
|---|---|---|---|
| 写作/笔记/文档 | 雅俗·书卷 + 新旧·旧 | 印刷纸本 | 缝线/折角/印章 |
| 数据/仪表盘/SaaS | 秩序·精确 + 粗细·精 | 实验室白瓷/终端绿字 | 刻度线/方钉 |
| 金融/契约/B端 | 轻重·笃定 + 雅俗·庙堂 | 黄铜仪器/台账 | 印记/编号牌 |
| 创作工具/设计产品 | 虚实·实 + 动静·静 | 钨丝灯+墨夜/档案袋 | 照亮的一块 |
| 生活方式/消费 | 温度·温 + 素艳·素 | 食物饮/自然 | 折角/圆点 |
| 开发者/极客 | 新旧·新 + 秩序·刻度 | 终端/显像管/VGA | 十字丝/网格点 |

> 程序的价值：**每一步都有词单兜底，不需要凭空发明**——AI 输入"一个给律师的合同审查工具"→ 走一遍：论证页？不对，工具页 → 骨=功能前置 → 主轴轻重·笃定 → 色板取"黄铜仪器+黑刻度" → 母题编号牌 → 材质哑光纸+顶光 → 出配方。
