# B19 · 普通 vs 惊艳逐项对照

> 同一个界面,普通版 vs 惊艳版,到底差在哪?
> 逐项拆解,每项一个"升级动作"。这是最直观的"怎么变好"指南。

---

## 一、字体

| 普通 | 惊艳 | 升级动作 |
|---|---|---|
| 默认 Inter 16px 一种字重 | Inter 16px/600/700 三档 + Display 字体做标题 | 加一个 Display 字体做标题 |
| 标题 24px | 标题 clamp(36px, 6vw, 72px) 巨型 | 放大 2-3 倍,用 clamp 流体 |
| 行高全部 1.5 | 标题 1.1 / 正文 1.6 / 分层 | 标题行高压低 |
| 字距默认 | 大标题 -0.03em / 全大写标签 +0.05em | 大字紧,小字松 |
| text-wrap 不管 | 标题 balance / 正文 pretty | 一行 CSS |
| 字号随手定(15/17/19) | 严格阶梯(14/16/20/24/32/48) | 定一套阶梯不偏离 |
| 一种字体走全站 | 衬线标题 + 无衬线正文 + Mono 数据 | 加字体对比 |
| 中英字体一样 | 中英分别指定最优 | 字体栈先英后中 |

---

## 二、色彩

| 普通 | 惊艳 | 升级动作 |
|---|---|---|
| 蓝色(#0000FF 类的刺眼蓝) | 哑光蓝(#3B82F6 或更灰) | 降饱和 |
| 纯黑背景 #000 | 曜石黑 #0A0A0A | 差 10 级亮度 |
| 纯白文字 #FFF | 柔白 #F5F5F5 | 减少刺眼 |
| 5-8 种颜色 | 1 主色 + 5 阶灰 + 1 强调 | 砍到极少 |
| 冷暖灰混用 | 统一冷或统一暖 | 全检查一遍 |
| 渐变:红到蓝(经过灰) | 渐变:邻近色 + oklch 插值 | 换色+换插值 |
| 无噪点 | 渐变叠 2% grain | 加一层 SVG noise |
| 阴影纯黑 | 阴影带主色调 rgba(主色,0.15) | 阴影变彩色 |

---

## 三、间距

| 普通 | 惊艳 | 升级动作 |
|---|---|---|
| 间距随手写(15/22/37) | 全部 4 的倍数(8/16/24/32/48/64/96) | 建间距系统 |
| section 之间 24px | section 之间 96px(桌面) | 放大 3-4 倍 |
| 组内组间间距相同 | 组内 8px,组间 32px | 接近性原则 |
| 首屏 padding 和别的一样 | 首屏 padding 128-200px | 首屏多呼吸 |
| 卡片间距=卡片内距 | 卡片间 24px > 卡片内 16-20px | 拉开差距 |
| 按钮 padding 正方(12×12) | 横向 2-2.5 倍纵向(12×28) | 调比例 |

---

## 四、布局

| 普通 | 惊艳 | 升级动作 |
|---|---|---|
| 三列卡片等距排 | Bento 非对称网格(大小混排) | 打破等分 |
| 每段一样结构(标题+三卡片) | 密-疏-密-疏节奏变化 | 加节奏起伏 |
| 内容铺满宽 | 正文 max-width 65ch | 限制行宽 |
| 所有元素严格在网格内 | 一处打破网格(图片/标题出血) | 故意破一处 |
| 首屏塞满信息 | 首屏只有一句话+一个CTA | 敢减 |
| 对称居中 | 非对称(左文右图偏移) | 加不对称性 |
| 分隔用直线 | 分隔用留白或形状(波浪/斜切) | 去线,加形 |

---

## 五、光影质感

| 普通 | 惊艳 | 升级动作 |
|---|---|---|
| 一层阴影 `0 4px 8px rgba(0,0,0,0.2)` | 四层递增阴影(每层 rgba 0.04) | 分层 |
| 阴影模糊小(8px)透明度高(0.3) | 模糊大(24px)透明度低(0.08) | 大而淡 |
| 深色下用黑阴影(看不见) | 微光边框 white/8 + 表面提亮 | 换策略 |
| 平面无质感 | 2% 噪点 + 微渐变 + 高光 | 加纹理 |
| 卡片就是白色方块 | 顶部 1px specular 高光 + 渐变底 | 加材质细节 |
| 无深度层次 | 3 层 surface 颜色递亮(深色模式) | 用颜色表达 z 轴 |

---

## 六、动效

| 普通 | 惊艳 | 升级动作 |
|---|---|---|
| 所有元素同时 fade-in | 三层入场(结构→内容→装饰) | 分层编排 |
| translateY(30px) | translateY(8px) | 缩短位移 |
| ease-in-out | cubic-bezier(0.16, 1, 0.3, 1) | 换缓动 |
| 无 stagger | 兄弟元素 stagger 50ms | 加错峰 |
| 滚回去重播动画 | 只触发一次 | 加标记 |
| 背景渐变 5s 循环 | 背景渐变 25s 循环 | 放慢 5 倍 |
| 无退场动画(硬消失) | 退场 fade + 反向位移(250ms) | 加对称退场 |
| 按钮无 hover | hover: 色+位移+阴影三联 200ms | 三联一致 |

---

## 七、图片

| 普通 | 惊艳 | 升级动作 |
|---|---|---|
| 图片各种色调混杂 | 统一调色(同一 LUT/滤镜) | 全部过一遍滤镜 |
| 图片加载白屏 | blur-up:先小模糊图→真图 | LQIP 占位 |
| 图片无 aspect-ratio(CLS 跳动) | 所有图预设 aspect-ratio | 一行 CSS |
| 图片圆角加在 img 上 | 容器加圆角 + overflow hidden | 移到容器 |
| 深色模式图片太亮 | 加半透明深色蒙层 | overlay |
| 图片拉伸 | object-fit: cover | 永远 cover |

---

## 八、悬浮

| 普通 | 惊艳 | 升级动作 |
|---|---|---|
| hover 只变色 | hover: 色 + translateY(-4px) + 阴影加深 | 三联 |
| 没有卡片组策略 | hover 当前卡片聚焦,其余 opacity 0.6 | 加暗化 |
| 链接 hover 加下划线 | 用 ::after scaleX(0→1) 动画 | 动画下划线 |
| 无光标效果 | 深色站加聚光灯径向光(跟随鼠标) | radial-gradient 跟随 |
| 按钮只有 hover 无 active | active: scale(0.96) 50ms | 加按下 |

---

## 九、表单

| 普通 | 惊艳 | 升级动作 |
|---|---|---|
| 标签在输入框上面不动 | 浮动标签(focus 时缩小上浮) | floating label |
| focus 只有蓝框 | 品牌色 2px ring + 2px offset | 自定义 focus |
| 错误:红色文字出现 | 红边框 + shake + 内联提示 | 加 shake |
| 提交按钮文字不变 | 按钮 → spinner → ✓ 三态 | 完整状态流 |
| 错误清空所有已填 | 只标记错误字段,保留其余 | 局部错误 |

---

## 十、背景

| 普通 | 惊艳 | 升级动作 |
|---|---|---|
| 纯白 #FFF 无变化 | 极微渐变(#FAFAFA→#F5F5F5) | 加微渐变 |
| 无背景装饰 | 极淡点阵/网格底纹(opacity 0.3) | 加纹理 |
| 深色底纯黑一片 | 2-3 个 blur 光球(opacity 0.15) | 加光球氛围 |
| 装饰太明显 | 装饰 opacity ≤ 0.2,blur ≥ 60px | 降低+模糊 |

---

## 十一、品牌细节

| 普通 | 惊艳 | 升级动作 |
|---|---|---|
| 默认选中色(蓝) | `::selection` 用品牌色 | 一行 CSS |
| 默认滚动条(粗灰) | 自定义 6px 窄滚动条 | 几行 CSS |
| 404 白屏 | 404 有品牌插图+幽默文案 | 设计一个 |
| footer 只有链接 | footer 与 hero 首尾呼应(用同一元素) | 加呼应 |
| 无 Logo 动画 | 首访 Logo path draw 2s | SVG 动画 |

---

## 十二、性能

| 普通 | 惊艳 | 升级动作 |
|---|---|---|
| 首屏白屏 2-3s | 首屏 SSR 直出 < 1.5s | 改渲染策略 |
| 字体加载闪烁(FOUT) | font-display: swap + preload 关键字体 | 加 preload |
| 图片全部即时加载 | 首屏外 lazy load | loading="lazy" |
| 大图原始尺寸 | WebP + srcset 响应式 | 格式+尺寸优化 |
| scroll 事件频繁触发 | CSS scroll-driven animations | 零 JS |

---

## 十三、无障碍

| 普通 | 惊艳 | 升级动作 |
|---|---|---|
| 去掉 focus outline | focus-visible 自定义样式 | 键盘用户有视觉 |
| 图标按钮无标签 | aria-label 描述 | 加 aria |
| 动画不可关 | prefers-reduced-motion 适配 | 去位移保 fade |
| 对比度勉强(3:1) | 正文 ≥ 4.5:1,大字 ≥ 3:1 | 调色 |

---

## 核心公式

```
惊艳 = 普通 + 50 个"升级动作"全部做完

每个升级动作都很小(一行 CSS / 一个值的调整)
但叠加在一起 = 完全不同的品质感
```

**没有一个大秘密,只有 50 个小纪律。**

---

## 使用方式

做完一个界面后,拿着这份对照表逐项过:
1. 字体 → 哪些还是"普通"列? 升级。
2. 色彩 → 哪些还是"普通"列? 升级。
3. 间距 → 哪些还是"普通"列? 升级。
4. …
5. 过完一遍,界面从"能看"变"精致"。

**或者:做之前就把"惊艳"列的规格写进 prompt,一步到位。**
