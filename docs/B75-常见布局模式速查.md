# B75 · 常见布局模式速查

> B3 讲布局**系统与原理**，V11 讲**风格特效**。
> 本文件是**布局构图库**——按页面类型和组件类型，给出高频、经典、有效的构图模式。
> 每种带 ASCII 示意 + 用途 + Prompt 措辞。让 AI "选一个用"而不是"随便拼"。

## 一、Hero 区（首屏英雄区）

### 1. 居中聚焦（Centered Focus）
```
┌─────────────────────────┐
│                         │
│      大标题（居中）      │
│      副标题（居中）      │
│    [CTA]  [Secondary]   │
│                         │
└─────────────────────────┘
```
- **场景**：品牌站、SaaS 主推、活动页
- **感觉**：郑重、聚焦、单一信息
- **Prompt**："Hero 居中聚焦，大标题占宽 60%，下方 2 个 CTA 水平居中"

### 2. 左文右图（Split Left Text）
```
┌──────────┬──────────┐
│ 大标题   │          │
│ 副标     │  产品图  │
│ [CTA]    │          │
└──────────┴──────────┘
```
- **场景**：SaaS、B2B、产品介绍
- **感觉**：信息清晰、有说服力
- **Prompt**："Hero 左文右图 40:60，标题斜切进入，右图带阴影浮起"

### 3. 全屏沉浸（Full Bleed）
```
┌─────────────────────────┐
│  [背景图/视频铺满]       │
│  暗色蒙层                │
│  大标题（左下/居中）      │
│  [CTA]                   │
│         ↓ 滚动指示       │
└─────────────────────────┘
```
- **场景**：品牌旗舰、创意作品集、活动
- **感觉**：电影感、震撼
- **Prompt**："Hero 全屏 100dvh，视频背景+40% 暗色蒙层，左下大字标题+CTA，底部滚动箭头"

### 4. 分屏对比（Split Diagonal / Duotone）
```
┌────────┐┌────────────┐
│ 深底   ││ 浅底        │
│ 白字   ││ 黑字        │
│ 概念A  ││ 概念B       │
└────────┘└────────────┘
```
- **场景**：对比性产品、二选一叙事
- **感觉**：戏剧化、张力
- **Prompt**："Hero 左右分屏，左深右浅，各占一半，中间无缝或错切"

### 5. 大字宣言（Manifesto / Editorial）
```
┌─────────────────────────┐
│  MASSIVE                │
│  BOLD                   │
│  TYPE.                  │
│  一段小字说明            │
└─────────────────────────┘
```
- **场景**：设计工作室、品牌宣言、代理商
- **感觉**：自信、艺术感
- **Prompt**："Hero 用 clamp(64px, 12vw, 200px) 的巨字标题，多行左对齐，负字距 -0.03em"

### 6. 产品截图前置（Product Shot）
```
┌─────────────────────────┐
│      标题+CTA            │
│  ┌───────────────────┐  │
│  │  产品界面截图       │  │
│  │  （倾斜/悬浮）      │  │
│  └───────────────────┘  │
└─────────────────────────┘
```
- **场景**：SaaS 落地页
- **感觉**：产品透明、可信
- **Prompt**："Hero 标题下大截图，perspective 3D 倾斜 6deg，多层阴影浮起"

### 7. 图标网格铺陈（Icon Grid）
```
┌─────────────────────────┐
│     标题+副标            │
│                         │
│  □ □ □ □ □ □             │
│  □ □ □ □ □ □             │
│  □ □ □ □ □ □             │
└─────────────────────────┘
```
- **场景**：集成平台、目录、Dev Tools
- **感觉**：丰富、可组合
- **Prompt**："Hero 标题下网格铺 30+ 集成 logo，hover 单个高亮其余变暗"

### 8. Bento 首屏（多卡展示）
```
┌───────┬────┬────┐
│       │ B  │ C  │
│   A   ├────┼────┤
│       │ D  │ E  │
└───────┴────┴────┘
```
- **场景**：多功能产品、Feature 宣传
- **感觉**：模块化、丰富
- **Prompt**："Hero 用 Bento 网格 4-5 个卡，1 大 + 4 小，圆角统一 12px"

### 9. 视频播放器居中（Video Center）
```
┌─────────────────────────┐
│     标题+副标            │
│  ┌───────────────────┐  │
│  │  [▶]              │  │
│  │  视频预览          │  │
│  └───────────────────┘  │
└─────────────────────────┘
```
- **场景**：产品演示、教程、发布会
- **Prompt**："Hero 中央 16:9 视频卡片，点击原地展开全屏播放"

### 10. 交互式画布（Interactive Canvas）
```
┌─────────────────────────┐
│  标题                    │
│ ┌────────────────────┐  │
│ │  可拖拽/可点击画布   │  │
│ │  (WebGL/Canvas)     │  │
│ └────────────────────┘  │
└─────────────────────────┘
```
- **场景**：创意工具、图形产品、玩具
- **Prompt**："Hero 中央可交互画布，鼠标移动触发粒子/光效"

### 11. 数据/统计强调（Big Number）
```
┌─────────────────────────┐
│                         │
│      1,247,391          │
│      lines saved        │
│      [CTA]              │
└─────────────────────────┘
```
- **场景**：数据类产品、社会证明
- **Prompt**："Hero 中央巨大数字（滚动计数），下方说明+CTA"

### 12. 双列并排 CTA（Dual Path）
```
┌─────────────────────────┐
│      共同标题            │
│                         │
│  ┌─────┐    ┌─────┐    │
│  │给开发者│    │给设计师│    │
│  │[CTA]│    │[CTA]│    │
│  └─────┘    └─────┘    │
└─────────────────────────┘
```
- **场景**：面向多人群、开发者/管理员双入口
- **Prompt**："Hero 下方两张并排卡片，各自面向一个用户角色，各有 CTA"

## 二、特性区（Features Section）

### 1. 三列图标 + 说明（Classic 3-Col）
```
┌───────┬───────┬───────┐
│  ⚡     │  🔒     │  📊    │
│ 标题   │ 标题   │ 标题   │
│ 描述   │ 描述   │ 描述   │
└───────┴───────┴───────┘
```
- **场景**：SaaS 核心特性、优势展示
- **注意**：不要多于 6 个，最好 3-4 个

### 2. 大图 + 小图交替（Zigzag）
```
┌────────┬──────────┐
│ 图     │ 标题+说明 │
└────────┴──────────┘
┌──────────┬────────┐
│ 标题+说明 │ 图     │
└──────────┴────────┘
```
- **场景**：详细功能介绍
- **感觉**：叙事节奏、不单调
- **Prompt**："特性区 zigzag 布局，图文交替，每对 py-24 间距"

### 3. Bento Grid（大小不等卡片）
```
┌────────┬──────┬──────┐
│        │  B   │  C   │
│   A    ├──────┴──────┤
│  (大)   │      D       │
└────────┴─────────────┘
```
- **场景**：Apple 风、多功能一屏展示
- **Prompt**："特性区 Bento 4 格：1 大 3 小，主特性占 2×2 位置，含插图/动画"

### 4. 竖向 Timeline（Sticky Feature）
```
┌────┬──────────┐
│ 01 │ 标题     │
│    │ 描述     │
├────┼──────────┤
│ 02 │ 标题     │
│    │ 描述     │
├────┼──────────┤
```
- **场景**：流程、教程、逐步展开
- **Prompt**："特性区竖向 timeline，左编号右说明，滚动时右侧图片 sticky 跟随"

### 5. Tab 切换特性（Feature Tabs）
```
┌────────────────────────┐
│ [Tab1] Tab2  Tab3      │
├────────────────────────┤
│                        │
│  当前 Tab 内容（图+文）  │
│                        │
└────────────────────────┘
```
- **场景**：多角色/多场景产品
- **Prompt**："特性区顶部 Tab 切换，内容区带 View Transitions 平滑切换"

### 6. 手风琴（Accordion Features）
```
┌────────────────────────┐
│ ▶ 特性 1               │
├────────────────────────┤
│ ▼ 特性 2（展开）        │
│   描述+图                │
├────────────────────────┤
│ ▶ 特性 3               │
└────────────────────────┘
```
- **场景**：内容多、空间紧
- **Prompt**："特性区手风琴，点击项目展开描述+图，一次仅一项打开"

### 7. 卡片翻转（Flip Cards）
```
[正面: 图标+标题]  hover  [背面: 详细说明]
```
- **场景**：紧凑展示、玩味产品

### 8. 大标题 + 卡片浮动（Sticky Title）
```
┌─────────┬───────────┐
│ 大标题   │ 卡片 1     │
│ (sticky) │ 卡片 2     │
│         │ 卡片 3     │
└─────────┴───────────┘
```
- **场景**：一个主题下多个子功能
- **Prompt**："特性区左侧标题 position: sticky，右侧卡片列表滚动，标题随视区固定"

## 三、定价页（Pricing）

### 1. 三档卡片并排（Classic 3-Tier）
```
┌──────┬──────┬──────┐
│ Free │ Pro  │ Team │
│  $0  │ $29  │ $99  │
│      │ [荐] │      │
│ ✓ 特性│ ✓ 特性│ ✓ 特性│
│[开始] │[订阅]│[联系]│
└──────┴──────┴──────┘
```
- **场景**：SaaS 标准定价
- **要点**：中间档"推荐"高亮，色边框/大 shadow/scale 1.05

### 2. 单一档（Simple One）
```
┌────────────────────┐
│      $29/月          │
│  所有功能            │
│  ✓ ✓ ✓ ✓ ✓          │
│  [开始试用]          │
└────────────────────┘
```
- **场景**：不搞档次，一价通吃
- **感觉**：透明、简单

### 3. 对比表格（Comparison Table）
```
┌────────┬────┬────┬────┐
│ 特性     │Free│Pro │Team│
├────────┼────┼────┼────┤
│ 用户数   │ 1  │ 5  │ 无限│
│ 存储     │1GB │10G │100G│
│ 支持     │社区│邮件│24/7│
└────────┴────┴────┴────┘
```
- **场景**：企业客户、复杂对比
- **要点**：粘性表头，行 hover 高亮

### 4. Toggle 月/年切换
```
┌────────────────────────┐
│    [月付] [年付 -20%]    │
├────────────────────────┤
│  [三档卡片，价格切换]     │
└────────────────────────┘
```
- **场景**：常规做法，鼓励年付
- **Prompt**："定价页顶部月/年 toggle，年付显示节省百分比，切换时价格数字动画"

### 5. Slider 按量定价（Usage-Based）
```
┌────────────────────────┐
│  用户数: [────●────] 25 │
│  每月: $87              │
│  [开始订阅]              │
└────────────────────────┘
```
- **场景**：API、开发者工具、按量付费

## 六、表单页（Form）

### 1. 单列（Single Column）
- 所有字段竖排，最佳可读性
- **默认选此，除非有特殊理由**

### 2. 分区（Fieldset Groups）
```
基础信息
├─ [姓名]
├─ [邮箱]
联系方式
├─ [电话]
├─ [地址]
```

### 3. 分步（Stepper）
```
[1 基础]───[2 详情]───[3 确认]
```

### 4. 左说明右字段
```
┌──────────┬──────────┐
│ 字段说明   │  [输入]     │
│ 帮助文字   │            │
└──────────┴──────────┘
```

### 5. 内联表单（Inline）
```
┌──────────┬──────┬────┐
│ [邮箱]     │[城市]│订阅│
└──────────┴──────┴────┘
```
- **场景**：newsletter、搜索、简单查询

### 6. 全屏引导（Full-Screen Onboarding）
- 一次一屏一问，仪式感强
- 底部大进度条

## 七、Prompt 模板

```
【布局构图】
- Hero: 用 {居中聚焦 / 左文右图 / 全屏沉浸 / Bento} 中的一种，
        不要"一个大标题下面一堆功能"的通用泥浆
- 特性区: 用 {三列图标 / zigzag 交替 / Bento / 竖 timeline / Tab 切换}
- 定价: 三档卡片中间"推荐"高亮 + 月/年 toggle
- 页脚: 多列链接 或 极简 或 大 CTA 页脚
- 详情: 图左信息右（产品） / 三栏（文档） / 顶图全宽（文章）
- 表单: 默认单列，长表单分区，超长用分步
- 每个 section 之间用 shape divider 或大留白，不是简单直线
```

## 八、检验清单

- [ ] Hero 不是通用"大标题+副标+CTA居中"，选了具体类型
- [ ] Features 不是等宽三列（除非刻意），有节奏变化
- [ ] Pricing 中间档明显高亮
- [ ] Footer 有明确类型（多列/极简/CTA），不是随意堆
- [ ] 详情页有清晰的信息层级（主图/主信息/次要信息）
- [ ] 表单默认单列，字段 ≤ 7 或分步
- [ ] Section 间距一致（推荐 py-24 桌面 / py-16 移动）
- [ ] 所有布局用 CSS Grid + Flexbox，不用 float/table
- [ ] 容器 max-width 一致（7xl / 6xl）
- [ ] 移动端有明确降级（列数 → 单列，字号 → 缩放）

## 九、v2 · 页面构造选择协议

布局模式不是风格标签，必须由产品目标、内容形态和视觉节奏共同决定。选模式前先填写：

```yaml
page_job:
content_shape: short-copy | long-form | dense-data | mixed-media | workflow
primary_focus:
secondary_focus:
content_density: low | medium | high | extreme
brand_mode: editorial | product | technical | playful | institutional
media_role: none | proof | atmosphere | explanation | interaction
desired_rhythm: calm | measured | energetic | dramatic
```

### 选择规则

| 条件 | 优先模式 | 避免 |
|---|---|---|
| 单一价值、单一 CTA | 居中聚焦 / 大字宣言 | 多个同权重模块 |
| 文字与媒介需要并行理解 | 左文右图 / Zigzag | 文字压在复杂背景上 |
| 产品需要被解释 | Product Shot / Sticky Feature / Timeline | 只放装饰 Hero |
| 内容密度高 | 三栏详情 / Table / Sidebar | 大量宽卡片和空洞留白 |
| 品牌叙事优先 | Full Bleed / Editorial / 场景编排 | 机械三列 Feature |
| 用户要快速完成任务 | 单列表单 / 聚焦工作区 | 全屏沉浸和复杂滚动 |

### 布局模式必须输出的规格

- 内容顺序和每个区域的单一职责
- 主焦点、次焦点和视觉重量
- 栅格、容器、对齐轴和破格位置
- 标题、正文、媒体和 CTA 的安全区
- 0/1/正常/大量内容下的变体
- 移动端的重排，而不是只减少列数
- 选择该模式的理由、禁用条件和验收问题

### v2 Prompt

```text
先根据产品目标、内容密度、核心任务、媒介角色和品牌人格选择页面构造模式。
不要默认使用居中 Hero、三列卡片或 Bento。
输出：页面结构图、内容顺序、视觉焦点、栅格、文字安全区、媒体位置、组件树、
移动端重排和该模式的反面条件。每个布局决策都说明 Reason、Spec、Check。
```
