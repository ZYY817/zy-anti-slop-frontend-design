# B72 · 模块化比例与尺度工程

> B22 讲比例的**审美原理**（黄金比、白银比、伊顿…），B30 讲**流体尺寸**，B42 讲**尺寸档位**。
> 本文补的是把这些理论落成**一套可工程化的 token 系统**——用一个比率贯穿字号、间距、圆角、边框、阴影，让整个界面自动"合拍"。

---

## 一、Modular Scale 是什么

**一句话**：选一个比率 `r`，用它生成一整套尺寸（`base × r^n`）。字号、间距、圆角都用这套阶梯，界面就有内在的数学一致性。

```
base = 16px, r = 1.25
──────────────────────
-2: 10.24    -1: 12.80    0: 16.00
 1: 20.00     2: 25.00    3: 31.25
 4: 39.06     5: 48.83    6: 61.04
```
任何尺寸都从这张表里取，不再随手写 `18px`、`22px`、`44px`。

---

## 二、比率选型对照

| 比率 | 名字 | 视觉性格 | 适合 |
|---|---|---|---|
| **1.067** | 小二度 Minor Second | 极紧凑、几乎无跳跃 | 数据密集后台、金融面板 |
| **1.125** | 大二度 Major Second | 温和、克制 | 阅读型、企业官网 |
| **1.200** | 小三度 Minor Third | 平衡、通用 | **最推荐**，SaaS 主流 |
| **1.250** | 大三度 Major Third | 稍有节奏 | 消费产品、内容平台 |
| **1.333** | 完美四度 Perfect Fourth | 明快、有戏剧感 | 落地页、Hero 大字 |
| **1.414** | 白银比 √2 | 优雅、纸张比 | 出版、图文杂志 |
| **1.500** | 完美五度 Perfect Fifth | 戏剧化、冲击 | 品牌宣传站 |
| **1.618** | 黄金比 φ | 经典、缓慢 | 艺术类、大字标题跨度 |
| **1.778** | 小七度 Minor Seventh (≈16:9) | 极端跳跃 | 仅用于 Hero 与正文差 |

### 双比率组合（进阶）
一个比率不够用时：字号用 1.25，间距用 1.5，让两者各自有节奏又不冲突。
```
type-scale:    1.25  (克制，正文接近)
space-scale:   1.5   (跳跃，层级清晰)
```

## 三、生成完整设计系统的阶梯

**核心思路**：把一个比率贯穿到多个维度。

```css
:root {
  --ratio: 1.25;
  --base: 1rem;         /* 16px */

  /* 字号阶梯：负数向下 */
  --fs--2: calc(var(--base) / var(--ratio) / var(--ratio));  /* 10.24 */
  --fs--1: calc(var(--base) / var(--ratio));                 /* 12.80 */
  --fs-0:  var(--base);                                       /* 16 */
  --fs-1:  calc(var(--base) * var(--ratio));                 /* 20 */
  --fs-2:  calc(var(--fs-1) * var(--ratio));                 /* 25 */
  --fs-3:  calc(var(--fs-2) * var(--ratio));                 /* 31 */
  --fs-4:  calc(var(--fs-3) * var(--ratio));                 /* 39 */
  --fs-5:  calc(var(--fs-4) * var(--ratio));                 /* 49 */

  /* 间距阶梯（可用不同比率或同比率） */
  --sp-1: 0.25rem;  --sp-2: 0.5rem;  --sp-3: 0.75rem;
  --sp-4: 1rem;     --sp-5: 1.5rem;  --sp-6: 2rem;
  --sp-7: 3rem;     --sp-8: 4rem;    --sp-9: 6rem;

  /* 圆角阶梯 */
  --r-1: 4px;  --r-2: 8px;  --r-3: 12px;  --r-4: 16px;  --r-5: 24px;
}
```

### 取整策略（避免别扭小数）
纯几何阶梯会产出 `31.25px`、`48.83px` 这类值。处理原则：

- **字号**：小数**保留**（浏览器会做亚像素渲染，`31.25px` 比强行取整更准）；用 `rem` 表达
- **间距 / 圆角 / 图标尺寸 / 边框**：**取整到 4px 网格**（`31.25 → 32`），因为这些会影响元素对齐，小数会导致 1px 缝隙
- **行高**：取整到"字号 × 行高 = 整数 px"，避免文本基线偏移半像素

```css
--fs-3: 1.953rem;   /* 31.25px — 字号保留小数 */
--sp-6: 2rem;       /* 32px — 间距对齐 4px 网格 */
```

### Utopia 方法（Fluid × Modular）
把每个尺度台阶做成 `clamp()`——移动端一套比率，桌面端另一套：
```css
/* 移动 375px 用 1.2，桌面 1440px 用 1.333 */
--fs-3: clamp(1.44rem, 1.2rem + 1.5vw, 2.37rem);
```
- 工具：**utopia.fyi** 可视化生成整套 fluid modular scale
- **prompt 措辞**："字号用 Utopia 方法生成流体模块化阶梯（移动 1.2 / 桌面 1.333）"

## 四、Fluid vs Fixed 的决策

不是所有维度都适合流体。混合策略最实用。

| 维度 | 推荐 | 原因 |
|---|---|---|
| 正文字号 | **Fixed**（16-17px） | 阅读舒适度是绝对的，不该被视口影响 |
| 标题字号 | **Fluid** clamp() | 大字最能吃视口宽度红利 |
| 段落间距 | **Fluid** | 跟字号变化 |
| 组件内 padding | **Fixed** 阶梯 | 组件在任何容器里都该稳定 |
| 组件外 gap | **Fluid** 或 **响应式阶梯** | 大屏可以更松 |
| 圆角 | **Fixed** | 视觉一致性 |
| 图标尺寸 | **Fixed** 档位 | 像素对齐 |
| 页面外边距 | **Fluid** | 大屏充分呼吸 |

### 经典组合
```css
/* 桌面 24-40 之间随视口，移动端固定 16 */
--page-gutter: max(16px, min(5vw, 40px));

/* 卡片内 padding 永远 24，不随视口 */
--card-pad: 1.5rem;
```

## 五、字号阶梯的**语义化命名**（推荐）

用数字（`fs-1..fs-8`）扩展性好，用语义命名（`display / heading / body / caption`）易读。**混合方案**最实用：

```css
:root {
  /* 语义层 */
  --text-display: var(--fs-5);   /* Hero 主标 */
  --text-h1:      var(--fs-4);
  --text-h2:      var(--fs-3);
  --text-h3:      var(--fs-2);
  --text-lg:      var(--fs-1);   /* 副标、大正文 */
  --text-body:    var(--fs-0);   /* 正文 */
  --text-sm:      var(--fs--1);  /* 辅助信息 */
  --text-xs:      var(--fs--2);  /* 标注、法务 */
}
```
组件用 `--text-body`，重构底层比率时上层零改动。见 **D3 设计令牌**。

## 六、把一个比率贯穿到"每个"细节（顶级做法）

- **字号阶梯**：`base × r^n`
- **行高**：随字号变化——`--lh-tight: 1.1（大标题）`、`--lh-body: 1.5`、`--lh-loose: 1.75`
- **段落间距**：`0.75 × 当前字号`
- **卡片内边距**：`1 × 该层字号` 或阶梯的相邻档
- **圆角**：容器 `--r-4`，内部按钮 `--r-2`（**外圆角 - 内边距 ≈ 内圆角**，避免"两个不同心"，见 B65）
- **阴影 y 偏移**：跟随尺度阶梯（小组件 y=2，大卡片 y=8，浮层 y=16）

**结果**：任意两个数值之间的关系都能被解释，看起来"就是对"。

---

## 七、越界与打破

模块化不等于死板。**故意的越界**是最容易做出高级感的手法：

- **Display 字号**：给英雄标题一个**跳出阶梯**的超大字号（如 `clamp(48px, 8vw, 128px)`），与正文形成断崖式跳跃率 → 见 **B57 对比工程学**
- **一处不对称圆角**：整站 8px 圆角，但某个卡片右上角用 4px → 精工细节
- **一处密度反差**：整页宽松，某处故意紧凑
- **一处比率跨越**：整体 1.25，但 Hero → 副标 用 1.5 的跳跃

规则是"**用规则打破规则**"——先建立预期，再有意识地打破一处。

## 九、检验清单

- [ ] 有一个明确的比率（1.2 / 1.25 / 1.333 之一）

- [ ] 圆角用阶梯，且遵循"外 - 内 ≈ 内"公式
- [ ] 正文字号 fixed，标题字号 fluid（clamp）
- [ ] 组件用语义化字号 token（--text-body 而非 --fs-0）
- [ ] Hero 主标故意跳出阶梯，制造对比
- [ ] 一处不对称/越界作为精工细节
- [ ] 间距/圆角/图标取整到 4px 网格，字号可保留小数
