# V9 · 悬浮与光标效果

> 悬浮效果是"这个网站很精致"的最直接信号。成本低、见效快。

---

## 一、基础悬浮效果

### 上移浮起 (Hover Lift) ★最常用
- **感觉**:响应、可交互、轻盈
- **场景**:卡片、按钮
- **prompt 措辞**:"卡片 hover 时上移 4px 且阴影加深,200ms"
- **实现**:
```css
transition: transform 200ms, box-shadow 200ms;
&:hover { transform: translateY(-4px); box-shadow: 0 12px 24px rgba(0,0,0,0.1); }
```
- **坑**:位移别超过 8px,否则跳跃感强

### 缩放 (Scale)
- **实现**:`&:hover { transform: scale(1.02); }`
- **数值**:1.01-1.03 克制,1.05+ 明显
- **按下**:`&:active { transform: scale(0.97); }`

### 颜色过渡 (Color Shift)
- 背景色/文字色/边框色平滑变化
- **时长**:150-200ms

### 发光 (Glow on Hover)
- **场景**:深色界面 CTA
- **实现**:`&:hover { box-shadow: 0 0 24px rgba(主色, 0.5); }`

### 边框显现 (Border Reveal)
- 默认透明边框,hover 时显现(避免布局跳动)
```css
border: 1px solid transparent;
&:hover { border-color: currentColor; }
```

## 二、高级悬浮效果

### 3D 倾斜 (Tilt / Perspective Hover) ★出彩
- **感觉**:立体、有趣、高科技
- **场景**:产品卡片、作品集
- **prompt 措辞**:"卡片跟随鼠标位置 3D 倾斜,最大 10 度,有光泽跟随"
- **实现**:JS 计算鼠标位置 → `rotateX/rotateY` + `perspective`
```css
transform: perspective(1000px) rotateX(var(--rx)) rotateY(var(--ry));
```
- **进阶**:加一层跟随鼠标的高光(specular)
- **库**:vanilla-tilt.js / Framer Motion
- **坑**:移动端无 hover,要有降级

### 光泽扫过 (Shine Sweep / Shimmer) ★高级
- **感觉**:精致、贵气、金属感
- **场景**:高端 CTA、会员卡片
- **prompt 措辞**:"按钮 hover 时一道斜向白色光泽从左扫到右"
- **实现**:伪元素 + 斜向渐变 + translateX 动画 + overflow hidden

### 边框流光 (Border Beam) ★2024-2026 热门
- **感觉**:科技、AI 感、吸睛
- **场景**:AI 输入框、特殊 CTA、高亮卡片
- **prompt 措辞**:"卡片边框有一道流光沿边框循环转动"
- **实现**:conic-gradient 旋转 + mask 只留边框区域

### 磁性吸附 (Magnetic)
- **感觉**:活泼、有生命、互动感
- **场景**:创意站的按钮
- **prompt 措辞**:"按钮轻微被鼠标吸引,最大偏移 8px,spring 缓动"
- **实现**:JS 计算鼠标距离 → translate 少量偏移

### 涟漪 (Ripple)
- **感觉**:Material 风格、触感反馈
- **场景**:按钮点击
- **实现**:点击位置生成圆形扩散 + 淡出

### 图片缩放 (Image Zoom)
- **场景**:卡片图片、画廊
- **实现**:图片 `scale(1.05)` + 容器 `overflow: hidden`
- **进阶**:图片放大同时轻微反向移动(视差感)

### 内容替换 (Content Swap)
- **场景**:卡片 hover 显示更多信息
- **实现**:默认内容淡出 + 新内容淡入,或滑动替换

### 遮罩揭示 (Mask Reveal on Hover)
- **场景**:图片/文字 hover 揭示
- **实现**:`clip-path` 或 `mask` 动画

### 下划线动画 (Underline Draw)
- **感觉**:精致细节
- **场景**:导航链接、文字链接
- **实现**:伪元素宽度 0→100%,或 scaleX(0→1)
```css
&::after {
  content: ''; position: absolute; bottom: -2px; left: 0;
  width: 100%; height: 1px; background: currentColor;
  transform: scaleX(0); transform-origin: left;
  transition: transform 250ms;
}
&:hover::after { transform: scaleX(1); }
```
- **变体**:从中间展开 / 从左到右 / 双线

### 文字上滑替换 (Text Slide)
- **感觉**:精致、有设计感
- **场景**:按钮、导航
- **实现**:两份相同文字上下排列,hover 时整体上移一行高度

## 三、光标效果（Cursor Effects）

### 自定义光标 (Custom Cursor)
- **场景**:创意站、作品集
- **实现**:`cursor: url(...)` 或隐藏原光标 + JS 跟随元素
- **坑**:必须保证可用性(知道自己在点什么)

### 光标跟随 (Cursor Follower) ★创意站标配
- **感觉**:高级、互动、有设计感
- **实现**:一个圆点/圆环跟随鼠标,有延迟(lerp 插值)
- **变体**:
  - hover 可点元素时放大
  - hover 图片时变成"View"文字
  - 拖尾粒子
- **坑**:移动端要禁用

### 磁性光标 (Magnetic Cursor)
- 光标接近可点元素时被"吸"过去并变形

### 聚光灯光标 (Spotlight Cursor) ★暗色界面出彩
- **感觉**:神秘、聚焦、高级
- **场景**:深色 hero、卡片网格
- **prompt 措辞**:"深色卡片网格,鼠标位置有径向光晕跟随照亮"
- **实现**:CSS 变量记录鼠标位置 + `radial-gradient`
```css
background: radial-gradient(
  400px circle at var(--mouse-x) var(--mouse-y),
  rgba(255,255,255,0.06), transparent 40%
);
```
- **谁在用**:大量现代 SaaS 的卡片网格

### 混合模式光标 (Blend Cursor)
- 光标用 `mix-blend-mode: difference`,经过深浅区域自动反色
- **感觉**:实验性、酷

## 四、卡片组的悬浮策略

### 单卡高亮
hover 的卡片高亮,其余变暗/降饱和 —— 强化焦点
```css
.grid:hover .card { opacity: 0.6; }
.grid .card:hover { opacity: 1; transform: translateY(-4px); }
```

### 邻居响应
hover 时相邻卡片轻微退让(高级细节)

---

## 五、移动端处理 ★必须考虑

**移动端没有 hover。** 所有悬浮效果需要:
```css
@media (hover: hover) {
  .card:hover { /* 只在支持 hover 的设备生效 */ }
}
```
移动端替代方案:
- 用 `:active` 提供按下反馈
- 用滚动进入视口触发
- 用长按显示更多

---

## 六、性能与无障碍

- 只用 `transform` + `opacity` 做 hover 动画
- 光标跟随用 `requestAnimationFrame`,不要监听每次 mousemove 直接改 DOM
- 尊重 `prefers-reduced-motion`:去掉位移,保留颜色变化
- 自定义光标要保证仍能识别可点元素
- hover 效果不能是获取信息的唯一途径(键盘用户 focus 也要有)

## Prompt 模板

### 精致 SaaS 卡片
```
【悬浮效果】
- 卡片 hover:translateY(-4px) + 阴影 sm→lg,200ms ease-out
- 卡片组:hover 时其他卡片 opacity 0.6,聚焦当前
- 深色卡片:鼠标位置径向光晕跟随(400px,white/6)
- 按钮 hover:背景色加深 + scale(1.02);active scale(0.97)
- 链接 hover:下划线从左展开 scaleX(0→1),250ms
- 图片 hover:scale(1.05),容器 overflow hidden
- 只在 @media (hover: hover) 生效,移动端用 :active
- focus-visible 与 hover 同等视觉反馈
```

### 创意作品集
```
【悬浮与光标】
- 自定义光标:隐藏系统光标,圆环跟随(lerp 0.15 延迟)
- hover 可点元素:圆环放大 2 倍并显示 "View"
- hover 作品图:3D tilt 跟随鼠标,最大 8 度 + 高光跟随
- 卡片:遮罩揭示动画,clip-path 从下到上
- 文字链接:文字上滑替换效果
- 移动端:禁用自定义光标,改用 :active 缩放反馈
```

### AI 产品输入框
```
【特殊悬浮】
- 输入框 focus:边框流光动画(conic-gradient 循环旋转 3s)
- 发送按钮 hover:柔和外发光 + 光泽扫过
- 建议 chips hover:轻微上浮 + 边框显现
```
