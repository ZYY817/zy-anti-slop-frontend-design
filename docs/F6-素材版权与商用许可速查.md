# F6 · 素材版权与商用许可速查

> 开源与商用场景的刚需：前端视觉一定用到字体/图片/图标/AI 生成素材，**一个授权错误 = 法律风险**。
> 美国字体侵权法定赔偿 $750-$150,000/字体，foundry 用爬虫主动检测全网侵权使用。
> 原则：**"免费下载" ≠ "可商用"**；"开源" = 许可证真正宽松（法律意义上），不是感觉上的免费。

---

## 一、字体许可总览

| 许可证 | 商用 | 修改 | 重新分发 | 注意 |
|---|---|---|---|---|
| **OFL**（SIL Open Font License） | ✅ | ✅（**改名后**） | ✅（需带 OFL.txt） | 有 Reserved Font Name 时修改必须换名 |
| **Apache 2.0** | ✅ | ✅ | ✅（保留 NOTICE/许可文本） | 衍生可换授权，最灵活 |
| **CC0** | ✅ | ✅ | ✅ | 放弃一切权利，少见但最自由 |
| **CC BY** | ✅（需署名） | ✅ | ✅ | 署名义务模糊，字体界不常用 |
| **CC BY-NC** | ❌ 商业项目不可用 | — | — | 看到 NC 直接跳过 |
| 商用 EULA（foundry 卖） | 按席位/用途 | 通常❌ | 通常❌ | 桌面/网页/App/服务器/广播/eBook 分开卖 |

**商用 EULA 的类型陷阱**：Desktop（印刷/Logo/PDF 静态）、Webfont（网页，常有 pageview 上限与域名绑定）、App、Server、Broadcast、Ebook——**一种授权不覆盖其他用途**。

> "Free for personal use"（个人免费）是最大陷阱：任何商业/客户/变现场景都需要商业授权——判定标准是**有没有经济行为附着**，不是作品质量或观众规模。

---

## 二、Google Fonts 商用细则（2026）

- ✅ 全部目录要么 OFL 要么 Apache 2.0，**免费商用**，无订阅无隐藏墙
- ✅ 商用网站/App/产品无需署名——署名只在**重新分发字体文件**时需要（附 OFL.txt/LICENSE.txt）
- ⚠️ 修改 OFL 字体做品牌字体：允许，但保留的 Reserved Font Name 必须换名
- 🔧 **建议自托管**：Chrome 86（2020）后浏览器按站点分区缓存，CDN 跨站缓存优势已消失；自托管免去 fonts.googleapis.com 的 DNS/连接开销；2022 德国法院裁决后 CDN 还有 GDPR 顾虑
- 合规审计：清点所有字体文件（本机 + 服务器 .ttf/.otf/.woff），确认许可覆盖实际用途

## 三、免费图片/图标/素材源速查

| 源 | 许可 | 商用 | 注意 |
|---|---|---|---|
| Unsplash / Pexels / Pixabay | 宽松（近似 CC0） | ✅ | 品牌/Logo 用途建议确认；Pixabay 有内容许可限制 |
| Openverse / Wikimedia Commons | 混合 | 按条目 | 逐个看条目许可，勿批量 |
| Font Awesome / Bootstrap Icons | OFL/CC BY 4.0 | ✅ | 免费版注意署名条款 |
| Lucide / Tabler / Heroicons | ISC/MIT | ✅ | 开发者友好 |
| Google Fonts Icons（Material Symbols） | Apache 2.0 | ✅ | 与 Google Fonts 同规则 |
| Envato / Shutterstock 等订阅站 | 订阅 EULA | ✅ | 注意派生限制与赔偿条款 |

> 图片池规则：**logo/品牌资产**用付费或明确授权的；**营销与包装**（图即商业资产）用有赔偿保障的；**概念稿/情绪板**随意。阶梯匹配用途，别倒挂。

## 四、AI 生成素材的商用阶梯（2026）

| 阶梯 | 用途 | 安全做法 |
|---|---|---|
| L1 概念稿 | 情绪板/方向探索 | 任何工具都行（含免费版） |
| L2 客户交付 | 交付物含 AI 图 | 付费计划 + 明确条款；不公开的客户概念别用公开输出的工具 |
| L3 付费广告/包装 | 图即商业资产 | 选有 IP 赔偿（indemnification）的工具/企业版 |

| 工具 | 商用要点（2026） |
|---|---|
| OpenAI（ChatGPT/DALL·E） | 消费版授予输出所有权并可商用；**但无赔偿**（indemnification 仅企业/API 客户） |
| Midjourney | 付费订阅用户拥有输出、可商用；注意 **$1M 年收入门槛规则**与免费版禁商用 |
| Canva AI | 付费计划可商用，但**无排他所有权**——社交贴可以，品牌资产单薄 |
| Leonardo AI | 免费版可商用但**平台保留所有权且创作公开**（客户概念别用）；付费版才完全拥有 |
| Freepik / 站内 AI 图 | 付费计划商用，细读条款与署名要求 |

> 契约性所有权 ≠ 版权：AI 生成物的版权归属在各国仍处争议（美国版权局不登记纯 AI 生成作品），企业客户要求"完全权利"时务必文字化澄清。

## 五、合规自检清单（上线前）

- [ ] 所有字体：许可类型 = 实际用途（网页/App/印刷不混用）
- [ ] 免费字体确认是 OFL/Apache/CC0，而非"个人免费"
- [ ] 重新分发字体文件的场景（开源项目/素材包）已附许可文本
- [ ] 图片/图标：每个条目许可可查，品牌用途无灰色地带
- [ ] AI 生成素材：工具条款覆盖当前阶梯，无公开泄露客户概念
- [ ] 无页面 view 上限/域名绑定的未授权 webfont 使用
- [ ] 审计留档：许可证文件与授权记录随项目走
