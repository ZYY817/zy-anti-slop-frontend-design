## 二、怎么"看"设计(Not Just Browse)

### 浏览 vs 分析 vs 拆解

| 层次 | 做什么 | 收获 |
|---|---|---|
| **浏览** | 快速扫,感受好不好 | 培养审美直觉 |
| **分析** | 停下来问"为什么好" | 理解设计决策 |
| **拆解** | 打开 DevTools 看数值 | 获得可复用的参数 |

**大多数人只做第一层。** 要有意识地做第二三层。

## 三、5 步拆解法(对每个喜欢的设计)

### 步骤 1:第一印象标注
看到一个好设计,先快速标注:
```
- 气质三词:___
- 最先注意到什么:___
- 整体感觉:___
- 与众不同的点:___
```
不分析,靠直觉。

### 步骤 2:结构拆解
```
- 布局:什么范式?(居中/分栏/Bento/满幅?)
- 栅格:几列?对齐了吗?
- 层级:一屏内什么最强/次强/最弱?
- 动线:眼睛怎么走?
- 密度:版面率大概多少?
- 节奏:section 之间间距均匀还是有变化?
```

### 步骤 3:元素拆解(DevTools)
```css
/* 打开 DevTools,逐个量: */
字体: 什么字体? 字号? 字重? 行高? 字距?
色彩: 主色? 中性色? 几种? 冷暖? 对比度?
间距: padding? gap? margin? 成系统吗?
圆角: 统一多少? 层级?
阴影: 几层? 模糊? 透明度? 颜色?
```

### 步骤 4:技巧提炼
```
- 它用了什么"手法"让这里变好?(具体技术/词汇)
- 如果我要做类似的,关键参数是什么?
- 这个手法可以迁移到什么场景?
```

### 步骤 5:归纳为规则
```
从这个设计中我学到:
"大标题配负字距 + 巨大行高差 + 单一焦点 = 编辑感"
"4 层递增阴影 + rgba 0.04 = 高级柔和阴影"
```
**变成规则才能复用。** 否则下次还是"好看但做不出"。

## 四、DevTools 量化工具箱

### 查字体
- **WhatFont**(Chrome 插件)— 点击看字体
- **Fontanello**(Chrome 插件)— 右键看字体详情
- DevTools → Elements → Computed → font-family / font-size / line-height

### 查颜色
- **CSS Peeper**(Chrome 插件)— 页面色彩提取
- **ColorZilla** — 吸管取色
- DevTools → Styles → 色值

### 查间距
- DevTools → Elements → 选中元素看 Box Model
- 快捷:选中元素后看 Computed 面板的 margin/padding/gap

### 查动效
- DevTools → Animations 面板(录制动画)
- Performance 面板 → 看帧率
- 右键检查 → transition / animation 属性

### 查整体统计
- **css-stats.com** — 输入 URL,看字号/颜色/间距有多少种
  - 字号种类 <10 = 有系统
  - 颜色种类 <30 = 有收敛
  - 超过 50 种颜色 = 失控

## 五、从"看到"到"做到"的四阶段

### 阶段 1:精确临摹(Copy Exactly)
选一个喜欢的页面,**1:1 临摹**(不是"差不多像",是像素级):
- 量每一个数值
- 用同一字体
- 匹配每一个间距
- 匹配动效

**目的**:训练"执行精度",知道顶级站具体怎么做到的。

### 阶段 2:换内容(Apply)
把临摹来的设计规则**套到自己的内容**:
- 用同样的字号阶梯
- 用同样的间距系统
- 但换颜色/字体/图片

**目的**:验证规则是否可迁移。

### 阶段 3:混合融合(Synthesize)
```
A 的布局 + B 的配色 + C 的动效 + D 的排版
→ 组合成新的
```
**目的**:创造属于自己的方案。

### 阶段 4:从概念出发(Originate)
```
先定概念("数据实验室"/"安静画廊")
→ 选手法服务概念
→ 有些手法是别人的,有些是新的
```
**目的**:不再"像谁",而是"有自己的语言"。

**规律**:大多数人卡在阶段 1-2。**阶段 3→4 的关键跃迁是"先有概念再选手法"。**

## 六、视觉笔记的记录格式

看到好设计,用这个格式记录(积累下来就是你的知识库):

```markdown
## [产品名] - [日期]

### 印象
气质三词:克制 / 精密 / 冷峻
第一眼:巨型等宽字体 hero,深色底

### 手法
1. 巨型字体 120px + 负字距 -0.04em
2. 深色底多层 surface 提亮(#0A/#14/#1C)
3. 微光边框 rgba(255,255,255,0.06)
4. 入场 stagger 50ms,位移仅 6px(极克制)
5. 背景:极淡点阵网格 opacity 0.03

### 数值(DevTools)
- 字号:128/20/16/14
- 字重:800/500/400
- 行高:1.0 / 1.5 / 1.5
- 间距:8/16/24/48/96
- 颜色:只有 3 种(#0A0A0A / #F5F5F5 / #10B981)
- 圆角:0(直角系统)
- 阴影:无(用边框)

### 可复用的规则
"等宽全站 + 零圆角 + 微光边框 + 极少色 = 终端/实验室感"

### 应用想法
我的 [某项目] 可以借用它的:
- 微光边框系统代替阴影
- 极克制的入场(6px 位移)
```

## 七、练习清单(每周可做)

### 每日(5 分钟)
- 浏览 Awwwards/Godly 当日更新
- 标注一个"喜欢"(培养直觉)

### 每周(30 分钟)
- 选一个喜欢的站,做 5 步拆解
- 记录视觉笔记
- 提炼一条"可复用规则"

### 每月(2 小时)
- 精确临摹一个喜欢的页面(像素级)
- 把临摹的规则套到自己的项目试试
- 回顾本月积累,有什么规律?

### 每季度
- 看自己 3 个月前的作品 → 能发现问题了 = 进步了
- 整理个人"视觉规则库"(积累的规则)
- 尝试一次"从概念出发"(阶段 4)

## 八、审美提升的三个阶段

### 1. 眼高手低(Good)
能分辨好坏,但做不出好。
→ 多做临摹(阶段 1-2)弥补。

### 2. 眼手一致(Pro)
能做出和看到的一样好。
→ 开始融合(阶段 3)。

### 3. 眼手超越(Master)
能做出"别人没做过但对"的东西。
→ 从概念出发(阶段 4)。

**判断你在哪**:
- 看到好设计能说出"为什么好"(具体技术原因)→ 至少阶段 1
- 能用 DevTools 量出参数并复现 → 阶段 2
- 能组合多个来源形成新方案 → 阶段 3
- 能不看参考做出有辨识度的东西 → 阶段 4

## 九、避免的学习误区

| 误区 | 正确做法 |
|---|---|
| 只浏览不分析 | 每次至少做 5 步拆解中的 1-2 步 |
| 只看网页 | 跨界看(建筑/摄影/杂志/包装) |
| 只看不做 | 每月至少临摹一次 |
| 照搬整体 | 提炼手法/规则,不是抄布局 |
| 只追潮流 | 经典和当代都看(B34 设计史) |
| 收藏=学会 | 收藏后做拆解笔记才算 |
| 追求独特 | 先做好基础,独特自然来 |
| 看太多太杂 | 每段时间聚焦一个方向深挖 |

## 十、学习路径推荐

### 初学者(0-6 个月)
```
1. 每天看 Awwwards/Godly 培养直觉
2. 读 Refactoring UI(最实操的书)
3. 做 3-5 次精确临摹
4. 学会用 DevTools 量数值
5. 掌握基础规则(B17 的 72 条)
```

### 进阶者(6-18 个月)
```
1. 深入拆解 20 个获奖站(做笔记)
2. 跨界输入(建筑/摄影/杂志)
3. 融合练习(A的布局+B的配色)
4. 学大师理论(B20)理解"为什么"
5. 建立个人规则库(积累)
```

### 高级者(18+ 个月)
```
1. 从概念出发做设计(先想再做)
2. 发展个人视觉语言(辨识度)
3. 教别人(教 = 最好的学)
4. 关注趋势但不追趋势
5. 追求极致工艺(B17)
```

```

   → 用 B35(创意方法)做探索

   → 用 B12/B15 做验收
```

## 十二、Prompt 模板(学习辅助)

```
【分析这个设计】

请从以下维度拆解这个界面:
1. 气质三词
2. 布局范式 + 动线
3. 字体策略(字族/字号/字重/行高)
4. 色彩策略(几种色/冷暖/对比)
5. 间距策略(成系统吗)
6. 光影/质感
7. 动效策略
8. 主视觉手段(hero 靠什么撑)
9. 最独特的 1-2 个手法
10. 可以迁移到其他项目的规则

请用具体数值和术语描述,不要笼统。
```
