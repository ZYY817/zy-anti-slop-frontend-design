# B49 · 参考拆解与视觉笔记法

> 本文原为"人类如何学习优秀设计"的方法论（平台清单/练习节奏/学习路径），已按 AI 检索场景重构：**保留的是"拿到一个好设计，如何把它拆成可复用参数与规则"的操作法**——这正是 B85 演化法第一步「拆解」的执行细节，也是 cases 案例库的记录格式。
> 灵感平台/收集工具目录见 F9（视觉灵感平台）；从参考到原创的完整方法论见 B85。

---

## 一、看设计的三个层次

| 层次 | 做什么 | 收获 |
|---|---|---|
| **浏览** | 快速扫，感受好不好 | 审美直觉 |
| **分析** | 停下来问"为什么好" | 理解设计决策 |
| **拆解** | 打开 DevTools 看数值 | **获得可复用的参数** |

**大多数"看了很多还是做不出"的原因：只做了第一层。** AI 做参考分析时必须走到第三层——形容词不够，要数值。

---

## 二、5 步拆解法（对每个喜欢的设计）

### 步骤 1：第一印象标注（不分析，靠直觉）
```
- 气质三词：___
- 最先注意到什么：___
- 与众不同的点：___
```

### 步骤 2：结构拆解
```
- 布局：什么范式？（居中/分栏/Bento/满幅?）
- 栅格：几列？对齐了吗？
- 层级：一屏内什么最强/次强/最弱？
- 动线：眼睛怎么走？
- 密度：版面率大概多少？
- 节奏：section 间距均匀还是有变化？
```

### 步骤 3：元素拆解（DevTools 量化）
```css
/* 打开 DevTools,逐个量: */
字体: 什么字体? 字号? 字重? 行高? 字距?
色彩: 主色? 中性色? 几种? 冷暖? 对比度?
间距: padding? gap? margin? 成系统吗?
圆角: 统一多少? 层级?
阴影: 几层? 模糊? 透明度? 颜色?
```

### 步骤 4：技巧提炼
```
- 它用了什么"手法"让这里变好？（具体技术/词汇）
- 如果我要做类似的，关键参数是什么？
- 这个手法可以迁移到什么场景？
```

### 步骤 5：归纳为规则（最重要一步）
```
从这个设计中我学到：
"大标题配负字距 + 巨大行高差 + 单一焦点 = 编辑感"
"4 层递增阴影 + rgba 0.04 = 高级柔和阴影"
```
**变成规则才能复用。** 否则下次还是"好看但做不出"。

## 三、DevTools 量化工具箱

| 查什么 | 工具/路径 |
|---|---|
| 字体 | WhatFont / Fontanello 插件；DevTools → Computed → font-* |
| 颜色 | CSS Peeper / ColorZilla；DevTools → Styles 色值 |
| 间距 | DevTools → 选中元素看 Box Model / Computed margin·padding·gap |
| 动效 | DevTools → Animations 面板录制；Performance 看帧率 |
| 整体统计 | css-stats.com —— 字号种类 <10=有系统；颜色 <30=有收敛；>50=失控 |

## 四、视觉笔记记录格式（cases 案例卡）

拆解结果用这个格式归档——它就是本库 `cases/` 层的条目格式：

```markdown
## [产品名] - [日期]

### 印象
气质三词：克制 / 精密 / 冷峻
第一眼：巨型等宽字体 hero,深色底

### 手法
1. 巨型字体 120px + 负字距 -0.04em
2. 深色底多层 surface 提亮(#0A/#14/#1C)
3. 微光边框 rgba(255,255,255,0.06)
4. 入场 stagger 50ms,位移仅 6px(极克制)

### 数值(DevTools)
- 字号:128/20/16/14  字重:800/500/400  行高:1.0/1.5/1.5
- 间距:8/16/24/48/96  颜色:3 种(#0A0A0A/#F5F5F5/#10B981)
- 圆角:0(直角系统)  阴影:无(用边框)

### 可复用的规则
"等宽全站 + 零圆角 + 微光边框 + 极少色 = 终端/实验室感"

### 应用想法
我的 [某项目] 可以借用它的：微光边框系统代替阴影 / 极克制的入场(6px 位移)
```

## 五、从"看到"到"做到"的四阶段（与 B85 的关系）

| 阶段 | 做什么 | 对应 B85 |
|---|---|---|
| 1. 精确临摹 | 1:1 像素级复刻，量每个数值 | 拆解（结构/参数/决策） |
| 2. 换内容 | 同样的规则套自己的内容 | 拆解的规则迁移 |
| 3. 混合融合 | A 的布局+B 的配色+C 的动效 | **杂交** |
| 4. 从概念出发 | 先定概念再选手法 | **约束变异 → 原创** |

**关键跃迁在 3→4：先有概念再选手法。** 这与 B85 四步演化法（拆解→杂交→约束变异→验证）完全同构——本表是它的学习视角版本，执行细节去 B85。

## 六、AI 分析用 Prompt 模板

```
【分析这个设计】

请从以下维度拆解这个界面：
1. 气质三词
2. 布局范式 + 动线
3. 字体策略(字族/字号/字重/行高)
4. 色彩策略(几种色/冷暖/对比)
5. 间距策略(成系统吗)
6. 光影/质感
7. 动效策略
8. 主视觉手段(hero 靠什么撑)
9. 最独特的 1-2 个手法
10. 可以迁移到其他项目的规则

请用具体数值和术语描述,不要笼统。
```

## 检验清单（拆解是否到位）

- [ ] 走到了第三层（DevTools 数值），没停在形容词
- [ ] 结构拆解覆盖：布局/栅格/层级/动线/密度/节奏
- [ ] 提炼了 ≥1 条"可复用规则"（不是"它很好看"）
- [ ] 记录用了视觉笔记格式（手法/数值/规则/应用想法）
- [ ] 学完的手法进入了 B85 的杂交/变异流程，而非照抄"指纹"（B85 反模式）

## 附录：可粘贴拆解 Prompt（参考 → 决策的第一公里）

```text
你是我的设计拆解员。对以下参考 [贴截图/URL/代码] 做三层拆解，**只拆解不仿制**。

三层（层层递进，缺一不可）：
1. 形容词层——先允许说感觉（最多 5 个词），然后全部作废，只当定位线索
2. 结构层——布局骨架/栅格/层级深度/动线入口/密度节奏，每项说"它具体做了什么"而非"它很好看"
3. 数值层——DevTools 级参数：字号/行高/字重组合、主色与强调色具体值及各自出现次数、间距节拍、圆角档位、动效时长与缓动、断点行为

输出视觉笔记格式：
| 手法 | 具体数值 | 可复用规则 | 我的应用想法 |

收尾三问（B85 反模式闸）：
- 这个设计里有没有"指纹级"元素（专属配色/标志布局）？标出来——只可学逻辑不可搬
- 哪 1-2 个手法值得进入我的项目？为什么与我的产品上下文匹配？
- 哪个手法看起来炫但我的项目用不上？说明理由后明确舍弃

禁止：输出"高级/现代/简洁"类无信息量形容词；没有结构层证据不许给结论。
```
