# B55 · 视觉的时间维度

> 界面不是静止的照片,而是活在**时间**里的存在。
> 一天里有黎明与深夜,一年里有春夏秋冬,产品的一生里有初见/成熟/衰老/重生。
> 用户第一次打开、第100次打开、离开半年后回来——看到的应该是**同一个品牌**,但**不同的表情**。
> 这份文档拆的是:界面如何在**时间尺度**上活起来——从毫秒的过渡到年度的刷新周期。

## 二、深浅模式完全系统

### 2.1 三态切换模型

```
系统跟随(Auto)  ─┬─→ prefers-color-scheme: light
                 └─→ prefers-color-scheme: dark

手动覆盖(Manual) ─┬─→ 强制 Light
                 └─→ 强制 Dark
```

**最佳实践**:提供三个选项 `Light / Dark / System`,默认 System。

```html
<div class="theme-switcher" role="radiogroup" aria-label="主题切换">
  <button role="radio" aria-checked="false" data-theme="light">☀️ Light</button>
  <button role="radio" aria-checked="false" data-theme="dark">🌙 Dark</button>
  <button role="radio" aria-checked="true"  data-theme="system">💻 System</button>
</div>
```

```javascript
// 状态存储 + 应用
const THEME_KEY = 'ui-theme';

function applyTheme(theme) {
  const root = document.documentElement;
  if (theme === 'system') {
    root.removeAttribute('data-theme');
  } else {
    root.setAttribute('data-theme', theme);
  }
  localStorage.setItem(THEME_KEY, theme);
}

// 初始化(防 FOUC:必须在 <head> 内联执行)
const saved = localStorage.getItem(THEME_KEY) ?? 'system';
applyTheme(saved);

// 监听系统变化(仅在 system 模式下响应)
matchMedia('(prefers-color-scheme: dark)').addEventListener('change', () => {
  if (localStorage.getItem(THEME_KEY) === 'system') {
    // 触发重绘,CSS 变量会自动响应 prefers-color-scheme
  }
});
```

### 2.3 切换的过渡动画


### 2.4 View Transitions API 高级切换

```javascript
// 涟漪式主题切换(从点击点扩散)
async function toggleTheme(event) {
  if (!document.startViewTransition) {
    applyTheme();
    return;
  }

  const x = event?.clientX ?? window.innerWidth / 2;
  const y = event?.clientY ?? window.innerHeight / 2;
  const endRadius = Math.hypot(
    Math.max(x, window.innerWidth - x),
    Math.max(y, window.innerHeight - y)
  );

  const transition = document.startViewTransition(() => applyTheme());

  await transition.ready;
  document.documentElement.animate(
    {
      clipPath: [
        `circle(0 at ${x}px ${y}px)`,
        `circle(${endRadius}px at ${x}px ${y}px)`,
      ],
    },
    {
      duration: 500,
      easing: 'cubic-bezier(0.4, 0, 0.2, 1)',
      pseudoElement: '::view-transition-new(root)',
    }
  );
}
```

## 三、昼夜节律设计(Circadian Design)

### 3.1 一天四时段的视觉调节

| 时段 | 时间 | 视觉调节 |
|---|---|---|
| **黎明** | 5-8 时 | 暖色调,饱和度低,唤醒感 |
| **白日** | 8-17 时 | 标准亮色,对比清晰,聚焦效率 |
| **黄昏** | 17-20 时 | 微暖偏黄,类似色温 4500K |
| **深夜** | 20-5 时 | 深色模式,低亮度,减少蓝光 |

```javascript
function getTimeOfDay() {
  const hour = new Date().getHours();
  if (hour >= 5 && hour < 8)   return 'dawn';
  if (hour >= 8 && hour < 17)  return 'day';
  if (hour >= 17 && hour < 20) return 'dusk';
  return 'night';
}

document.documentElement.dataset.time = getTimeOfDay();
```

```css
[data-time="dawn"] {
  --bg-tint: oklch(97% 0.02 60);   /* 微暖 */
  --brand:   oklch(55% 0.18 20);   /* 温暖偏红 */
}

[data-time="dusk"] {
  --bg-tint: oklch(94% 0.03 55);   /* 偏黄橙 */
  filter: sepia(0.05);              /* 全局微暖化 */
}

[data-time="night"] {
  /* 应用暗色主题 + 蓝光过滤 */
  --bg: oklch(10% 0.005 30);        /* 深底带暖色相 */
  --blue-light-filter: 1;
}

[data-time="night"] body::before {
  content: "";
  position: fixed;
  inset: 0;
  background: oklch(50% 0.05 30 / 0.03);  /* 极淡暖色叠加 */
  pointer-events: none;
  mix-blend-mode: multiply;
  z-index: 9999;
}
```

### 3.2 f.lux 式蓝光过滤

```css
/* 夜间自动降低蓝光 */
@media (prefers-color-scheme: dark) {
  html {
    filter: hue-rotate(-5deg) saturate(0.95);
  }
}

/* 深夜模式:更强的暖色偏移 */
[data-time="deep-night"] html {
  filter: sepia(0.15) hue-rotate(-10deg);
}
```

### 3.3 慢速呼吸动画(Ambient Animation)

界面在闲置时**保持微妙生命感**,不打扰但不死板。

```css
@keyframes ambient-breathe {
  0%, 100% {
    opacity: 0.6;
    transform: scale(1);
  }
  50% {
    opacity: 0.9;
    transform: scale(1.02);
  }
}

.hero-glow {
  animation: ambient-breathe 8s ease-in-out infinite;
}

/* 尊重用户设置 */
@media (prefers-reduced-motion: reduce) {
  .hero-glow { animation: none; }
}
```

**关键**:周期 6-12 秒,幅度 ≤ 5%,视觉几乎察觉不到但整体"有心跳"。

## 四、季节性设计

### 4.1 四季视觉映射

| 季节 | 主色调 | 意象元素 | 光影 | 触发日期 |
|---|---|---|---|---|
| **春** | 嫩绿 + 樱粉 | 花瓣/嫩芽/柔风 | 明亮通透 | 3.1 - 5.31 |
| **夏** | 蔚蓝 + 明黄 | 阳光/海浪/绿荫 | 强烈饱和 | 6.1 - 8.31 |
| **秋** | 橙红 + 金黄 | 落叶/枫叶/暖光 | 温暖低角度 | 9.1 - 11.30 |
| **冬** | 冷蓝 + 银白 | 雪花/冰晶/静谧 | 冷冽通透 | 12.1 - 2.28 |

```javascript
function getSeason() {
  const m = new Date().getMonth() + 1;
  if (m >= 3 && m <= 5)  return 'spring';
  if (m >= 6 && m <= 8)  return 'summer';
  if (m >= 9 && m <= 11) return 'autumn';
  return 'winter';
}
```

### 4.2 季节化细节(不改品牌主体)

**克制原则**:季节表达只体现在**5% 装饰性区域**——不动 Logo、CTA、核心色板。

```css

  --accent-decoration: oklch(85% 0.08 340);  /* 樱粉装饰 */
}
[data-season="autumn"] {
  --accent-decoration: oklch(65% 0.15 45);   /* 秋橙装饰 */
}

/* 装饰只出现在:装饰性背景/加载动画/空态插图/首页 hero 背景光斑 */
.decoration-blob {
  background: radial-gradient(circle,
    var(--accent-decoration) 0%,
    transparent 70%);
}
```

## 五、节日主题(Holiday Theming)

### 5.1 节日介入尺度

| 尺度 | 表现 | 举例 |
|---|---|---|
| **L1 极轻** | 仅 favicon / Logo 微调 | Google Doodle 常规日 |

### 5.2 节日日程表设计

```javascript
const HOLIDAYS = [
  { name: 'spring-festival', start: '02-10', end: '02-17', level: 'L3' },
  { name: 'women-day',       start: '03-08', end: '03-08', level: 'L1' },
  { name: 'valentine',       start: '02-14', end: '02-14', level: 'L2' },
  { name: 'children-day',    start: '06-01', end: '06-01', level: 'L2' },
  { name: 'national-day',    start: '10-01', end: '10-07', level: 'L3' },
  { name: 'double-11',       start: '11-01', end: '11-12', level: 'L4' },
  { name: 'christmas',       start: '12-20', end: '12-26', level: 'L2' },
  { name: 'new-year',        start: '12-30', end: '01-02', level: 'L2' },
  { name: 'anniversary',     start: '05-15', end: '05-17', level: 'L4' }, // 产品周年
];

function activeHoliday() {
  const today = new Date();
  const mmdd = String(today.getMonth() + 1).padStart(2, '0') + '-' +
               String(today.getDate()).padStart(2, '0');

  return HOLIDAYS.find(h => {
    if (h.start <= h.end) {
      return mmdd >= h.start && mmdd <= h.end;
    } else {
      return mmdd >= h.start || mmdd <= h.end; // 跨年
    }
  });
}
```

## 六、使用频率演变(Usage Frequency Evolution)

### 6.1 三阶段用户视觉

| 阶段 | 特征 | 视觉策略 |
|---|---|---|
| **新手期** (1-7次) | 陌生,需引导 | 大按钮/详细说明/引导层/示例数据 |
| **熟练期** (7-30次) | 掌握基本 | 常规密度/隐藏教程/显示进阶提示 |
| **专家期** (30+次) | 追求效率 | 高密度/键盘快捷键/命令面板/隐藏引导 |

```javascript
// 使用次数追踪
const usageCount = parseInt(localStorage.getItem('usage-count') ?? '0');
localStorage.setItem('usage-count', usageCount + 1);

const userLevel =
  usageCount < 7  ? 'novice' :
  usageCount < 30 ? 'regular' : 'expert';

document.documentElement.dataset.userLevel = userLevel;
```


### 6.3 相对时间的智能显示

```javascript
function relativeTime(date) {
  const diff = (Date.now() - date.getTime()) / 1000; // 秒
  if (diff < 60)         return '刚刚';
  if (diff < 3600)       return `${Math.floor(diff/60)} 分钟前`;
  if (diff < 86400)      return `${Math.floor(diff/3600)} 小时前`;
  if (diff < 86400 * 7)  return `${Math.floor(diff/86400)} 天前`;
  if (diff < 86400 * 30) return `${Math.floor(diff/86400/7)} 周前`;
  return date.toLocaleDateString('zh-CN');  // 超过 1 个月显示绝对日期
}

// 悬停显示绝对时间
<time datetime="2026-08-04T14:30" title="2026-08-04 14:30:00">
  刚刚
</time>
```

## 七、品牌视觉刷新周期

### 7.1 三种更新尺度

| 类型 | 频率 | 变化幅度 | 用户感知 |
|---|---|---|---|
| **微调** (Tune) | 每季度 | 单个 Token 优化 | 几乎无感 |
| **刷新** (Refresh) | 2-3 年 | 主色调整/字体升级/圆角调整 | "变精致了" |
| **重塑** (Rebrand) | 5-10 年 | Logo/名字/整体气质 | "完全变了" |

### 7.2 视觉演进的三条原则

```
1. 保留识别核 — Logo 形状 / 主色相 / 排版气质 的其中至少一项要保留
2. 渐进过渡 — 不搞"某天一觉醒来完全变了",分阶段灰度发布
```

## 十一、实现代码 · 完整时间感知系统

```html
<script>
  // 防 FOUC:必须内联在 <head>
  (function () {
    const theme = localStorage.getItem('theme') ?? 'system';
    if (theme !== 'system') {
      document.documentElement.setAttribute('data-theme', theme);
    }

    const h = new Date().getHours();
    const time =
      h >= 5 && h < 8  ? 'dawn'  :
      h >= 8 && h < 17 ? 'day'   :
      h >= 17 && h < 20 ? 'dusk' : 'night';
    document.documentElement.dataset.time = time;

    const m = new Date().getMonth() + 1;
    const season =
      m >= 3 && m <= 5  ? 'spring' :
      m >= 6 && m <= 8  ? 'summer' :
      m >= 9 && m <= 11 ? 'autumn' : 'winter';
    document.documentElement.dataset.season = season;

    const count = parseInt(localStorage.getItem('usage-count') ?? '0');
    localStorage.setItem('usage-count', count + 1);
    document.documentElement.dataset.userLevel =
      count < 7 ? 'novice' : count < 30 ? 'regular' : 'expert';
  })();
</script>
```

## 十二、踩坑指南

### 坑1:FOUC(Flash of Unstyled Content)
**症状**:切换主题后刷新页面,先闪一下浅色再变深色。
**解法**:主题脚本必须**内联在 `<head>` 里最早执行**,不能放外链 JS。

### 坑2:主题切换时闪烁
**症状**:切换瞬间部分元素来不及过渡,一闪一闪。
**解法**:全局给 background-color / color / border-color 加 transition,但页面初始加载时禁用(添加 `.no-transition` 类,DOMContentLoaded 后移除)。

### 坑3:图片 dark mode 下过亮
**解法**:`filter: brightness(0.9) contrast(1.1)` 或提供两套图片资源。

### 坑4:代码高亮主题不切换
**解法**:两个 CSS 文件用 `media="(prefers-color-scheme: ...)"` 加载,或 JS 动态换 stylesheet。

### 坑5:节日主题过期没撤
**症状**:圣诞过了一个月还在飘雪。
**解法**:自动化,基于日期判断,过期立即失效;CI 定期检查过期资源。

### 坑6:年度回顾数据未准备好就发布
**症状**:用户点开 Wrapped 显示 "还在计算中"。
**解法**:后端提前一周预计算所有用户的数据,前端点开即渲染。

### 坑7:倒计时数字跳动
**症状**:秒数变化时布局左右晃。
**解法**:`font-variant-numeric: tabular-nums` 或用等宽字体。

### 坑8:View Transitions API 不兼容
**解法**:特性检测 `if (document.startViewTransition)`,不支持时降级到普通切换。

### 坑9:季节粒子影响性能
**症状**:老旧设备飘雪卡顿。
**解法**:限制粒子数量(≤ 50),用 CSS 动画不用 JS,监听 `prefers-reduced-motion`,提供关闭开关。

### 坑10:相对时间不刷新
**症状**:显示"3 分钟前",过一小时还是"3 分钟前"。
**解法**:每分钟统一 tick 更新所有 `<time>` 标签(或用 IntersectionObserver 只更新可见的)。

### 坑11:时区错误
**症状**:美国用户看到北京时间。
**解法**:后端存 UTC,前端用 `Intl.DateTimeFormat` 转本地时区。

### 坑12:品牌重塑用户拒绝
**症状**:新 Logo 上线用户骂声一片。
**解法**:灰度发布 + 保留切换旧版选项 + 提前通过博客/邮件预告。
