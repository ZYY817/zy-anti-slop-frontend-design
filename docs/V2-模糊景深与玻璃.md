# V2 · 模糊、景深与玻璃

> 模糊是"高级感"和"层次感"的利器。玻璃拟态是当下最火的视觉语言之一。

---

## 一、模糊类（Blur）

### 高斯模糊 (Gaussian Blur)
- **感觉**:柔和、朦胧、退到背景
- **场景**:背景虚化、装饰光球、非焦点内容
- **实现**:`filter: blur(20px)`
- **坑**:blur 值大时性能开销大,大面积慎用

### 背景模糊 / 毛玻璃 (Backdrop Blur) ★最常用
- **感觉**:通透、高级、有层次(能看到后面但模糊)
- **场景**:导航栏、Modal 背景、卡片、iOS 风格面板
- **prompt 措辞**:"导航栏毛玻璃效果,半透明白 + 背景模糊"
- **实现**:
```css
background: rgba(255,255,255,0.7);
backdrop-filter: blur(12px) saturate(180%);
```
- **关键**:`saturate(180%)` 让后面的颜色更鲜艳,是毛玻璃"高级"的秘密
- **坑**:必须有半透明背景色配合,否则模糊看不出;性能开销较大
- **谁在用**:macOS、iOS、Windows 11 Acrylic

### 运动模糊 (Motion Blur)
- **感觉**:速度、动感
- **场景**:快速动画的拖尾
- **实现**:一般用多帧叠加或 SVG filter 模拟

### 渐进模糊 (Progressive Blur) ★高级
- **感觉**:高级、优雅的过渡
- **场景**:内容底部渐隐、图片下方文字区
- **prompt 措辞**:"内容底部渐进式模糊,从清晰过渡到模糊"
- **实现**:多层 backdrop-blur + 渐变遮罩叠加
- **谁在用**:Apple 官网(滚动内容底部)

### 焦外虚化 / 散景 (Bokeh)
- **感觉**:摄影感、梦幻光斑
- **场景**:背景装饰
- **实现**:模糊的彩色圆形光斑叠加

---

## 二、景深（Depth of Field）

- **感觉**:焦点突出,前后虚化,摄影级
- **场景**:突出主体,弱化背景
- **实现**:焦点元素清晰,背景/前景 blur
- **prompt 措辞**:"主卡片清晰,背景其他元素轻微模糊营造景深"

### 层次模糊
不同 z 层用不同模糊程度,越远越模糊,增强空间感。

---

## 三、玻璃拟态（Glassmorphism）★当下热门

### 标准玻璃
- **感觉**:通透、现代、高级、有层次
- **场景**:深色背景上的卡片/面板、仪表盘、登录框
- **prompt 措辞**:"玻璃拟态卡片:半透明 + 背景模糊 + 细白边框 + 微妙高光"
- **实现**:
```css
background: rgba(255,255,255,0.1);
backdrop-filter: blur(16px);
border: 1px solid rgba(255,255,255,0.2);
border-radius: 16px;
box-shadow: 0 8px 32px rgba(0,0,0,0.2);
```
- **四要素**:半透明底 + 背景模糊 + 细边框 + 圆角
- **坑**:
  - 文字可读性差 → 加半透明深色 scrim 层
  - 性能开销 → 别在滚动列表里大量使用
  - 浅色背景上效果弱 → 主要用于深色或彩色背景

### 液态玻璃 (Liquid Glass) —— 2025-2026 最新
- **感觉**:折射、流动、物理真实(Apple iOS 26 语言)
- **场景**:高端 iOS 风格、前沿产品
- **prompt 措辞**:"液态玻璃效果:动态模糊 + 边缘折射高光 + 深度透明"
- **实现要点**:backdrop-blur + 边缘折射(SVG filter / WebGPU)+ 高光响应
- **坑**:完整效果需 WebGL/WebGPU,纯 CSS 只能近似

### 彩色玻璃 (Tinted Glass)
- **感觉**:有品牌色的通透感
- **实现**:半透明底用品牌色而非白色
```css
background: rgba(59,130,246,0.15);
backdrop-filter: blur(16px);
```

## 四、玻璃效果的可读性处理 ★必看

玻璃上放文字是最大的坑。解决方案:

1. **Scrim 蒙层**:文字下方加一层半透明深色渐变
```css
/* 文字区域下方 */
background: linear-gradient(transparent, rgba(0,0,0,0.4));
```

2. **文字加阴影**:`text-shadow: 0 1px 3px rgba(0,0,0,0.5)`

3. **提高玻璃不透明度**:文字多的地方玻璃更"实"一点

4. **文字描边**:极端情况用细描边

**prompt 措辞**:
> "玻璃卡片上的文字加半透明深色 scrim 保证可读性,对比度达 WCAG AA"

## 五、模糊的性能优化

- `backdrop-filter` 开销大,避免在长列表/频繁滚动区大量用
- 大面积 `blur()` 会掉帧
- 移动端更敏感
- 用 `will-change` 谨慎(用完删)
- 静态模糊背景可以预渲染成图片

**prompt 措辞**:
> "毛玻璃仅用于固定导航和 Modal,不在滚动列表项上使用,保证性能"

## 六、模糊/玻璃的气质对照

| 效果 | 气质 | 典型场景 |
|---|---|---|
| 毛玻璃导航 | 通透现代 | 顶部导航吸顶 |
| 玻璃卡片 | 高级层次 | 深色仪表盘 |
| 液态玻璃 | 前沿未来 | iOS 26 风格 |
| 渐进模糊 | 优雅过渡 | 内容边缘渐隐 |
| 背景虚化 | 聚焦主体 | 突出焦点 |
| 散景光斑 | 梦幻氛围 | 背景装饰 |

## 七、Prompt 模板

### 玻璃拟态仪表盘
```
【模糊与玻璃】
- 背景:深色 + 彩色 mesh gradient(让玻璃有东西可模糊)
- 卡片:玻璃拟态
  - background: rgba(255,255,255,0.08)
  - backdrop-filter: blur(16px) saturate(180%)
  - border: 1px solid rgba(255,255,255,0.12)
  - border-radius: 16px
- 卡片文字:加 scrim 或 text-shadow 保证可读性,对比度 AA
- 顶部导航:毛玻璃吸顶
- 性能:玻璃只用于卡片和导航,列表项不用
```

### 毛玻璃导航
```
【导航栏】
- 半透明白 rgba(255,255,255,0.7)
- backdrop-filter: blur(12px) saturate(180%)
- 底部 1px 极淡边框
- 滚动时才出现毛玻璃(顶部时透明)
```
