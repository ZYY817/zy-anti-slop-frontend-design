## 第一节 · 视觉风格谱系（先定调性）

> 这是"调色板"：选主调 + 副调（点缀 20%）。**词条正文与更细的风格语汇见 `B16`、`E1`、`B34`，本节只做速查与选择。**

### 1.1 主流风格清单（按气质分类）

#### 极简系
- **极简主义**：留白 / 几何 / 单色 / 克制动效
- **新粗野主义（Neo-Brutalism）**：粗黑边 / 硬阴影 / 原色 / 毫不修饰
- **日式极简**：墨色 / 留白 / 单一焦点 / 呼吸感

#### 复古未来系
- **赛博朋克（Cyberpunk）**：霓虹 / 扫描线 / 故障 / 雨夜 / ASCII
- **复古未来（Retro-Futurism）**：80s 网格 / 铬金属 / 磁带 / VHS
- **蒸汽朋克（Steampunk）**：铜绿 / 齿轮 / 蒸汽 / 黄铜

#### 有机自然系
- **有机未来（Organic Future）**：曲线 / 流体 / 生命感
- **自然生物**：细胞 / 植物 / 微生物 / 仿生
- **极简有机**：自然纹理 + 几何克制

#### 数字美学系
- **酸性美学（Acid Graphics）**：熔岩 / 彩虹 / 高饱和 / 流动形变
- **数字巴洛克（Digital Baroque）**：繁复 / 装饰 / 过度华丽
- **故障美学（Glitch）**：信号丢失 / 像素错位 / RGB 分离
- **孟菲斯（Memphis）**：几何 / 波点 / 撞色 / 80s 平面
- **孟加拉电子（Bengali Electronic）**：故障 + 噪点 + 霓虹 + 扭曲

#### 物质拟态系
- **黏土 / 羊毛毡（Claymorphism / Felt）**：柔软 / 捏感 / 磨砂
- **玻璃拟态（Glassmorphism）**：半透 / 模糊 / 漂浮层
- **新拟态（Neumorphism）**：极轻凹凸 / 单色系
- **流体金属（Liquid Metal）**：水银 / 铬 / 虹彩
- **像素艺术（Pixel Art）**：颗粒 / 限制色块 / 怀旧

#### 超现实系
- **超现实梦境（Surreal Dreamscape）**：梦境 / 解构 / 失重
- **全息投影（Holographic）**：虹彩 / 半透明 / 衍射
- **超写实（Hyperrealism）**：3D 真实感 / HDR / 光追感
- **生成艺术（Generative）**：算法生长 / 独一无二

> 对应提示词条目：风格化与媒介模拟见 `R7`，物质拟态与 UI 材质见 `R9`，生成艺术见 `R8`。

### 1.2 混合策略（强烈推荐）

- **主风格 70% + 副风格 20% + 个人签名 10%**
- 示例组合：
  - 极简 + 故障点缀
  - 黏土 + 赛博霓虹
  - 日式 + 酸性
  - 复古未来 + 全息
- **反例**：同时塞 5 个风格 = 视觉灾难
- **个人签名 = 遮住 logo 也能认出来的那一处**（原创性三问见 `B85`）

### 1.3 调性决策辅助

回答以下问题定位调性：
1. 想让人 **惊叹** 还是 **平静**？
2. 想让人 **想起未来** 还是 **回到过去**？
3. 想让人 **感到人类** 还是 **感到超人类**？
4. 想让人 **看懂** 还是 **看不懂但震撼**？

## 附录：可粘贴·视觉定方向 Prompt（R 管线第一公里）

第十五节决策树是流程，下面这个 prompt 把它变成可直接发给 AI 的指令。**先有方向卡，才准进 R0 挑条目**——没有方向卡就开选技法 = "全都要"= AI 味的来源。

```text
你是我的视觉定调师。为 [产品/页面 + 品牌气质线索] 定一张方向卡，**只定方向，不选技法**。

规则（全部来自本库，不许发明）：
1. 主风格只选 1 个（R21 第一节风格谱系），混合风格最多再搭 1 个且须说清主从关系（主 80%/辅 20%）
2. 签名峰值只许 1 个（K18·视觉配额：这一个元素可以破格，其余全部让位）
3. 装饰手法预算 ≤2 种；纹理/模糊剂量给上限（K18 同约束）
4. 强调色出现次数预估 ≤5 处
5. 禁用清单逐条列：本项目明确不要什么（对照 B82 反 AI 味清单，但取舍理由要跟产品上下文绑定，不是照抄）

输出方向卡：
【主风格】名称 + 一句话气质（禁用"高级/现代"类形容词，用"像谁"参照）
【签名峰值】哪一个元素破格、破在哪
【配色与材质】主色/强调色取值 + 材质（哑光/玻璃/噪点…）+ 各自剂量
【动效气质】R20·L2 三气质选哪个 + 时长基调
【禁用清单】不少于 5 条，每条一句话理由
【验证句】用一句话向用户确认："这个方向要让你觉得 ___，不是 ___"

方向卡未获确认前，不进 R0 挑任何条目。
```
