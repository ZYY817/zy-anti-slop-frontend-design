# V4 · 质感、纹理与混合模式

> "廉价 vs 高级"的分水岭往往在质感。一层微妙的噪点能让 UI 从"数字塑料"变"精工作品"。

---

## 一、噪点与颗粒（Noise & Grain）★高级秘诀

### 噪点 (Noise)
- **感觉**:有质感、消除数字感、消除色带
- **场景**:纯色背景、渐变背景、卡片
- **prompt 措辞**:"背景叠加 2% 微噪点,消除色带,增加质感"
- **实现**:SVG turbulence 滤镜 + 混合模式,或噪点 PNG 平铺
```css
background:
  linear-gradient(135deg, #667eea, #764ba2),
  url("data:image/svg+xml,<svg xmlns=...><filter><feTurbulence.../></filter></svg>");
```
- **透明度**:2-5% 最佳,超过就"脏"

### 胶片颗粒 (Film Grain)
- **感觉**:摄影感、复古、温度
- **场景**:图片处理、复古风格
- **区别**:比噪点更粗、更暖

### 数字颗粒 (Digital Grain)
- **感觉**:精细、现代
- **区别**:更细、更均匀

## 二、纹理类（Textures）

### 纸纹 (Paper Texture)
- **感觉**:温暖、传统、手工
- **场景**:编辑感、生活方式、传统品牌

### 布纹 / 织物 (Fabric)
- **感觉**:柔软、贴近、生活
- **场景**:时尚、家居

### 拉丝金属 (Brushed Metal)
- **感觉**:工业、精工、科技
- **场景**:高端产品、汽车

### 网点 (Halftone)
- **感觉**:印刷、复古、漫画
- **场景**:艺术、创意、复古
- **实现**:CSS radial-gradient 平铺,或图片

### 抖动 / 点阵 (Dithering)
- **感觉**:8bit、复古电脑、艺术
- **场景**:复古主题、艺术站

### 扫描线 (Scanlines)
- **感觉**:CRT 显示器、复古、故障感
- **实现**:水平细线渐变平铺

### 像素化 (Pixelate)
- **感觉**:低分辨率、复古游戏
- **实现**:`image-rendering: pixelated`

### 做旧 / 磨损 (Grunge / Weathered)
- **感觉**:粗野、复古、真实
- **场景**:摇滚、街头文化

## 三、混合模式（Blend Modes）★强大工具

**混合模式**是把两层颜色按算法融合,是高级设计的秘密武器。

### 最常用 5 种

| 模式 | 效果 | 用途 |
|---|---|---|
| **Multiply 正片叠底** | 变暗,白色透明 | 阴影、深色叠加、给图片染色 |
| **Screen 滤色** | 变亮,黑色透明 | 光效、发光、亮色叠加 |
| **Overlay 叠加** | 对比增强 | 混合色调、纹理叠加 |
| **Soft Light 柔光** | 柔和的 overlay | 微妙调色 |
| **Difference 差值** | 反相效果 | 光标反色、艺术效果 |

### 全部 15 种(备查)
- normal 正常
- multiply 正片叠底 ★
- screen 滤色 ★
- overlay 叠加 ★
- darken 变暗
- lighten 变亮
- color-dodge 颜色减淡
- color-burn 颜色加深
- hard-light 强光
- soft-light 柔光 ★
- difference 差值 ★
- exclusion 排除
- hue 色相
- saturation 饱和度
- color 颜色
- luminosity 明度

### 两种 CSS 属性
```css
mix-blend-mode: multiply;    /* 元素与背景混合 */
background-blend-mode: overlay; /* 元素内多个背景混合 */
```

## 四、混合模式的经典用法

### 1. 图片染色（Duotone via Multiply）
```css
.image-container { background: #4F46E5; }  /* 主色底 */
img { mix-blend-mode: multiply; opacity: 0.85; }
```
效果:图片带上主色调,统一品牌感

### 2. 光效叠加（Screen）
```css
.light-flare { mix-blend-mode: screen; }
```
在深色背景上叠加光斑,黑色自动透明

### 3. 纹理叠加（Overlay）
```css
.card::after {
  content: '';
  position: absolute; inset: 0;
  background: url('noise.png');
  mix-blend-mode: overlay;
  opacity: 0.3;
}
```
给纯色卡片加纹理感

### 4. 反色光标（Difference）
```css
.custom-cursor { mix-blend-mode: difference; }
```
光标经过深/浅区域自动反色

### 5. 文字穿透背景（Difference / Overlay）
巨型文字用 mix-blend-mode: difference,与背景反色形成有趣效果

## 五、质感的"高级 vs 廉价"

| 廉价 | 高级 |
|---|---|
| 纯色无质感 | 加了 2% 噪点 |
| 高光塑料感 | 哑光质感 |
| 单一材质 | 多层材质叠加(渐变 + 噪点 + 微光) |
| 强反光 | 微反光(specular 一道) |
| 无纹理 | 微妙纹理暗示材质 |

**核心口诀**:好质感 = **微妙**。加 2% 噪点 vs 20% 噪点,前者高级,后者脏。

## 六、Prompt 模板

### 精致 hero 背景
```
【质感与纹理】
- 底层:aurora mesh gradient(靛蓝→紫→粉)
- 中层:2-3% 细噪点叠加(SVG turbulence)
- 消除色带,增加"胶片感"
- 顶层:一道 specular 高光在左上,mix-blend-mode: screen
- 效果:通透、有质感、非纯数字塑料感
```

### 产品图统一调色
```
【图片处理】
- 所有产品图外包一层容器,背景是主色 #4F46E5
- 图片本身 mix-blend-mode: multiply, opacity 0.9
- 效果:所有图统一带上品牌色,视觉一致
```

### 高端卡片
```
【卡片质感】
- 背景:极淡渐变(#FAFAFA → #F5F5F5)
- 叠加:1.5% 极细噪点纹理
- 边框:1px solid rgba(0,0,0,0.05)
- 阴影:多层柔和阴影(4 层递增)
- 顶部:1px 白色高光 border-top(specular)
- 效果:哑光、精工、有厚度
```

### 复古 CRT 风
```
【CRT 质感】
- 底层:深色内容 + 荧光绿字
- 中层:水平扫描线(1px 深色间隔 2px)
- 叠加层:粗噪点 5-8%
- 混合:overlay
- 顶层:轻微 chromatic aberration(RGB 微偏移)
- 效果:复古 CRT 显示器
```

## 七、性能与坑

- **SVG 噪点** > CSS 生成,性能更好
- **大面积混合模式**开销大,慎用于滚动区
- **`will-change`** 谨慎使用,用完删
- **移动端**混合模式支持不完善,测试
- **打印**混合模式无效
