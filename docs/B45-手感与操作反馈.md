# B45 · 手感与操作反馈

> "手感"是最难描述但最影响品质的维度。同样的功能,手感好的产品让人愿意反复用。
> 这份把"手感"拆成可设计的参数。

---

## 一、手感的四个构成

```
1. 响应速度(Latency)     — 多快有反应
2. 反馈强度(Feedback)    — 反应有多明显
3. 物理拟真(Physicality) — 像不像真实物体
4. 预期匹配(Predictability) — 是否符合直觉
```

**手感好 = 快 + 明确 + 有物理感 + 符合预期。**

---

## 二、响应速度的分级

| 延迟 | 感受 | 应对 |
|---|---|---|
| **<16ms** | 瞬时(同一帧) | 理想 |
| **16-100ms** | 即时(感觉不到延迟) | ★目标区间 |
| **100-300ms** | 轻微延迟(可感知但可接受) | 加过渡动画掩盖 |
| **300-1000ms** | 明显延迟(需要 loading) | 骨架屏/spinner |
| **1-3s** | 慢(需要进度) | 进度条 + 预期时间 |
| **>3s** | 很慢(需要后台化) | 通知机制 + 可离开 |

### Doherty 阈值
系统响应 **<400ms** 时用户保持专注和高效。超过就会分心。

### 视觉响应 ≠ 数据响应
```
用户点击 → 100ms 内必须有视觉反馈(即使数据还没回来)
         → 视觉反馈 = 按钮变色/scale/loading 态
         → 数据回来后更新内容
```
**这就是"感觉快"的秘密。**

## 三、点击手感(Tap/Click Feel)

### 三段式反馈
```
1. Hover(桌面)  — 预告"这可以点"
   背景色变化 + translateY(-1px),200ms

2. Active(按下)  — 确认"按下了"
   scale(0.96) + 背景加深,100ms(要快!)

3. Release(松开) — 完成
   回弹到 hover 或 default,spring 缓动
```

### 按下的物理感
```css
/* 硬按键感(机械键盘) */
.button-hard {
  box-shadow: 0 3px 0 var(--shadow-color);
}
.button-hard:active {
  transform: translateY(3px);
  box-shadow: 0 0 0 var(--shadow-color);   /* 阴影消失=真的按下去 */
}

/* 软按键感(橡胶) */
.button-soft:active {
  transform: scale(0.95);
  transition: transform 100ms;
}
/* 松开 spring 回弹 */

/* 玻璃按键感 */
.button-glass:active {
  filter: brightness(1.2);   /* 被按亮 */
}
```

### 点击区域扩大
```css
/* 视觉小,点击区大 */
.icon-btn {
  position: relative;
}
.icon-btn::before {
  content: '';
  position: absolute;
  inset: -12px;   /* 向外扩大 12px */
}
```

## 四、拖拽手感(Drag Feel)

### 拖拽的完整状态
```
1. 可拖暗示    — cursor: grab + 拖动手柄图标
2. 按下(抓取)  — cursor: grabbing + scale(1.02) + 阴影加深(拿起来了)
3. 拖动中      — 跟随鼠标 + 略微倾斜(rotate 2deg)增加物理感
4. 悬停目标    — 目标区高亮 + 虚线边框 + 占位符出现
5. 松开(放下)  — spring 落定到目标位 + 阴影恢复
6. 无效放下    — 弹回原位(spring)+ 轻微 shake
```

### 关键参数
```css
.draggable {
  cursor: grab;
  transition: transform 200ms, box-shadow 200ms;
}
.draggable:active { cursor: grabbing; }
.dragging {
  transform: scale(1.03) rotate(2deg);
  box-shadow: 0 16px 32px rgba(0,0,0,0.2);
  opacity: 0.9;
  z-index: 100;
}
.drop-zone-active {
  background: var(--primary-alpha-10);
  border: 2px dashed var(--primary);
}
```

### 拖拽的物理细节
- **拿起时略微放大**(1.02-1.05)= "离开表面"
- **轻微倾斜**(1-3deg)= 有重量
- **阴影加深**= 悬空高度
- **半透明**(0.9)= 可以看到下面
- **占位符**= 显示会落在哪
- **松手 spring**= 有质感的落定

### 惯性拖拽(Momentum)
松手后继续滑行减速(轮播/列表):
```js
// 简化逻辑
velocity = (currentPos - lastPos) / deltaTime;
// 松手后
position += velocity;
velocity *= 0.95;   // 摩擦衰减
```

## 五、滚动手感(Scroll Feel)

### 原生滚动的问题
浏览器默认滚动"硬"——立即停止,无惯性感。

### 平滑滚动
```css
html { scroll-behavior: smooth; }   /* 锚点跳转平滑 */
```

### Lenis(2024-2026 主流)
给滚动加惯性和柔化:
```js
const lenis = new Lenis({
  duration: 1.2,        // 惯性时长
  easing: (t) => Math.min(1, 1.001 - Math.pow(2, -10 * t)),
  smoothWheel: true,
});
```
**注意**:会影响原生行为(锚点/搜索定位/无障碍),要权衡。

### 橡皮筋效果(Rubber Band)
滚到边界时的弹性回弹(iOS 原生有,Web 需模拟)。

### 滚动的视觉反馈
- **滚动条**:自定义窄滚动条(6px)
- **滚动进度**:顶部进度条
- **滚动位置**:侧边目录高亮当前
- **可滚动暗示**:底部渐隐/下箭头
- **吸顶变化**:导航滚动后加毛玻璃

### Scroll Snap(吸附滚动)
```css
.carousel {
  scroll-snap-type: x mandatory;
  overflow-x: auto;
}
.item {
  scroll-snap-align: center;
}
```
每次滚动"咔"地吸附到位 = 好手感。

## 六、滑动手感(Swipe Feel,移动端)

### 滑动操作(Swipe Actions)
```
列表项左滑 → 露出操作按钮

状态:
1. 开始滑动   — 内容跟手移动,按钮从右侧逐渐露出
2. 滑动阈值   — 超过 40% 时按钮完全显示 + haptic 轻震
3. 松手       — 吸附到"完全打开"或"回弹关闭"
4. 继续滑到底 — 直接触发操作(如删除)+ haptic 重震
```

### 跟手感的关键
```
❌ 松手后才动 → 迟滞
✅ 手指移动时内容 1:1 跟随 → 跟手
✅ 超过边界时阻尼(移动量递减)→ 有物理感
```

### 阻尼(Damping)
```js
// 超过边界后位移递减
if (offset > maxOffset) {
  offset = maxOffset + (offset - maxOffset) * 0.3;   // 阻尼系数
}
```

### 下拉刷新
```
1. 下拉      — 内容跟手下移 + loading 图标旋转角度跟随下拉距离
2. 超过阈值  — 图标变为"释放刷新" + haptic
3. 松手      — 吸附到刷新位置 + spinner 开始转
4. 完成      — ✓ 短暂显示 + 回弹到顶部
```

## 七、缩放手感(Zoom Feel)

### 捏合缩放(Pinch)
```
- 双指距离变化 → 1:1 映射到 scale
- 缩放中心 = 双指中点(不是元素中心)
- 超出范围阻尼(不硬停)
- 松手吸附到边界值(spring)
- 双击快速缩放(2x/复原)
```

### 图片查看器手感
```
1. 点击缩略图  — 图片从原位置放大到全屏(shared element)
2. 全屏中      — 可捏合缩放/拖动平移
3. 下滑关闭    — 跟手缩小 + 背景渐透明
4. 松手        — 超过阈值则关闭,否则回弹
```

## 八、输入手感(Input Feel)

### 输入框
```
focus:    边框色变 + ring 出现,200ms
输入中:   实时字数/校验反馈
校验成功: 右侧 ✓ 淡入(绿)
校验失败: 红边框 + shake + 内联提示
清除:     ✕ 按钮 hover 变红
```

### 键盘反馈
- 打字时无延迟(输入必须即时)
- 自动补全下拉不遮挡输入
- Enter 提交 / Esc 取消
- Tab 顺序合理

### 数字输入
- 上下箭头微调
- 上下方向键 ±1
- Shift+方向键 ±10

## 九、切换手感(Toggle Feel)

### Switch 开关
```
1. 点击      — 滑块开始移动
2. 移动中    — 滑块略微拉长(挤压拉伸)
3. 到位      — spring 回弹到圆形
4. 背景色    — 同步渐变(不是突变)
5. haptic    — rigid impact
时长:200ms
```

### Tab 切换
```
- 指示条滑动到新位置(不是跳变)
- 内容 crossfade(不是硬切)
- 时长 250ms
```

### Checkbox
```
- 勾选:✓ 路径绘制动画(200ms)+ 背景色填充
- 取消:反向
- 整体 scale(0.9→1.05→1) spring 弹
```

## 十、手感的量化参数表

| 交互 | 反馈延迟 | 动画时长 | 缓动 | 位移/缩放 |
|---|---|---|---|---|
| Hover | 0ms | 150-200ms | ease-out | translateY -1~-4px |
| Active/按下 | 0ms | 80-100ms | ease-out | scale 0.95-0.97 |
| 松开回弹 | 0ms | 200ms | spring | 回到 hover |
| Toggle | 0ms | 200ms | spring | 滑块移动 |
| Tab 切换 | 0ms | 250ms | ease-in-out | 指示条滑动 |
| 展开/折叠 | 0ms | 250-300ms | ease-out | height + fade |
| Modal 出现 | 0ms | 300-400ms | ease-out | scale 0.96→1 + fade |
| 页面过渡 | 0ms | 300-400ms | ease-in-out | crossfade / slide |
| 拖拽跟随 | 0ms | 0(1:1 跟手) | — | 1:1 |
| 拖拽落定 | 0ms | 400ms | spring | 吸附到位 |
| 滑动跟手 | 0ms | 0(1:1) | — | 1:1 + 阻尼 |
| 数字滚动 | 0ms | 800-1200ms | ease-out | counter |
| 骨架→内容 | — | 200ms | ease | crossfade |

## 十一、手感差的常见原因

| 症状 | 原因 |
|---|---|
| 迟滞 | 反馈延迟 >100ms / 无即时视觉反馈 |
| 生硬 | 用 linear 缓动 / 无过渡直接跳变 |
| 廉价 | 位移过大 / 动画过慢 / 无按下反馈 |
| 不跟手 | 拖拽/滑动不是 1:1 映射 |
| 无重量 | 缺挤压拉伸 / 缺阴影变化 / 无 spring |
| 意外 | 行为不符合平台惯例 |
| 卡顿 | 用 top/left 动画 / 主线程阻塞 |
| 迷失 | 无状态反馈 / 不知道操作是否成功 |

## 十二、Prompt 模板

```
【手感与操作反馈】

响应速度:
- 所有交互 <100ms 有视觉反馈(不等数据)
- 目标 Doherty 阈值 <400ms
- 超 1s 有进度提示

点击手感:
- hover: 背景变化 + translateY(-2px),200ms ease-out
- active: scale(0.96),100ms(快!)
- 松开: spring 回弹
- 图标按钮点击区向外扩 12px(视觉 20px,点击 44px)

拖拽手感:
- cursor: grab → grabbing
- 拿起: scale(1.03) + rotate(2deg) + 阴影加深 + opacity 0.9
- 目标区: 主色 10% 背景 + 2px dashed 边框 + 占位符
- 落定: spring 400ms
- 无效: 弹回 + 轻 shake

滚动手感:
- Lenis 平滑滚动(duration 1.2)
- 自定义滚动条 6px
- 顶部阅读进度条
- 轮播用 scroll-snap-align: center
- 底部渐隐暗示可滚动

滑动手感(移动端):
- 1:1 跟手,超边界阻尼系数 0.3
- 40% 阈值 + haptic 轻震
- 松手吸附(spring)
- 下拉刷新:图标旋转角度跟随下拉距离

切换手感:
- Switch: 滑块移动 + 挤压拉伸 + spring + rigid haptic,200ms
- Tab: 指示条滑动 + 内容 crossfade,250ms
- Checkbox: ✓ 路径绘制 + scale spring

统一参数:
- 缓动:ease-out 系(cubic-bezier(0.16,1,0.3,1))
- 位移:≤12px(克制)
- 缩放:0.95-1.03(克制)
- 拖拽/滑动:1:1 跟手,不用 transition
```
