# B86 · 界面生成维度词库

> 收录标准：**用了这个词，AI 会做出不同的决定**——不是形容词，是"维度词"：每个词背后挂着参数、结构或规则。
> 来源：四路子代理外部调研（vocab.design/Bringhurst/M3/IBM Carbon/GSAP/NNg/Elam/humanebydesign/Calm Technology/Design for Real Life 等）+ 库内覆盖核查，只收空白与半空白词。
> 用法：写 prompt 时按维度挑词组合；词不够用再回到 B16/B10 风格词库。判断词有没有用的标准一句话：**能不能翻译成具体设计决策**——"手作感"能（不规则边缘+纸质纹理+衬线），"现代的"不能。

## 一、排版文字

| 词 | 是什么 → 改什么决策 | prompt 用法 |
|---|---|---|
| **字面高 x-height** | 小写主体高度，决定"显多大"的真实变量 → 正文/UI 选高 x-height；混排两字体要求 x-height 相近 | `正文选高 x-height 无衬线；标题衬线允许低 x-height` |
| **展示切割/正文切割 Display cut / Text cut** | 同族为大字与小字分别画的两套字形 → 不再把一款字缩放用到底；带 opsz 轴开 auto | `标题 Display cut 收紧 -0.02em；正文 Text cut` |
| **配对三关系 Concord / Contrast / Conflict** | 两字体只有三种关系：同族协和、差异够大=对比、似像非像=冲突（最差）→ 像就干脆用一个 | `字体搭配走 concord 或 contrast，禁 conflict` |
| **超级字族 Superfamily** | 共享骨架的跨类字族（serif+sans+mono 同骨）→ 多字体页天然统一 | `全站 IBM Plex：Sans 正文 Serif 标题 Mono 数据` |
| **排版灰度 Typographic color** | 段落模糊后应呈均匀灰场 → 正文内不插粗体（强调用斜体）、small-caps 替高喊 | `段落灰度要匀：强调用斜体不插 bold` |
| **行尾参差 Rag** | 左对齐右侧不齐轮廓 → 禁 justify 造河道；好 rag 是错落锯齿 | `正文 flush left + ragged right，禁 text-align:justify` |
| **窄体/宽体 Condensed / Extended** | 字宽轴两端 → 密度用窄体（数据面板）、气场用宽体（hero caps） | `仪表板 condensed；hero 标题 extended caps + 宽字距` |
| **笔画对比度 Stroke contrast** | 一字内最粗最细之比 → 高对比只准 ≥48px 展示位；小字一律低对比 | `小字全用低 stroke contrast；高对比衬线只做展示` |
| **现代衬线 Didone** | Bodoni/Didot 系极细横画极粗竖画 → "高级时尚"精确到亚类，自动限大字 | `奢侈页 didone 大字+大跳跃率+大留白` |
| **等线体 Monolinear** | 笔画全程等宽 → 工程/仪器感精确到"无 modulation" | `参数面板 monolinear grotesque` |
| **字腔开口 Aperture** | c/e/s 开口大小 → 与 x-height 互补的选字尺：小字必须高开口 | `12px 以下辅助字必须高 aperture` |
| **油墨陷印 Ink trap** | 笔画交角挖缺口 → 技术感辨识度细节 | `展示体选带 ink trap 的 grotesque` |
| **反白正文 Knockout / Reverse type** | 深底浅字需整套补偿 → 降半档字重、不用纯白、长文慎用 | `反白区字重 400→350、色 #E8E8E8 非纯白` |
| **编辑家具 Editorial furniture** | 杂志配角系统：眉题 kicker/副题 deck/导语 lede/拔引 pull quote/边注/**首字下沉 drop cap**/悬挂标点 hanging punctuation → 产出杂志结构非标题+段落堆 | `题组：kicker 11px mono 大写 → h1 48px serif → deck 斜体灰 ≤20ch；第3段后插 pull quote；章首 drop cap 3 行高` |
| **双宽体 Duospace** | 比例体与等宽体之间 → 内联代码更融正文 | `内联代码用 duospace 比全 mono 顺` |
| **负字距区间** | 展示字收紧不是定值是区间 → 48px+ 给 -0.02~-0.04em，越大负越多 | `h1 -0.03em、display -0.04em、正文 0` |

## 二、色彩

| 词 | 是什么 → 改什么决策 | prompt 用法 |
|---|---|---|
| **在位色对 On-color** | 每个底色强制带"保证可读的前景色" → 消灭亮底白字 | `primary 配 on-primary；浅琥珀主色上 on-primary 近黑` |
| **带色中性灰 Tinted neutral** | 灰掺 2-4% 品牌色相 → 灰"属于"这套色板 | `灰阶每级混 3% 品牌橄榄色相，不是纯灰` |
| **高调/中调/低调 High/Mid/Low-key** | 整幅画面的明度取值区间 → 决定"曝光档位"再谈配色 | `整体 low-key：色值限 L≤45%，只有一盏光进高亮区` |
| **来源色板「取自×××」** | 不从色轮配色，从真实来源取色 → 色板自带材质/年代/温度，天然和谐 | `色板取自风化青铜：patina 绿主、裸铜辅、氧化近黑` |
| **矿物颜料色名** | ochre/sienna/umber/vermilion/ultramarine/verdigris/malachite → 比"棕/蓝"精确两级，自带表面与年代感 | `主色 raw sienna、辅 burnt umber、唯一强调 ultramarine` |
| **中国传统色** | 朱砂/黛蓝/月白/竹青/天青/缃黄/藕荷/玄色 → 国风不再"红+金"刻板 | `茶品牌：月白底+黛蓝主+朱砂缀+竹青辅，全含灰` |
| **低饱和衍生 Muted derivatives** | secondary/tertiary = primary 降 chroma 不换色相 → 整套色天然协和 | `secondary 同色相 C0.14→0.07，只降色度不换色相` |
| **前进/后退色 Advancing / Receding** | 暖前跳冷退后的空间效应 → 深度靠色温不靠投影 | `CTA 暖橙前进，辅助面板冷灰蓝后退` |
| **色度渐消 Chroma taper** | 色阶两端降 chroma 中段最纯 → 浅色不晃眼、深底不塑料 | `11 阶 chroma 在 step9 达峰 0.14，两端渐降到 0.02-0.04` |
| **不协和强调色 Discord accent** | 协和色板里故意放一个"不对"的色 = 唯一记忆点 | `陶土暖灰全套 + 一个电光蓝只做 logo 点和主 CTA` |
| **限定色板 Limited / Zorn palette** | 全页只用 3-4 色，其余 color-mix 混出 → 油画级统一 | `只许 ochre/vermilion/ink/bone 四色，其余全部 mix` |
| **无彩色 Achromatic** | chroma=0 纯灰阶 → 色彩职责让给内容/照片 | `全页 achromatic，唯一色相来自图片本身` |
| **色彩角色岗 Color roles** | 颜色按"职务"命名（primary/container/outline + 各带 on-）→ 组件只许引用岗位名 | `色表按 roles 交付；hover/边框/选中底各归其位` |
| **明暗构成 Notan** | 先压成 2-3 个明度大块检验再上色 → 明度是骨架，色彩是皮肤 | `配色先过 notan：压 3 档明度构成要成立` |
| **明暗对照 Chiaroscuro** | 伦勃朗式：大面积深暗托一小块高亮 → 敢用极端光比 | `hero 90% 深墨底+一束硬光打产品，光比 8:1` |
| **灰化词族 dusty/milky/smoky/washed/bleached/sooty** | 同一色相的七种降纯路径 → "低饱和"精确到手感 | `绿要 dusty sage 不要 mint；蓝要 washed denim` |
| **三色分工 tint=洗底/shade=压深/tone=降调** | tint≠降透明度（会透底色）→ 各衍生色各干各活 | `selected 用 tint-100 洗底、pressed 用 shade-700` |
| **有性格的黑 Rich/Warm/Cool black** | 黑也分冷暖材质 → 最深端做色相偏置 | `页面黑用 warm black #16130F 不要 #000` |
| **同族渐变 Same-hue-family gradient** | 渐变不跨色相家族 → 紫蓝渐变的正面替代规则 | `渐变 hue 只在 40-70 区间爬（米白→杏→陶土）` |
| **单墨透明度阶 One ink, alpha steps** | 一个墨色多档透明度做层级 → 自动融进任何底色 | `中性阶 = --ink 的 100/83/40/12/4% 五档，不引第二灰` |
| **分类色相组 Categorical hues** | 图表/标签色：等明度等饱和均分色相 → 数据配色有纪律 | `6 个分类色同 L65% 同 C0.09 均分色轮` |
| **配色版本 Colorway** | 同结构换色出平行皮肤 → 换色=换整组 role 值 | `给 3 个 colorway：米调/曜石/高对比黑白` |
| **单色描述五槽** | `[明度]+[饱和度]+[色温]+[材质]+[色名]` → 把单个颜色说准的句式（并入自 B10 色名语法） | `低明度+中饱和+暖温+绸缎感+栗色` |
| **oklch 插值** | 渐变/色阶插值走 oklch 色彩空间 → 防中段发灰（RGB 插值通病） | `linear-gradient(in oklch, 米白, 陶土)` |
| **视觉热源 Visual heat** | 全页唯一暖点=视觉焦点 → 暖点放主 CTA，其余冷处理 | `整页冷灰，唯一暖橙在主 CTA=热源` |

## 三、布局构图

| 词 | 是什么 → 改什么决策 | prompt 用法 |
|---|---|---|
| **轴式构图 Axial** | 所有元素沿一条偏心轴线两侧排布 → 编辑感的斜向秩序 | `30% 处竖轴：标题 CTA 居右、数据图居左，轴不画出` |
| **模块栅格+空间区 Modular grid / Spatial zones** | 列×行交叉成模块，相邻模块合成空间区 → 声明哪些占位哪些留空 | `12×4 栅格：主特性 3×2 区、次特性 2×1，留 ≥4 空模块` |
| **流线/悬挂线 Flowlines** | 栅格横向停靠沿，元素顶边挂线 → 卡片参差仍有横向秩序 | `设 3 条流线：标题沿/媒体沿/数据沿，元素顶边挂线` |
| **编辑题组 Kicker–Headline–Deck** | 眉题+主标+副题三件式 → 跳层 ≥4:1:1 的杂志层级 | `每 section：kicker 大写 mono → h1 serif → deck 斜体灰` |
| **拔引 Pull quote** | 正文拔一句话放大 → 长文的编辑式断点 | `第 3-4 段间拔引 28px serif 斜体+品牌色竖线` |
| **破网格 Broken grid（构图类型）** | 破格从"一处意外"升级为"整页策略" → 每区 1 个跨列重叠/越界，有锚定边 | `每区 1 元素跨列重叠 20% 或负 margin 5-10%，移动端归位` |
| **层叠拼贴 Layered collage** | 多元素带旋转/投影/叠压的手工构图 → 关于页/团队页的"人做"感 | `4-6 张图 ±3° 叠压，纸胶带+手写标注，z 轴 3 层` |
| **画中框 Frame within frame** | 前景元素把主体再框一层 → 双框制造纵深聚焦 | `截图外套浏览器框再居色块中=双框；hero 拱形容器` |
| **手稿栅格 Manuscript grid** | 一个大文本块+不等边距 → 偏置栏+功能性宽边距，书页感 | `正文 62ch 偏左（不居中），右 30% 宽边距放边注` |
| **层级栅格 Hierarchical grid** | 按内容重要性定制的不等轨栅格 → 列宽本身传达重要性 | `主轨 5fr/辅轨 2fr/留白轨 1fr，按需合并` |

## 四、层级与纵深

| 词 | 是什么 → 改什么决策 | prompt 用法 |
|---|---|---|
| **深度线索组 Depth cues** | 遮挡/相对大小/画面高度/纹理梯度/空气透视 → 平面页面的纵深工具箱 | `前景元素遮挡背景 20%+纹理梯度渐细，建纵深不靠投影` |
| **前中后景三段 Fore/Mid/Background staging** | 每屏三分景层 → 元素必须报自己在哪一层 | `hero 三段：前景产品/中景色块/背景渐变雾` |
| **画面高度 Height in picture plane** | 元素在画面里的垂直位置=远近 → 高位显得远/有距离感 | `远景元素放画面上 1/3 区，近景压底边` |
| **配重与支点 Counterweight / Fulcrum** | 视觉重量围绕支点平衡 → 不对称但稳 | `左大标题配右下小 CTA，支点在 60% 处` |
| **弱角规避 Fallow corners** | 四个角不能全空——至少一角有内容或锚点 → 破"中间一坨四周荒" | `四角检查：右下用页脚信息锚住，不让四角全荒` |
| **悬挑 Cantilever / Overhang** | 元素一部分悬出容器/边界 → 制造"压不住"的张力 | `特性图左缘悬出容器 40px 悬挑，右侧仍锚网格` |
| **千层饼标题层 Layer-cake headings** | 标题、图、色块错位叠三层 → 廉价的层叠感解药是"有意的层序" | `h1 压在图上图再压色块，三层错 24px` |
| **步进触发 Step trigger** | 滚动叙述的"触发点-固定件"对 → scrollytelling 的最小单元 | `文本分 4 步进，右图 sticky 按步切换` |
| **钉住段 Pinned section (pin & scrub)** | 区段固定+滚动驱动内部进度 → 何时该钉（连续进程）何时不该 | `仅"工作原理"区钉住 3 屏时长，其余自由滚动` |
| **扫描模式 Layer-cake / Spotted / Lawn-mower** | NNg 眼动三模式（补 F/Z 之外）→ 标题分层的真实目的=服务扫读路径 | `每节标题层清晰分层，支持 layer-cake 式只读标题扫页` |
| **相斥 Repulsion / 悬置 Suspension** | 两大元素几乎相碰却不接触/元素悬在半空不着地 → 张力来自"差一点的临界" | `两巨字间距仅 8px 相斥；标题悬置在图与边之间` |
| **深度四档 平/薄/厚/深** | 页面声明自己的纵深档位 → 阴影预算按档给（薄=阴影仅 0.04-0.06 alpha 且仅 modal 上 z 轴） | `空间语言=薄：阴影 0.05 alpha，只有浮层离地` |
| **视觉重心偏上** | 重心应高于几何中心 5-10% → 居中构图的"发闷"来源 | `hero 主体放 45% 高处不放正中` |

## 五、空间节奏

| 词 | 是什么 → 改什么决策 | prompt 用法 |
|---|---|---|
| **被困留白 Trapped whitespace** | 被四周内容围死的孤立空区=视觉死潭 → 留白必须连通页面边缘或通道 | `自查：无被困留白；每块负空间连通页面外缘` |
| **微/中/宏观留白 Micro / Meso / Macro** | 字距行距/组件内/区块间三级 → 三级要配比（约 1:4:8） | `micro 4-8px、meso 24-32、macro 80-120，按级配比` |
| **视平线 Horizon line** | 页面隐含的地平线位置 → 元素"在地上还是天上" | `视平线设在 60% 高，产品"站"线上，标语浮上` |
| **头顶空间 Headroom** | 元素上方留白必须 ≥ 下方 → 顶到边的局促感来源 | `标题上方留白≥1.5×下方，禁头顶贴边` |
| **视线留向 Leading / Nose room** | 朝向性元素（人像/箭头/走势）前方必须留白 → 视线有处可去 | `人像右看，右侧留白≥人像宽度 2/3` |
| **安全区 Live area / Safe margin** | 关键内容离边的最小距离 → 出血与裁切的边界纪律 | `logo/标题在安全区内 48px；装饰可出血` |
| **出血分级 Full / Partial / None** | 元素出界程度分档 → 每区块声明出血级 | `hero 图 full bleed、特性区 partial、表单 none` |
| **留白通道 Whitespace channel** | 负空间连成"路"引导视线 → 留白不是残渣是通道 | `主 CTA 到次 CTA 间留白连成对角通道` |
| **密度梯度 Density gradient** | 密度沿滚动方向渐变（上松下紧或反） → 页面"越来越密"是有方向的设计（档位/呼吸峰/序列规则 → K18·密度节奏） | `首屏 L1 → 特性 L3 → 表格 L4，密度梯度向下收紧` |
| **休止符 Caesura / 呼吸词族** | 区块间刻意的大空白拍 → 不是间距是"停顿"；词族：**屏息**=持续密集不给喘、**叹息**=密后突然大留白、**深呼吸**=128-200px 大拍（结构层的同物 → B87 换气岗） | `第 2 与第 3 区间插一屏纯空白+一句话，作叹息式休止符`（手段：大留白/底色切换/全屏分隔图/单一元素/渐变消隐） |

## 六、动画与动效

### 性格词（空白的"性格→参数"映射——库内此前只有参数没有名目）

| 词 | 参数映射 | 适用 |
|---|---|---|
| **双轨 Productive / Expressive** | 干活交互走高效轨（≤200ms、位移≤8px、无回弹）；仅首次入场/里程碑走表现轨（400-600ms、允许 overshoot/reveal） | **元规则**：每页先分轨再选参数 |
| **干脆 Snappy / Crisp** | 反馈 100-150ms、spring(400,40) 临界阻尼、位移 4-8px、退场 ×0.6 | Linear/Vercel 气质，工具产品 |
| **慵懒 Languid** | 600-900ms quint/sine 长尾、stagger 80-120ms、lerp 0.05、禁 <150ms 快反馈 | 奢侈/艺术向 |
| **俏皮 Bouncy** | spring(300,12) 欠阻尼、squash&stretch、1-2° 微旋转 | 游戏化/年轻品牌 |
| **仪式 Ceremonial** | 1500-2500ms 多幕（blur-in→逐词→mask→落定），localStorage 记首访只演一次 | 首页/首访限定 |
| **机械精密 Mechanical / Stepped** | 80-150ms、steps(3-6) 或 easeInOutQuint、零 spring 零回弹 | 终端/仪表盘 |
| **沉重有分量 Weighty** | spring(80,20,mass 1.5)、起步段拉长、位移可大 24-32px 但无弹跳 | 金融/企业级"贵重感" |

### 转场名目（此前只有通用 mask/crossfade）

| 词 | 是什么 | 何时用 | prompt 用法 |
|---|---|---|---|
| **光圈揭示 Iris** | 圆形 clip-path 从触发点扩散/收缩 | 页面级大切换、点击点即圆心 | `clip-path circle(0% at 点击坐标)→circle(150%) 500ms` |
| **推/盖/揭 Push / Cover / Reveal 三态** | slide 的三种空间语义：push=挤走（前进）、cover=盖上（临时）、reveal=滑走露出（返回） | 层级导航进出；同级 tab 禁 slide | `进详情 cover+旧页退30%变暗；返回 reveal；同级 crossfade` |
| **交叉缩放 Cross-zoom** | 旧页 scale→1.06 淡出+新页 0.96→1 淡入 | 纵深穿越（进详情/回列表） | `前进放大、返回缩小，重叠 100ms` |
| **柱式擦除 Column wipe** | 5-9 竖条交替反向入场汇合 | 整页过场/章节切换 | `7 条奇上偶下 stagger 50ms 400ms 汇合切换` |
| **像素溶解 Pixel dissolve** | 网格块乱序淡入铺满 | 数字/故障气质页过场 | `12×8 块 random stagger 各 150ms 总 500ms` |
| **照片漂游 Ken Burns** | 静态图缓推缓拉 8-20s alternate | 纯氛围 hero/无内容等待区 | `hero 图 scale 1→1.08，15s linear 往返` |
| **共享元素过渡 View Transitions** | 两态间浏览器自动插值同名元素 | SPA/筛选切换的"变形"过渡 | `document.startViewTransition()，卡片→详情共享图` |

### 时机词带（时长名目梯——词=档位）

| 词 | 时长 | 用在哪 |
|---|---|---|
| **即时 Instant** | <100ms | 按压/hover 反馈——反馈只许这档 |
| **迅疾 Swift** | 100-200ms | productive 轨主档 |
| **从容 Measured** | 300-500ms | 区块入场/expressive 下限 |
| **悠长 Leisurely** | 500ms-1s | expressive 编排 |

| **冰河 Glacial** | >3s | 纯氛围循环（Ken Burns 即此档）——装饰要极慢 |

### 微交互与编排（精选）

| 词 | 是什么 | prompt 用法 |
|---|---|---|
| **按住确认 Hold to confirm** | 危险操作按住 600-900ms 进度走满才触发 → 时间作为输入，免确认框 | `删除按住 800ms 径向填充，松手 spring 退回` |
| **坞放大 Dock magnification** | 指针距离按高斯场映射 scale，邻近级联 | `scale=1+0.5·exp(-(d/60px)²)` |
| **段落顿挫 Detent** | 滑过刻度给 80ms 微形变=视觉"咔哒" | `每过刻度 thumb scale 0.96→1 弹回 80ms` |
| **定帧 Hold / Beat** | 编排中故意 0 运动拍 → 治"动画首尾相接填满" | `标题落定静 200ms 再出副标` |
| **接力 Relay** | A 动作 60-80% 处把动交给 B → 段间重叠非串行 | `卡片位移 70% 时内部标题开始 stagger` |
| **过冲-落定 Overshoot & Settle** | "弹一下"拆两参：越界% + 回稳时长；4-12% 为宜，>15% 廉价 | `弹窗 overshoot 6% settle 150ms` |
| **感知时长 Perceptual duration** | spring 物理未停但"看起来已停" → 下一段按振幅 <2% 锚定，不等 finished | `spring 后续编排在振幅 <2% 即触发` |
| **强调减速 Emphasized decelerate** | M3 招牌曲线 (0.05,0.7,0.1,1)——起步冲尾部飘 | `入场统一 emphasized decelerate 400ms` |
| **蓄力曲线 easeInBack / Wind-up** | 先反向 8-15% 再冲出 = anticipation 曲线化 | `发射按钮 easeInBack 先沉 10% 再弹 400ms` |
| **错峰变体 Edges / Random / From-point stagger** | stagger 的原点与序：从两端收拢/乱序/从点击点涟漪（默认 stagger 30-60ms，黄金 50ms） | `菜单从被点项 from-index 向两侧扩散，stagger 50ms` |
| **干脆签名曲线 easeOutExpo** | `cubic-bezier(0.16,1,0.3,1)`——起步即峰、长尾落定 | `与 emphasized decelerate 并列的"干脆"首选` |

## 七、人性与温度（外部 prompt 生态的空白维——本库差异化资产）

|---|---|---|
| **照管感 Tended** | "有人一直在打理"的信号 → 更新日期/changelog/季节痕迹 | `内容带"最后更新 X 天前"，footer 挂 changelog` |
| **在场感 Presence** | 证明另一端有活人 → 真人头像/署名/在线态 | `支持入口和空态放真人头像名字，不用图标` |
| **诚实进度 Honest progress** | 进度条说真话 → 不确定用 indeterminate，禁假百分比 | `等待用 indeterminate，骨架形状匹配真内容` |
| **真实世界锚 Real-world anchors** | 证明屏幕外真存在 → 可核验证据非口号 | `团队页真人照片；案例带可搜索的公司名` |
| **坦诚意图 Transparent intent** | 不藏动机 → 价格/AI 标注/推荐理由就地明说 | `定价无隐藏费用；"为什么推荐"可展开` |

| **语气调光 Tone modulation** | voice 恒定 tone 随场景 → 错误安抚/成功庆祝/深夜安静 | `错误=安抚不指责；成功=真高兴不浮夸；深夜=安静` |
| **共谋感 On your side** | 界面站用户一边 → 默认值对用户最好而非对我们最好 | `推荐按用户利益排序；文案明说"为何对你更好"` |
| **被款待 Hosted** | 界面像好主人 → 接引/领位/交代/认出四场景统一"主人"视角 | `空态像"带你到空桌前讲规矩"不是"暂无数据"` |
| **署名与手痕 Maker's mark** | "这是人做的"证据 → 署名/colophon/一处手工元素（有职责的破格） | `每篇署名真人；footer 加 colophon 说明制作方式` |
| **有限性 Finite** | 体验有尽头 → feed 设计"看完了"终点态；未读可清零 | `"全部读完了"是一个状态，不是无限加载` |

| **自主解释器 Agency / "Why this"** | 用户能管算法 → 推荐带解释入口+关闭开关 | `每个推荐带"为什么是这条"和"不再显示此类"` |
| **故障得体 Graceful failure** | 坏了也要能用 → 每个外部依赖有降级态 | `图表 API 挂→表格；断网→保留已加载+横幅` |
| **慢允许 Unhurried** | 界面不催促 → 禁假紧迫；长文节奏放慢；表单存草稿 | `无倒计时压力；阅读区允许从容` |
| **压力场景设计 Stress-case compassion** | 为用户人生最糟的时刻设计 → 不哄，是不撒盐 | `premortem：用户在急/慌/悲/手抖时打开这页会怎样？` |
| **被看见 Acknowledged** | 每个付出有收条 → 收到+接下来+何时回音三层确认 | `提交后给：收到了/会发生什么/何时有回音` |
| **渐进亲密 Progressive intimacy** | 关系随使用深度变化 → 引导与语气按次数分档 | `1-3 次全引导、10+ 零引导简练、50+ 可开玩笑` |
| **谦逊 Humility** | 界面不自夸 → 禁最高级与不可证形容词；缺失如实标 | `文案删"最好/第一"；没有的功能标 coming soon` |

## 八、气质词轴（"三词有张力"的机械化解法——选词不是想词）

> 规则：**气质三词 = 三根不同轴各取一端**。取词必报轴名；"高级/现代/大气"是无轴词，禁用。
> 同轴取两端=没答（"冷+暖"）；三词全同端=单调（全冷=冷感产品，全暖=甜腻）——**张力来自混合端位**。

| 轴 | 冷端 | 暖端 | 影响哪项决策 |
|---|---|---|---|
| 温度轴 | 极冷/冷峻/清冷/微凉 | 微温/温润/琥珀/灼热 | 色板源+色温 |
| 动静轴 | 安静 / 禅定 / 凝固 / 值守 | 躁动 / 雀跃 / 湍流 / 节庆 | 动效配额+版式松紧 |
| 疏密轴 | 疏朗 / 留白感 / 呼吸 | 致密 / 充盈 / 编织感 | 密度基准档 |
| 粗细轴 | 精致 / 发丝 / 瓷感 / 薄刃 | 粗犷 / 野拙 / 生猛 / 厚涂 | 线宽/字重/边框 |
| 新旧轴 | 摩登 / 锐利 / 未来感 | 做旧 / 包浆 / 手稿 / 档案感 | 材质词 |
| 素艳轴 | 素净 / 哑光 / 灰调 / 禁欲 | 浓烈 / 饱和 / 荧光 / 喜庆 | 色板源+chroma |
| 轻重轴 | 轻盈 / 漂浮 / 羽毛 / 薄纱 | 厚重 / 笃定 / 铸铁 / 基石 | 投影/字重/节奏（调重杆：深色=重/大=重/高饱和=重/粗字重=重/密纹理=重） |
| 雅俗轴 | 书卷 / 庙堂 / 学院 / 编辑 | 街头 / 市井 / 地下 / 涂鸦 | 字体选+文案调 |
| 虚实轴 | 空灵 / 雾气 / 半透 / 幽灵 | 实体 / 落地 / 有据 / 实测 | 证据件类型 |
| 秩序轴 | 网格 / 精确 / 仪仗 / 刻度 | 有机 / 随性 / 错动 / 手写 | 栅格/对齐 |

**实证对照**：V1c「安静/精确/有秩序」=动静冷+秩序冷+粗细冷——全冷端所以偏冷；W1「克制/书卷气/笃定」=素艳素+雅俗雅+轻重重——混合端所以温润。**想暖就把某根轴拨到暖端，不用换词库**。

## 速查：维度检查句（生成前自问）

0. **结构**：每块报岗了吗？（B87：页面类型/区块职责/证据件）
1. **排版**：字体什么性格、几岗？（x-height/配对关系/题组/排版灰度）
2. **色彩**：色从哪来、各干什么、怎么淡出？（来源色板/色岗/chroma taper）
3. **构图**：骨架什么秩序？（轴式/空间区/题组/破格）
4. **纵深**：平面怎么有前后？（深度线索组/前中后景/悬挑）
5. **空间**：留白是通道还是残渣？（呼吸峰/密度梯度/被困留白/休止）
6. **动效**：什么性格、哪条轨？（双轨/性格词/签名缓动/感知时长）
7. **人性**：另一端是谁、被当人吗？（照管/在场/被款待/有限性）
8. **气质**：三词报了哪三根轴？（禁无轴词）
9. **材质光**：什么料、光从哪来？（材质词/光位/影的色温）
10. **母题**：哪个形状反复、变奏了吗？（母题库/3-5 次带变奏）
11. **年代锚**：风格锚定了哪个时代/文化？（§十二 14+7 锚）

写 prompt 或审计时按顺序过一遍——每维至少给出一个词，给不出就是该维没做决策。
