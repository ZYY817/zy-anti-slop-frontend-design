# R10 · 排印的图形化（提示词库 I 组）

> **定位**：排印技法的「货架」——每个技法给出术语、层级、档位、成本、值域、同族拓展与可直接投喂的提示词片段，供按项目挑选组合，而不是一份必须全用的清单。
> **覆盖层**：本组覆盖 **L1 骨 + L3 肉 + L5 髓**；另含少量 **L0**（选型层）条目（字体选型、中文字体选型）。L 标记表示该技法作用在视觉的哪一层，不是优先级。
> **条目卡格式**：`技法名（英文术语）` · **L 层级** · **档位**（基础 / 进阶 / 电影级）· **成本**（低 / 中 / 高）；卡内字段按需出现：视觉收益、强度档位、参考值域、参考映射、参考判断、参考做法、关键用途、关键约束、关键提示、同族拓展、提示词片段。
> **来源说明**：融合自外部「视觉提示词库」I 组（v1.x，2026-08-16）。技术术语、属性名与参数值为原库调研结果，本文做忠实迁移与命名规范适配，未新增未经验证的数据。原库的组内交叉引用已改写为本库 R 编号（见文末「参考资料」）。
> **核心判断（保留原库结论）**：**排印是 UI 视觉最大的杠杆。** 一个只有文字、留白和一种颜色的页面可以非常高级；反之字排错了，加多少特效都救不回来。

## 使用说明

本组给的是**货架**——每个技法的术语、值域、同族拓展、提示词片段，供你挑选组合。库内的排印**地基与铁律**见 `B1` 字体排版、`B33` 排版完整技术、`P1` 排版基础；反 AI 味相关的默认值风险清单见 `B82` 与 `B44`，那是**参考清单，不是硬性铁律，按项目自行取舍**。

三条判断：
1. **中文排印和西文排印是两套规则**。绝大多数教程只讲西文，直接套用中文会出问题（`R10·I5`）
2. **90% 的"排版不好看"是字距、行高、对齐三件事**，不是字体选错
3. **字体是最便宜的高级感**，也是最便宜的廉价感

```
I1 可变字体与轴            I5 中英混排与 CJK（最容易错）
I2 OpenType 特性           I6 动态排印
I3 光学调整与视觉补偿      I7 文本节奏与可读性
I4 文字作为图形            I8 canvas/WebGL 内的文字
```

## I1 可变字体与轴（Variable Fonts）

**一个文件顶一整个字族，且所有中间值都能用、都能动画。**

- **字重轴（wght）** · L3 · 基础 · 成本:低
  - 视觉收益：可以用 450、550 这种"中间字重"，而不是被 400/700 限制
  - 强度档位：常用 300/400/500/600/700；可变字体可取任意值
  - 同族拓展：`font-variation-settings: 'wght' 450`、`font-weight: 450`（更推荐，语义正确）
  - 提示词片段：`用可变字体；字重取 380/460/620 等非标准值以获得更精确的层级；hover 时 wght 平滑过渡不切换字体文件`

- **光学尺寸轴（opsz / Optical Sizing）** · L3 · 进阶 · 成本:低
  - 视觉收益：**这是专业排印的分水岭**。大字号需要更细的笔画和更紧的字距，小字号需要更粗和更松。opsz 自动处理
  - 同族拓展：`font-optical-sizing: auto`、手动 `'opsz' 值`、Optical size 与 grade 的区别
  - 提示词片段：`开启 font-optical-sizing:auto；巨型标题手动设更小的 opsz 以获得更精致的细笔画`

- **字宽轴（wdth）** · L3 · 进阶 · 成本:低
  - 视觉收益：压缩体做紧凑标题、扩展体做宽松展示，同一字族内变化
  - 同族拓展：`'wdth'`、`font-stretch`、压缩体用于长标题避免换行
  - 提示词片段：`长标题用 wdth 88 压缩以在一行内容纳；不要用 transform:scaleX（会畸变笔画）`

- **等级轴（GRAD / Grade）** · L3 · 电影级 · 成本:低
  - 视觉收益：改变视觉粗细但**不改变字宽**（不引起重排），适合深色模式补偿
  - 关键用途：深色背景上的浅色文字视觉上会显粗（光渗），用负 grade 补偿
  - 同族拓展：`'GRAD'`、深浅模式的字重补偿、见 `R2·K1` 光学错觉
  - 提示词片段：`深色模式下文字用 GRAD -25 或字重降一档，补偿浅色文字在深底上的视觉加粗`

- **其他轴（slnt / ital / 自定义轴）** · L3 · 进阶 · 成本:低
  - 视觉收益：`slnt` 连续倾斜、`ital` 真斜体、部分字体有 `CASL`（休闲度）、`MONO`（等宽度）、`XTRA`/`YOPQ` 等精细轴
  - 关键约束：**绝不用 `transform: skew` 伪造斜体**（笔画会畸变）
  - 提示词片段：`斜体用真 ital 或 slnt 轴；禁止 skew 伪造；禁止 CSS 合成粗体（faux bold）`

- **字体选型（Typeface Selection）** · L0 · 基础 · 成本:低
  - 视觉收益：字体本身携带 80% 的气质
  - 参考映射：中性无衬线（Inter/Helvetica Now/Söhne）=理性专业｜几何无衬线（Poppins/Futura）=现代友好｜Grotesk（Neue Haas/Founders）=瑞士克制｜衬线（Freight/Tiempos/Canela）=编辑权威｜展示衬线（Playfair/GT Super）=奢华｜等宽（JetBrains Mono/Berkeley Mono）=技术精密｜手写/怪异（Redaction/Migra）=先锋
  - 关键约束：**不超过 2 个字族**；一个用于标题一个用于正文
  - 默认值风险提示：`B82` / `B44` 把「通篇 Inter / Roboto / 系统默认」列为高风险默认值，建议主动偏离；但这是**参考清单，不是硬性铁律，按项目自行取舍**——中性无衬线在需要理性专业气质时依然是正确选择，风险在于"没选过就用了它"
  - 风格谱系与气质对应见 `B16`、`E1`；全维度选型清单见 `B15`
  - 提示词片段：`字体限 2 族：标题用 <展示型>，正文用 <中性无衬线>；给出完整 font-stack 与 fallback 度量匹配`

- **可变字体的体积权衡（VF Size Trade-off）** · L5 · 进阶 · 成本:低
  - 视觉收益：可变字体不是无条件更小——**用不到 3 个字重时，多个静态字重反而更轻**
  - 参考判断：
    - 需要 **≥3 个字重** 或需要**字重动画** → 用 VF（一个文件通常 60–120KB，抵 3–4 个静态字重）
    - 只需 400 + 700 两档且不做动画 → 用 **2 个静态 woff2**（每个 15–30KB，合计更小）
    - 拉丁 VF 全轴文件常在 100–250KB；只用 wght 一根轴时，**子集化时同时裁掉不用的轴**（`instance`/`drop axis`）能砍掉一半
    - CJK 无论如何都必须子集化（见 `R10·I5`，原始 3–10MB），CJK VF 更要慎用
  - 同族拓展：`fonttools varLib.instancer`、`glyphhanger`、`unicode-range` 分片、`woff2` 是唯一需要的格式（不要再出 ttf/eot）
  - 提示词片段：`字重需求 ≥3 档或要做字重动画才用可变字体；只需 2 档时用 2 个静态 woff2；VF 必须裁掉未使用的轴与字符集，只输出 woff2；字体总量预算 ≤200KB`

- **加载策略与首屏文字（FOIT vs FOUT）** · L5 · 基础 · 成本:低
  - 视觉收益：字体加载方式决定首屏那 200–800ms 里用户看到什么
  - 参考取舍：
    - **FOIT**（`font-display: block`，文字先隐形）= 不跳动但可能空白 → 只适合超小体积的标题字体
    - **FOUT**（`font-display: swap`，先用回退字体）= 立刻可读但会跳字 → **默认选这个**，配合 `size-adjust` 把跳动压到几乎不可见
    - `font-display: optional` = 首次访问直接用回退、字体进缓存后下次才用 → **对首屏指标最友好**，适合正文字体
    - 关键：`swap` 必须搭配 `@font-face` 的 `size-adjust` / `ascent-override` / `descent-override` 做度量匹配（见 `R15·O4`），否则字体一到整页重排
  - 参考做法：首屏用到的字体 `preload`（只 preload 真正首屏用的那 1–2 个文件，preload 过多等于没有优先级）
  - 同族拓展：见 `R15·O4` 字体覆盖与回退、`R11·F6` 布局稳定、`document.fonts.ready`（分割/逐字动画必须等它，否则行会错位）
  - 提示词片段：`标题字体 font-display:swap + preload + size-adjust 度量匹配；正文字体用 optional；只 preload 首屏真正用到的 1-2 个 woff2；逐字/分行动画必须等 document.fonts.ready 之后再计算`

## I2 OpenType 特性（OpenType Features）

**字体里藏着的功能，默认大多是关的。开对了立刻显专业。**

- **数字形式（Figure Styles）** · L5 · 基础 · 成本:低
  - 视觉收益：
    - `tnum`（表格数字）— 等宽，用于表格、计时器、价格列表，**防止数字跳动**
    - `pnum`（比例数字）— 变宽，用于正文中的数字
    - `onum`（旧式数字）— 有升降部，融入正文更优雅
    - `lnum`（衬线式/等高数字）— 全部同高，用于标题
    - `zero`（带斜线的零）— 技术场景区分 0 与 O
  - 提示词片段：`表格与计时器数字用 font-variant-numeric: tabular-nums；正文数字用 oldstyle-nums；技术数据开 slashed-zero`

- **连字与替代字（Ligatures & Alternates）** · L5 · 进阶 · 成本:低
  - 视觉收益：`liga`（标准连字，默认开）｜`dlig`（自由连字，装饰性）｜`ss01`–`ss20`（风格集，很多字体的"单层 a""直线 l"等替代形都在这里）｜`calt`（上下文替代）｜`swsh`（花饰）
  - 关键提示：**很多字体最好看的字形藏在 `ss01`/`ss02` 里**，不开就浪费了
  - 提示词片段：`检查所选字体的 ss01-ss04 风格集，选用更符合调性的字形（如单层 a、直线 l）；开启 calt`

- **大小写与小型大写（Case & Small Caps）** · L5 · 进阶 · 成本:低
  - 视觉收益：`smcp`（小型大写，比全大写优雅得多）｜`c2sc`｜`case`（全大写时调整标点位置）｜`cpsp`（全大写时增加字距）
  - 关键约束：全大写时**必须加字距**（0.05–0.1em），否则挤在一起；全大写句子禁止超过 3–5 词
  - 提示词片段：`标签用 font-variant-caps: small-caps 而非 text-transform:uppercase；必须用全大写时加 letter-spacing 0.08em 并开启 case 特性`

- **分数与上下标（Fractions & Positions）** · L5 · 进阶 · 成本:低
  - 视觉收益：`frac`（真分数 ½ 而非 1/2）｜`sups`/`subs`（真上下标而非缩小字号）｜`ordn`（序数 1st 的 st）
  - 提示词片段：`分数用 font-variant-numeric: diagonal-fractions；上标用 font-variant-position: super（不用 <sup> 默认缩放）`

- **中文相关特性** · L5 · 进阶 · 成本:低
  - 视觉收益：`palt`（比例间距，中文标点自动收紧，**中文排版必开**）｜`halt`｜`vert`（竖排字形）｜`hwid`/`fwid`（半宽/全宽）
  - 提示词片段：`中文正文开启 font-feature-settings: 'palt' 1，让标点自动收紧；标题额外手调标点间距`

## I3 光学调整与视觉补偿（Optical Adjustment）

**数值正确 ≠ 视觉正确。** 这一节是"看着就是专业排版"的来源。

- **字距（Letter-Spacing / Tracking）** · L5 · 基础 · 成本:低
  - 视觉收益：字号越大字距越应该紧，字号越小越应该松。**默认字距只对一个字号正确**
  - 参考值域：
    - 巨型标题（>64px）：`-0.03em` ~ `-0.05em`
    - 标题（32–64px）：`-0.02em` ~ `-0.01em`
    - 正文（16–20px）：`0`
    - 小字（12–14px）：`+0.01em` ~ `+0.02em`
    - 全大写标签：`+0.06em` ~ `+0.12em`
  - 同族拓展：kerning（字符对间距，`font-kerning: normal`）vs tracking（整体字距）、可变字体的 `XTRA` 轴
  - 提示词片段：`按字号设字距：>64px 用 -0.04em、标题 -0.02em、正文 0、小字 +0.015em、全大写 +0.08em；开启 font-kerning`

- **行高（Line Height）** · L5 · 基础 · 成本:低
  - 视觉收益：行高与字号、行宽三者联动。行越长需要行高越大
  - 参考值域：巨型标题 `0.95–1.05`（可以负行距）｜标题 `1.1–1.25`｜正文 `1.5–1.7`｜小字 `1.4–1.5`｜宽行长文 `1.7–1.8`
  - 关键约束：**标题行高必须比正文小得多**。标题用 1.5 行高是最常见的业余标志
  - 提示词片段：`行高按层级：巨型标题 1.0、标题 1.15、正文 1.6、小字 1.45；行宽越长行高越大`

- **行宽（Measure / Line Length）** · L5 · 基础 · 成本:低
  - 视觉收益：最佳可读行宽 45–75 字符（西文）/ 25–35 字（中文）
  - 同族拓展：`max-width: 65ch`、`ch` 单位、中文用 `em` 估算
  - 提示词片段：`正文 max-width: 68ch（中文用 34em）；超宽容器内的文本必须限宽，禁止满屏通栏正文`

- **视觉对齐（Optical Alignment）** · L5 · 进阶 · 成本:低
  - 视觉收益：数值对齐 ≠ 视觉对齐。引号、括号、圆形字母、斜线需要**溢出边界一点**才看着对齐
  - 同族拓展：`hanging-punctuation: first`（悬挂标点）、负 margin 手动补偿、`text-indent` 负值
  - 提示词片段：`引号开头的段落用 hanging-punctuation:first 或负 text-indent 让引号悬挂到边界外；圆形/尖角图标略微超出对齐线`

- **文字盒裁剪（text-box-trim）** · L5 · 进阶 · 成本:低
  - 视觉收益：**终于能真正按字形边界对齐**，不再有莫名的上下空隙
  - 关键用途：按钮内文字垂直居中、标题与相邻元素的精确间距
  - 同族拓展：`text-box-trim: trim-both` + `text-box-edge: cap alphabetic`、旧方案（负 margin / `leading-trim` polyfill）
  - 提示词片段：`标题与按钮文字用 text-box-trim:trim-both + text-box-edge:cap alphabetic，消除行高造成的额外空隙`

- **断行控制（Text Wrapping）** · L5 · 基础 · 成本:低
  - 视觉收益：`text-wrap: balance`（标题各行长度均衡，**免费提升标题美观度**）｜`text-wrap: pretty`（正文避免孤字）｜避免"寡行/孤字"
  - 同族拓展：`text-wrap: balance/pretty`、`hyphens: auto`、`<wbr>`、`&nbsp;` 防断、`overflow-wrap`
  - 提示词片段：`标题加 text-wrap:balance；正文加 text-wrap:pretty；关键短语用 &nbsp; 防止孤字断行`

- **基线网格（Baseline Grid）** · L1 · 进阶 · 成本:低
  - 视觉收益：所有文本落在统一基线上，产生"看不见的秩序"
  - 同族拓展：行高为基线整数倍、`rlh` 单位、margin 用行高倍数、`round()` 函数对齐
  - 提示词片段：`建立 4px 基线网格；所有行高与垂直间距为 4 的倍数；用 rlh 单位表达段落间距`

## I4 文字作为图形（Type as Image）

**当文字足够大，它就不再是文字，而是形状。** 这是最省成本的视觉奇观。

- **巨型排印（Oversized Type）** · L1 · 进阶 · 成本:低
  - 视觉收益：标题占屏 30–60%，靠尺寸本身产生冲击，**不需要任何图片或 3D**
  - 强度档位：大（占屏 25%）/ 巨型（40%）/ 极端（60%+，允许裁切出屏）
  - 同族拓展：见 `R1·G1` 尺寸对比、`R1·G2` 裁切出血、可变字体压缩配合
  - 提示词片段：`主标题用 clamp(3rem, 14vw, 12rem)，字距 -0.04em，行高 0.92，允许左右出血裁切`

- **文字填充（Text Fill）** · L3 · 进阶 · 成本:低
  - 视觉收益：文字内部填图片/视频/渐变/canvas，一招出效果
  - 同族拓展：见 `R9·H4` background-clip:text、`mask` 用文字、`paint-order`（描边在填充下）
  - 提示词片段：`巨型标题用 background-clip:text 填充缓慢漂移的 mesh gradient；保留 DOM 文字可选中与 SEO`

- **文字描边与镂空（Outlined Type）** · L3 · 进阶 · 成本:低
  - 视觉收益：空心字与实心字交替，层次与节奏
  - 同族拓展：`-webkit-text-stroke`、`paint-order: stroke fill`、SVG `stroke`、双层文字（描边层 + 填充层错位）
  - 提示词片段：`标题中部分单词用 -webkit-text-stroke:1.5px 空心处理，与实心词交替产生节奏`

- **文字沿路径（Type on a Path）** · L3 · 进阶 · 成本:中
  - 视觉收益：圆形/曲线排字，徽章感与动态感
  - 同族拓展：SVG `<textPath>`、旋转每个字符（JS 拆分）、`offset-path`（CSS Motion Path）
  - 提示词片段：`用 SVG textPath 做环形文字并缓慢旋转（40s/圈）；或用 offset-path 让字符沿曲线分布`

- **文字网格与拼贴（Type Grid / Collage）** · L1 · 进阶 · 成本:低
  - 视觉收益：文字块作为构成元素排布，瑞士/新粗野风
  - 同族拓展：见 `R1·G5` 几何构成、旋转 90° 的侧边文字、超大数字作为装饰
  - 提示词片段：`用超大半透明数字/单词作为背景构成元素（不作为信息），旋转 90° 贴边`

- **文字变形与形变（Type Distortion）** · L3 · 电影级 · 成本:中
  - 视觉收益：拉伸、波浪、液化、透视投影，实验性排印
  - 关键约束：**不要用 scaleX/Y 拉伸**（笔画畸变）；要变形就转成路径或用 shader
  - 同族拓展：SVG path 变形、`R10·I8` shader 文字、可变字体 wdth 轴（正确的"压缩"方式）
  - 提示词片段：`文字变形先转 SVG path 或喂给 shader；宽度变化用可变字体 wdth 轴，禁止 scaleX`

- **文字作为纹理（Type as Texture）** · L3 · 进阶 · 成本:低
  - 视觉收益：极小字号的大量文字形成灰度纹理块（报纸感、数据感）
  - 同族拓展：微排印、`R7·E4` ASCII 艺术、滚动的代码/日志背景
  - 提示词片段：`用 9px 等宽字排满一块区域形成纹理（不为阅读），透明度 12%，缓慢滚动`

## I5 中英混排与 CJK（CJK Typography）※ 最容易错

**绝大多数排印教程只讲西文。** 中文有一整套独立规则，不处理就"总觉得哪里怪"。

- **中西文混排间距（CJK-Latin Spacing）** · L5 · 基础 · 成本:低
  - 视觉收益：中文与拉丁文/数字之间需要约 1/4 空格的间隙，否则挤在一起
  - 同族拓展：`text-autospace`（新属性）、手动插入 `<span class="latin">` + margin、pangu.js（自动加空格）
  - 提示词片段：`中英混排在中文与拉丁/数字之间加 0.15em 间隙（用 text-autospace 或构建时处理）`

- **标点挤压（Punctuation Compression）** · L5 · 进阶 · 成本:低
  - 视觉收益：中文全角标点自带大量空白，连续标点或行首行尾标点需要收紧
  - 同族拓展：`font-feature-settings: 'palt' 1`（比例间距）、`'halt'`、手动 letter-spacing 负值
  - 提示词片段：`中文开启 palt 让标点自动收紧；标题里的连续标点手动加负字距`

- **行首行尾禁则（Kinsoku Shori）** · L5 · 进阶 · 成本:低
  - 视觉收益：句号逗号不能出现在行首，开引号不能出现在行尾
  - 同族拓展：`line-break: strict/normal/loose`、`word-break: keep-all`（保持词不断）、`text-spacing-trim`
  - 提示词片段：`中文正文设 line-break: strict 启用禁则；标题设 word-break: keep-all 避免词内断行`

- **中文字体选型（CJK Typeface）** · L0 · 基础 · 成本:低
  - 视觉收益：中文字体选择比西文更影响气质，且**字重可用范围通常更窄**
  - 参考映射：思源黑体/Noto Sans SC（中性通用）｜苹方（现代清晰）｜思源宋体（编辑权威）｜霞鹜文楷（人文温和）｜方正系列（更多风格）
  - 关键约束：中文字体文件极大（3–10MB），**必须做子集化**或用系统字体栈
  - 同族拓展：`unicode-range` 分片、字体子集化（fontmin/subfont）、系统字体栈（`system-ui, -apple-system, "PingFang SC", "Microsoft YaHei"`）
  - 提示词片段：`中文优先用系统字体栈避免加载开销；必须用自定义中文字体时做子集化 + unicode-range 分片按需加载`

- **中文的字距与行高** · L5 · 基础 · 成本:低
  - 视觉收益：中文方块字排满时更密，**行高要比西文更大**（1.7–1.9），字距通常为 0 或轻微正值
  - 关键约束：中文标题加正字距（0.02–0.05em）会显得"疏朗高级"；正文不要加
  - 提示词片段：`中文正文行高 1.75、字距 0；中文标题字距 +0.03em 增加疏朗感`

- **竖排（Vertical Writing）** · L3 · 电影级 · 成本:中
  - 视觉收益：竖排中文/日文，强烈的东方与传统气质
  - 同族拓展：`writing-mode: vertical-rl`、`text-orientation`、`text-combine-upright`（数字合并）、`vert` OpenType 特性
  - 提示词片段：`装饰性文本用 writing-mode: vertical-rl；其中的数字用 text-combine-upright:all 横向合并`

- **数字与量词（Numerals）** · L5 · 进阶 · 成本:低
  - 视觉收益：中文语境里数字用等高数字（`lnum`）更整齐；单位与数字之间要有细间隙
  - 提示词片段：`中文中的数字用 lnum + tnum；数字与中文单位间加 0.1em`

## I6 动态排印（Kinetic Typography）

- **逐字/逐词/逐行揭示** · L5 · 基础 · 成本:低
  - 视觉收益：见 `R11·F3` 文字逐字动画
  - 关键约束：逐字只用于 ≤8 字的短标题；长句用逐词或逐行
  - 提示词片段：`标题按词拆分 + overflow遮罩从下推入，错峰 50ms；正文整块淡入`

- **字重脉动（Weight Pulse）** · L5 · 进阶 · 成本:低
  - 视觉收益：可变字体字重随时间/滚动/hover 连续变化，只有可变字体能做
  - 同族拓展：见 `R10·I1`、滚动驱动 wght、鼠标距离驱动 wght（每个字母根据到光标距离变粗）
  - 提示词片段：`导航项 hover 时 wght 400→650 过渡 250ms；标题各字母按到光标距离动态调 wght（距离越近越粗）`

- **数字滚动（Number Roll / Odometer）** · L5 · 进阶 · 成本:低
  - 视觉收益：数值变化时数字滚动而非跳变
  - 同族拓展：`tnum` 防跳动、垂直 translate 数字列、`@property` 计数动画 + `counter()`
  - 提示词片段：`数字变化用垂直滚动（每位独立）+ tabular-nums；或用 @property --num 动画配合 counter()`

- **打字机与解码（Typewriter / Decode）** · L5 · 进阶 · 成本:低
  - 视觉收益：逐字出现、字符随机跳变后定型（解码感）
  - 关键约束：必须**预留最终宽度**避免布局跳动；速度不能太慢（>40 字/秒）
  - 同族拓展：scramble/decode effect、光标闪烁、`ch` 单位控制宽度
  - 提示词片段：`标题用解码效果：随机字符跳变 3 次后定型，逐字错峰 30ms；容器预留最终尺寸`

- **文字跟随与磁吸** · L5 · 进阶 · 成本:低
  - 视觉收益：字母对鼠标产生个体反应（推开/吸引/放大）
  - 同族拓展：见 `R11·F1` 磁吸、逐字符 DOM 拆分的性能考量（用 transform 不用 layout 属性）
  - 提示词片段：`标题各字母按到光标距离做位移（上限 8px）与字重变化；只用 transform 保证性能`

- **滚动驱动排印** · L5 · 进阶 · 成本:低
  - 视觉收益：滚动时字重/字宽/字距连续变化，把滚动可视化
  - 同族拓展：`animation-timeline: view()` + `font-variation-settings`
  - 提示词片段：`大标题的 wdth 与 wght 随滚动进度变化（animation-timeline: view()）`

## I7 文本节奏与可读性（Rhythm & Readability）

- **模块化字阶（Type Scale）** · L1 · 基础 · 成本:低
  - 视觉收益：字号按固定比例递增，天然和谐
  - 参考比例：1.2（微弱）/ 1.25（major third，常用）/ 1.333（perfect fourth）/ 1.5（强）/ 1.618（黄金，戏剧）
  - 同族拓展：见 `R1·G7` 模块化标尺、Utopia 流式字阶（视口与比例双维度）
  - 提示词片段：`字阶用 1.333 比例，6 级；每级用 clamp() 在视口间流式过渡`

- **层级数量控制（Hierarchy Count）** · L1 · 基础 · 成本:低
  - 视觉收益：层级超过 3–4 级就失效。**宁可少不可多**
  - 提示词片段：`正文区只用 3 级层级（标题/正文/辅助）；不够用时靠间距与色彩区分而非新增字号`

- **段落节奏（Paragraph Rhythm）** · L1 · 进阶 · 成本:低
  - 视觉收益：段落长短交错（一句话的短段 + 4 行的长段），阅读有呼吸
  - 同族拓展：段落间距（`margin` 用行高倍数）vs 首行缩进（**二者只选一个**）、见 `R1·G3` 间距节奏
  - 提示词片段：`段落长短交错；段间距用 1 个行高（不要同时用首行缩进与段间距）`

- **强调的层级（Emphasis Hierarchy）** · L5 · 基础 · 成本:低
  - 视觉收益：加粗 > 色彩 > 斜体 > 下划线 > 高亮。**同一段落里不要用超过 2 种强调方式**
  - 关键约束：`text-decoration` 用 `text-underline-offset` + `text-decoration-thickness` 调整才好看；避免默认下划线贴字
  - 提示词片段：`链接下划线用 text-underline-offset:0.2em + thickness:1px + skip-ink:auto；一段内强调方式不超过 2 种`

- **首字下沉与装饰（Drop Cap）** · L3 · 进阶 · 成本:低
  - 视觉收益：编辑感与仪式感
  - 同族拓展：`::first-letter`、`initial-letter` 属性（真正的首字下沉，跨行对齐）
  - 提示词片段：`长文首段用 initial-letter: 3 做首字下沉（不用手调 float+line-height）`

- **引用与引号（Blockquote & Quotes）** · L3 · 进阶 · 成本:低
  - 视觉收益：引用块是天然的"呼吸点"与视觉变化
  - 同族拓展：`quotes` 属性、悬挂引号（见 `R10·I3`）、超大装饰引号、左侧边线 vs 缩进 vs 变字体
  - 提示词片段：`引用块换字体族（正文无衬线→引用衬线）+ 悬挂引号 + 左侧 2px 边线；不要只是斜体`

- **暗色模式的排印补偿（Dark Mode Type）** · L5 · 进阶 · 成本:低
  - 视觉收益：浅色文字在深底上视觉显粗（光渗效应），需要降字重
  - 同族拓展：见 `R10·I1` GRAD 轴、`R2·K1` 光学错觉、`-webkit-font-smoothing: antialiased`（深色模式下更细）
  - 提示词片段：`深色模式下正文字重降 1 档（400→350 或用 GRAD -25）；文字色不用纯白用 #E8E8E8 级`

## I8 canvas / WebGL 内的文字（Text in Canvas）

**把文字放进 shader 世界的正确方式。** 也是"什么时候不该这么做"。

- **优先原则：文字不进 canvas** · L5 · 基础 · 成本:低
  - 关键约束：canvas 内的文字不可选中、不可搜索、不被读屏器读、缩放会糊。**除非文字本身是视觉主体，否则永远用 DOM 层叠在 canvas 之上**
  - 提示词片段：`所有可读文字用 DOM 层置于 canvas 之上；canvas 内只放作为图形的装饰性文字，并提供 aria-label 与文字版内容`

- **SDF / MSDF 文字（Signed Distance Field Text）** · L3 · 电影级 · 成本:中
  - 视觉收益：单张图集实现任意缩放清晰的文字，可加描边/发光/变形/挤出
  - 强度档位：SDF（单通道，圆角处略糊）/ MSDF（多通道，尖角也锐利，推荐）
  - 同族拓展：msdf-bmfont-xml、three-msdf-text、troika-three-text（最省事）、`fwidth` 抗锯齿
  - 提示词片段：`3D 文字用 MSDF 图集（troika-three-text），用 fwidth 做解析抗锯齿；支持描边与发光`

- **文字转几何（Text to Geometry）** · L3 · 进阶 · 成本:中
  - 视觉收益：真 3D 挤出文字，可以有厚度、有材质、有物理
  - 同族拓展：TextGeometry（three.js）、opentype.js 取路径、挤出 + 倒角、性能（顶点数很高）
  - 提示词片段：`标题转 3D 挤出几何（倒角 0.02），PBR 金属材质；仅用于一个词，不用于长文本`

- **DOM 文字 + shader 背景的配合** · L5 · 基础 · 成本:低
  - 视觉收益：兼得可访问性与视觉效果
  - 同族拓展：`mix-blend-mode` 让 DOM 文字与 canvas 混合（见 `R9·H2`）、`background-clip:text` 采样 canvas、canvas 作为 CSS 背景
  - 提示词片段：`DOM 文字用 mix-blend-mode:difference/screen 与下方 canvas 产生光学关系，而不是把文字画进 canvas`

- **文字驱动 shader（Text as Mask/Input）** · L3 · 进阶 · 成本:中
  - 视觉收益：把文字渲染到纹理，作为 shader 的遮罩/密度场/发射源
  - 同族拓展：offscreen canvas 渲染文字 → texture、文字形状作为粒子发射器、文字作为流体障碍
  - 提示词片段：`把标题渲染到离屏 canvas 作为纹理，用它作为粒子发射源/流体密度场的初始形状`

## I 组 · 组合速查

| 想要的效果 | 组合 |
|---|---|
| 纯排印的高级页面 | `R10·I4` 巨型排印 + `R10·I3` 字距行高全套 + `R10·I7` 字阶 + `R1·G3` 大留白 |
| 专业编辑感 | `R10·I1` 衬线+opsz + `R10·I2` oldstyle数字+smallcaps + `R10·I7` 首字下沉 + `R10·I3` 悬挂标点 |
| 技术精密感 | `R10·I1` 等宽字体 + `R10·I2` tnum+slashed-zero + `R10·I3` 基线网格 + `R10·I7` 三级层级 |
| 中文排版做对 | `R10·I5` 全套（混排间距/palt/禁则/行高1.75/子集化） |
| 标题的免费美化 | `R10·I3` text-wrap:balance + `R10·I3` 负字距 + `R10·I3` 行高 1.0 + `R10·I1` opsz |
| 动态排印奇观 | `R10·I6` 字重脉动 + `R10·I6` 滚动驱动 + `R10·I4` 文字填充 |
| 文字作为视觉主体 | `R10·I4` 巨型 + `R10·I4` 描边镂空交替 + `R10·I4` 文字填图 + `R10·I8` mix-blend-mode |
| 3D 文字 | `R10·I8` MSDF（长文本）或 `R10·I8` 挤出几何（单词）+ `R5·C4` PBR |

**常见坑（按出现频率）**：
- 标题行高用了 1.5 → `R10·I3` 标题必须 1.0–1.25
- 所有字号用同一个字距 → `R10·I3` 字距必须随字号反向调整
- 正文通栏满屏宽 → `R10·I3` 缺 max-width: 68ch
- 中英文挤在一起 → `R10·I5` 缺混排间隙
- 中文行高照搬西文 1.5 → `R10·I5` 中文要 1.7–1.9
- 表格数字宽度跳动 → `R10·I2` 缺 tabular-nums
- 全大写句子挤成一团 → `R10·I2` 缺 letter-spacing
- 用 transform:scaleX 压缩标题 → `R10·I1` 应用 wdth 轴
- 用 skew 伪造斜体 → `R10·I1` 应用真 ital/slnt
- 深色模式文字显粗 → `R10·I7` 缺字重补偿
- 中文字体加载 8MB → `R10·I5` 缺子集化
- 按钮里文字垂直不居中 → `R10·I3` 用 text-box-trim
- canvas 里放了可读文字 → `R10·I8` 违反优先原则
- 字体用了 4 个字族 → `R10·I1` 限 2 族

> **I 组的检验方法**：把页面截图，只留文字（去掉所有图片、颜色、特效）。如果只剩黑白文字还好看，排印过关了。如果不好看，说明你的"好看"全靠特效撑着。
