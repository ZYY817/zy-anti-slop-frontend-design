# B88 · 界面文案词库（UX Writing 决策对象）

> 六个决策对象：行描述信息位 / 利益 vs 对象 / CTA 文案 / 空态解剖 / 错误两句式 / 人味检查。
> case07 终审第 7 轮点名"展示的文案内容信息没处理好"——本词补全库的文案层空白。全部规则来自 research/E 四家体系收敛（Polaris/Mailchimp/GOV.UK/Google）+ canonical 案例。

| 对象 | 定义与决策点 | 验收句 | prompt 用法 | 来源 |
|---|---|---|---|---|
| **行描述信息位** | 设置行/列表行的描述文字必须含**原因/后果/去向**至少其一；只重述字段名=失败（"自动保存：开启自动保存"=零信息）。自查：删掉这句用户失去什么？答案为空则删 | 逐行查：描述给出新信息；无"字段名复读机" | "每行描述给原因/后果/去向其一" | Carbon/Atlassian + Polaris "weigh every word" |
| **利益 vs 对象** | 措辞指向用户得到的**结果**而非对象本身：canonical 案例 "Book a room"→"Check availability" 参与率 +17%——描述能力/结果胜过描述动作/对象 | CTA 与标题读得出"我会得到什么"；仅复述对象=返工 | "写结果不写对象（Check availability 型）" | Google UX writing（UX Encyclopedia） |
| **CTA 文案** | 祈使动词+名词 ≤2 词（中文 ≤4 字）："Build next week's rota"型；禁"确定/OK/好的"类无信息量词；全程同名一致（Publish→Published 不混用）；破坏性动作也写清后果（"永久删除"非"确认"） | 每个按钮读得出点了会发生什么；无单字确认语 | "CTA=动词+名词≤2词，禁确定/OK" | Atlassian/GitLab/Vercel guidelines |
| **空态解剖** | 三件套公式（Atlassian/Carbon/GitLab/Acorn 一致）：**标题**正向陈述 ≤5 词（"Start by adding X"/"还没有 X"，禁"没有/无"开头，句尾不加句号）+**正文**1-2 句（为什么空+去哪，不重复标题）+**CTA**动词起 ≤2 词；语气按场景分（首用=教育激励/完成=庆祝/无结果=中性） | 每个空态三件齐；标题正向非否定；CTA 动词开头 | "空态=正向标题+去向+动词CTA" | Carbon/Acorn/Atlassian/GitLab |
| **错误两句式** | "发生了什么 + 怎么修"两句封顶；用户词汇非系统词汇（"That card was declined"非"Transaction error 4021"）；不归咎（"that email needs an @"非"你输错了"）；错误码可附但不能当主语 | 每条错误读完知道下一步；无裸错误码；无指责主语 | "错误=发生了什么+怎么修" | Polaris error messages + UX Encyclopedia |
| **前置加载与人味** | 区分性词放句首（F-pattern：用户只扫前 1-2 词——"Delete account"非"Would you like to…"）；朗读测试：不像人说的话就改；7 年级阅读级；clear>clever>cute（个性与清晰冲突时清晰赢）；Jenga 删法：每个词称重，删到会塌为止 | 每行前 2 词有信息量；朗读不拗口；无填充词 | "区分词放句首；朗读测试" | NN/g F-pattern + Polaris/Mailchimp |

## 附：文案病名速查（research/F·F 族）

- **空词表**（密度即指纹）：Supercharge/Unlock/Unleash/Seamless/Empower/Revolutionize/All-in-one/World-class/Best-in-class/Delve/Leverage/Streamline/Utilize + 感叹号
- **失重标题**："Build faster. Ship smarter."、"Transform your X with Y"——可形容任何产品的标题=零信息；三拍排比（"Build, ship, scale"）永不破节奏
- **破折号密+否定枢轴**：em-dash 密度超人类基线、"It's not just X. It's Y."——LLM 句法指纹
- **2026 buzz 腔**："agents"/"frontier"/"infrastructure/intelligence/platform"——写能力别写范畴词
- **假信任层**：查无此人的"S"（"Sarah Chen"）/编合规徽章/John Doe/lorem 残留——伪造=强 tell

## 边界

文案质量本体（"这句写得好不好"）部分归人审——规则管"有信息、无腔调、指结果"，不管"动人"。语气选型（教育/庆祝/中性）随场景，错的是场景错配不是语气本身。
