# B35 · 创意方法论

> 从"不知道做什么样"到"知道做什么样"的完整流程。
> 顶级设计不是灵感闪现,是有方法的探索。

---

## 一、创意流程五阶段

```
1. 输入(Input)      — 收集参考、理解语境
2. 发散(Diverge)    — 大量探索,不判断
3. 收敛(Converge)   — 挑选方向,做决定
4. 深化(Refine)     — 打磨细节
5. 验证(Validate)   — 测试、迭代
```

**大多数人跳过 1 和 2,直接做 4 → 结果平庸。**

---

## 二、阶段 1:输入(参考收集)

### 心情板(Mood Board)★ 必做
不是"好看的图集合",是**提炼视觉方向的工具**。

**做法**:
1. 收集 15-30 张图(不只是网页——摄影/建筑/包装/时尚/自然都可以)
2. **删到只剩 5-8 张**(最难但最关键的一步)
3. 从留下的图提炼共同点:
   - 色调是什么?
   - 质感是什么?
   - 情绪是什么?
   - 构图特征是什么?
4. 写出 3 个气质关键词

**工具**:Cosmos / Savee / Pinterest / Are.na / Figma / Milanote

### 参考的三个层次
```
层次 1:直接参考(同类产品)— 学惯例,别抄
层次 2:跨界参考(其他行业)— 找差异化灵感
层次 3:非设计参考(自然/建筑/艺术/电影)— 找独特气质
```
**只看层次 1 → 永远做出竞品的样子。**

### 竞品视觉审计(Visual Audit)
列出 5 个竞品,记录:
- 主色 / 字体 / 布局范式 / 气质关键词
- **找出共同点** = 行业惯例(要遵守的部分)
- **找出空白** = 差异化机会(要突破的部分)

例:
```
5 个竞品都用蓝色 + 圆角卡片 + Inter
→ 惯例:布局范式、组件模式(遵守)
→ 空白:颜色(可以用非蓝)、字体(可以用衬线)
```

### 关键词墙(Keyword Wall)
不写"好看",写具体的:
```
克制 / 精密 / 冷峻 / 数据感 / 实验室 / 有重量 / 哑光
```
5-10 个词,然后**挑 3 个作为核心**。

## 三、阶段 2:发散(不判断地探索)

### 快速草图(Crazy 8s)
8 分钟画 8 个不同的布局方案。**强制数量,不追求质量。**
目的:跳出第一个想法(第一个想法通常最平庸)。

### 极端化练习(Extremes)
对每个维度做极端版本:
```
极简版:只有文字,零装饰
极繁版:装饰满屏
极大版:字号 200px
极小版:字号 12px
极空版:90% 留白
极密版:信息塞满
```
**极端版本会暴露"什么才是核心"。** 然后回到中间地带。

### 变量矩阵(Variable Matrix)
列出关键变量,组合出方案:
```
        深色    浅色
巨型字   A       B
3D 主视觉 C       D
数据图表  E       F
```
6 个组合,快速评估哪个方向对。

### 借用异域(Domain Transfer)
问:如果这是 __ 会怎么设计?
```
如果这是一本杂志?
如果这是一个终端?
如果这是一间美术馆?
如果这是一台仪器?
如果这是苹果做的?
如果这是 90 年代做的?
```
**强制跳出惯性思维。**

### 限制驱动创意(Constraints)
故意加限制:
```
只能用黑白 → 逼你靠排版和布局
只能用一种字号 → 逼你靠字重和间距
不能用图片 → 逼你靠类型和图形
只能用 3 个元素 → 逼你极致提炼
```
**限制是创意的催化剂,不是障碍。**

## 四、阶段 3:收敛(做决定)

### 方案对比表
```
        | 方案A | 方案B | 方案C
气质匹配 | ★★★  | ★★    | ★★★★
差异化   | ★★    | ★★★★  | ★★★
可实现性 | ★★★★  | ★★    | ★★★
用户理解 | ★★★★  | ★★★   | ★★
```
按权重打分,不靠"感觉哪个好"。

### 眯眼测试筛选
把所有方案缩小到 200px 宽并排看:
- 哪个层级最清晰?
- 哪个最有辨识度?
- 哪个记得住?

### A/B 方案取长补短
不一定二选一,可以:方案 A 的布局 + 方案 B 的配色。

---

## 五、阶段 4:深化(打磨)

### 从粗到细的顺序
```
1. 布局骨架(灰块占位,不管颜色字体)
2. 层级关系(字号阶梯 + 间距系统)
3. 色彩系统(先中性色,再加主色)
4. 字体细节(负字距 / 行高 / 特性)
5. 光影质感(阴影 / 噪点 / 材质)
6. 动效(入场 / 悬浮 / 微交互)
7. 状态(hover / loading / empty / error)
8. 精工细节(对齐 / 光学调整 / 圆角层级)
```
**顺序错了会反复重做。**

### 打磨的判断:20 分钟规则
一个界面看 20 分钟还看不出问题 = 该找别人看 / 该放一天再看。

### 反向检查(Reverse Check)
- 删掉一个元素,变差了吗?没变差 → 该删
- 缩小一个元素,还够醒目吗?够 → 该缩小
- 去掉这个动效,信息还传达吗?能 → 该去掉

## 六、阶段 5:验证

### 5 秒测试
给人看 5 秒,然后问:
- 这是什么产品?
- 最醒目的是什么?
- 你会点哪里?

答不对 → 首屏有问题。

### 眯眼测试
眯眼看,应该看到:一个主块 + 一个次块 + 清晰留白。

### 单一职责测试
每个 section 只做一件事?

### 拿掉 Logo 测试
去掉 logo 还认得出是你吗?认不出 → 缺差异化。

### 竞品并排测试
和 3 个竞品并排放,你的能被认出吗?

## 七、从模仿到超越四阶段

```
阶段 1:抄(Copy)
  照着做,理解手法
  → 学会"怎么做到"

阶段 2:改(Modify)
  换颜色/字体/布局参数
  → 学会"变量在哪"

阶段 3:融(Synthesize)
  A 的布局 + B 的配色 + C 的动效
  → 学会"组合创新"

阶段 4:创(Originate)
  从概念出发,手法为概念服务
  → 学会"从内而外"
```

**大多数人停在阶段 2(换色改字),所以永远是"像某某"。**

**关键跃迁**:阶段 3 → 4 的转折点是**先有概念,再选手法**,而不是先看到好看的手法然后套上去。

## 八、创意的常见卡点与破法

| 卡点 | 破法 |
|---|---|
| 不知道做什么样 | 做心情板 → 提炼 3 个气质词 |
| 做出来像竞品 | 看跨界参考(层次 2-3) |
| 感觉平庸但不知道哪里 | 做极端版本对比 |
| 改了半天没变好 | 顺序错了,回到布局层重做 |
| 想不出创意 | 加限制(只能黑白/只能一种字号) |
| 有想法但落地差 | 缺工艺细节(查 B17) |
| 好看但没个性 | 缺概念,补第 0 层立意 |
| 到处都想突出 | 强制排序,只留一个焦点 |

## 九、AI 时代的创意流程调整

传统流程 + AI 的最佳结合:

```
1. 输入   — 人做(心情板/参考/概念)★ AI 帮不了
2. 发散   — AI 做(快速出 6-10 个方向)
3. 收敛   — 人做(判断哪个对)★ AI 帮不了
4. 深化   — AI + 人(AI 执行,人给规格)
5. 验证   — 人做 + AI 自查
```

**结论**:AI 极大加速阶段 2 和 4。但阶段 1(概念)和 3(判断)必须人做。
**这就是"品味"仍然值钱的原因。**

### 用 AI 做发散
```
"给我 6 个完全不同方向的 hero 布局方案,
每个方案用一句话概括视觉概念,
不要都是'居中大标题+CTA'的变体。
方向要有:一个极简的、一个数据密集的、
一个巨型排版的、一个 3D 主视觉的、
一个非对称的、一个编辑感的。"
```

### 用 AI 做自查
```
"用眯眼测试评估这个设计的视觉层级"
"这个设计像不像通用 AI 生成的?哪里像?"
"如果去掉 Logo,还有辨识度吗?"
```

## 十一、Prompt 模板(创意探索阶段)

```
【创意探索请求】

背景:
- 产品:{什么}
- 用户:{谁}
- 目标:{什么}

我的心情板提炼:
- 气质三词:{克制 / 精密 / 冷峻}
- 参考:{A 的排版} + {B 的暗色} + {C 的数据感}
- 反面:不要 {通用 SaaS 蓝 / 圆角卡片堆砌}

请给我 6 个完全不同方向的方案,
每个用 3 句话描述视觉概念(不要写代码):
1. 视觉概念是什么
2. 主视觉手段靠什么
3. 最独特的一点是什么

要求方向多样:
- 一个极简排版驱动
- 一个数据密集
- 一个巨型字体
- 一个 3D/生成艺术
- 一个非对称编辑感
- 一个大胆反常规

不要都是"居中标题+CTA"的变体。
```

## 检验清单

- [ ] 做了心情板并提炼出 3 个气质词
- [ ] 参考包含跨界/非设计来源(不只是竞品)
- [ ] 做了竞品视觉审计(找惯例和空白)
- [ ] 探索了 ≥5 个不同方向(不是第一个想法)
- [ ] 做过极端版本练习
- [ ] 用打分表而非"感觉"做收敛
- [ ] 深化顺序是布局→层级→色彩→字体→质感→动效→状态
- [ ] 做了 5 秒测试
- [ ] 做了拿掉 Logo 测试
- [ ] 概念先于手法(不是看到好手法才套)
