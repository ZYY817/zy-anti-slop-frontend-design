# B54 · 品牌视觉识别系统

> 界面好看是本事,界面「一看就知道是谁家的」才是品牌。
> 品牌识别系统不是一个 Logo + 一个主色,而是一整套**可复制、可扩展、可审计**的视觉语法。
> 顶级产品的秘密:把品牌拆成 Token,让每个像素都在说同一句话。
> 这份文档拆的是:从 Logo 规范到 tone of voice 的视觉化,再到一致性审计的完整链路。

## 二、Logo 使用规范

### 2.1 净空区(Clear Space)

**规则**:以 Logo 内某个元素为度量单位定义净空。

```
    ↕ X
  ┌─────────────────┐
X │   [LOGO]        │ X      X = Logo 高度的 50%
  └─────────────────┘        (或 Logo 中字母 "o" 的高度)
    ↕ X
```

```css
.brand-logo {
  --logo-height: 32px;
  --clear-space: calc(var(--logo-height) * 0.5);

  height: var(--logo-height);
  padding: var(--clear-space);
  box-sizing: content-box;
}
```

**精工细节**:
- 净空区内不能有任何其他元素(文字/图形/边框)
- 常见度量:Logo 高度的 50%、字母 x-height、图形宽度的 1/4
- 在导航栏中,净空可折让至 0.25×(空间紧张时的实用妥协)

### 2.2 最小尺寸

| 使用场景 | 最小高度 | 说明 |
|---|---|---|
| 网页导航栏 | 24px | 低于此高度细节丢失 |
| 移动端 | 20px | 用简化版 Logomark |
| Favicon | 16px | 只用图形符号,不带文字 |
| App 图标 | 1024px 源文件 | 输出多尺寸,每档单独优化 |
| 印刷品 | 10mm 宽 | 印刷网点限制 |

### 2.3 响应式 Logo 系统

```
全尺寸(≥ 200px 宽):  [图形] Brand Name  Slogan
中尺寸(120-200px):    [图形] Brand Name
小尺寸(48-120px):     [图形] BN
极小(< 48px):        [图形]
```

```css
/* 用容器查询切换 Logo 版本 */
.logo-wrap { container-type: inline-size; }

.logo-full { display: block; }
.logo-compact,
.logo-mark { display: none; }

@container (width < 200px) {
  .logo-full { display: none; }
  .logo-compact { display: block; }
}

@container (width < 100px) {
  .logo-compact { display: none; }
  .logo-mark { display: block; }
}
```

**或者用 SVG 内部媒体查询(单文件方案)**:
```html
<svg viewBox="0 0 200 40">
  <style>
    .wordmark { display: none; }
    @media (min-width: 120px) { .wordmark { display: inline; } }
  </style>
  <g class="mark">...</g>
  <g class="wordmark">...</g>
</svg>
```

### 2.4 Logo 禁忌清单

```
❌ 拉伸变形(非等比缩放)
❌ 旋转任意角度
❌ 加投影/描边/发光(除品牌指南明确允许)
❌ 改变颜色(除规定的单色/反白版)
❌ 在复杂背景上直接放(可读性差)
❌ 重新排列组合元素位置
❌ 加边框/圆角容器(除非是明确的 avatar 场景)
❌ 与其他图形距离过近(侵入净空区)
❌ 在与品牌色相近的背景上使用彩色版
❌ 用低分辨率位图(必须用 SVG)
```

### 2.5 深浅背景适配

```css
/* 亮色背景 → 彩色/深色 Logo */
.logo { color: var(--brand-primary); }

/* 暗色背景 → 反白 Logo */
@media (prefers-color-scheme: dark) {
  .logo { color: oklch(98% 0 0); }
}

/* 图片背景 → 加保护层 */
.logo-on-image {
  filter: drop-shadow(0 1px 3px oklch(0% 0 0 / 0.4));
}

/* 或加半透明底板 */
.logo-badge {
  background: oklch(100% 0 0 / 0.9);
  backdrop-filter: blur(8px);
  padding: 8px 12px;
  border-radius: 8px;
}
```

## 三、品牌色系统延伸

### 3.1 从单一主色到完整色板

**输入**:一个品牌主色 → **输出**:一套可用的完整系统

```
品牌主色  ────┬──→ 9 级色阶(50-900)      用于状态/背景/边框
             ├──→ 色相偏移辅助色           用于分类/图表
             ├──→ 语义色重校              success/warning/error 与主色协调
             ├──→ 中性色带色温            灰色不是纯灰,带一丝品牌色相
             └──→ 暗色模式重校            降饱和 + 提亮度
```

### 3.2 用 OKLCH 生成色阶

```css
:root {
  /* 品牌主色: oklch(55% 0.20 265) */
  --brand-h: 265;      /* 色相固定 */

  --brand-50:  oklch(97% 0.02 var(--brand-h));
  --brand-100: oklch(94% 0.04 var(--brand-h));
  --brand-200: oklch(88% 0.08 var(--brand-h));
  --brand-300: oklch(80% 0.12 var(--brand-h));
  --brand-400: oklch(68% 0.17 var(--brand-h));
  --brand-500: oklch(55% 0.20 var(--brand-h));  /* 基准 */
  --brand-600: oklch(47% 0.19 var(--brand-h));
  --brand-700: oklch(39% 0.16 var(--brand-h));
  --brand-800: oklch(31% 0.12 var(--brand-h));
  --brand-900: oklch(23% 0.08 var(--brand-h));
}
```

**关键规律**:
- 两端(50/900)饱和度必须降低,否则脏
- 中段(400-600)饱和度最高
- 亮度递减不是线性:浅色段间隔小(97→94→88),深色段间隔大

### 3.3 带品牌色温的中性色

```css
:root {
  /* 不是纯灰,带 0.3%-1.2% 的品牌色相 chroma */
  --gray-50:  oklch(98.5% 0.003 265);
  --gray-100: oklch(96%   0.005 265);
  --gray-200: oklch(92%   0.007 265);
  --gray-300: oklch(85%   0.009 265);
  --gray-400: oklch(70%   0.011 265);
  --gray-500: oklch(56%   0.012 265);
  --gray-600: oklch(45%   0.011 265);
  --gray-700: oklch(35%   0.009 265);
  --gray-800: oklch(25%   0.007 265);
  --gray-900: oklch(16%   0.005 265);
}
```

**为什么**:纯灰(chroma=0)与品牌色并置时会显得"死"。加一点点品牌色相让整体和谐。这是高级感的隐形来源。

### 3.4 语义色与品牌色协调

```css
/* ❌ 直接用默认语义色 — 与品牌不搭 */
--error: #FF0000;
--success: #00FF00;

/* ✅ 语义色的明度饱和度对齐品牌,只改色相 */
:root {
  /* 品牌主色相 265(蓝紫) */
  --success: oklch(60% 0.16 150);  /* 绿 */
  --warning: oklch(72% 0.16 75);   /* 橙 */
  --error:   oklch(58% 0.20 25);   /* 红,饱和度与 brand-500 一致 */
  --info:    oklch(60% 0.15 245);  /* 蓝,靠近品牌色相 */
}
```

**核心原则**:语义色的**明度和饱和度**对齐品牌色,只有**色相**不同。这样它们看起来是"一家人"。

### 3.5 品牌色比例分配(60-30-10 法则)

```
60%  中性色(背景/大面积区域)
30%  品牌辅助色(卡片/区块/次要元素)
10%  品牌主色(CTA/强调/活跃状态)
```

**误区**:品牌主色到处铺 → 反而失去强调力。**主色越吝啬,越有力量。**

## 四、品牌字体系统

### 4.1 字体角色分配

| 角色 | 用途 | 特征要求 |
|---|---|---|
| **Display** | 巨型标题/Hero | 有个性,可以夸张,大字才好看 |
| **Heading** | 各级标题 | 清晰有力,字重丰富 |
| **Body** | 正文 | 极致易读,x-height 高,字腔开放 |
| **Mono** | 代码/数字 | 等宽,0 有斜线或点,易区分 1lI |
| **Accent** | 引用/装饰 | 可选,增加编辑感(衬线/手写) |

### 4.2 字体栈规范

```css
:root {
  --font-display: "Brand Display", "Söhne", -apple-system,
                  "PingFang SC", "Microsoft YaHei", sans-serif;

  --font-body: "Inter", -apple-system, BlinkMacSystemFont,
               "Segoe UI", "PingFang SC", "Hiragino Sans GB",
               "Microsoft YaHei", sans-serif;

  --font-mono: "JetBrains Mono", "SF Mono", "Menlo",
               "Cascadia Code", monospace;
}
```

**中英混排关键**:英文字体放前面,中文字体放后面。让英文用英文字体渲染,中文自动降级到中文字体。

### 4.3 字号阶梯(Type Scale)

```css
:root {
  /* 1.25 倍率(Major Third),流体缩放 */
  --text-xs:   clamp(0.75rem, 0.73rem + 0.1vw, 0.8125rem);   /* 12-13 */
  --text-sm:   clamp(0.875rem, 0.85rem + 0.12vw, 0.9375rem); /* 14-15 */
  --text-base: clamp(1rem, 0.97rem + 0.15vw, 1.0625rem);     /* 16-17 */
  --text-lg:   clamp(1.125rem, 1.08rem + 0.22vw, 1.25rem);   /* 18-20 */
  --text-xl:   clamp(1.375rem, 1.3rem + 0.37vw, 1.625rem);   /* 22-26 */
  --text-2xl:  clamp(1.75rem, 1.6rem + 0.73vw, 2.25rem);     /* 28-36 */
  --text-3xl:  clamp(2.25rem, 1.98rem + 1.34vw, 3.125rem);   /* 36-50 */
  --text-4xl:  clamp(2.75rem, 2.1rem + 3.2vw, 4.5rem);       /* 44-72 */
  --text-5xl:  clamp(3.5rem, 2.2rem + 6.5vw, 7.5rem);        /* 56-120 */
}
```

### 4.4 字重语义化

```css
:root {
  --weight-light:    300;  /* 巨型标题的副标(与粗标形成极端对比) */
  --weight-regular:  400;  /* 正文 */
  --weight-medium:   500;  /* 小标题/按钮/导航 */
  --weight-semibold: 600;  /* 各级标题 */
  --weight-bold:     700;  /* 强调 */
  --weight-black:    800;  /* Hero 标题 */
}
```

**中文特殊处理**:中文字重视觉上比英文重。同样 600,中文看起来更粗。
```css
:lang(zh) h1 { font-weight: 600; }  /* 英文用 700 时中文用 600 */
```

### 4.5 品牌字体加载策略

```css
@font-face {
  font-family: "Brand Display";
  src: url("/fonts/brand-display.woff2") format("woff2");
  font-weight: 400 800;              /* 可变字体范围 */
  font-display: swap;                /* 先显示后备字体 */
  unicode-range: U+0000-00FF;        /* 只加载拉丁字符,减小体积 */
}

/* 减少 FOUT 跳动:后备字体度量对齐 */
@font-face {
  font-family: "Brand Fallback";
  src: local("Arial");
  ascent-override: 92%;
  descent-override: 24%;
  size-adjust: 103%;
}
```

## 五、图形语言(Graphic Language)

### 5.1 形状 DNA

品牌的形状语言应该**统一到一个基因**:

| 品牌气质 | 圆角策略 | 线条策略 | 形状偏好 |
|---|---|---|---|
| **友好/亲和** | 大圆角 16-24px | 圆头线端,粗线 2-3px | 圆形/胶囊/blob |
| **专业/可靠** | 中圆角 6-8px | 方头线端,细线 1.5px | 矩形/直角 |
| **锐利/科技** | 小圆角 2-4px 或 0 | 尖角连接,极细 1px | 斜切角/多边形 |
| **奢华/高端** | 0 或极小 2px | 极细 0.5-1px | 长方形/严格几何 |
| **有趣/年轻** | 混合圆角(不对称) | 手绘感变宽线条 | 不规则/有机形 |

```css
/* 圆角 Token 系统 */
:root {
  --radius-xs:   4px;
  --radius-sm:   6px;
  --radius-md:   10px;
  --radius-lg:   16px;
  --radius-xl:   24px;
  --radius-full: 9999px;
}

/* 嵌套圆角公式: 外圆角 = 内圆角 + padding */
.card {
  --card-padding: 16px;
  border-radius: calc(var(--radius-sm) + var(--card-padding));
  padding: var(--card-padding);
}
.card > .inner { border-radius: var(--radius-sm); }
```

### 5.2 品牌图案(Pattern)

```css
/* 品牌点阵图案 */
.brand-pattern-dots {
  background-image: radial-gradient(
    circle at 1px 1px,
    var(--brand-200) 1px,
    transparent 0
  );
  background-size: 16px 16px;
}

/* 品牌网格 + 边缘羽化 */
.brand-pattern-grid {
  background-image:
    linear-gradient(var(--gray-100) 1px, transparent 1px),
    linear-gradient(90deg, var(--gray-100) 1px, transparent 1px);
  background-size: 32px 32px;
  mask-image: radial-gradient(ellipse 80% 50% at 50% 0%, black 40%, transparent 100%);
}

/* 品牌斜线 */
.brand-pattern-stripes {
  background-image: repeating-linear-gradient(
    -45deg,
    var(--brand-100) 0 2px,
    transparent 2px 10px
  );
}
```

### 5.3 图标系统规范

```
风格:      线性 / 填充 / 双色 / 渐变(选一,不混)
线宽:      1.5px(小)/ 2px(标准)/ 2.5px(粗)
网格:      24×24 基准,内容区 20×20(留 2px 边距)
线端:      round / butt(与品牌形状 DNA 一致)
圆角:      内部圆角 2px(与品牌小圆角一致)
光学尺寸:  16 / 20 / 24 / 32 / 40,每档单独绘制不缩放
```

```css
.icon {
  width: 20px;
  height: 20px;
  stroke-width: 1.5;
  stroke-linecap: round;
  stroke-linejoin: round;
  fill: none;
  stroke: currentColor;   /* 继承文字色,自动适配主题 */
  flex-shrink: 0;         /* 防止 flex 布局中被压扁 */
}
```

### 5.4 插画风格规范

```
✓ 定义 3-5 条硬规则:
  - 线条:  有轮廓线 / 无轮廓线
  - 配色:  只用品牌色板中的 X 个色
  - 人物:  有面部 / 抽象无面部 / 只有剪影
  - 透视:  平面 / 等距 2.5D / 透视
  - 细节:  极简符号 / 中等 / 丰富场景

✗ 不允许:
  - 混用不同风格的插画
  - 用免费素材库的通用插画(一眼假)
  - 插画配色超出品牌色板
```

### 5.5 摄影风格规范

```
色调:  暖调 / 冷调 / 中性 → 统一后期(可用 CSS filter 兜底)
明度:  明亮通透 / 低调深沉
构图:  居中对称 / 三分法 / 大量留白
主题:  真实场景 / 产品特写 / 抽象材质
人物:  有人 / 无人,是否直视镜头
```

```css
/* 图片统一调色兜底 */
.brand-image {
  filter: saturate(0.9) contrast(1.05) brightness(1.02);
}

/* 品牌色调统一(双色调处理) */
.brand-image-duotone {
  filter: grayscale(1);
  mix-blend-mode: luminosity;
  background: linear-gradient(var(--brand-700), var(--brand-300));
}
```

## 六、Tone of Voice 视觉化

### 6.1 语气 → 视觉映射表

| 品牌语气 | 字体选择 | 圆角 | 色彩 | 间距 | 动效 | 图形 |
|---|---|---|---|---|---|---|
| **专业严肃** | 无衬线中性(Helvetica/Inter) | 4-6px | 低饱和 + 深色 | 紧凑规整 | 快速克制 150ms | 直线/矩形 |
| **温暖亲切** | 圆润无衬线(Nunito/Poppins) | 16-24px | 暖色调 + 中饱和 | 宽松 | 弹性 400ms | 圆形/曲线 |
| **前沿科技** | 几何无衬线(Space Grotesk) | 2-4px | 深底 + 荧光强调 | 精密 | 精确 200ms cubic | 斜切/网格 |
| **奢华高端** | 优雅衬线(Playfair/Canela) | 0-2px | 黑金/低饱和深色 | 极宽松 | 缓慢 600ms ease | 细线/极简 |

| **叛逆先锋** | 极端字重对比 | 0 | 黑白 + 一个刺激色 | 极端对比 | 突兀切换 | 粗野边框 |

## 七、品牌 Token 化(可执行的品牌)

### 7.1 三层 Token 架构

```
L1 原始层(Primitive)     — 纯值,无语义
   --blue-500: oklch(55% 0.20 265)

L2 语义层(Semantic)      — 有意义的角色
   --color-brand-primary: var(--blue-500)
   --color-text-primary: var(--gray-900)

L3 组件层(Component)     — 具体组件消费
   --button-primary-bg: var(--color-brand-primary)
   --card-border: var(--color-border-subtle)
```

### 7.2 完整品牌 Token 示例

```css
:root {
  /* ===== L1 原始层 ===== */
  --brand-h: 265;
  --blue-50:  oklch(97% 0.02 var(--brand-h));
  --blue-500: oklch(55% 0.20 var(--brand-h));
  --blue-700: oklch(39% 0.16 var(--brand-h));
  --gray-50:  oklch(98.5% 0.003 var(--brand-h));
  --gray-900: oklch(16% 0.005 var(--brand-h));

  /* ===== L2 语义层 ===== */
  --color-brand:          var(--blue-500);
  --color-brand-hover:    var(--blue-700);
  --color-brand-subtle:   var(--blue-50);
  --color-bg:             var(--gray-50);
  --color-surface:        oklch(100% 0 0);
  --color-text-primary:   var(--gray-900);
  --color-text-secondary: oklch(45% 0.011 var(--brand-h));
  --color-border:         oklch(90% 0.007 var(--brand-h));

  /* ===== 品牌形状 ===== */
  --brand-radius:       10px;
  --brand-radius-sm:    6px;
  --brand-radius-lg:    16px;
  --brand-border-width: 1px;

  /* ===== 品牌动效 ===== */
  --brand-ease:        cubic-bezier(0.4, 0, 0.2, 1);
  --brand-ease-spring: cubic-bezier(0.34, 1.56, 0.64, 1);
  --brand-duration:    200ms;

  /* ===== 品牌阴影(带品牌色相) ===== */
  --brand-shadow-sm: 0 1px 3px oklch(30% 0.02 var(--brand-h) / 0.08);
  --brand-shadow-md: 0 4px 12px oklch(30% 0.02 var(--brand-h) / 0.10);
  --brand-shadow-lg: 0 12px 32px oklch(30% 0.02 var(--brand-h) / 0.12);

  /* ===== L3 组件层 ===== */
  --button-primary-bg:     var(--color-brand);
  --button-primary-radius: var(--brand-radius);
  --card-bg:               var(--color-surface);
  --card-radius:           var(--brand-radius-lg);
  --card-shadow:           var(--brand-shadow-sm);
}

/* 暗色模式:只覆盖 L2,L1 和 L3 不动 */
@media (prefers-color-scheme: dark) {
  :root {
    --color-bg:             oklch(12% 0.005 var(--brand-h));
    --color-surface:        oklch(17% 0.007 var(--brand-h));
    --color-text-primary:   oklch(95% 0.003 var(--brand-h));
    --color-text-secondary: oklch(70% 0.008 var(--brand-h));
    --color-border:         oklch(28% 0.010 var(--brand-h));
    --color-brand:          oklch(68% 0.17 var(--brand-h)); /* 提亮降饱和 */
  }
}
```

**核心价值**:换一个品牌只需要改 `--brand-h` 和几个 L1 值,整站视觉自动跟着变。

## 八、品牌一致性审计

### 8.1 12 维度审计清单

| 维度 | 检查内容 | 常见问题 |
|---|---|---|
| **Logo** | 尺寸/净空/变体使用正确 | 拉伸变形,净空被侵入 |
| **色彩** | 所有色值来自 Token | 出现硬编码 #FF5733 |
| **字体** | 字体家族/字号来自阶梯 | 出现 15px、17px 这种非阶梯值 |
| **字重** | 只用规定的 4-6 档 | 混用 450、550 等 |
| **间距** | 4/8px 基准网格 | 出现 5px、11px、23px |
| **圆角** | 只用 Token 中的档位 | 同一页 6px/8px/10px 混用 |
| **阴影** | 统一投影系统 | 各组件投影参数不一致 |
| **图标** | 同一风格/线宽/尺寸 | 线性和填充混用 |
| **动效** | 缓动曲线/时长统一 | 有的 200ms 有的 350ms 无规律 |
| **插画** | 风格一致 | 混入素材库通用图 |
| **文案语气** | 全站语气统一 | 有的地方亲切有的地方冷硬 |
| **组件** | 同功能用同一组件 | 三个不同样式的"确认"按钮 |

### 8.2 自动化审计(像 Lint 一样查设计)

```javascript
// 检查非 4px 网格间距
function auditSpacing() {
  const violations = [];
  const props = ['paddingTop','paddingBottom','paddingLeft','paddingRight',
                 'marginTop','marginBottom','gap','rowGap','columnGap'];

  document.querySelectorAll('*').forEach(el => {
    const s = getComputedStyle(el);
    props.forEach(prop => {
      const px = parseFloat(s[prop]);
      if (px && px % 4 !== 0) {
        violations.push({ el, prop, value: px });
      }
    });
  });
  return violations;
}

// 检查圆角一致性:超过 5 种就是失控
function auditRadius() {
  const used = new Map();
  document.querySelectorAll('*').forEach(el => {
    const r = getComputedStyle(el).borderRadius;
    if (r && r !== '0px') {
      used.set(r, (used.get(r) ?? 0) + 1);
    }
  });
  return used.size > 5 ? [...used.entries()] : [];
}

// 收集全站实际使用的色值,人工比对品牌色板
function auditColors() {
  const used = new Map();
  ['color','backgroundColor','borderTopColor'].forEach(prop => {
    document.querySelectorAll('*').forEach(el => {
      const v = getComputedStyle(el)[prop];
      if (v && v !== 'rgba(0, 0, 0, 0)') {
        used.set(v, (used.get(v) ?? 0) + 1);
      }
    });
  });
  // 按使用频次排序,长尾就是野值
  return [...used.entries()].sort((a, b) => b[1] - a[1]);
}
```

### 8.3 Token 覆盖率计算

```
Token 覆盖率 = 使用 Token 的样式声明数 / 总样式声明数

健康度标准:
> 90%    优秀 — 品牌可控可换肤
80-90%   良好 — 有少量特例
60-80%   警告 — 品牌开始漂移
< 60%    危险 — 品牌系统形同虚设
```

## 十、踩坑指南

### 坑1:主色用太多,失去强调力
**症状**:整页都是品牌蓝,CTA 反而不突出。
**解法**:严格 10% 上限。主色只给最重要的一个动作。

### 坑2:纯灰配品牌色显脏
**症状**:灰色区域和品牌色区域"不像一家的"。
**解法**:灰色加 0.003-0.012 的品牌色相 chroma。

### 坑3:暗色模式主色直接复用
**症状**:亮色下好看的主色,暗底上刺眼或看不清。
**解法**:亮度提到 65-70%,饱和度降 15%。

### 坑4:圆角种类爆炸
**症状**:同一页面出现 4px/6px/8px/10px/12px/16px。
**解法**:只保留 3-4 档,写进 Token,禁止硬编码。

### 坑5:Logo 在图片上不可读
**解法**:加 drop-shadow 或半透明底板 + backdrop-filter。

### 坑6:字体加载导致布局跳动(CLS)
**解法**:`font-display: swap` + 后备字体 metric override(`size-adjust` / `ascent-override`)。

### 坑7:插画混用素材库通用图
**症状**:一眼看出"这个是免费素材库的",瞬间失去品牌感。
**解法**:要么全部自绘,要么用同一套素材并统一改色到品牌色板。

### 坑8:子品牌视觉失控
**症状**:主品牌和子品牌看起来毫无关系。
**解法**:定义"共享层"(字体+形状+间距)和"差异层"(仅主色相变化)。

### 坑9:品牌漂移无人察觉
**症状**:半年后新页面和老页面完全不像一家。
**解法**:CI 加 Token 覆盖率检查 + 视觉回归测试,PR 不达标不能合。

### 坑10:阴影用纯黑
**症状**:阴影发灰发死,不通透。
**解法**:阴影色加环境色/品牌色相。
