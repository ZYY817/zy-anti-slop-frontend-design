# B14 · 边界情况美学

> "能用"和"经得起用"的分水岭,就在边界情况。
> **业余作品在正常状态下也能好看,专业作品在崩溃时也保持体面。**

---

## 为什么边界情况最能拉开差距

Happy Path(正常场景)人人会做。但真实产品里:
- 名字可能有 50 个字
- 列表可能是空的
- 网络可能断
- 数字可能是 1,234,567,890
- 用户可能只填了一半

**AI 生成时最容易跳过这些**——它只按典型场景出图。这一份文档就是把所有边界情况穷举出来,写进 prompt。

---

## 一、空态（Empty States）★最重要

空态不是"暂无数据",是**引导用户下一步的机会**。

### 空态类型

| 类型 | 场景 | 设计要点 |
|---|---|---|
| **首次使用** | 用户还没创建任何数据 | 插图 + 引导 + 主 CTA |
| **无搜索结果** | 搜索关键词无匹配 | 建议其他关键词 + 清除搜索 |
| **筛选无结果** | 筛选条件太严 | 提示放宽 + 重置按钮 |
| **已清空** | 用户主动清完了(收件箱清空) | 庆祝 + 温暖文案 |
| **权限不足** | 用户没权限看 | 说明原因 + 申请入口 |
| **加载失败** | 网络/服务出错 | 说明 + 重试按钮 |
| **不支持** | 浏览器/设备不支持 | 说明 + 替代方案 |
| **等待中** | 数据在生成 | 进度提示 + 预期时长 |

### 空态标准结构
```
[插图或图标] — 视觉,让页面不孤零零
[标题]      — 一句话说清状态
[描述]      — 为什么空 + 能做什么(1-2 行)
[主 CTA]    — 明确的下一步
[次 CTA]    — 可选(浏览示例/查看文档)
```

### 空态文案示例
```
❌ "暂无数据"
✅ "还没有项目
    创建你的第一个项目,几秒钟就好。
    [创建项目] [查看示例]"

❌ "无结果"
✅ "没找到「Xxx」相关的内容
    试试其他关键词,或浏览全部。
    [清除搜索] [浏览全部]"
```

## 二、错误状态（Error States）

### 分级设计

| 级别 | 场景 | 视觉 | 处理 |
|---|---|---|---|
| **字段错误** | 单个输入格式错 | 红色边框 + 内联提示 | 说明格式,聚焦字段 |
| **表单错误** | 提交失败 | 顶部横条 + 各字段红色 | 汇总 + 定位错误 |
| **区块错误** | 某模块加载失败 | 该模块内错误占位 | 重试按钮,不影响其他 |
| **页面错误** | 整页失败 | 全屏错误页 | 图标 + 说明 + 返回首页 |
| **系统错误** | 服务器 500 | 全屏说明 + 联系方式 | 记录 + 通知 |
| **网络错误** | 用户断网 | 顶部横幅 + 保留状态 | 恢复后自动重连 |

### 错误页设计要点
- **别用错误代码作为标题**("500 Internal Server Error"太吓人)
- **有插图** — 缓解焦虑,不用太严肃
- **说明原因** — 用户能理解的语言
- **给出出路** — 至少一个可点击的操作
- **保留导航** — 让用户可以离开这个错误页
- **404 有个性** — 品牌感的加分项(GitHub 的 404、Airbnb 的 404)

## 三、加载状态（Loading States）

### 时长与手段

| 预计时长 | 建议手段 |
|---|---|
| <100ms | 无需 loading(用户感知不到) |
| 100-1000ms | 简单 spinner / 光标变化 |
| 1-3s | 骨架屏 / progress bar / 有动效但无进度 |
| 3-10s | 骨架屏 + 进度百分比 + 剩余时间 |
| >10s | 拆步展示 + 可后台执行 + 通知机制 |

### 加载设计层次
- **微操作**(点赞) — 无 loading,乐观 UI 立即反馈
- **列表加载** — 骨架屏,不用 spinner
- **页面切换** — 顶部进度条(NProgress 风格)
- **上传/下载** — 明确百分比 + 速度 + 剩余
- **后台任务** — 通知中心可查看

### 骨架屏原则
- **形状要像真内容**(不是随机灰块)
- **有 shimmer 动效**(告诉用户"正在动")
- **过渡到真内容 crossfade 200ms**(不硬切)
- **骨架数量与真数据相仿**(不要显示 20 条骨架结果 3 条)

## 四、极端内容（Extreme Content）

### 文本极端
| 情况 | 处理 |
|---|---|
| 超长名字("XXXXXXXXXXXXX") | 截断 + ... + tooltip 全文 |
| 单个超长单词(URL/token) | `word-break: break-all` 或换行 |
| 全大写(BIG YELL) | 视觉容忍度设计好 |
| 表情符号混排 | 字体栈支持 emoji |
| 多语言混排(中英日韩) | 字体栈覆盖 |
| RTL 语言(阿拉伯) | 支持镜像布局 |
| 空字符串 | 显示占位 / 隐藏元素 |

### 数字极端
| 情况 | 处理 |
|---|---|
| 超大数(1,234,567,890) | 缩写 "1.2B" + tooltip 全值 |
| 超小数(0.000001) | 科学计数或"< 0.01" |
| 负数 | 明确视觉(红色/括号/负号) |
| 零 | 特殊处理,不显示"$0.00" |
| 极长小数 | 保留 2-4 位 |
| 表格数字 | 用 tabular-nums 等宽 |

### 列表极端
| 情况 | 处理 |
|---|---|
| 0 条 | 空态设计(见上) |
| 1 条 | 别用复数文案("1 items") |
| 大量(1000+) | 虚拟滚动 / 分页 / 搜索优先 |
| 加载中 | 骨架屏 |
| 部分错误 | 该项显示错误,其他正常 |

### 图片极端
| 情况 | 处理 |
|---|---|
| 图片加载失败 | 占位图 + alt 文字 |
| 图片超大 | 懒加载 + 响应式 srcset |
| 图片太小 | 别拉伸,居中显示 |
| 图片无 alt | 装饰图 `alt=""` + `aria-hidden` |
| 图片正在加载 | blur-up 占位 |

## 五、极端状态组合

真实场景往往是**多个极端叠加**:

- **空 + 错误**:数据是空的,但也不知道是"真空"还是"加载失败"→ 必须区分
- **加载 + 部分数据**:数据分批到,先显示已到的
- **成功 + 有警告**:主操作成功但有次要问题("已保存,但 2 项未同步")
- **禁用 + 有原因**:禁用状态一定要说为什么

## 六、断网与离线

### 断网处理
- **顶部横幅提示** "已断线,内容可能不是最新"
- **保留已有数据** 不要清空
- **失败的操作排队** 恢复后自动重试
- **明确离线可用范围** 哪些能看/能操作

### 离线优先(PWA)
- 关键页面缓存
- 离线可读 / 联网后再同步
- 明确"你现在是离线状态"

---

## 七、异步与并发

- **乐观 UI 失败回滚** — 先立即反馈,失败要撤回
- **重复提交防护** — 提交中禁用按钮
- **并发编辑** — 多人同时改怎么办(合并/覆盖警告/CRDT)
- **过期数据** — 后台数据变了,前端显示的还是旧的

---

## 八、权限与访问

- **未登录** — 引导到登录,保留原意图路径
- **已登录但无权限** — 说明原因,提供申请入口
- **权限被撤销** — 优雅退出,不崩
- **访客模式** — 部分功能可用,标注哪些需要登录

---

## 九、时间边界

- **时区** — 显示相对时间("2 小时前")+ tooltip 绝对时间
- **未来时间** — 倒计时("还剩 3 天")
- **过期** — "已过期" + 后续动作
- **持续时间** — 格式化("2h 30m")

## 十、边界情况检验清单(超实用)

对着这张表检查 AI 生成的界面,能立刻发现"半成品":

**空态**:
- [ ] 有插图或图标,不孤零零
- [ ] 有标题说明状态
- [ ] 有描述引导下一步
- [ ] 有主 CTA
- [ ] 文案不是"暂无数据"

**错误态**:
- [ ] 字段错误有内联提示
- [ ] 页面错误不是英文错误代码
- [ ] 有插图缓解焦虑
- [ ] 有"重试"或"返回"出口
- [ ] 保留导航,能离开错误页

**加载态**:
- [ ] 短加载用 spinner / 无
- [ ] 中长加载用骨架屏,不用白屏
- [ ] 长加载有进度百分比
- [ ] 骨架屏形状像真内容
- [ ] 骨架 → 真内容 crossfade

**极端内容**:
- [ ] 超长名字截断 + tooltip
- [ ] 超大数字缩写 + tooltip
- [ ] 图片加载失败有占位
- [ ] 表格数字用 tabular-nums
- [ ] 1 条 vs 多条文案区分

**权限与网络**:
- [ ] 断网有明确提示
- [ ] 无权限有说明和申请入口
- [ ] 未登录保留意图路径
- [ ] 数据过期有刷新提示

## 十一、Prompt 模板(必抄)

```
【边界情况全覆盖要求】

空态设计:
- 首次使用:插图 + 引导标题 + 描述 + [主 CTA] + [次 CTA]
- 搜索无结果:提示 + 建议关键词 + [清除搜索]
- 已清空:轻庆祝文案 + 图标
- 权限不足:说明 + [申请]

错误态:
- 字段错误:红色边框 + 内联提示 + 聚焦
- 页面错误:插图 + 人性化标题(非错误码) + [重试] + [返回首页]
- 404 页面:品牌感设计 + 幽默文案 + 站内导航

加载态:
- 短(<1s):无 loading 或 spinner
- 中(1-3s):骨架屏 + shimmer,形状像真内容
- 长(>3s):进度百分比 + 预期时长
- 骨架 → 内容 crossfade 200ms

极端内容:
- 文本超长:overflow ellipsis + tooltip 全文
- 数字超大:1.2B 缩写 + tooltip 全值
- 表格数字:font-variant-numeric: tabular-nums
- 图片失败:占位图 + alt
- 列表 0/1/多 三态文案区分

网络与权限:
- 断网:顶部横幅 + 保留已有数据 + 恢复后自动重连
- 无权限:说明 + 申请入口
- 未登录:引导登录 + 记住原意图路径
- 过期数据:提示 + 刷新按钮

组合极端:
- 空 vs 错要区分(不能"看起来一样")
- 部分数据 + 加载 支持
- 成功 + 警告 有提示
- 禁用必须说明为什么
```

---

**记住**:AI 默认只做 happy path,你不点名边界情况,它就不做。**这份文档的价值就是让你不再忘记问"如果 X 呢?"**。
