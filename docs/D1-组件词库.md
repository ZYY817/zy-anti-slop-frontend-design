## 一、基础元素（Primitives）

### Button 按钮
- **变体**：primary / secondary / outline / ghost / link / destructive / icon-only
- **尺寸**：xs / sm / md / lg / xl
- **状态**：default / hover / active / focus / disabled / loading
- **附加**：左图标 / 右图标 / 图标+文字 / 纯图标 / 圆形 / 分组（Button Group）

### Input 输入框
- **类型**：text / password / email / number / search / tel / url / date / datetime / file
- **变体**：有标签 / 浮动标签 / 内联标签
- **状态**：empty / filled / focus / error / disabled / readonly
- **附加**：前缀图标 / 后缀图标 / 清除按钮 / 密码可见切换 / 字数统计

### Textarea 多行输入
- **附加**：auto-resize / max-height / 字数限制

### Select 选择器
- **变体**：单选 / 多选 / 分组 / 可搜索 / 可创建
- **状态**：open / closed / loading / empty

### Checkbox 复选框
- **状态**：unchecked / checked / indeterminate / disabled
- **变体**：单个 / 组 / 带描述

### Radio 单选按钮
- **状态**：unselected / selected / disabled
- **变体**：按钮组样式 / 卡片选择

### Toggle / Switch 开关
- **状态**：off / on / disabled
- **变体**：有标签 / 有图标

### Slider 滑块
- **变体**：单值 / 范围 / 多刻度 / 垂直
- **状态**：dragging / disabled

### Link 链接
- **变体**：inline / standalone / with-icon / breadcrumb

### Label 标签
- **附加**：必填标记 / 可选标记 / 帮助文字

### Badge 徽标
- **变体**：dot / count / text / icon
- **颜色**：neutral / success / warning / danger / info

## 十一、组件状态矩阵（通用）

每个可交互组件都应考虑这些状态：

```
default → hover → focus → active → disabled
                                  → loading
                                  → error
                                  → success
                                  → selected
                                  → indeterminate
                                  → readonly
                                  → dragging
                                  → resizing
```

### 按类型

**按钮型**（Button, MenuItem, Tab, Link）：
default / hover / focus / active / disabled / loading

**输入型**（Input, Select, Datepicker, Textarea）：
empty / filled / focus / error / disabled / readonly / loading

**选择型**（Checkbox, Radio, Switch, Tag）：
unselected / selected / indeterminate / disabled / focus

**展示型**（Card, Avatar, Badge）：
default / loading(skeleton) / error(fallback)

## 十三、Prompt 表达模板

```
【组件需求】：
- Button: primary (md/lg)，带 loading 和 disabled 态
- Input: 带浮动标签 + 前缀图标 + 错误提示
- Card: 横向带图 + CTA + hover elevation 变化
- Table: 可排序 + 可筛选 + 分页 + 行 hover 高亮
- Modal: 居中 + overlay + 可 Escape 关闭
- Toast: success/error/info 三态 + 自动 3s 消失 + 可手动关闭
- Skeleton: 卡片骨架组合，带 shimmer 动效
```

## 十四、v2 · UI 组合决策

组件不是页面的基本答案，内容和任务才是。选组件前先回答：

```text
用户要理解什么？
用户要比较什么？
用户要输入什么？
用户要等待什么？
用户要确认什么？
用户要恢复什么？
```

### 内容到组件的映射

| 内容/任务 | 优先组件 | 视觉要求 |
|---|---|---|
| 单一主任务 | Focused Form / Primary CTA | 只保留一个主动作 |
| 多项比较 | Table / List / Filter | 数字对齐、排序和状态可见 |
| 长内容阅读 | Prose / TOC / Quote / Progress | 行宽和阅读节奏优先 |
| 复杂工作区 | Sidebar / Toolbar / Panel | 高密度但保留操作层级 |
| 空状态 | Explanation / Example / CTA | 说明原因和下一步 |
| AI Agent | Plan / Progress / Approval / Trace | 体现控制权和可追溯性 |
| 视觉叙事 | Media / Editorial Block / Scene | 组件服从叙事，不做卡片拼盘 |

### 组件蓝图

每个页面组件都要标记：

```yaml
semantic_role:
content_input:
visual_weight: primary | secondary | supporting | utility
variant:
states:
interaction:
mobile_form:
when_not_to_use:
accessibility:
performance:
```

### v2 Prompt

```text
不要先罗列组件。先分析内容层级和用户任务，再建立 Component Map。
对每个组件说明：语义角色、内容输入、视觉权重、状态、移动端形态、无障碍要求、
何时不用。禁止用 Card、Bento、Modal 或图标装饰填补没有内容逻辑的区域。
```
