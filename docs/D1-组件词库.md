## 一、组件名录速查（按类别）

| 类别 | 组件名（精确命名优先用主流库的叫法） |
|---|---|
| 基础元素 | Button · Input · Textarea · Select · Checkbox · Radio · Switch · Slider · Link · Label · Badge |
| 数据展示 | Table · Card · Avatar · Tag/Chip · List · Timeline · Stat/Metric · Empty State · Skeleton · Tree |
| 导航 | Navbar · Sidebar · Tabs · Breadcrumb · Pagination · Stepper · Menu · Command Palette(⌘K) · Bottom Bar |
| 反馈 | Toast/Snackbar · Alert/Banner · Dialog/Modal · Drawer · Popover · Tooltip · Progress · Spinner · Notification |
| 表单 | Form · DatePicker · TimePicker · ColorPicker · Upload · OTP Input · Rating · Transfer · **Combobox** |
| 覆盖层 | Sheet(底部面板) · Lightbox · Context Menu · Dropdown Menu |
| 容器/结构 | Accordion/Collapse · Divider · Stack · Grid · Container · Scroll Area · Resizable Panel |
| 富内容 | Carousel · Code Block · Calendar · Chart · Map · Video/Audio Player · PDF Viewer |
| AI/Chat | Chat Bubble · Streaming Text · Citation Card · Tool Calling · Suggested Actions · Message Composer · Agent Card |
| 工具行为 | Kbd · Visually Hidden · Portal · Focus Trap · Scroll Lock · Intersection Observer · Resize Observer |

**易混命名辨析**（说错名字 AI 会猜错组件）：
- **Combobox ≠ Select**：Combobox 可输入+可下拉；Select 只能选不能输入
- **Popover ≠ Tooltip**：Popover 承载交互内容（click 触发）；Tooltip 只有说明文字（hover/focus 触发）
- **Modal ≠ Drawer**：Modal 居中打断任务；Drawer 从边缘滑出常用于二级详情/筛选
- **Toast ≠ Alert**：Toast 自动消失轻提示；Alert 常驻需要用户处理
- **Sheet ≠ Modal**：Sheet 是移动端 bottom 面板的专名

## 二、变体命名规范

```
<Component>.<Variant>.<Size>.<State>

Button.primary.md.default
Button.destructive.lg.loading
Input.outlined.md.error
Card.elevated.lg.selected
Avatar.circular.sm.fallback
```

## 三、Prompt 表达模板（精确命名的示范）

```
【组件需求】：
- Button: primary (md/lg)，带 loading 和 disabled 态
- Input: 带浮动标签 + 前缀图标 + 错误提示
- Card: 横向带图 + CTA + hover elevation 变化
- Table: 可排序 + 可筛选 + 分页 + 行 hover 高亮
- Modal: 居中 + overlay + 可 Escape 关闭
- Toast: success/error/info 三态 + 自动 3s 消失 + 可手动关闭
- Skeleton: 卡片骨架组合，带 shimmer 动效
```

## 四、UI 组合决策（v2 · 本库独有价值）

组件不是页面的基本答案，内容和任务才是。选组件前先回答：

```text
用户要理解什么？
用户要比较什么？
用户要输入什么？
用户要等待什么？
用户要确认什么？
用户要恢复什么？
```

### 内容到组件的映射

| 内容/任务 | 优先组件 | 视觉要求 |
|---|---|---|
| 单一主任务 | Focused Form / Primary CTA | 只保留一个主动作 |
| 多项比较 | Table / List / Filter | 数字对齐、排序和状态可见 |
| 长内容阅读 | Prose / TOC / Quote / Progress | 行宽和阅读节奏优先 |
| 复杂工作区 | Sidebar / Toolbar / Panel | 高密度但保留操作层级 |
| 空状态 | Explanation / Example / CTA | 说明原因和下一步 |
| AI Agent | Plan / Progress / Approval / Trace | 体现控制权和可追溯性 |
| 视觉叙事 | Media / Editorial Block / Scene | 组件服从叙事，不做卡片拼盘 |

### 组件蓝图

每个页面组件都要标记：

```yaml
semantic_role:
content_input:
visual_weight: primary | secondary | supporting | utility
variant:
states:
interaction:
mobile_form:
when_not_to_use:
accessibility:
performance:
```

### v2 Prompt

```text
不要先罗列组件。先分析内容层级和用户任务，再建立 Component Map。
对每个组件说明：语义角色、内容输入、视觉权重、状态、移动端形态、无障碍要求、
何时不用。禁止用 Card、Bento、Modal 或图标装饰填补没有内容逻辑的区域。
```
