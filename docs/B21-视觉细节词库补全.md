# B21 · 视觉细节词库(未覆盖维度补全)

> 前面 20 份覆盖了大方向。这份补的是"顶级设计师的口头禅"——那些描述细节和感觉的高精度词汇。
> 越能用这些词精准描述,AI 生成越接近你脑中的样子。
> 每个维度:是什么 / 词汇 / 怎么用 / prompt 措辞。

---

## 维度 1｜构图张力（Compositional Tension）

**是什么**:元素之间制造"紧张感"的手段。不是"漂亮",是"有戏"。

**词汇**:
- 视觉张力 visual tension
- 相斥 repulsion(元素互相推开)
- 相吸 attraction(元素被引向彼此)
- 濒临 on-the-edge(元素快出边界的紧张)
- 打断 interruption(有序中突然断裂)
- 悬置 suspension(元素"悬"在空间中不落地)
- 挤压 compression(元素被空间挤压)
- 逸出 escape(元素冲出容器)
- 平衡杠杆 counter-balance
- 视觉悖论 visual paradox

**怎么做**:
- 大留白 + 一个偏小的元素放到不寻常的位置(黄金点)
- 巨型标题一部分被视口切掉(裁切张力)
- 密集内容旁边放极端空的区域(密疏对比张力)
- 两个大元素几乎相碰但不接触(相斥张力)

**Prompt 措辞**:
> "首屏视觉张力:巨型标题左上,单个小 CTA 右下,中间大面积留白制造视觉杠杆平衡。标题被视口右侧裁切一部分,制造濒临感。"

## 维度 2｜边缘与转角处理（Edge & Corner Treatment）

**是什么**:元素的"轮廓"处理。这是"专业感"最直接的信号。

**词汇**:
- 硬边缘 crisp edge / sharp edge
- 柔边缘 soft edge / feathered
- 羽化 feathered / gradient edge
- 描边 stroked / outlined
- 内嵌边 inset / recessed
- 悬浮边 lifted / elevated
- 无缝 seamless
- 断口 clean break

**转角**:
- 直角 sharp corner(工业/技术)
- 圆角 rounded(亲切/现代)
- 大圆角 pill / capsule(温暖/年轻)
- 斜切 chamfered(几何/精工)
- 切角 notched(游戏/科技)
- 不对称圆角 asymmetric radius(个性/新粗野)
- 混合圆角 mixed radius(高级细节)

**顶级细节**:
- **同一元素不同角不同圆角** —— `border-radius: 24px 4px 24px 4px`(创意站爱用)
- **卡片圆角比按钮大** —— 视觉层级
- **图片圆角给容器不给 img** —— 抗锯齿更好

**Prompt 措辞**:
> "卡片:大圆角 24px,内部按钮圆角 8px(层级差),右上角故意用 4px 制造不对称精工细节。图片圆角加在容器加 overflow hidden。"

## 维度 3｜光线质量（Light Quality）

**是什么**:光如何"存在"于界面。不只是"发光/阴影",是**光的性格**。

**词汇**:
- 环境光 ambient(整体柔和)
- 定向光 directional(有明确来源方向)
- 硬光 harsh light(强反差)
- 软光 soft light(柔和过渡)
- 漫射光 diffused(如阴天)
- 斑驳光 dappled(如树影)
- 逆光 backlit(轮廓发光)
- 顶光 top light(垂直下照)
- 侧光 side light(戏剧感)
- 边缘光 rim light(勾勒轮廓)
- 折射光 refracted(玻璃/水)
- 反射光 reflected
- 镜面反射 specular
- 散射光 scattered

**光的品质词**:
- 通透 luminous / translucent
- 温暖 warm / golden
- 冷冽 cool / clinical
- 柔和 gentle / soft
- 强烈 intense / brilliant
- 微弱 dim / faint
- 光晕 halo / halation
- 光泽 sheen / gloss
- 哑光 matte
- 珠光 pearlescent

**Prompt 措辞**:
> "深色界面:模拟斜上方定向光源。卡片顶部有 1px specular 高光,右下角自然阴影加深。整体氛围是漫射光柔和感,不是强对比。CTA 有柔和 halo 光晕。"

## 维度 4｜运动质感（Motion Quality）

**是什么**:动效的"性格"。同样是移动,可以是机械的、慵懒的、活泼的。

**词汇**:
- 利落 snappy(短快)
- 从容 fluid(平滑不急)
- 慵懒 languid(慢而拖)
- 弹跳 bouncy(有 spring)
- 顺滑 smooth(无停顿)
- 有力 punchy(强 acceleration)
- 优雅 elegant(慢+平缓)
- 机械 mechanical(linear/精准)
- 有机 organic(不规则/自然)
- 跳跃 jittery(突然)
- 迟缓 sluggish(过慢)
- 稳健 steady(节奏一致)
- 舞蹈 choreographed(编排感)
- 呼吸 breathing(循环起伏)
- 潜行 stealthy(悄悄发生)
- 戏剧 dramatic(强对比+慢)

**Prompt 措辞**:
> "整体运动质感:利落+优雅并存。按钮 hover 利落(200ms easeOut),页面过渡从容(400ms easeInOutExpo),背景光球呼吸(20s 循环)。避免慵懒和机械感。"

## 维度 5｜空间语言（Spatial Language）

**是什么**:z 轴/深度/层次怎么表达。

**词汇**:
- 前景 foreground
- 中景 midground
- 背景 background
- 图层 layer / plane / tier
- 深度 depth
- 立体感 dimensionality
- 悬浮 hovering / floating
- 贴地 grounded / anchored
- 沉入 embedded / recessed
- 突出 protruding / raised
- 层叠 stacked / layered
- 重叠 overlapping
- 交叠 interlocking
- 分层 stratified

**顶级站的空间语言**:
- **"平" flat** — 无阴影无深度,一切在同一平面(极简/瑞士)
- **"薄" thin** — 有极微阴影,几乎贴地(Vercel/Linear)
- **"厚" thick** — 明确阴影层级(Material)
- **"深" deep** — 3 层以上 z 轴,视差(Apple/Spatial UI)

**Prompt 措辞**:
> "空间语言:'薄'——所有元素几乎贴地,阴影极浅(rgba 0.04-0.06)。仅 Modal 有明显 z 轴。避免堆积多层阴影。"

## 维度 6｜视觉重量与体量（Visual Weight & Mass）

**是什么**:元素在视觉上"有多重"。

**词汇**:
- 轻盈 airy / weightless / featherlight
- 悬浮 floating / suspended
- 稀薄 sparse / thin
- 沉重 heavy / dense / weighty
- 扎实 solid / grounded / substantial
- 饱满 full / plump
- 空心 hollow / open
- 实心 solid / filled
- 雕塑感 sculptural
- 建筑感 architectural
- 纪念碑感 monumental
- 剪影感 silhouette

**怎么控制**:
- 深色 = 重 / 浅色 = 轻
- 大 = 重 / 小 = 轻
- 高饱和 = 重 / 低饱和 = 轻
- 粗字重 = 重 / 细字重 = 轻
- 密集纹理 = 重 / 光滑 = 轻

**Prompt 措辞**:
> "整体视觉重量:轻盈。用大量浅色 + 细字重 + 无阴影 + 大量留白营造漂浮感。仅主 CTA 用深色制造锚点。"

## 维度 7｜关系与连接（Relationships）

**是什么**:元素之间怎么互相"呼应"。这是"整体感"的来源。

**词汇**:
- 呼应 echo(某处出现的元素在别处呼应)
- 镜像 mirror(左右/上下对称)
- 重复 repetition(建立节奏和品牌)
- 变奏 variation(同一主题的变化)
- 对话 dialogue(两个元素"看着"彼此)
- 对峙 confrontation(元素相对制造张力)
- 追随 following(视线引导)
- 平行 parallel
- 交叉 intersecting
- 相切 tangent(几乎接触)
- 环绕 orbiting
- 簇集 clustering
- 孤立 isolation(单独突出)
- 首尾呼应 bookending

**顶级手法**:
- Hero 出现的一个图形元素 → Footer 用同样元素收尾(**首尾呼应**)
- 每个 section 用同一装饰 motif 变奏(**主题变奏**)
- 视觉动线用元素引导(**追随**)

**Prompt 措辞**:
> "全站视觉主题:一个几何图形(细线圆环)。Hero 中央大版,section 之间小版分隔,Footer 收尾。所有出现处 stroke 宽度一致,建立首尾呼应。"

## 维度 8｜隐喻氛围（Metaphorical Atmosphere）

**是什么**:界面"像什么"。视觉隐喻决定整体气质。

**常见隐喻**:
- 实验室 laboratory(数据/精密/白色/绿色)
- 终端 terminal(黑绿/Mono/命令)
- 剧院 theater(深色/聚光/戏剧)
- 画廊 gallery(白墙/大留白/单一焦点)
- 编辑室 editorial(大标题/衬线/多栏)
- 工作室 studio(手工/温暖/展示)
- 展览 exhibition(大空间/引导动线)
- 图书馆 library(书本感/衬线/静谧)
- 太空舱 spacecraft(黑背景/发光/数据)
- 机场 airport(数据大屏/标识/时间)
- 音乐盒 music box(玩味/圆润/温暖)
- 森林 forest(有机/绿/自然)
- 博物馆 museum(庄重/极简/展品)
- 咖啡馆 café(温暖/纸质/亲切)
- 电影 cinema(宽银幕/戏剧/大字)

**怎么用**:选一个隐喻,让所有决定服务于它。
- "画廊感"→ 大留白 + 单一焦点 + 白墙灰调
- "终端感"→ Mono 字体 + 深色 + 命令行灵感
- "实验室感"→ 数据展示 + 精密网格 + 冷色

**Prompt 措辞**:
> "整体视觉隐喻:'数据实验室'——白色/极浅灰底 + 精密网格 + Mono 数据标签 + 冷色调 + 无装饰 + 每处像实验仪器一样有精确刻度。"

## 维度 9｜张力对立词（Tension Pairs）

**是什么**:两个对立的品质并存,产生高级感。

**经典对立**:
- 秩序 vs 混沌 order vs chaos
- 数字 vs 有机 digital vs organic
- 冷 vs 暖 cold vs warm
- 精密 vs 手工 precise vs handcrafted
- 密集 vs 稀疏 dense vs sparse
- 大胆 vs 精致 bold vs delicate
- 复杂 vs 简约 complex vs simple
- 传统 vs 前卫 classical vs avant-garde
- 静 vs 动 static vs dynamic
- 严肃 vs 玩味 serious vs playful

**顶级设计规律**:纯粹一种质感容易平庸。**两个对立的质并存 = 张力 = 高级感**。

- 严格栅格 + 一处打破 = 惊喜
- 冷灰基调 + 一抹暖色 = 有温度的科技
- 极简布局 + 一个大胆细节 = 敢
- 传统衬线 + 前卫布局 = 编辑感
- 精密数据 + 有机粒子 = 数据美学

**Prompt 措辞**:
> "整体调性:严肃 + 玩味的张力。用极简瑞士栅格(严肃)+ 一个手绘感的圆圈标记特殊内容(玩味)。冷灰基调(冷)+ 一个焦糖色作为唯一强调(暖)。"

## 维度 10｜跨媒介借词（Cross-medium Borrowed Vocabulary）

**是什么**:借摄影/音乐/建筑/电影的词描述视觉,精度更高。

### 借自摄影
- 构图 composition
- 取景 framing
- 裁切 cropping / crop
- 焦距 focal length
- 景深 depth of field
- 曝光 exposure
- 对比度 contrast
- 高光 highlight
- 阴影 shadow
- 中间调 midtone
- 胶片颗粒 film grain
- 光晕 lens flare
- 电影感 cinematic
- 宽银幕 widescreen / anamorphic

### 借自音乐
- 节奏 rhythm
- 节拍 tempo
- 旋律 melody
- 和谐 harmony
- 不和谐 dissonance
- 渐强 crescendo(视觉逐渐加强)
- 渐弱 decrescendo
- 断奏 staccato(短促节奏)
- 连奏 legato(平滑过渡)
- 复调 counterpoint
- 静默 silence(留白)
- 独奏 solo(单一焦点)
- 合奏 ensemble(元素合奏)

### 借自建筑
- 骨架 structure
- 框架 framework
- 承重 load-bearing
- 悬臂 cantilever(视觉悬挑)
- 跨度 span
- 门槛 threshold(视觉入口)
- 中庭 atrium(大空间中心)
- 立面 facade
- 基础 foundation
- 支柱 pillar

### 借自电影
- 场景 scene
- 镜头 shot(close-up/wide/medium)
- 剪辑 cut / transition
- 淡入淡出 fade
- 时间轴 timeline
- 铺垫 setup
- 高潮 climax
- 尾声 denouement
- 慢镜头 slow motion
- 蒙太奇 montage

**Prompt 措辞**:
> "整个长页面的节奏像交响乐:hero 是主题呈现,features 是发展,demo 是crescendo到达 climax,CTA 是收束。使用留白作为视觉'silence'制造呼吸。"

## 维度 11｜风格修饰词（Style Modifiers）

**是什么**:修饰某个基础风格的形容词,让方向更精准。

**修饰词库**:
- **克制的** restrained / considered / composed
- **原始的** raw / rough / unrefined
- **精致的** refined / polished / crafted
- **松散的** loose / relaxed / casual
- **紧凑的** tight / compact / controlled
- **野性的** wild / untamed / wild-hearted
- **克制的** quiet / hushed / whispered
- **喧嚣的** loud / shouting / thundering
- **温柔的** gentle / tender / delicate
- **凶猛的** fierce / aggressive / brutal
- **克制的** deliberate / intentional
- **随性的** spontaneous / carefree
- **成熟的** mature / seasoned
- **年轻的** youthful / fresh / vibrant

**用法示例**:
```
基础风格 + 修饰词 = 更精准

极简 → 克制的极简(quiet minimalism)
极简 → 大胆的极简(bold minimalism)
新粗野 → 精致的新粗野(refined neo-brutalism)
新粗野 → 野性的新粗野(wild neo-brutalism)
```

**Prompt 措辞**:
> "风格:克制的编辑感(quiet editorial)——不是喧嚣的巨字,是温柔的衬线加大量留白。"

## 维度 12｜视觉个性形容词（Design Attitude）

**是什么**:界面像什么"人格"。

**词库**:
- 自信 confident(大胆决定/敢留白)
- 犹豫 hesitant(处处妥协/塞满)
- 冷静 aloof / detached(极简/无情绪)
- 热情 warm / inviting
- 严肃 serious / stoic
- 幽默 witty / humorous
- 讽刺 ironic / cheeky
- 真诚 sincere / earnest
- 神秘 mysterious / enigmatic
- 开放 open / transparent
- 内敛 introverted / contemplative
- 外向 extroverted / expressive
- 傲慢 haughty / imperious
- 谦逊 humble / understated
- 大方 generous(留白多)
- 吝啬 stingy(塞满信息)

**Prompt 措辞**:
> "视觉人格:自信 + 大方 + 内敛。用极端留白表达自信,不解释太多。文案克制,不喋喋不休。"

## 维度 13｜密度分级词汇（Density Vocabulary）

**是什么**:精确描述信息密度。

**词库**:
- 稀薄 sparse(一屏 <5 个信息块)
- 空旷 spacious(大量留白)
- 呼吸 breathable
- 舒适 comfortable(中等密度)
- 紧凑 compact
- 密集 dense
- 拥挤 crowded
- 窒息 suffocating(过度密集)

**顶级站的密度控制**:
- Hero:极空旷
- Features:呼吸
- 数据/对比:紧凑
- Footer:呼吸

**长页面 = 密度节奏起伏,而非均匀铺开**。

---

## 维度 14｜时机词汇(Timing Vocabulary)

**是什么**:动效发生的"时机感"。

- 即时 instant(<100ms)
- 迅速 swift(100-200ms)
- 从容 measured(300-500ms)
- 舒缓 leisurely(500-1000ms)
- 悠长 lingering(1-3s)
- 极慢 glacial(3-30s,如背景光球)

**规律**:
- 反馈类要即时/迅速
- 过渡类要从容
- 装饰类要悠长/极慢

---

## 维度 15｜精工程度词（Craftsmanship Level）

**是什么**:界面"打磨到什么程度"。

- 半成品 rough(有明显问题)
- 完成 finished(能用没错)
- 打磨 polished(细节到位)
- 精工 crafted(细节讲究)
- 大师级 masterful(处处有考究)
- 雕琢 refined(打磨到极致)
- 珠宝级 jewel-like(每一处像珠宝)

**Prompt 措辞**:
> "整体精工程度:大师级。每个圆角、每个间距、每个动画时长都是有意的,不是随手值。"

## 综合应用:高精度 prompt 模板

```
【视觉细节全维度】

构图张力:{visual tension / on-the-edge / suspension}
边缘转角:{crisp/soft/mixed radius/notched} + 圆角策略
光线质量:{directional/diffused/rim-lit/luminous/matte}
运动质感:{snappy/fluid/languid/organic/breathing}
空间语言:{flat/thin/thick/deep + 层数}
视觉重量:{airy/grounded/heavy + 具体手段}
关系连接:{echo/repetition/首尾呼应元素}
隐喻氛围:{实验室/画廊/终端/编辑室…}
张力对立:{冷+暖 / 严+玩 / 密+疏 / 传统+前卫}
借词描述:{cinematic/staccato/atrium/crescendo…}
风格修饰:{quiet/bold/refined/raw + 基础风格}
视觉人格:{confident/aloof/generous/introverted…}
密度节奏:{sparse-breathable-compact-breathable 起伏}
时机感:{instant/swift/measured/glacial 各处不同}
精工程度:masterful(每处都有意为之)
```

## 核心认知

> **你能说的词越精准,AI 能生成的越接近你脑中的样子。**
>
> "做得高级" → AI 只能给你"平均高级"
> "克制的编辑感,quiet editorial,大方留白,cinematic 节奏,首尾呼应细线圆环,masterful 精工程度" → AI 才知道你到底想要什么
>
> **词汇精度 = 输出精度。**

---

## 建议使用方式

1. 每个新项目前,过一遍这 15 个维度
2. 每个维度选 1-2 个词精准描述你的意图
3. 组合起来 = 独一无二的视觉方向 prompt
4. 生成后对照哪个维度没做到,补进 prompt 迭代

**这 15 个维度 + 前面 20 份文档,基本就是"世界最全视觉描述词库"了。**
