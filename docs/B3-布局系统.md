# B3 · 布局系统

> 布局是页面的骨架。好布局让内容有秩序、有节奏、有呼吸。

---

## 一、间距系统（Spacing Scale）

### 4pt / 8pt 网格
所有间距是 4 或 8 的倍数。

**4pt 网格**（更精细）：
```
0, 4, 8, 12, 16, 20, 24, 32, 40, 48, 56, 64, 80, 96, 128
```

**8pt 网格**（更简洁）：
```
0, 8, 16, 24, 32, 40, 48, 64, 80, 96, 128, 160, 192
```

### Tailwind 标准
```
0, 0.5(2px), 1(4px), 2(8px), 3(12px), 4(16px), 5(20px),
6(24px), 8(32px), 10(40px), 12(48px), 16(64px), 20(80px),
24(96px), 32(128px), 40(160px), 48(192px), 56(224px), 64(256px)
```

### 语义化间距
```
space.xxs: 4px    (紧凑内间距)
space.xs:  8px    (小元素间)
space.sm:  12px
space.md:  16px   (标准)
space.lg:  24px   (卡片间)
space.xl:  32px   (区块间小)
space.2xl: 48px   (section 内)
space.3xl: 64px   (section 间)
space.4xl: 96px   (大 section)
space.5xl: 128px  (超大留白)
```

## 二、栅格系统（Grid System）

### 12 列栅格（经典）
- 灵活分割：6+6 / 4+4+4 / 3+3+3+3 / 8+4 / 9+3
- 装订线（gutter）常用 16/24/32px
- 边距（margin）常用 24/48/64px

### 4 列 / 8 列 / 16 列
- **移动**：4 列
- **平板**：8 列
- **桌面**：12 列或 16 列

### Bento 网格（2024-2026 流行）
非对称、模块化。经典组合：
```
[  2x2  ][ 1x1 ]
[       ][ 1x1 ]
[ 1x1 ][ 1x2 ]
[ 1x1 ][      ]
```

### Bootstrap
```
sm:  576px

lg:  992px
xl:  1200px

```

### Material 3
```
Compact:  <600px    (手机)
Medium:   600-840px (平板/折叠)
Expanded: 840-1200px
Large:    1200-1600px
Extra:    >1600px
```

### 移动优先原则
```css
/* 默认样式（移动端） */
.card { padding: 16px; }

/* 平板及以上覆盖 */
@media (min-width: 768px) {
  .card { padding: 24px; }
}

/* 桌面及以上覆盖 */
@media (min-width: 1280px) {
  .card { padding: 32px; }
}
```

## 五、Flexbox 术语

### 主轴与交叉轴
- `flex-direction: row / column`
- 主轴对齐：`justify-content`
- 交叉轴对齐：`align-items`

### 属性
- `flex-wrap: wrap / nowrap`
- `flex-grow: 1`（占据剩余空间）
- `flex-shrink: 0`（不缩小）
- `flex-basis: 200px`（初始尺寸）
- `gap: 16px`（间隙，替代 margin）

### 常用模式
- **等分**：`flex: 1` 每个子元素
- **两端**：`justify-content: space-between`
- **居中**：`justify-content: center; align-items: center`
- **右对齐**：`margin-left: auto`（单个元素）

## 六、CSS Grid 术语

### 基础
```css
display: grid;
grid-template-columns: repeat(12, 1fr);   /* 12 列等分 */
grid-template-rows: auto;
gap: 24px;
```

### 单位
- `fr` — 剩余空间的比例
- `auto` — 自适应内容
- `minmax(200px, 1fr)` — 最小 200 最大等分

### 高级
- `grid-template-areas` — 命名区域
- `grid-column: span 3` — 跨列
- `grid-auto-flow: dense` — 自动填空

### 响应式网格（无媒体查询）
```css
grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));
```
自动根据宽度换行。

## 七、容器查询（Container Queries）

**问题**：媒体查询看视口，但组件应看自己所在容器。
**解决**：容器查询看父容器尺寸。

```css
.card-container {
  container-type: inline-size;
}

@container (min-width: 400px) {
  .card {
    display: flex;
    padding: 24px;
  }
}
```

**意义**：真正的组件驱动响应式。

## 八、层叠上下文（Stacking Context）

`z-index` 只在同一层叠上下文内比较。

**创建层叠上下文的条件**：
- `position: relative/absolute/fixed` + `z-index`
- `opacity < 1`
- `transform`
- `filter`
- `will-change`

**z-index 层级规划**：
```
Base:     0
Dropdown: 10
Sticky:   20
Fixed:    30
Overlay:  40
Modal:    50
Popover:  60
Tooltip:  70
Toast:    80
```

## 十、间距应用（Spacing Application）

### 卡片内部
```

```

### 表单
```
label 到 input:  4-8px
field 到 field:  16-24px
group 到 group:  32-48px
```

### 按钮
```
padding-x: 16-24px (根据尺寸)
padding-y: 8-12px
icon 到 label: 8px
button 到 button: 12-16px
```

### 章节
```
section 内上下：64-96px (桌面) / 40-64px (移动)
section 之间: 96-128px (桌面) / 48-64px (移动)
```

## 十一、构图法则

### 黄金分割（1:1.618）
布局分割最"舒服"的比例。
- 侧栏 vs 主区：≈ 38 : 62

### 三分法
画面分 3x3，重要元素放在交叉点。

### F 型 / Z 型阅读
- **F 型**：内容密集页（Blog、Feed）— 横扫顶 → 横扫中 → 纵扫左
- **Z 型**：稀疏页（Landing）— 左上 → 右上 → 左下 → 右下

### 对角线引导
用图片朝向、箭头、线条引导视线到 CTA。

### 呼吸节奏
密集 - 稀疏 - 密集 - 稀疏 交替，避免全屏平铺。

## 十二、视口单位

| 单位 | 说明 |
|---|---|
| `vw` | 视口宽度 1% |
| `vh` | 视口高度 1% |
| `vmin` | 视口较小边 1% |
| `vmax` | 视口较大边 1% |
| `dvh` | 动态视口高（考虑地址栏） |
| `svh` | 静态视口高（不变） |
| `lvh` | 大视口高 |
| `svw / lvw / dvw` | 宽度对应 |

**移动端全屏用 `dvh` 而非 `vh`**（避免地址栏遮挡）。

## 十三、Aspect Ratio（宽高比）

### 常见比例
- **1:1** — 头像、正方形卡片
- **4:3** — 传统照片
- **16:9** — 视频、封面
- **21:9** — 电影级横幅
- **3:4** — 竖版海报
- **9:16** — 短视频、竖版

### CSS
```css
aspect-ratio: 16 / 9;
```

## 十四、响应式策略

### 移动优先
先移动再桌面。默认样式 = 移动。

### 桌面优先
先桌面再移动。用 `max-width` 覆盖。

### 断点思路
- **不要**为每个设备写断点
- **要**在设计"崩了"的地方加断点
- 常用断点：640 / 768 / 1024 / 1280 就够

### 流体设计
```css
font-size: clamp(1rem, 2vw + 0.5rem, 2rem);
padding: clamp(16px, 4vw, 48px);
```

## 十五、常见错误

- ❌ 间距随手写（`padding: 15px 22px`）
- ❌ 栅格不一致（有的 8 列有的 12 列）
- ❌ 内容宽度太宽（>1600px 阅读困难）
- ❌ 移动端 padding 太小（<16px 觉得挤）
- ❌ 断点太多（5+ 个）
- ❌ 桌面用 vh 不用 dvh
- ❌ 不同卡片间距不一样
- ❌ 只用媒体查询不用容器查询

## 十六、Prompt 表达模板

```
【布局系统】：
- 栅格：12 列，装订线 24px，桌面 max-width 1280px
- 断点：mobile <768 / tablet 768-1024 / desktop >1024
- 间距系统：4pt 基础，用 4/8/12/16/24/32/48/64/96/128
- 容器 padding：mobile 16px / desktop 24px
- 组件：flex 布局主导，卡片网格用 CSS Grid + auto-fit
- 首屏 hero：min-height 600px，padding-y 96px
- section 间距：桌面 96px / 移动 48px
- 使用容器查询让卡片组件独立响应
```
