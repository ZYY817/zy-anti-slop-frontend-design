# R16 · 声音与多感官（提示词库 P 组）

> 定位：**声音是被浪费的一半带宽。** 加了对的声音，同一个视觉的沉浸感翻倍；加了错的声音，作品被立刻关掉——本组是"视觉配上声音"（音频作为输出）与触觉等其他通道的可粘贴提示词条目库。
> 覆盖层：L0 意 + L5 髓（本组以 L5 为主）。
> 条目卡格式：每条为 `名称（英文）· L层级 · 档位 · 成本`，其下含「视觉收益 / 参考值 / 同族拓展 / 提示词片段」若干字段；提示词片段可直接粘贴使用。
> 来源：融合自外部「视觉提示词库 P 组」（v1.x，2026-08-16），组内总索引见 `R0`。
> 关键判断：**默认静音；要做就做全套。** 是否做声音由项目自行决定——默认静音是安全默认值，要做就按本组做全套（礼貌开关 + 语义体系 + 精确同步）。半成品音频比没有音频更糟。

---

## 使用说明

`R11·F4` 讲的是"音频驱动视觉"（音频作为输入）。P 组讲的是**"视觉配上声音"**（音频作为输出），以及触觉等其他通道。

铁律四条，违反任何一条不如不做：
1. **默认静音**。浏览器策略也不允许自动播放，且未经许可发声是最快的关闭理由
2. **开关必须显眼**。右上/右下角常驻，一眼能找到
3. **音量默认低**（≤30%），淡入不突现
4. **UI 音效必须极短极轻**（<120ms，-20dB 级），能被忽略才是对的

```
R16·P1 声音的礼貌与开关       R16·P4 空间音频
R16·P2 UI 音效体系            R16·P5 触觉反馈
R16·P3 程序化音频合成         R16·P6 多通道冗余与无障碍
```

## P1 声音的礼貌与开关（Audio Etiquette）

- **默认静音与手势解锁（Muted by Default）** · L0 · 基础 · 成本:低
  - 视觉收益：不触发用户反感，也符合浏览器自动播放策略
  - 同族拓展：`AudioContext.resume()` 需用户手势、`autoplay` 策略、静音自动播放视频（视觉可用）
  - 提示词片段：`音频默认关闭；首次用户手势后才 resume AudioContext；开启时 1.5s 淡入到音量 0.25`

- **显眼且持久的开关（Visible Toggle）** · L5 · 基础 · 成本:低
  - 视觉收益：用户能立刻关掉，才会愿意打开
  - 同族拓展：常驻角标、状态图标（波形/静音）、localStorage 记住、键盘快捷键（M）
  - 提示词片段：`音频开关常驻右下角（带波形动画指示状态）；快捷键 M 切换；localStorage 记住选择`

- **淡入淡出与无缝循环（Fade & Seamless Loop）** · L5 · 进阶 · 成本:低
  - 视觉收益：突然开始/结束/接缝爆音都很业余
  - 同族拓展：`gain.linearRampToValueAtTime`、crossfade 循环点、避免 loop 接缝、`AudioBufferSourceNode.loopStart/End`
  - 提示词片段：`所有音频渐入渐出（≥800ms）；循环点做 crossfade（重叠 2s）避免接缝爆音`

- **页面可见性联动（Visibility Sync）** · L5 · 基础 · 成本:低
  - 视觉收益：切走标签页自动静音，回来恢复——不然用户找不到声音来源会很烦
  - 同族拓展：见 `R11·F5` 页面可见性、`visibilitychange`、淡出而非硬停
  - 提示词片段：`页面不可见时音频淡出静音（不是硬停）；恢复可见时淡入`

- **音量层级（Volume Hierarchy）** · L5 · 进阶 · 成本:低
  - 视觉收益：氛围底噪最轻、交互音效中等、关键事件最响，形成层级
  - 参考值：环境音 0.15–0.25｜UI 音效 0.2–0.35｜关键事件 0.4–0.5｜绝不到 1.0
  - 同族拓展：master gain + bus gain（分组音量）、ducking（说话时压低背景）
  - 提示词片段：`分 master/ambient/sfx 三条 gain 总线；环境 0.2、UI 0.3、关键事件 0.45；提供总音量滑块`

## P2 UI 音效体系（UI Sound System）

- **音效语义映射（Sound Semantics）** · L0 · 进阶 · 成本:低
  - 视觉收益：每类交互有一致的声音"语言"，与视觉语言平行
  - 参考映射：
    - hover — 极轻的高频短点（<40ms，几乎察觉不到）
    - click/确认 — 短促上行音（60–100ms）
    - 取消/关闭 — 短促下行音
    - 成功 — 两音上行（大三度或纯五度）
    - 错误 — 低沉钝音（不要刺耳警报）
    - 切换/tab — 中性短音，左右可有轻微声道差异
    - 加载完成 — 轻柔的到达感
  - 提示词片段：`建立 6 个音效语义（hover/click/cancel/success/error/switch）；上行=正向、下行=取消；错误用低沉不用刺耳`

- **音效时长与频段（Duration & Frequency）** · L5 · 基础 · 成本:低
  - 视觉收益：UI 音效必须短且不占据人声频段（避免疲劳与干扰）
  - 参考值：时长 40–150ms｜主频 500Hz–4kHz｜避开 2–4kHz 的刺耳峰｜加快速衰减包络
  - 提示词片段：`UI 音效时长 ≤150ms，快速衰减；避开 2-4kHz 刺耳区；不使用长尾混响`

- **音效与视觉同步（Audio-Visual Sync）** · L5 · 基础 · 成本:低
  - 视觉收益：声音必须与视觉反馈**同帧**（延迟 >80ms 就会感到脱节）
  - 同族拓展：预加载解码（decodeAudioData 提前）、AudioContext 精确调度、避免 `<audio>` 元素的延迟
  - 提示词片段：`音效用 Web Audio 预解码 + 精确调度（不用 <audio> 元素）；与视觉反馈同帧触发，延迟 <30ms`

- **防轰炸（Rate Limiting）** · L5 · 基础 · 成本:低
  - 视觉收益：快速划过 20 个按钮不能响 20 次
  - 同族拓展：throttle（最小间隔 60–120ms）、voice limit（同时发声数上限）、随机微调音高避免机械重复
  - 提示词片段：`hover 音效节流 ≥100ms；同时发声上限 4；每次触发音高随机 ±3% 避免机械重复`

- **音效的可选性（Optional Layer）** · L5 · 基础 · 成本:低
  - 视觉收益：音效与氛围音分开开关——有人想要音效不想要音乐
  - 提示词片段：`音效与背景音乐独立开关；默认都关闭`

## P3 程序化音频合成（Procedural Audio）

**不需要音频文件，代码生成，且能与视觉参数联动。** 对"零资源依赖"的项目极友好。

- **振荡器与包络（Oscillators & Envelopes）** · L2 · 进阶 · 成本:低
  - 视觉收益：sine/triangle/square/sawtooth + ADSR 包络，合成 UI 音效
  - 同族拓展：`OscillatorNode`、ADSR（attack/decay/sustain/release）、`GainNode` 自动化、detune
  - 提示词片段：`UI 音效用 OscillatorNode 合成（triangle 波更柔和）+ 快速 AD 包络（attack 5ms / decay 90ms）；无音频文件依赖`

- **噪声与滤波（Noise & Filters）** · L2 · 进阶 · 成本:低
  - 视觉收益：白噪声 + 带通滤波 = 风声、气流、沙沙声；低通扫频 = 冲击感
  - 同族拓展：`BiquadFilterNode`（lowpass/bandpass/highpass）、噪声缓冲、滤波器扫频、共振（Q值）
  - 提示词片段：`环境风声用白噪声 + 带通滤波（中心频率随时间缓慢漂移）；冲击音用低通扫频`

- **氛围铺底（Ambient Drone）** · L2 · 进阶 · 成本:低
  - 视觉收益：低频持续音铺底，产生"空间存在感"，是沉浸感最便宜的来源
  - 同族拓展：多个失谐低频正弦叠加（beating 拍频）、缓慢 LFO 调制、混响（ConvolverNode 或算法混响）
  - 提示词片段：`氛围底噪用 2-3 个失谐低频正弦（如 55/55.3/82.5Hz）叠加，LFO 缓慢调制音量；加长混响`

- **参数联动（Parameter Coupling）** · L2 · 电影级 · 成本:低
  - 视觉收益：**声音随视觉参数变化**——相机靠近黑洞时嗡鸣变低变响，滚动速度改变噪声强度
  - 同族拓展：视觉 uniform → audio param、`AudioParam` 平滑（`setTargetAtTime`）、避免突变咔嗒声
  - 提示词片段：`把视觉关键参数（相机距离/滚动速度/强度）映射到音频（频率/音量/滤波），用 setTargetAtTime 平滑避免咔嗒`

- **音阶与和谐（Scales & Harmony）** · L0 · 进阶 · 成本:低
  - 视觉收益：交互音落在同一音阶内，多次触发也和谐不刺耳
  - 同族拓展：五声音阶（最不易出错）、大调音阶、纯五度、避免半音相邻
  - 提示词片段：`交互音的音高从五声音阶中取（最不易出错），随位置/序号选音级；同时发声保持和谐音程`

- **混响与空间（Reverb & Space）** · L2 · 进阶 · 成本:低
  - 视觉收益：混响量暗示空间大小——小房间干、大教堂湿
  - 同族拓展：`ConvolverNode` + 脉冲响应、算法混响、dry/wet 混合、见 `R16·P4`
  - 提示词片段：`混响量匹配视觉空间尺度（狭窄空间 wet 0.1、开阔空间 wet 0.4）；场景切换时平滑过渡混响`

## P4 空间音频（Spatial Audio）

- **3D 定位（PannerNode / HRTF）** · L2 · 电影级 · 成本:中
  - 视觉收益：声音从物体所在的方向传来，3D 场景沉浸感质变
  - 同族拓展：`PannerNode` (HRTF 模式)、`AudioListener` 跟随相机、距离衰减模型、锥形方向性
  - 提示词片段：`3D 场景中的音源用 PannerNode(HRTF)，位置跟随物体；AudioListener 跟随相机位置与朝向`

- **距离衰减（Distance Attenuation）** · L2 · 进阶 · 成本:低
  - 视觉收益：远处声音小且闷（高频先衰减），符合物理直觉
  - 同族拓展：`distanceModel: 'inverse'`、`refDistance`/`maxDistance`/`rolloffFactor`、距离联动低通滤波
  - 提示词片段：`距离衰减用 inverse 模型；同时按距离加低通滤波（远处更闷），比单纯降音量真实得多`

- **遮挡与阻隔（Occlusion）** · L2 · 电影级 · 成本:中
  - 视觉收益：墙后的声音变闷变小，空间感立体
  - 同族拓展：raycast 检测遮挡 → 低通 + 衰减、房间混响切换
  - 提示词片段：`射线检测音源与听者间的遮挡，遮挡时加强低通（cutoff 降到 800Hz）并降音量 40%`

- **立体声场宽度（Stereo Width）** · L5 · 进阶 · 成本:低
  - 视觉收益：即使 2D 界面，左右声道差异也能强化"位置感"（左侧面板的音效偏左）
  - 同族拓展：`StereoPannerNode`、简单 pan 按屏幕 x 位置、避免极端 pan（±0.6 以内）
  - 提示词片段：`2D 界面音效按元素屏幕 x 位置做轻微 pan（±0.4 以内），强化位置感`

## P5 触觉反馈（Haptics）

- **振动反馈（Vibration API）** · L5 · 进阶 · 成本:低
  - 视觉收益：移动端的物理确认感，成本极低
  - 关键约束：**必须极短**（10–30ms）；Android 支持好，iOS Safari 支持受限；连续振动很招人烦
  - 同族拓展：`navigator.vibrate([10])`、pattern 数组、iOS 的替代方案（有限）
  - 提示词片段：`移动端关键操作加 10-20ms 轻振动（navigator.vibrate）；不做连续或长振动；可关闭`

- **触觉语义（Haptic Semantics）** · L5 · 进阶 · 成本:低
  - 视觉收益：不同操作不同触感模式
  - 参考映射：轻点确认 10ms｜切换 15ms｜成功 [10,40,10]｜错误 [30,60,30]｜吸附对齐 8ms
  - 提示词片段：`触觉分级：确认 10ms、切换 15ms、成功 [10,40,10]、错误 [30,60,30]、吸附 8ms`

- **与视听同步（Tri-Modal Sync）** · L5 · 电影级 · 成本:低
  - 视觉收益：视觉 + 声音 + 触觉同时到达，确认感极强
  - 提示词片段：`关键操作三通道同步（视觉 scale 反馈 + 短音效 + 轻振动），全部在 50ms 内触发`

## P6 多通道冗余与无障碍（Multi-Modal Redundancy）

- **信息不依赖单一通道（No Single-Channel Info）** · L5 · 基础 · 成本:低
  - 视觉收益：这既是无障碍要求，也让所有用户更容易接收信息
  - 同族拓展：见 `R2·K3` 色彩不能是唯一通道、声音不能是唯一提示、字幕
  - 提示词片段：`任何状态/提示不得只靠声音或只靠颜色传达；至少两个通道（视觉+文字 / 视觉+触觉）`

- **音频的文字替代（Audio Alternatives）** · L5 · 基础 · 成本:低
  - 视觉收益：听障用户与静音用户都能获得信息
  - 同族拓展：字幕、`aria-live` 播报、视觉波形指示、音频内容的文字说明
  - 提示词片段：`有语音/旁白时提供字幕；音频驱动的视觉变化同时有视觉指示，不依赖听觉`

- **屏幕阅读器与 canvas（Screen Reader）** · L5 · 基础 · 成本:低
  - 视觉收益：canvas 内容对读屏器不可见，必须给文字替代
  - 同族拓展：见 `R10·I8`、`aria-label`、`role="img"` + 描述、隐藏的文字版内容
  - 提示词片段：`canvas 加 role="img" + aria-label 描述画面；提供隐藏的文字版内容供读屏器`

- **前庭失调与晕动（Vestibular / Motion Sickness）** · L5 · 基础 · 成本:低
  - 视觉收益：大幅视差、快速缩放、旋转会让部分用户头晕
  - 同族拓展：`prefers-reduced-motion`（见 `R11·F5`）、限制视差幅度、避免大面积快速位移、提供关闭 3D 的选项
  - 提示词片段：`尊重 prefers-reduced-motion 关闭视差与相机运动；视差幅度上限 30px；提供"简化视觉"开关`

- **闪烁安全（Flash Safety）** · L5 · 基础 · 成本:低
  - 视觉收益：>3Hz 的大面积闪烁可能诱发光敏性癫痫——这是安全问题不是美观问题。**闪烁安全与多通道冗余属于安全项，不可省。**
  - 同族拓展：WCAG 2.3.1（三闪阈值）、避免高对比快闪、glitch 效果要短（见 `R7·E3`）
  - 提示词片段：`禁止大面积闪烁超过 3Hz；glitch/闪光效果限制在 200ms 内且面积 <25% 视口`

## P 组 · 组合速查

| 想要的效果 | 组合 |
|---|---|
| 最低成本的沉浸感提升 | R16·P3 氛围铺底 + R16·P1 默认静音开关 + R16·P3 参数联动 |
| 完整 UI 音效体系 | R16·P2 六语义 + R16·P3 振荡器合成 + R16·P2 防轰炸 + R16·P1 独立开关 |
| 3D 场景的声音 | R16·P4 HRTF 定位 + R16·P4 距离衰减+低通 + R16·P4 遮挡 + R16·P3 混响匹配空间 |
| 零资源依赖的音频 | R16·P3 全套（振荡器+噪声滤波+算法混响），不加载任何音频文件 |
| 移动端确认感 | R16·P5 触觉分级 + R16·P5 三通道同步 |
| 无障碍达标 | R16·P6 全套（多通道冗余/字幕/aria/reduced-motion/闪烁安全） |

**常见坑**：
- 一进页面就放音乐 → R16·P1 违反默认静音铁律（也会被浏览器拦）
- 用户找不到关闭按钮 → R16·P1 开关不显眼
- 循环音有咔嗒接缝 → R16·P1 缺 crossfade
- 快速划过按钮响成一片 → R16·P2 缺节流与发声数限制
- 音效很刺耳很累 → R16·P2 落在 2-4kHz 且时长过长
- 音效比视觉慢半拍 → R16·P2 用了 `<audio>` 元素，改 Web Audio 预解码
- 每次都同一个音很机械 → R16·P2 缺音高随机微调
- 参数变化时有咔嗒声 → R16·P3 缺 setTargetAtTime 平滑
- 远处声音只是变小不够真 → R16·P4 缺距离低通
- 切标签页后声音还在响 → R16·P1 缺 visibility 联动
- 长时间振动很烦 → R16·P5 应该 ≤30ms
- 大面积快闪 → R16·P6 安全问题，必须限制

> **P 组心法**：**声音的默认答案是"不要"**，但一旦要做就必须做全（礼貌开关 + 语义体系 + 精确同步）。半成品音频比没有音频更糟。程序化合成（R16·P3）是性价比最高的路——零资源、可联动、可无限变化。
