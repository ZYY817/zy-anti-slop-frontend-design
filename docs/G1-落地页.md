# G1 · 落地页 Prompt 库

> 最实战的部分。直接抄、填空、发给 AI。
> 每个模板经过结构化设计，覆盖"视觉+布局+交互+体验+工程"全五层。

## 模板一：SaaS 产品落地页

```
【场景】：B2B SaaS 产品主页，面向技术团队决策者。目标：30 秒内理解产品价值并注册试用。
【气质】：克制、精密、专业。参考 Linear / Vercel / Raycast 的气质。
【技术栈】：React + TypeScript + Tailwind CSS + Framer Motion + shadcn/ui

【结构】（7 段）：
1. Hero — 一句话价值主张 + 副标题 + 主 CTA (Start free) + 次 CTA (Live demo) + 产品截图/视觉
2. Social Proof — Logo 墙（6-8 家客户 Logo）+ "Trusted by X teams"
3. Features — 3 列特性卡片，每张：图标 + 标题 + 一句话描述
4. How it works — 3 步骤，带序号和连接线
5. Testimonials — 2-3 条用户评价，头像 + 姓名 + 职位 + 引言
6. Pricing — 3 个方案（Free / Pro / Enterprise），推荐方案突出
7. CTA + Footer — 最终号召 + 简洁 footer

【视觉系统】：
- 主色：#0A0A0A（近黑），强调色：#3B82F6（蓝）
- 中性色：Tailwind slate 系列
- 字体：Inter + 系统字体栈
- 字号阶梯（1.25）：Display 64/1.1/700, H2 36/1.2/600, Body 16/1.5/400, Caption 14/1.5/400
- 字重：400/500/700 三档
- 圆角统一 8px，卡片 12px
- 阴影：仅 hover 时微浮（shadow-sm → shadow-md）
- 60% neutral + 30% 主色 + 10% 蓝强调

【布局】：
- 12 列栅格，max-width 1280px，container padding 24px
- Hero padding-y 128px，section 间距 96px
- 断点：mobile <768 / desktop ≥1024
- 移动端单栏，Features 卡片改为纵向堆叠

【交互与动效】：
- 入场：fadeIn + translateY(20→0)，duration 400ms，stagger 80ms
- 按钮 hover: scale(1.02) + 背景色 600
- 按钮 active: scale(0.97)
- 滚动入场：每个 section 视口 80% 时触发
- 减弱动效时：仅保留 fade
- CTA 按钮有微光(shimmer)吸引注意

【体验】：
- 首屏 3 秒内明白"这是什么 + 我能获得什么 + 下一步做什么"
- 导航 ≤5 项（遵循希克定律）
- 主 CTA 全站最醒目（菲茨定律）
- 定价方案用锚定效应 + 社会证明标签

【无障碍】：
- 对比度 WCAG AA
- focus ring 清晰
- 键盘可导航
- 图片有 alt
- 语义化 HTML (header/main/section/footer)
```

## 模板二：品牌/创意落地页

```
【场景】：创意工具产品首页，面向设计师/创作者。目标：传达品牌气质，驱动注册。
【气质】：大胆、表现力强、有创意。参考 Figma / Framer / Pitch 的活力感。
【技术栈】：Next.js + Tailwind + Framer Motion + GSAP (滚动动画)

【结构】（6 段）：
1. Hero — 巨型标题(Display 96/1.0/800) + 动态产品展示(自动播放动画) + CTA
2. Showcase — 用户作品瀑布流 / 动态画廊
3. Features — 交替图文（Z 形布局），每行一个核心功能 + 动态展示
4. Community — 用户数量 / 社区规模 / 集成数量 统计数字
5. Pricing — 简洁 2 方案
6. Footer CTA — 全宽深色背景 + 最终号召

【视觉】：
- 深色基底 #0A0A0A + 多彩强调（紫→蓝→粉 mesh gradient）
- Display 字体超大(72-128px)、字重 800-900
- 大量留白（section padding 128-160px）
- 渐变：aurora style mesh gradient 背景
- 圆角 16px，卡片玻璃质感 (backdrop-blur + border white/10)

【动效】：
- GSAP ScrollTrigger 驱动
- Hero 文字按字出现
- 产品图 parallax（不同层速度不同）
- 数字统计 counter tween 动画
- 整体节奏感强

【体验要点】：
- 更偏"感受"而非"功能列表"
- 峰终定律：Hero 的视觉冲击是峰，Footer CTA 是终
- 长页面但每屏都有新内容奖励
```

## 模板三：极简/编辑感落地页

```
【场景】：独立开发者工具 / 博客平台 / 文档类产品。低调、有品味。
【气质】：编辑感、杂志排版、极度克制。参考 iA Writer / Notion 官网 / Arc Browser。
【技术栈】：Astro + Tailwind + 无额外动画库

【结构】（5 段）：
1. Hero — 一句话（字号 48-56, 字重 500）+ 副标（灰色 16/400）+ 单 CTA
2. 产品截图 — 全宽、真实截图、无花哨
3. Features — 文字为主的列表，无图标无图片，每条一行加解释
4. Testimonial — 单条，大字引用
5. Footer — 极简链接

【视觉】：
- 几乎纯黑白（#111 / #fafafa / #666）
- 字体：衬线体标题 (Playfair / EB Garamond) + 无衬线正文 (Inter)
- 字号对比极强：Hero 56px vs Body 16px（比例 1.618 黄金比）
- 零阴影、零圆角或仅 2px
- 间距极大（section 160px，hero padding 200px）

【交互】：
- 几乎无动画
- hover 仅 underline 或 opacity 变化
- 页面加载直接呈现（无 stagger）

【关键词】：editorial, monochrome, generous whitespace, typography-driven
```

## 模板四：电商/消费品落地页

```
【场景】：DTC 消费品品牌（护肤/食品/时尚）首页。目标：品牌好感 + 转化。
【气质】：温暖、有质感、生活方式感。参考 Glossier / Aesop / Apple Store。
【技术栈】：Next.js + Tailwind + Framer Motion

【结构】（8 段）：
1. Hero — 全屏产品大图 + overlay 文字 + Shop Now CTA
2. Story — 品牌故事，文字+生活方式图交替
3. Products — 4 列产品卡片网格，悬浮变体切换
4. Benefits — 4 个图标+标题+描述的特性
5. Social Proof — UGC 照片墙 + 评价
6. How to Use — 步骤图
7. Newsletter — 邮箱订阅
8. Footer — 品牌 + 链接 + 社交

【视觉】：
- 暖色调：背景 #FDFBF7（米色）/ 主色 #1A1A1A / 强调 #C8A96B（金）
- 字体：衬线标题 + 无衬线正文
- 产品图占比大，高质量
- 圆角 12-16px，阴影柔和
- 大量呼吸空间

【交互】：
- 产品卡片 hover 换图
- 滚动入场 fade
- 加购按钮微弹
- 惯性滚动

【转化优化】：
- 损失厌恶："仅剩 X 件"
- 社会证明："4.9⭐ 2000+ 评价"
- 信任信号：退换政策、安全支付、客户 Logo
```

## 模板五：AI/Chat 产品落地页

```
【场景】：AI 工具/Chat 产品主页。目标：让用户理解 AI 能做什么 + 立即试用。
【气质】：科技、未来、智能但不冷冰冰。参考 ChatGPT / Anthropic / Perplexity。
【技术栈】：Next.js + Tailwind + Framer Motion

【结构】（6 段）：
1. Hero — "What can I help you with?" 对话式 + 可直接输入的搜索/对话框 + suggested prompts
2. Demo — 动态 mock 对话展示 AI 能力（流式输出效果）
3. Capabilities — 3-4 个核心能力卡片
4. Use Cases — 标签切换不同场景
5. Trust — 安全/隐私/准确性承诺
6. CTA — "Try it free" + 无需注册

【视觉】：
- 深色 #0D0D0D + 紫蓝渐变强调 + 柔光效果
- Aurora mesh gradient 背景
- 字体 Geist / Inter
- 对话气泡卡片：backdrop-blur + 边框 white/5
- 流式文字的光标闪烁效果

【特殊交互】：
- Hero 输入框是真正可用的（直接跳转到产品）
- Demo 区域模拟实时打字效果
- Suggested prompts 横向可滚动 chips
- Capability 卡片 hover 展示详情

【AI 界面特殊术语】：
- streaming response（流式响应）
- typing indicator（输入指示器）
- citation card（引用卡片）
- confidence indicator（置信度指示）
- tool calling visualization（工具调用可视化）
```

## 模板六：移动端 App 推广页

```
【场景】：App 下载推广页，移动端为主要访问设备。
【气质】：简洁有力、下载转化导向。参考 Arc / Notion / Linear 的 App 推广页。
【技术栈】：Astro + Tailwind

【结构】（5 段）：
1. Hero — 手机 Mockup + 标题 + App Store / Google Play 按钮
2. Features — 纵向特性滚动（左图右文交替）
3. Screenshots — 手机截图横向滑动
4. Ratings — 评分 + 精选评价
5. Download CTA — 固定底部悬浮 CTA (移动端)

【视觉】：
- 手机 Mockup 是视觉核心
- 圆角跟随手机形状 (44px)
- 渐变背景
- 移动端 padding 24px
- 字号偏大（移动端正文 17px）

【移动端特殊】：
- 无桌面宽幅布局
- CTA sticky bottom bar
- 截图可左右滑动
- 单列堆叠
```

## 使用方法

1. 选择最接近你场景的模板
2. 替换 `{}` 中的变量为你的实际信息
3. 删除不需要的段落
4. 直接发给 AI

**关键认知**：prompt 信息量 ≈ 产出质量。上面任何一个模板发给 AI，产出都远超"帮我做个好看的落地页"。
