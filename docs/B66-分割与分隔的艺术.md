# B66 · 分割与分隔的艺术

> 界面不是一锅粥——它需要**结构**。但结构不意味着到处画线。
> 分隔是排版的标点符号:逗号(小间距)、句号(大间距)、分号(分隔线)、段落换行(背景色变)。
> 用得好是"清晰",用多了是"吵"。最高境界是**看不见分隔,却感受到结构**。
> 这份文档拆的是:何时用什么分隔、每种分隔的视觉参数、以及"不分隔"的力量。

---

## 一、分隔术语表

| 中文术语 | 英文术语 | 一句话含义 |
|---|---|---|
| 分隔线 | Divider / Separator | 用线条划分两个区域 |
| 间距分隔 | Space Separator | 用空白距离隐性划分 |
| 背景色分隔 | Color Separator | 用不同底色划分区域 |
| 边框分隔 | Border Separator | 用容器边框划分 |
| 阴影分隔 | Shadow Separator | 用投影制造层次分离 |
| 显性分隔 | Explicit Division | 有可见元素的分隔(线/框/色) |
| 隐性分隔 | Implicit Division | 无可见元素,仅靠间距对齐 |
| 全宽分隔线 | Full-bleed Divider | 横跨全宽的分隔线 |
| 缩进分隔线 | Inset Divider | 左右留出边距的分隔线 |
| 中段分隔线 | Middle Divider | 较短,居中的分隔线 |
| 竖分隔线 | Vertical Divider | 垂直方向的分隔线 |
| 分割面 | Section Break | 大板块之间的强分割 |
| 装饰分隔 | Decorative Divider | 带装饰(波浪/斜切/图案)的分隔 |
| 格式塔-接近 | Proximity (Gestalt) | 近的元素被感知为一组 |
| 格式塔-相似 | Similarity (Gestalt) | 相似的元素被感知为同类 |
| 格式塔-共同区域 | Common Region | 同一区域内的元素被感知为一组 |
| 内容分组 | Content Grouping | 相关内容归为一组的行为 |
| 视觉断裂 | Visual Break | 视线路径上的中断/跳变 |

## 二、分隔手段的优先级

### 2.1 六种分隔手段(从轻到重)

```
⓵ 间距(最轻,首选)
⓶ 对齐/缩进
⓷ 背景色差
⓸ 分隔线
⓹ 边框/容器
⓺ 阴影/层级

越轻的手段越优先使用。越重的手段越慎重。
```

### 2.2 决策树

```
需要分隔两个元素?
  └─ 它们在同一组内吗?
      ├─ 是 → ⓵ 小间距(8-12px)足够
      └─ 否 → 它们在同一板块内吗?
              ├─ 是 → ⓵ 大间距(24-40px)或 ⓸ 细线
              └─ 否 → ⓷ 背景色变 或 ⓵ 极大间距(64-120px)
```

### 2.3 量化标准

| 关系 | 推荐间距 | 是否需要显性分隔 |
|---|---|---|
| 同组内元素 | 8-12px | ❌ 不需要 |
| 组与组之间 | 24-32px | 可选极细线 |
| 板块与板块 | 48-80px | 可选背景色变 |
| 大章节之间 | 96-160px | 可选强分隔(色+间距) |

## 三、间距分隔(最高境界)

### 3.1 格式塔-接近原则

**近的 = 一组,远的 = 分开。不需要任何线。**

```css
/* 组内间距小,组间间距大 → 自然分组 */
.form-group {
  display: flex;
  flex-direction: column;
  gap: 8px;        /* 组内:标签到输入框 8px */
}

.form-group + .form-group {
  margin-top: 24px;  /* 组间:24px,是组内的 3 倍 */
}

.form-section + .form-section {
  margin-top: 48px;  /* 板块间:48px,是组间的 2 倍 */
}
```

### 3.2 间距倍率法则

```
分组间距 ≥ 组内间距 × 2.5
板块间距 ≥ 分组间距 × 2

实例:
组内 8px → 分组 24px(3×)→ 板块 64px(2.7×)
```

**如果间距倍率不足(比如组内 12px,组间 16px),用户就分不清哪些是一组。**

## 四、分隔线的精细用法

### 4.1 分隔线三种类型

```css
/* ① 全宽线(最强):横跨容器 */
.divider-full {
  width: 100%;
  height: 1px;
  background: oklch(0% 0 0 / 0.06);
  margin-block: 20px;
}

/* ② 缩进线(中等):两端留 padding */
.divider-inset {
  width: calc(100% - 32px);
  height: 1px;
  background: oklch(0% 0 0 / 0.06);
  margin: 16px auto;
}

/* ③ 中段线(最弱):短而居中 */
.divider-middle {
  width: 40px;
  height: 1px;
  background: oklch(0% 0 0 / 0.12);
  margin: 32px auto;
}
```

### 4.2 分隔线的视觉参数

```
线宽:    1px(最常用)/ 0.5px(极细精致)/ 2px(强分隔)
颜色:    oklch(0% 0 0 / 0.06-0.10)(亮色模式)
         oklch(100% 0 0 / 0.06-0.10)(深色模式)
外间距:  上下各 16-24px(线本身占的空间)
```

```css
/* 语义化分隔线组件 */
.divider {
  --divider-color: oklch(0% 0 0 / 0.06);
  --divider-space: 16px;
  --divider-width: 1px;

  width: 100%;
  height: var(--divider-width);
  background: var(--divider-color);
  margin-block: var(--divider-space);
  border: none;
}

/* 变体 */
.divider--strong { --divider-color: oklch(0% 0 0 / 0.12); }
.divider--subtle { --divider-color: oklch(0% 0 0 / 0.03); }
```

### 4.3 何时该用 / 不该用分隔线

```
✅ 该用:
- 列表项之间(数据表格行)
- 评论之间
- 侧栏中不同分组(导航组)
- Footer 上方

❌ 不该用(用间距代替):
- 卡片之间(已经有间距+独立容器)
- 表单字段之间(间距足够)
- 段落之间(行高+段距已分开)
- 每个元素之间(过度分隔 = 视觉噪音)
```

### 4.4 竖分隔线

```css
.vertical-divider {
  width: 1px;
  height: 20px;
  background: oklch(0% 0 0 / 0.10);
  align-self: center;
  margin-inline: 12px;
  flex-shrink: 0;
}

/* 用于:面包屑分隔/工具栏分组/元信息 */
```

## 五、背景色分隔

### 5.1 交替色带

```css
.section:nth-child(odd)  { background: oklch(100% 0 0); }
.section:nth-child(even) { background: oklch(97% 0.003 265); }
/* 明度差 3% 就足够区分,但不会太跳 */
```

### 5.2 背景色渐进加深

```css
/* 从浅到深,创造向下的"深入"感 */
.section-1 { background: oklch(99% 0.002 265); }
.section-2 { background: oklch(96% 0.005 265); }
.section-3 { background: oklch(92% 0.008 265); }
.section-4 { background: oklch(15% 0.010 265); color: oklch(95% 0 0); }
```

### 5.3 背景色差的安全范围

```
亮色模式:
- 微妙(几乎看不出):  ΔL 1-2%
- 清晰(明确分区):    ΔL 3-5%
- 强烈(明确"不同区"): ΔL 8-15%

❌ 过度: ΔL > 20% 且无过渡 → 看起来像 bug
```

## 六、装饰性分隔(Section Break)

### 6.1 波浪分隔

```css
.wave-divider {
  position: relative;
  margin-top: -40px;
}
.wave-divider svg {
  display: block;
  width: 100%;
  height: 40px;
  fill: oklch(97% 0.003 265);  /* 下一 section 的背景色 */
}
```

```html
<div class="wave-divider">
  <svg viewBox="0 0 1440 40" preserveAspectRatio="none">
    <path d="M0,20 C480,60 960,0 1440,20 L1440,40 L0,40 Z"/>
  </svg>
</div>
```

### 6.2 斜切分隔

```css
.slant-divider {
  position: relative;
}
.slant-divider::after {
  content: "";
  position: absolute;
  bottom: 0;
  left: 0;
  right: 0;
  height: 80px;
  background: inherit;
  clip-path: polygon(0 0, 100% 60%, 100% 100%, 0 100%);
}
```

### 6.3 渐变羽化分隔

```css
/* 上下 section 之间用渐变过渡,无硬边 */
.section-fade::after {
  content: "";
  position: absolute;
  bottom: -60px;
  left: 0;
  right: 0;
  height: 120px;
  background: linear-gradient(
    to bottom,
    currentBackgroundColor,
    nextBackgroundColor
  );
  pointer-events: none;
}
```

### 6.4 何时该用装饰分隔

```
✅ 用:
- 落地页/品牌页 section 之间(增加趣味)
- 白 → 深色的过渡
- 需要"这里是新篇章"的视觉信号

❌ 不用:
- 后台/工具型产品(不合气质)
- 所有 section 都用(审美疲劳)
- 与品牌极简调性冲突
```

## 七、"不分隔"的力量

### 7.1 格式塔:共同区域代替线

```css
/* 不用线,用"同一个背景"表示一组 */
.card-group {
  background: var(--surface);
  border-radius: 12px;
  padding: 4px;
  display: flex;
  flex-direction: column;
}

.card-group .item {
  padding: 12px 16px;
  border-radius: 8px;
}

.card-group .item:hover {
  background: oklch(0% 0 0 / 0.03);
}

/* 没有分隔线,但 items 在同一个"容器"内,自然感知为一组 */
```

### 7.2 对齐代替线

```css
/* 左侧对齐线本身就是"隐形分隔" */
.list {
  padding-left: 16px;
  border-left: 2px solid var(--brand);  /* 只有这一根左线暗示分组 */
}
```

### 7.3 typography 代替线

```css
/* 用标题/字号变化代替分隔线 */
.section-title {
  font-size: 11px;
  font-weight: 600;
  text-transform: uppercase;
  letter-spacing: 0.08em;
  color: var(--text-tertiary);
  margin-top: 32px;
  margin-bottom: 12px;
  /* 不需要线:字号+大写+色彩已经"断开"了前后内容 */
}
```

## 九、踩坑指南

### 坑1:到处画线
**症状**:每两个元素之间都有分隔线,界面像表格。
**解法**:80% 的分隔用间距就够了,线只用于必要处。

### 坑2:间距不足导致需要额外加线
**症状**:因为间距太小分不清分组,只好加线。
**解法**:先加大间距(倍率 ≥ 2.5×),问题自然消失。

### 坑3:分隔线颜色太深
**症状**:分隔线 alpha 0.2+,抢夺内容注意力。
**解法**:alpha 0.06-0.08,几乎看不见但能感知到。

### 坑4:背景色差太大且无过渡
**症状**:白色直接跳深灰,像坏了。
**解法**:ΔL ≤ 5% 渐进,或用渐变/波浪过渡。

### 坑5:装饰分隔每个 section 都用
**症状**:每个区块都有波浪/斜切,审美疲劳。
**解法**:一页最多 1-2 处装饰分隔。

### 坑6:深色模式忘记翻转分隔线颜色
**症状**:深色底上用 rgba(0,0,0,0.1) 完全看不见。
**解法**:深色模式用 rgba(255,255,255,0.06)。

## 十、谁在用(分隔典范)

| 产品 | 分隔手法 | 值得学的 |
|---|---|---|
| **Apple** | 纯间距分隔 | 几乎无线,靠极致间距区分 |
| **Notion** | 极细缩进线 | 只在列表项间用,hover 才显示 |
| **Linear** | 间距+微光线 | 深色模式用 0.5px 微光线 |
| **Stripe 落地页** | 背景色渐进 | 白→浅灰→深色的叙事感 |
| **iOS 设置** | 缩进线(左侧齐图标) | 经典:线不到最左,从图标后开始 |
| **Vercel** | 无线设计 | 纯靠间距和字号变化分组 |

## 检验清单

- [ ] 80% 的分隔靠间距实现(不是线)
- [ ] 间距倍率:组间 ≥ 组内 × 2.5
- [ ] 分隔线 alpha 0.06-0.08(不过深)
- [ ] 分隔线有明确用途(不是"好像该加根线")
- [ ] 深色模式分隔线用 rgba(255,255,255,0.06)
- [ ] 背景色差 ΔL ≤ 5%(不跳变)
- [ ] 装饰分隔一页 ≤ 2 处
- [ ] 无"卡片间还加分隔线"的冗余
- [ ] 标题/字号变化能代替线的地方不用线
