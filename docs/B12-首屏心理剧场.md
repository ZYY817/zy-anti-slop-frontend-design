# B12 · 首屏心理剧场

> 用户进入页面的前 3 秒,大脑经历了一整场戏。
> 高手设计首屏时,设计的不是元素,是这场心理小剧场。

---

## 一、这 3 秒里,用户大脑发生了什么

时间线(基于 Google + Basel 大学眼动研究):

```
0-17ms      视觉冲击进入视网膜
17-50ms     大脑形成审美判断("好看/难看/廉价/高级")
50-200ms    识别是什么(是电商?工具?品牌?)
200-500ms   开始理解价值主张(我为什么在这)
500-1500ms  评估要不要留下
1500-3000ms 决定下一步动作
```

**结论**:
- 前 50ms 决定了"审美好感度"——**这是视觉层的战场**
- 200-500ms 决定了"我理解了"——**这是文案层的战场**
- 1-3 秒决定了"我要行动"——**这是转化层的战场**

三个战场,首屏必须同时打赢。

---

## 二、前 50ms 战场:审美瞬间判断

用户看到的**第一眼**,基于什么下判断?

- **明暗基调** — 深色 vs 浅色 → 稳重 vs 明快
- **色彩饱和度** — 高饱和 = 活力/廉价 / 低饱和 = 高级/克制
- **构图密度** — 稀疏留白 = 高级 / 密集 = 廉价或专业
- **对比度** — 高对比 = 果断 / 低对比 = 柔和
- **字体感觉** — 衬线 = 传统权威 / 无衬线 = 现代
- **圆角强度** — 大圆角 = 亲切 / 直角 = 严肃
- **图片质感** — 高质图 = 专业 / 低质图 = 山寨

**这一层几乎是本能反应,用户自己都说不清"为什么感觉好"。**

### 首屏审美信号强化清单
- [ ] 单一主色调,不花哨
- [ ] 中性色统一冷暖
- [ ] 至少 40% 留白
- [ ] 一个明确视觉焦点
- [ ] 字体考究(不用系统默认宋体/Arial)
- [ ] 图片高清、色调统一
- [ ] 无俗气装饰(渐变滥用、纯色阴影)

## 三、200-500ms 战场:理解发生

50ms 后开始读文字。这时大脑在问三个问题:

### 问题 1:这是什么(What is this?)
必须**一句话说清产品/服务是什么**。
- ✅ "为团队打造的现代协作平台"
- ❌ "重新定义生产力的下一代解决方案"(废话)

### 问题 2:与我有什么关系(Why me?)
用户能不能对号入座?
- ✅ 具体场景:"如果你正在管理 5+ 人的设计团队..."
- ❌ 泛泛而谈:"面向所有人"

### 问题 3:我能得到什么(What's in it for me?)
明确的收益承诺。
- ✅ "让 Standup 从 45 分钟压缩到 5 分钟"
- ❌ "提升团队效率"(空)

### 首屏文案三层公式
```
第一行(H1):     产品是什么   (What)
第二行(副标):    我为什么在意   (Why)
第三行(小字):    具体给我什么   (Benefit)
CTA:             下一步做什么   (Action)
```

## 四、1-3 秒战场:行动决策

用户理解了,现在决定"要不要试试"。这时起作用的是**信任信号**和**摩擦力**。

### 增加信任(推力)
- 客户 Logo 墙("Trusted by...")
- 用户数量("50,000+ teams")
- 评分("4.9 ⭐ on ...")
- 媒体报道 Logo
- 安全/隐私标识
- 具体数字("Ship 3x faster")
- 权威背书

### 降低摩擦(拉力)
- CTA 文案降门槛:"免费试用" > "购买"
- 消除顾虑:"无需信用卡"、"随时取消"
- 简化下一步:"1 分钟设置"、"30 秒开始"
- 提供试用:"看看演示"作为副 CTA

Cialdini 七原则+锚定/稀缺/权威实现方式 → `H3`§六（正典）。**警告**：滥用 = dark pattern → `B84`/`B44`§八。

## 六、首屏动线三大布局

### 1. 中心聚焦式（Centered Focus）
```
       Logo (小,左上)
             │
       ┌─────▼─────┐
       │  H1 主标题 │
       │  副标      │
       │  [主 CTA]  │
       │  信任信号  │
       └────────────┘
```
适合:品牌页、单一强意图页面
气质:极简、克制、高级(Linear / Vercel / Apple)

### 2. 左右分栏式（Split Layout）
```
┌──────────────┬──────────────┐
│  H1 主标题     │              │
│  副标          │   产品截图   │
│  [主 CTA]      │   / 动效展示 │
│  信任信号      │              │
└──────────────┴──────────────┘
```
适合:SaaS、需要展示产品的场景
气质:高效、信息型(Stripe / Notion)

### 3. 沉浸背景式（Immersive Background）
```
╔═══════════════════════════════╗
║        [全屏视觉背景]           ║
║                                ║
║          H1 主标题              ║
║          副标                   ║
║          [主 CTA]               ║
║                                ║
╚═══════════════════════════════╝
```
适合:品牌大片、消费级、创意工具
气质:情感冲击、氛围(Airbnb / Apple 新品页)

## 七、首屏必须回答的问题

首屏四问 → `B87`§四（正典）。本文档补三问：**差异点**(和别的有什么不同)/**信任**(值不值得信)/**成本**(要花多少,明或暗)。

## 八、走/留速查

**走**（3 秒劝退）：看不出是什么/弹窗挡首屏/自动播放有声/CLS 跳动/无主 CTA/"重新定义 XX"废话文案/首屏逼注册 → 排雷细则 `B44`、反模式 `H3`§九。
**留**：3 秒看懂+与我相关+视觉专业+主 CTA 明确+信任信号+下 section 露一角作暗示。

## 九、首屏心理设计的 Prompt 模板

```
【首屏心理剧场设计】

前 50ms(审美冲击):
- 单一主色调,中性色统一冷暖
- ≥40% 留白,单一视觉焦点
- 字体考究(Inter / Geist / 定制)
- 无俗气装饰

200-500ms(理解发生):
文案三层结构:
- H1(What):一句话讲清产品是什么,不用形容词
- 副标(Why):具体场景,让用户对号入座
- 小字(Benefit):具体、可量化的收益承诺
CTA 文案:动词开头 + 降门槛(免费试用/查看演示)

1-3s(行动决策):
信任信号:
- 客户 Logo 墙(6-8 家)
- 用户数量或评分
- "无需信用卡"或"随时取消"
主/次 CTA 层级:
- 主 CTA:强视觉突显,唯一强调色
- 次 CTA:低调,ghost/link 样式

心理触发器(温和使用):
- 社会证明:"10万+团队信任"
- 权威:知名媒体 Logo
- 具体数字:"3 倍效率"、"5 分钟设置"

动线设计:
- Z 型布局:Logo 左上 → 导航 → 中央 H1 → 主 CTA
- 视觉锚点在中央,主 CTA 是全屏视觉最强点
- 底部 section 露出 10-20% 作滚动暗示

回答 7 个隐藏问题:
- What / Who / Why / Differentiator / Trust / Cost / CTA
每个用一句话或一个符号回答

避免:
- 弹窗遮挡、自动播放视频、注册墙
- 废话文案("重新定义"、"下一代")
- 视觉俗气(高饱和、劣质渐变、免费素材图)
```

## 十、检验清单

- [ ] 前 50ms 的视觉冲击是"好感"而非"廉价"
- [ ] 一句话讲清产品是什么(无形容词)
- [ ] 用户能对号入座
- [ ] 收益承诺具体可量化
- [ ] 主 CTA 是全屏最强视觉信号
- [ ] 有 ≥3 个信任信号
- [ ] CTA 文案降低门槛
- [ ] 回答了 7 个隐藏问题
- [ ] 有滚动暗示引导下一屏
- [ ] 没有弹窗/自动播放/注册墙
- [ ] 加载 <2.5s,无 CLS
