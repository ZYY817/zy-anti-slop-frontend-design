# P2 · 布局基础

> 从零开始。页面元素怎么摆、怎么排、怎么居中、怎么适配手机。
> 这份看完,你能说清任何页面的布局结构。

---

## 一、盒模型（Box Model）★ 最基础的基础

网页上每个元素都是一个"盒子",由四层组成:

```
┌───────────────────────────────────┐
│  margin 外边距(盒子外面的空隙)      │
│  ┌─────────────────────────────┐  │
│  │ border 边框                  │  │
│  │  ┌───────────────────────┐  │  │
│  │  │ padding 内边距          │  │  │
│  │  │  ┌─────────────────┐  │  │  │
│  │  │  │ content 内容区    │  │  │  │
│  │  │  └─────────────────┘  │  │  │
│  │  └───────────────────────┘  │  │
│  └─────────────────────────────┘  │
└───────────────────────────────────┘
```

### 四层的作用
- **content** — 文字/图片本身
- **padding** — 内容与边框之间的空隙(盒子"内部"的呼吸)
- **border** — 边框线
- **margin** — 盒子与其他盒子之间的距离

### 关键设置
```css
* { box-sizing: border-box; }
```
**作用**:让 `width` 包含 padding 和 border,不用做加法。**几乎所有项目都会加这一行。**

对比:
```
box-sizing: content-box(默认)
  width: 200px + padding 20px×2 = 实际占 240px  ← 麻烦

box-sizing: border-box(推荐)
  width: 200px(含 padding) = 实际占 200px      ← 直观
```

## 二、元素的两种基本类型

### 块级元素（Block）
- **独占一行**,前后自动换行
- 可以设置宽高
- 例子:`<div>` `<p>` `<h1>` `<section>`

```
┌──────────────────────────┐
│ 块级元素 1                │
└──────────────────────────┘
┌──────────────────────────┐
│ 块级元素 2                │
└──────────────────────────┘
```

### 行内元素（Inline）
- **不换行**,横向排列
- 设置宽高无效
- 例子:`<span>` `<a>` `<strong>` `<em>`

```
[行内1][行内2][行内3] 文字继续...
```

### 行内块（Inline-block）
- 横向排列,但可以设宽高
- 例子:`<img>` `<button>`

---

## 三、文档流（Normal Flow）

默认情况下,元素按 HTML 顺序**从上到下、从左到右**排列。这叫"文档流"。

```
HTML 顺序        →     页面显示
<h1>            →     标题在最上
<p>             →     段落跟着
<div>           →     再往下
```

**布局的本质**:要么顺着文档流,要么把元素"拿出来"另外摆(定位/浮动)。

## 四、居中 —— 最常见的需求

### 水平居中(块级元素)
```css
.box {
  width: 600px;
  margin: 0 auto;   /* 左右自动分配 */
}
```

### 水平居中(文字)
```css
.text { text-align: center; }
```

### 水平垂直都居中(现代方法,推荐)
```css
.parent {
  display: flex;
  justify-content: center;  /* 水平居中 */
  align-items: center;      /* 垂直居中 */
}
```

### 更简单的写法
```css
.parent {
  display: grid;
  place-items: center;   /* 一行搞定水平+垂直 */
}
```

## 五、Flexbox —— 一维布局(最常用)

**适合**:一行或一列的排列。导航栏、按钮组、卡片横排。

### 基本用法
```css
.container {
  display: flex;
}
```
子元素自动横向排列。

### 方向
```css
flex-direction: row;      /* 横向(默认) */
flex-direction: column;   /* 纵向 */
```

### 主轴对齐(横向时=水平)
```css
justify-content: flex-start;    /* 靠左(默认) */
justify-content: center;        /* 居中 */
justify-content: flex-end;      /* 靠右 */
justify-content: space-between; /* 两端对齐,中间平分 */
justify-content: space-around;  /* 每个周围等距 */
justify-content: space-evenly;  /* 所有间隙相等 */
```

**图示 space-between**:
```
[A]          [B]          [C]
↑左边缘                    ↑右边缘
```

### 交叉轴对齐(横向时=垂直)
```css
align-items: stretch;      /* 撑满(默认) */
align-items: center;       /* 垂直居中 */
align-items: flex-start;   /* 顶部对齐 */
align-items: flex-end;     /* 底部对齐 */
```

### 间隙
```css
gap: 16px;   /* 子元素之间的间距,最简单的方法 */
```

### 弹性伸缩
```css
.item { flex: 1; }         /* 平分剩余空间 */
.item { flex-grow: 1; }    /* 可以变大 */
.item { flex-shrink: 0; }  /* 不许变小 */
```

### 换行
```css
flex-wrap: wrap;   /* 装不下就换行 */
```

### 实用组合
```css
/* 导航栏:Logo 左,菜单右 */
.nav { display: flex; justify-content: space-between; align-items: center; }

/* 按钮组:横排,间距 12px */
.buttons { display: flex; gap: 12px; }

/* 卡片内容:纵向,间距 16px */
.card { display: flex; flex-direction: column; gap: 16px; }

/* 单个元素靠右 */
.push-right { margin-left: auto; }
```

## 六、Grid —— 二维布局

**适合**:网格排列。卡片墙、图片画廊、复杂页面结构。

### 基本用法
```css
.container {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;   /* 三列等宽 */
  gap: 24px;
}
```

### fr 单位
`fr` = fraction(份数),表示剩余空间的比例。
```css
grid-template-columns: 1fr 2fr;      /* 1:2 比例 */
grid-template-columns: 200px 1fr;    /* 固定+自适应 */
grid-template-columns: repeat(4, 1fr); /* 四列等宽 */
```

### 自动响应式网格(超实用)
```css
grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));
```
**意思**:每列最小 280px,能放几列就放几列,自动换行。**不用写媒体查询就响应式了。**

### 跨列跨行
```css
.item { grid-column: span 2; }   /* 占 2 列 */
.item { grid-row: span 2; }      /* 占 2 行 */
```

### 命名区域(复杂布局)
```css
.layout {
  display: grid;
  grid-template-areas:
    "header  header"
    "sidebar main"
    "footer  footer";
  grid-template-columns: 240px 1fr;
}
.header  { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main    { grid-area: main; }
.footer  { grid-area: footer; }
```

## 七、Flexbox vs Grid 怎么选

| 情况 | 用什么 |
|---|---|
| 一行按钮 | Flex |
| 导航栏 | Flex |
| 卡片纵向堆叠 | Flex column |
| 卡片网格墙 | Grid |
| 整页布局(头/侧/主/尾) | Grid |
| 内容决定大小 | Flex |
| 需要严格对齐网格 | Grid |

**口诀**:一维用 Flex,二维用 Grid。

## 八、定位（Position）

把元素"拿出"文档流,精确摆放。

| 值 | 效果 |
|---|---|
| `static` | 默认,跟着文档流 |
| `relative` | 相对自己原位置偏移,原位置还占着 |
| `absolute` | 相对最近的定位祖先摆放,脱离文档流 |
| `fixed` | 相对浏览器窗口固定,滚动不动 |
| `sticky` | 滚动到阈值后变固定 |

### 常见用法
```css
/* 徽标贴在头像右上角 */
.avatar { position: relative; }
.badge  { position: absolute; top: -4px; right: -4px; }

/* 顶部导航吸顶 */
.header { position: sticky; top: 0; z-index: 20; }

/* 悬浮按钮固定右下 */
.fab { position: fixed; bottom: 24px; right: 24px; }

/* 全屏遮罩 */
.overlay { position: fixed; inset: 0; }   /* inset:0 = 四边都 0 */
```

## 九、z-index 层级

元素重叠时,谁在上面。数字越大越上面。

```css
/* 建议的层级规划 */
.dropdown { z-index: 10; }
.sticky   { z-index: 20; }
.fixed    { z-index: 30; }
.overlay  { z-index: 40; }
.modal    { z-index: 50; }
.tooltip  { z-index: 70; }
.toast    { z-index: 80; }
```

**注意**:`z-index` 只在有 `position`(非 static)时生效。

## 十、间距系统 —— 让页面整齐的关键

### 为什么要"系统"
```
❌ 随手写:padding: 15px; margin: 22px; gap: 13px;
   → 看起来"乱",说不出哪里不对

✅ 用系统:padding: 16px; margin: 24px; gap: 12px;
   → 看起来"整",专业
```

### 4pt 系统(推荐)
所有间距都是 4 的倍数:
```
4, 8, 12, 16, 20, 24, 32, 40, 48, 64, 80, 96, 128
```

### 用在哪
```
4px   图标与文字之间
8px   紧密相关的元素
12px  按钮之间
16px  标准间距、卡片内 padding(小)
24px  卡片内 padding(标准)、卡片之间
32px  小区块之间
48px  区块之间(移动端)
64px  区块之间
96px  大区块之间(桌面)
```

### 接近性原则
**相关的靠近,无关的远离**:
```
标题
  ↕ 8px  ← 近,说明标题和描述是一组
描述文字
  ↕ 32px ← 远,说明下面是新内容
下一个标题
```

## 十一、宽度与容器

### 内容最大宽度
不要让内容铺满超宽屏幕:
```css
.container {
  max-width: 1280px;   /* 内容最宽 1280 */
  margin: 0 auto;      /* 居中 */
  padding: 0 24px;     /* 两侧留白 */
}
```

### 常见最大宽度
```
640px   窄内容
768px   文章
1024px  中等
1280px  标准网站 ← 最常用
1440px  宽网站
65ch    纯文本阅读(约 700px)
```

## 十二、响应式基础

### 视口设置(必须有)
```html
<meta name="viewport" content="width=device-width, initial-scale=1">
```
**没有这行,手机上会显示成缩小的桌面版。**

### 媒体查询
```css
/* 默认:手机样式 */
.card { padding: 16px; }

/* 768px 以上:平板 */
@media (min-width: 768px) {
  .card { padding: 24px; }
}

/* 1024px 以上:桌面 */
@media (min-width: 1024px) {
  .card { padding: 32px; }
}
```

### 移动优先（Mobile First）
**先写手机样式,再用 `min-width` 逐级覆盖。**
好处:手机加载的 CSS 更少,逻辑更清晰。

### 常用断点
```
640px   手机横屏 / 大手机
768px   平板
1024px  小笔记本
1280px  桌面
1536px  大屏
```

### 响应式常见变化
| 元素 | 手机 | 桌面 |
|---|---|---|
| 布局 | 单栏 | 多栏 |
| 导航 | 汉堡菜单 | 横向菜单 |
| 卡片 | 1 列 | 3-4 列 |
| padding | 16px | 24-32px |
| 字号 | 稍小 | 稍大 |
| 图片 | 竖版 | 横版 |

## 十四、语义化 HTML 标签

用有意义的标签,而不是全用 `<div>`:

```html
<header>   页头
<nav>      导航
<main>     主内容(每页一个)
<article>  独立文章
<section>  章节
<aside>    侧边补充
<footer>   页脚
<figure>   图片+说明
<figcaption> 图片说明
```

**为什么重要**:SEO 更好、屏幕阅读器能理解、代码更易读。

## 十五、布局新手最常犯的 10 个错

1. ❌ 忘了 `box-sizing: border-box`
2. ❌ 忘了 viewport meta 标签(手机显示异常)
3. ❌ 间距随手写(15px/22px,不成系统)
4. ❌ 用 `float` 做布局(过时了,用 Flex/Grid)
5. ❌ 内容铺满超宽屏(没设 max-width)
6. ❌ 移动端 padding 太小(<16px 觉得挤)
7. ❌ 全用 `<div>`(不用语义标签)
8. ❌ z-index 乱写(999999)
9. ❌ 只在桌面测试(手机全乱)
10. ❌ 用绝对定位摆一切(难维护)

## 十六、给 AI 的基础布局 prompt

```
【布局要求】
- 全局 box-sizing: border-box
- 容器 max-width 1280px,居中,两侧 padding:移动 16px / 桌面 24px
- 间距系统:4pt 基础(4/8/12/16/24/32/48/64/96)
- 布局技术:一维用 Flexbox,网格用 CSS Grid
- 卡片网格用 repeat(auto-fit, minmax(280px, 1fr)) 自动响应式
- 移动优先:默认手机样式,min-width 逐级覆盖
- 断点:768 / 1024 / 1280
- 响应式变化:移动单栏 + 汉堡菜单,桌面三栏 + 横向导航
- section 间距:移动 48px / 桌面 96px
- 卡片 padding 24px,卡片间距 24px
- 语义化标签:header/nav/main/section/aside/footer
- z-index 分层:dropdown 10 / sticky 20 / modal 50 / toast 80
- 顶部导航 sticky 吸顶
```
