# V7 · 文字视觉效果

> 文字不只是"读"的,也是"看"的。文字效果是最能出彩且成本最低的视觉手段。

---

## 一、渐变文字（Gradient Text）★最常用

- **感觉**:亮眼、现代、品牌感
- **场景**:标题关键词、Logo 文字、数字统计
- **prompt 措辞**:"标题的关键词用渐变文字,靛蓝到粉的渐变"
- **实现**:
```css
background: linear-gradient(135deg, #4F46E5, #EC4899);
-webkit-background-clip: text;
background-clip: text;
color: transparent;
```
- **坑**:
  - 整段用会影响可读性 → 只用于短标题/关键词
  - 忘了 `color: transparent` 就不显示
  - 渐变色对比度可能不达标 → 大字才用

---

## 二、描边文字（Outlined / Stroked Text）

- **感觉**:轻盈、现代、编辑感、有设计感
- **场景**:巨型标题、装饰文字、层叠标题
- **prompt 措辞**:"巨型标题用描边文字,内部透明,只有 1px 白色轮廓"
- **实现**:
```css
color: transparent;
-webkit-text-stroke: 1px currentColor;
```
- **变体**:实体字 + 描边字交替(经典编辑设计手法)
- **谁在用**:创意机构、时尚品牌

---

## 三、图片填充文字（Image-in-Text / Text Mask）

- **感觉**:高级、有质感、意外惊喜
- **场景**:hero 巨型标题、品牌名
- **prompt 措辞**:"标题文字内填充背景图片/视频,用 background-clip: text"
- **实现**:
```css
background-image: url('texture.jpg');
background-clip: text;
color: transparent;
```
- **进阶**:填充视频、填充动画渐变、填充随滚动移动的图片
- **坑**:图片要选纹理明显但不干扰识字的

---

## 四、3D 挤出文字（Extruded / 3D Text）

- **感觉**:立体、复古、有冲击力
- **场景**:游戏、复古风、Y2K
- **实现**:多层 text-shadow 递增偏移
```css
text-shadow:
  1px 1px 0 #ccc, 2px 2px 0 #ccc,
  3px 3px 0 #bbb, 4px 4px 0 #bbb;
```

---

## 五、发光文字（Glowing / Neon Text）

- **感觉**:霓虹、赛博、夜生活
- **场景**:游戏、音乐、深色 hero
- **实现**:
```css
text-shadow:
  0 0 5px #fff,
  0 0 10px currentColor,
  0 0 20px currentColor,
  0 0 40px currentColor;
```
- **坑**:亮度过高伤眼,深色背景才用

---

## 六、打字机效果（Typewriter）

- **感觉**:叙事感、AI 感、期待感
- **场景**:hero 标题、AI 输出、终端风格
- **prompt 措辞**:"标题打字机效果逐字出现,末尾光标闪烁"
- **实现**:CSS 逐字显示 + 光标闪烁,或 JS 逐字追加
- **坑**:
  - 太慢会烦(每字 30-60ms 合适)
  - 布局会跳 → 提前占位
  - 无障碍:屏幕阅读器该一次读完整文字

---

## 七、逐词/逐字浮现（Word / Char Reveal）★高级

- **感觉**:优雅、有节奏、高级
- **场景**:hero 标题入场、滚动揭示
- **prompt 措辞**:"标题逐词浮现,每词 stagger 80ms,fade + 从下浮起 12px"
- **实现**:文字拆成 span,每个加延迟动画
- **对比**:
  - 逐字 = 更细腻但可能过度
  - 逐词 = 更自然,推荐
  - 逐行 = 最克制
- **谁在用**:Apple、高端品牌页

---

## 八、可变字体动画（Variable Font Animation）★前沿

- **感觉**:精密、有生命、独特
- **场景**:hover 字重变化、滚动字宽变化、加载动画
- **prompt 措辞**:"hover 时文字字重从 400 平滑过渡到 700(可变字体)"
- **实现**:
```css
font-variation-settings: "wght" 400;
transition: font-variation-settings 300ms;
&:hover { font-variation-settings: "wght" 700; }
```
- **需要**:可变字体(Inter Variable / Recursive)

---

## 九、跑马灯（Marquee / Infinite Scroll Text）

- **感觉**:动感、连续、时尚
- **场景**:Logo 墙滚动、公告条、装饰文字带
- **prompt 措辞**:"无限横向滚动的文字带,匀速,hover 时暂停"
- **实现**:两份内容并排 + `translateX` 无限循环
- **坑**:
  - 用 `linear` 缓动(匀速),不要 ease
  - 边缘加渐变遮罩淡出更精致
  - 提供 hover 暂停(无障碍)

---

## 十、文字描边绘制动画（Stroke Draw）

- **感觉**:精密、技术感、有仪式感
- **场景**:Logo 动画、开场
- **实现**:SVG 文字路径 + `stroke-dasharray` / `stroke-dashoffset` 动画

---

## 十一、文字扭曲与变形（Text Warp / Morph）

- **感觉**:实验性、创意、大胆
- **场景**:艺术站、创意机构
- **实现**:SVG `textPath` 沿曲线排列 / CSS transform / WebGL

---

## 十二、巨型字体裁切（Oversized Type Clipping）

- **感觉**:大胆、编辑感、有张力
- **场景**:hero、品牌页
- **prompt 措辞**:"巨型标题部分超出视口被裁切,制造张力"
- **实现**:字号超大 + `overflow: hidden` 容器
- **谁在用**:创意机构、时尚品牌

---

## 十三、文字随滚动变化（Scroll-linked Text）

- **感觉**:互动、现代
- **场景**:长页面标题、滚动叙事
- **变体**:
  - 滚动改变字重
  - 滚动改变字号
  - 滚动逐词高亮(阅读进度感)
  - 滚动改变颜色
- **实现**:CSS scroll-driven animations
```css
h1 {
  animation: weight-shift linear;
  animation-timeline: scroll();
}
```

---

## 十四、文字高亮效果（Text Highlight）

- **感觉**:重点突出、手工感
- **变体**:
  - 荧光笔背景(倾斜的色块)
  - 下划波浪线
  - 背景色块随 hover 展开
  - 划线动画(从左到右画出)
- **实现**:
```css
/* 荧光笔效果 */
background: linear-gradient(transparent 60%, #FDE047 60%);
```

---

## 十五、平衡换行（Text Balance）★细节但重要

- **感觉**:精致、专业
- **问题**:标题换行后最后一行只剩一个词(很丑)
- **实现**:
```css
h1 { text-wrap: balance; }   /* 标题:自动平衡各行长度 */
p  { text-wrap: pretty; }    /* 正文:避免孤字 */
```
- **这是 2025+ 原生 CSS 能力,一行代码提升精致度**

---

## 十六、文字效果的气质对照

| 效果 | 气质 | 慎用场景 |
|---|---|---|
| 渐变文字 | 现代品牌 | 正文(可读性) |
| 描边文字 | 编辑创意 | 小字(看不清) |
| 图片填充 | 高级质感 | 需要清晰阅读处 |
| 3D 挤出 | 复古冲击 | 极简风格 |
| 霓虹发光 | 赛博夜店 | 浅色背景、正式场景 |
| 打字机 | 叙事 AI | 频繁重复处 |
| 逐词浮现 | 优雅高级 | 短文字够了 |
| 可变字重动画 | 精密前沿 | 无可变字体时 |
| 跑马灯 | 动感时尚 | 重要信息(会滚走) |
| 巨型裁切 | 大胆张力 | 保守品牌 |

## Prompt 模板

### 高端品牌 hero
```
【文字效果】
- H1 巨型字体 clamp(48px, 8vw, 120px),字重 800,负字距 -0.03em
- text-wrap: balance 平衡换行
- 关键词用渐变文字(靛蓝 → 粉)
- 入场:逐词浮现,每词 stagger 80ms,fade + translateY(16px→0),ease-out 500ms
- 副标题:400 字重,text-wrap: pretty 避免孤字
```

### AI 产品
```
【文字效果】
- Hero 标题:打字机效果逐字出现(每字 40ms),末尾光标闪烁
- 流式输出模拟:文字逐字追加 + 光标
- 提前用占位符预留高度防布局跳动
- 无障碍:aria-live 一次性播报完整文字
```

### 编辑感/创意
```
【文字效果】
- 实体字与描边字交替(奇数行实体,偶数行 -webkit-text-stroke: 1px)
- 巨型标题部分超出视口裁切制造张力
- 关键短语用荧光笔高亮背景
- Logo 墙用跑马灯无限滚动,边缘渐变遮罩淡出,hover 暂停
```

## 检验清单

- [ ] 渐变文字只用于短标题
- [ ] 标题加了 text-wrap: balance
- [ ] 正文加了 text-wrap: pretty
- [ ] 大标题加了负字距
- [ ] 打字机效果有占位防跳动
- [ ] 打字机/跑马灯有无障碍处理
- [ ] 逐词浮现 stagger 在 60-100ms
- [ ] 发光文字只用于深色背景
- [ ] 文字效果不影响可读性
- [ ] 效果克制(一个页面 1-2 种文字特效)
