# B4 · 图标与图形

> 图标是界面的第二语言。图形系统的一致性直接决定专业度。

---

## 一、图标风格

### 按填充
- **线性 (Outline / Line / Stroked)** — 空心描边。轻盈、现代、中性。
- **填充 (Filled / Solid)** — 实心。醒目、稳重，常用于激活态。
- **双色 (Duotone)** — 两个透明度层次。有层次感。
- **微立体 (Duocolor / Two-tone)** — 两种颜色。
- **手绘 (Hand-drawn)** — 有机、亲切。

### 常见做法
- 默认线性，激活时切换填充（Tab bar 经典做法）
- 全站统一一种风格，不混用

---

## 二、图标尺寸规范

| 尺寸 | 用途 |
|---|---|
| 12px | 内联小图标、辅助 |
| 16px | 表单、按钮内、列表 |
| 20px | 标准 UI 图标 |
| 24px | 导航、工具栏（最常用基准） |
| 32px | 功能入口、特性图标 |
| 40-48px | 空态、大图标 |
| 64px+ | 插画式图标 |

### 关键规范
- 图标画布（如 24x24）+ 内边距（live area 20x20）
- 描边宽度：1.5px 或 2px（跟随字重）
- 圆角：与整体设计一致
- 光学尺寸：某些图标需要放大对齐视觉重量

## 四、图标使用原则

- **一致性**：全站一套图标库
- **可辨识**：抽象图标配文字标签
- **语义正确**：垃圾桶=删除，不要用于其他
- **对齐文字**：图标与文字基线/居中对齐
- **触控区域**：图标按钮点击区 ≥ 44px（图标本身可小）
- **色彩**：图标色跟随文字色（currentColor）

## 五、插画（Illustration）

### 风格流派
- **扁平 (Flat)** — 无阴影纯色
- **等距 (Isometric)** — 2.5D 立体
- **线条 (Line art)** — 单线勾勒
- **拟态 (3D render)** — 三维渲染，Blender/C4D
- **手绘 (Hand-drawn)** — 有机、亲切
- **抽象几何 (Abstract geometric)** — 图形拼接
- **拼贴 (Collage)** — 混合媒介
- **吉祥物 (Mascot)** — 品牌角色

### 插画系统
- 统一色板（与品牌一致）
- 统一线条粗细
- 统一透视角度
- 统一人物比例风格

### 插画库
- **unDraw** — 免费可改色
- **Storyset** — 可定制可动画
- **Humaaans** — 人物拼装
- **Blush** — 可定制
- **Open Peeps** — 手绘人物
- **Icons8 Ouch** — 多风格
- **DrawKit** — 精致
- **Lottiefiles** — 动画插画

## 六、Emoji 使用

### 场景
- 空态、庆祝、轻松语境
- 微文案点缀
- 分类标识

### 注意
- 跨平台渲染不一致
- 不要用于严肃/专业界面主要信息
- 无障碍：加 aria-label
- 不要滥用

## 七、图形语言（Graphic Elements）

### 装饰图形
- **Blob** — 有机不规则形状
- **Grid pattern** — 网格底纹
- **Dot pattern** — 点阵
- **Noise / Grain** — 噪点质感
- **Mesh gradient** — 网格渐变
- **Blur orbs** — 模糊光球
- **Line pattern** — 线条纹理
- **Wave / Blob divider** — 波浪分隔

### 用途
- 背景增加层次
- 品牌视觉锤
- 引导视线
- 填充空白但不喧宾夺主

## 八、Logo 使用

### 变体
- 完整版（图形+文字）
- 简版（仅图形/首字母）
- 横版 / 竖版
- 单色 / 反白 / 全彩

### 规范
- 最小尺寸限制
- 安全边距（clear space）
- 禁止拉伸/变色/加阴影
- 深浅背景各一套

## 九、图片方向（Photography）

### 风格
- **产品图** — 白底 / 场景 / 细节
- **人物图** — 真实 / 情绪 / 生活方式
- **抽象图** — 纹理 / 光影 / 概念
- **图标化插画** — 替代照片

### 处理
- 统一色调（滤镜、调色）
- 统一裁剪比例
- 蒙层保证文字可读（gradient overlay）
- 懒加载 + 模糊占位（blur-up / LQIP）

### 格式
- **WebP** — 通用，比 JPG 小 30%
- **AVIF** — 更小，兼容性稍差
- **SVG** — 矢量图形/图标
- **PNG** — 需透明时
- 响应式 `srcset` + `sizes`

## 十一、Prompt 表达模板

```
【图标与图形】：
- 图标库：Lucide（线性风格），默认 20px，导航 24px
- 描边宽度 1.5px，跟随文字色 (currentColor)
- 激活态切换 filled 版本
- 插画：unDraw 风格，扁平，主色系配色
- 背景装饰：subtle mesh gradient + noise 质感
- 图片：统一 16:9 裁剪，gradient overlay 保证文字可读
- 图片格式 WebP，懒加载 + blur-up 占位
```
