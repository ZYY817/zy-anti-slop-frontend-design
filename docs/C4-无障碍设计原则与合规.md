## 十六、按障碍类型补充（并入自 B43）

### 认知障碍设计
- 一屏一个主任务；语言简单直接（❌"身份验证失败,请重新鉴权" → ✅"登录失败,请重新输入密码"）
- 步骤清晰编号；一致布局与交互；避免时间压力（不倒计时逼决策）
- 帮助与容错：明确错误提示+修复方法、允许撤销、保存进度、确认破坏性操作
- 专注辅助：阅读模式、减少动画干扰、高亮当前位置

### 降级策略（不是全去掉）
```
正常:  fade + translateY(20px) + scale
降级:  只保留 fade(去掉位移和缩放)
```
保留反馈，去掉引发不适的部分；产品内另提供"减少动效"开关。

### 光敏感补充
- ❌ 高对比条纹快速移动（摩尔纹）——闪烁阈值之外的第二风险源
- 危险动效须提供暂停控制

### prefers-contrast
```css
@media (prefers-contrast: more) {
  :root {
    --border: rgba(0,0,0,0.3);   /* 加强边框 */
    --text-muted: #333;           /* 加强次要文字 */
  }
}
```

### 通用设计收益表（为边缘用户设计，所有人受益）
| 无障碍特性 | 顺带好处 |
|---|---|
| 高对比 | 强光下也能看清 |
| 大触控目标 | 所有人少误触 |
| 字幕 | 嘈杂/静音环境可看视频 |
| 清晰语言 | 所有人少犯错 |
| 键盘可达 | 高级用户提速 |
| 语义化 | SEO 更好 |
| reduced-motion | 省电、省流量 |
