# B67 · 视觉重量与平衡

> 界面不是"放整齐"就行——元素有**重量**。
> 一个深色大块很"重",一段小灰字很"轻"。如果重量分布不均,界面就会"歪"。
> 对称是最简单的平衡,但顶级设计追求的是**不对称平衡**——像天秤,两边不一样但重量相等。
> 这份文档拆的是:如何量化元素的视觉重量,以及如何用不对称达到精妙的平衡。

---

## 一、重量与平衡术语表

| 中文术语 | 英文术语 | 一句话含义 |
|---|---|---|
| 视觉重量 | Visual Weight | 元素在视觉上的"分量感" |
| 视觉平衡 | Visual Balance | 画面中元素重量分布的均衡感 |
| 视觉重心 | Visual Center of Gravity | 所有元素重量的综合中心点 |
| 对称平衡 | Symmetrical Balance | 中轴两侧镜像对称的平衡 |
| 不对称平衡 | Asymmetrical Balance | 两侧不同但重量相等的平衡 |
| 径向平衡 | Radial Balance | 从中心向外辐射的平衡 |
| 马赛克平衡 | Mosaic Balance | 无明确中心的均匀分散平衡 |
| 重力感 | Gravity Feel | 元素是轻盈向上还是沉重向下 |
| 锚定 | Anchoring | 重元素固定画面的作用 |
| 浮力 | Visual Buoyancy | 轻元素在视觉上的"上升"感 |
| 张力 | Visual Tension | 元素之间的拉扯/紧张关系 |
| 稳定感 | Stability | 画面给人的安稳、可靠感 |
| 动态感 | Dynamism | 画面给人的运动、活力感 |
| 视觉杠杆 | Visual Lever | 小而重的元素远离中心产生的杠杆力 |
| 画面偏沉 | Visual Tilt | 重量分布不均导致的倾斜感 |

## 二、什么决定视觉重量

### 2.1 八大重量因素(从重到轻)

| 因素 | 重 → | → 轻 |
|---|---|---|
| **面积** | 大 | 小 |
| **色彩明度** | 深/暗 | 浅/亮 |
| **饱和度** | 高饱和 | 低饱和/灰 |
| **对比度** | 高对比 | 低对比 |
| **密度/复杂度** | 密/复杂 | 疏/简单 |
| **质感** | 实/粗糙/纹理 | 空/光滑/透明 |
| **形状** | 规则/几何 | 不规则/有机 |
| **位置** | 下方/右侧/前景 | 上方/左侧/背景 |

### 2.2 重量估算公式(粗略)

```
视觉重量 ≈ 面积 × 深度(明度反转) × 饱和度 × 密度系数
```

**实用经验**:
- 一个 200×200 的深色块 ≈ 四个 100×100 的灰色块
- 一个高饱和红按钮 ≈ 三个灰色文字链接
- 一个实色图标 ≈ 两个线性图标

### 2.3 位置对重量的影响

```
心理期望:
- 下方的东西"应该重"(重力)→ 如果下方很轻,感觉"头重脚轻"
- 右侧的东西"略重"(阅读方向偏好)
- 画面中心的东西"更稳"

实际操作:
- 如果大图在左上,右下需要有一个深色/重的元素平衡
- 如果 Hero 很重,下方 section 需要有足够"地基"
```

## 三、对称平衡(Symmetrical)

### 3.1 特点与适用

```
特点: 稳定/庄重/正式/可靠/传统
适用: 企业官网/政府/金融/法律/婚礼
不适合: 创意/年轻/科技/前沿/探索型产品
```

```css
/* 对称布局 */
.symmetric-hero {
  text-align: center;
  max-width: 800px;
  margin-inline: auto;
  padding: 120px 20px;
}

.symmetric-hero h1 { text-align: center; }
.symmetric-hero p  { text-align: center; max-width: 60ch; margin: 0 auto; }
.symmetric-hero .cta-group {
  display: flex;
  justify-content: center;
  gap: 16px;
}
```

### 3.2 对称的"解闷"技巧

```
纯对称容易沉闷。在对称中加入一个"不对称"的微小元素:
- 标题左侧一个装饰线
- 图片微微倾斜
- 一个文字元素偏向一侧
```

## 四、不对称平衡(Asymmetrical)

### 4.1 核心原则

```
大而轻(面积大/浅色) = 小而重(面积小/深色/高饱和)
左边一个大图 ⟺ 右边一个小标题 + 一段文字 + 一个按钮(三者总重量平衡)
```

### 4.2 经典不对称布局

```css
/* 左图右文:不对称但平衡 */
.asymmetric-section {
  display: grid;
  grid-template-columns: 1.618fr 1fr;  /* 黄金比 */
  gap: 64px;
  align-items: center;
}

/* 左侧:大面积浅色图(轻) */
.section-image {
  aspect-ratio: 4/3;
  border-radius: 16px;
  background: oklch(95% 0.01 265);
  /* 面积大但颜色浅,总重量 = 中 */
}

/* 右侧:小面积深色文字(重) */
.section-text h2 {
  font-size: 36px;
  font-weight: 700;
  color: oklch(15% 0.01 265);
  /* 面积小但深色粗字,总重量 = 中 */
}
```

### 4.3 不对称平衡的五种手法

**1. 面积换明度**
```
大浅 = 小深
600px 浅灰块 ≈ 200px 纯黑块
```

**2. 面积换饱和度**
```
大灰 = 小鲜艳
大面积中性 ≈ 一个高饱和 CTA 按钮
```

**3. 面积换复杂度**
```
大简单 = 小复杂
一大块纯色 ≈ 一小块复杂图表
```

**4. 距离换大小(杠杆原理)**
```
远离中心的小元素 = 靠近中心的大元素
（就像天秤:杠杆臂越长,越少重量就能平衡）
```

**5. 数量换大小**
```
一个大 = 多个小
一张大图 ≈ 四个小图标 + 文字块
```

## 五、实用平衡模式

### 5.1 Hero 区的平衡

```
模式 A: 居中对称(安全)
┌──────────────────────────────────┐
│            [标题]                  │
│          [副标题]                  │
│          [CTA][CTA]              │
└──────────────────────────────────┘

模式 B: 左文右图(经典不对称)
┌──────────────────────────────────┐
│  标题           │    ┌──────┐    │
│  副标题         │    │ 图片  │   │
│  [CTA]         │    └──────┘    │
└──────────────────────────────────┘
                   ↕ 文字重(深色粗体) ⟺ 图片面积大但浅

模式 C: 错位(高级不对称)
┌──────────────────────────────────┐
│          标题                     │
│              副标题               │
│     [CTA]                        │
│                  ┌────────┐      │
│                  │  图片   │     │
│                  └────────┘      │
└──────────────────────────────────┘
                  文字左上 ⟺ 图片右下(对角线平衡)
```

### 5.2 卡片网格的平衡

```css
/* 不等高 Masonry 也要平衡:不要让所有大卡片都在左边 */
.card.featured {
  grid-column: span 2;
  /* 大卡片的位置要考虑整体平衡 */
}

/* 或用交替布局 */
.feature-row:nth-child(odd)  { grid-template-columns: 2fr 1fr; }
.feature-row:nth-child(even) { grid-template-columns: 1fr 2fr; }
```

### 5.3 留白作为"重量"

**大量留白在视觉上≠轻**。留白包围的元素反而**更重**(因为隔离效应)。

```css
/* 单独一行只有一个按钮 + 大量留白 = 按钮极重(注意力集中) */
.cta-isolation {
  padding-block: 80px;
  text-align: center;
}
```

## 六、平衡的检验方法

### 6.1 眯眼法

```
眯起眼:
- 界面变成一堆模糊的明暗块
- 检查这些色块是否分布均匀
- 如果集中在一侧 → 失衡
```

### 6.2 翻转法

```
水平翻转界面(镜像):
- 如果翻转后"感觉不对" → 说明原来的平衡是假的
- 真正的平衡翻转后也应该舒服
```

### 6.3 灰度法

```
去掉颜色看明暗分布:
filter: grayscale(1);
如果暗块集中在一角 → 不平衡
```

### 6.4 拇指遮挡法

```
用手指挡住画面某个元素:
- 如果感觉"少了什么"→ 这个元素是平衡的关键
- 如果没感觉 → 可能是冗余
```

## 七、动态平衡(交互中的平衡)

### 7.1 展开/折叠时保持平衡

```css
/* 侧栏展开时内容区变窄 → 重新平衡 */
.layout {
  display: grid;
  grid-template-columns: var(--sidebar-width) 1fr;
  transition: grid-template-columns 300ms;
}

.sidebar.collapsed { --sidebar-width: 64px; }
.sidebar.expanded  { --sidebar-width: 260px; }
```

### 7.2 Modal 打开时的画面平衡

```css
/* Modal 居中:自动平衡 */
.modal {
  position: fixed;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
}

/* 稍微偏上(视觉中心比几何中心高 5%) */
.modal-visual-center {
  top: 45%;  /* 比 50% 高一点 */
}
```

## 八、Prompt 模板

```
【视觉重量与平衡】

═══ 布局平衡策略 ═══
Hero: {居中对称 / 左文右图不对称 / 错位对角线}
内容区: {交替左右 / 网格均匀 / 特色卡打破规则}
全局: 不对称平衡优先(对称用于正式场合)

═══ 重量因素 ═══
重: 深色/大面积/高饱和/密集/实色/前景
轻: 浅色/小面积/低饱和/稀疏/透明/背景

═══ 不对称平衡手法 ═══
- 大浅 = 小深(面积换明度)
- 大灰 = 小鲜艳(面积换饱和度)
- 远小 = 近大(杠杆原理)
- 一大 = 多小(数量换大小)
- 留白包围 = 元素更重(隔离效应)

═══ 平衡检验 ═══
- 眯眼看明暗块分布是否均匀
- 水平翻转后是否仍舒适
- 去色后暗块是否不偏一侧
- 遮挡某元素是否感到"缺了"

═══ 避免 ═══
- 所有重元素集中在一侧(头重脚轻)
- 纯对称太多(沉闷)
- 大面积深色无平衡(压迫)
```

## 九、踩坑指南

### 坑1:头重脚轻
**症状**:Hero 很重(大图+深色),下方 section 很轻,整页像倒三角。
**解法**:底部加深色 Footer 或 CTA 区做"地基"。

### 坑2:所有重量都在左边
**症状**:左边侧栏+图标+头像很密,右边大片空白。
**解法**:右侧加内容、或左侧减轻(用线性图标代替实色)。

### 坑3:对称太死板
**症状**:所有东西居中,像 PPT,不够专业。
**解法**:主体居中但标题/CTA/图片微妙偏移。

### 坑4:不对称失衡
**症状**:想做不对称但没平衡好,看着就是"歪了"。
**解法**:用"面积×深度"粗估,确保两侧总重量接近。

### 坑5:Modal 几何居中显偏下
**症状**:Modal `top: 50%` 看起来偏下。
**解法**:视觉中心比几何中心高,用 `top: 45%` 或 `top: 40%`。
