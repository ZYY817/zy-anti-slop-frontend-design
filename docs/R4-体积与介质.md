# R4 · 体积与介质（提示词库 B 组）

> 定位：让画面里的介质"有厚度、有流动、有细节"——这是从"贴片感"到"真实感"最大的一次质变。
> 覆盖层：L3 肉（少量 L2）。绝大多数 AI 生成视觉之所以"假"，都死在这一层：形体和后期都做了，但中间的介质是空的。
> 条目卡格式：每条目为「名称（英文术语）· L 层级 · 档位 · 成本」，其下含【视觉收益】/【强度档位】（部分条目）/【同族拓展】/【提示词片段】四栏。
> 来源：融合自外部「视觉提示词库 B 组」（v1.x，2026-08-16），原始技术术语（volumetric rendering、FBM、curl noise、scattering 等）与参数值均忠实保留。

---

## 使用说明

**这一组是本库最有价值、也是原库其他板块完全缺失的部分。**

判断你需不需要 B 组：如果画面里有云、烟、雾、火、水、星云、吸积盘、光柱、大气、任何"半透明有厚度的东西"——你需要。

```
B1 体积渲染骨架          B5 流体与运动场
B2 密度场构造            B6 相变与形态细节
B3 噪声家族（核心）      B7 粒子与 GPGPU
B4 散射与吸收            B8 大气与天空
```

**推荐推进顺序**：R4·B1 搭骨架 → R4·B2 定密度分布 → R4·B3 加噪声细节 → R4·B4 加散射（这一步质变）→ R4·B5 加运动 → R4·B6 修边缘。

## B1 体积渲染骨架（Volumetric Rendering Core）

不是"有没有体积"的开关，是一整套积分框架。**二维贴片和三维体积的分界线在这里**。

- **体积光线步进（Volumetric Raymarching）** · L2 · 进阶 · 成本:高
  - 视觉收益：沿光线定步长前进、逐步累积密度与发光，得到真正有厚度、有自遮挡的介质
  - 强度档位：步数 16（移动）/ 32–48（标准）/ 64–128（电影级）
  - 同族拓展：fixed-step marching、ray-box intersection（限定积分区间）、cone tracing
  - 提示词片段：`吸积盘/云用 volumetric raymarching，定步长 48 步，禁止用平面几何或贴图伪造厚度`

- **发光-吸收模型（Emission-Absorption Model）** · L3 · 进阶 · 成本:中
  - 视觉收益：介质既自己发光又遮挡后面的光，是"通透但有实体"的物理基础
  - 同族拓展：emission-only（纯加性，见组合速查·极光星云）、absorption-only（纯遮挡，如烟）、full scattering
  - 提示词片段：`每步累积 color += emission × density × transmittance × dt；同时 transmittance *= exp(-density×dt)`

- **比尔-朗伯吸收（Beer-Lambert Law）** · L3 · 进阶 · 成本:低
  - 视觉收益：透射率按指数衰减，厚处不透明、薄处通透——**这一条决定"有厚度"的观感**
  - 同族拓展：optical depth（光学厚度）、extinction coefficient、Beer's powder（见 R4·B6）
  - 提示词片段：`透射率用 exp(-σ×density×dt) 指数衰减，σ=1.5`

- **前向合成 vs 后向合成（Front-to-Back / Back-to-Front）** · L2 · 基础 · 成本:低
  - 视觉收益：前向合成可提前终止（省算力），后向合成不能。默认选前向
  - 同族拓展：premultiplied alpha、over operator、透射率累积
  - 提示词片段：`用 front-to-back 合成，透射率 <0.01 时提前 break`

- **积分区间求交（Ray-Volume Intersection）** · L2 · 基础 · 成本:低
  - 视觉收益：只在体积包围盒/圆盘范围内步进，其余跳过，性能翻倍
  - 同族拓展：ray-box、ray-sphere、ray-slab（云层高度带）、analytic disk bounds
  - 提示词片段：`先解析求交得到 tNear/tFar，只在区间内步进`

- **多次穿越（Multiple Volume Crossings）** · L2 · 电影级 · 成本:高
  - 视觉收益：弯曲光线可能多次穿过同一介质（黑洞吸积盘的正面+背面像），产生标志性的"上下两条弧"
  - 同族拓展：re-entry detection、multi-hit accumulation
  - 提示词片段：`允许光线多次穿越吸积盘并各自累积，产生盘的正面像与经透镜的背面像`

## B2 密度场构造（Density Field）

密度**在空间里怎么分布**。这决定形态，比噪声本身更重要。

- **高度密度重映射（Height-Based Density Remap）** · L3 · 进阶 · 成本:低
  - 视觉收益：云底平、云顶蓬松；盘中间厚、上下薄。让体积有可识别的剖面
  - 强度档位：线性 / smoothstep 双端衰减 / 分段曲线
  - 同族拓展：density gradient、vertical profile、cloud layer remap
  - 提示词片段：`密度沿垂直方向用双端 smoothstep 衰减，中面最厚、上下缘归零`

- **径向密度剖面（Radial Density Profile）** · L3 · 进阶 · 成本:低
  - 视觉收益：吸积盘内缘（ISCO）陡然截断、外缘缓慢淡出，形成清晰的环结构
  - 同族拓展：inner radius cutoff、power-law falloff、exponential taper
  - 提示词片段：`盘密度 = smoothstep(rIn, rIn×1.2, r) × exp(-(r-rIn)/scale)`

- **密度重映射曲线（Density Remap / Contrast Shaping）** · L3 · 进阶 · 成本:低
  - 视觉收益：把噪声的 0–1 重映射，控制"稀疏丝缕"还是"厚重团块"
  - 强度档位：smoothstep(a,b,n) 中 a 越高越稀疏
  - 同族拓展：coverage threshold、remap()、pow curve、histogram shaping
  - 提示词片段：`密度 = smoothstep(coverage, 1.0, fbm)；coverage=0.45 得稀疏丝缕`

- **体积包围与衰减（Volume Falloff）** · L3 · 基础 · 成本:低
  - 视觉收益：体积边界不能是硬切，必须软过渡，否则看到"盒子边"
  - 同族拓展：edge fade、soft clip、distance-based fade
  - 提示词片段：`体积边界做 smoothstep 软衰减，禁止硬裁切`

- **三维纹理 vs 程序化（3D Texture vs Procedural）** · L3 · 进阶 · 成本:中
  - 视觉收益：3D 纹理快但占显存且有限；程序化零显存但每步都要算
  - 同族拓展：baked 3D noise texture、tileable 3D texture、runtime FBM
  - 提示词片段：`用程序化 FBM（无 3D 贴图依赖），循环 ≤5 层保证性能`

## B3 噪声家族（Noise Family）

**L3 的核心工具箱**。没有噪声就没有细节，一切表面都是塑料。

- **值噪声 / 哈希（Value Noise / Hash）** · L3 · 基础 · 成本:低
  - 视觉收益：最便宜的随机基础，做颗粒、闪烁、随机偏移
  - 同族拓展：hash11/hash21/hash33、white noise、integer hash
  - 提示词片段：`自写 hash 函数（禁止依赖纹理），用于抖动与随机种子`

- **Perlin / Simplex 噪声** · L3 · 基础 · 成本:低
  - 视觉收益：平滑连续的随机场，一切有机形态的起点
  - 同族拓展：gradient noise、Simplex（更少方向伪影）、Perlin improved
  - 提示词片段：`基础噪声用 Simplex（比 Perlin 少方向性伪影）`

- **分形布朗运动（FBM, Fractal Brownian Motion）** · L3 · 基础 · 成本:中
  - 视觉收益：**做云、烟、雾、湍流的标准答案**。多个八度叠加，得到自然的多尺度细节
  - 强度档位：3 层（快，粗）/ 5 层（标准）/ 7–8 层（电影级，慢）
  - 同族拓展：octaves、lacunarity（频率倍率，常用 2.0）、gain/persistence（常用 0.5）、turbulence（abs 版）、ridged multifractal（山脊状）
  - 提示词片段：`密度用 FBM 5 个八度，lacunarity 2.0，gain 0.5；每层旋转坐标避免轴向对齐伪影`

- **域扭曲（Domain Warping）** · L3 · 进阶 · 成本:中
  - 视觉收益：**性价比最高的一招**。用噪声去扰动噪声的输入坐标，让"云"变成"流动的丝缕"，一行代码质变
  - 强度档位：单层扭曲（微）/ 双层递归（推荐）/ 三层（极强，易糊）
  - 同族拓展：iq domain warping、flow warping、recursive warp
  - 提示词片段：`对 FBM 做双层 domain warping：q=fbm(p), r=fbm(p+4q), d=fbm(p+4r)`

- **Worley / Voronoi 噪声** · L3 · 进阶 · 成本:中
  - 视觉收益：细胞状、蓬松团块状。做云的蓬松边缘、水面焦散、裂纹、鳞片
  - 强度档位：F1（团块）/ F2-F1（裂纹网格）/ inverted（蓬松云）
  - 同族拓展：cellular noise、Voronoi edges、jittered grid、Worley-Perlin 混合（云的标准配方）
  - 提示词片段：`云的基础用 Perlin-Worley 混合，边缘细节用 inverted Worley 侵蚀`

- **旋度噪声（Curl Noise）** · L3 · 电影级 · 成本:中
  - 视觉收益：无散度的向量场，产生**真实的涡旋流动**而非平移。烟、吸积盘剪切流的关键
  - 同族拓展：divergence-free、potential field、vorticity、见 R4·B5
  - 提示词片段：`盘面湍流用 curl noise 驱动，产生螺旋涡旋而非整体平移`

- **山脊噪声（Ridged Noise）** · L3 · 进阶 · 成本:中
  - 视觉收益：`1-abs(noise)` 得到尖锐山脊线，做山脉、闪电、丝状纤维
  - 同族拓展：ridged multifractal、turbulence、absolute-value FBM
  - 提示词片段：`纤维状结构用 ridged FBM（1-abs），锐化 pow 2.0`

- **蓝噪声（Blue Noise）** · L5 · 进阶 · 成本:低
  - 视觉收益：高频均匀分布的噪声，用于采样抖动**几乎不可见**，远优于白噪声
  - 同族拓展：void-and-cluster、interleaved gradient noise（IGN，程序化近似）、Bayer matrix、见 R6·D6
  - 提示词片段：`采样抖动用 interleaved gradient noise（程序化蓝噪声近似），无需贴图`

- **反应扩散（Reaction-Diffusion）** · L3 · 电影级 · 成本:高
  - 视觉收益：Gray-Scott 生成有机斑纹、珊瑚、豹纹，需多帧迭代
  - 同族拓展：Gray-Scott、Turing pattern、cellular automata、需要 ping-pong RT（见 R4·B7）
  - 提示词片段：`用 Gray-Scott 反应扩散在 ping-pong RT 上迭代生成有机纹样`

> **噪声选型速查**
> 云雾烟 → Perlin-Worley 混合 + FBM + domain warping
> 流体丝缕 → domain warping + curl noise
> 蓬松边缘 → inverted Worley 侵蚀
> 山脉纤维 → ridged FBM
> 细胞裂纹 → Voronoi F2-F1
> 采样抖动 → 蓝噪声 / IGN
> 颗粒噪点 → hash 白噪声

## B4 散射与吸收（Scattering & Absorption）

**加了这一节，体积才从"半透明糊"变成"有光在里面走"。质变点。**

- **单次散射（Single Scattering）** · L4 · 进阶 · 成本:高
  - 视觉收益：每个采样点向光源发射阴影射线，得到介质内部的明暗与自投影
  - 强度档位：阴影射线 4 步（快）/ 6–8 步（标准）/ 16 步（电影级）
  - 同族拓展：light marching、shadow ray、self-shadowing、transmittance to light
  - 提示词片段：`每 2 个主步做 1 次向光阴影射线（6 步），累积向光透射率`

- **各向异性相函数（Henyey-Greenstein Phase Function）** · L4 · 电影级 · 成本:低
  - 视觉收益：**逆光时介质边缘透亮**（云的银边、烟的光晕）。成本极低收益极高
  - 强度档位：g=0（等向）/ g=0.3–0.6（前向散射，云）/ g=0.8（强前向，雾）/ 双叶（前+后）
  - 同族拓展：Mie scattering、Rayleigh scattering、dual-lobe HG、Schlick phase approximation
  - 提示词片段：`散射用 Henyey-Greenstein 相函数，g=0.5 前向；逆光时云边缘必须透亮出银边`

- **多次散射近似（Multiple Scattering Approximation）** · L4 · 电影级 · 成本:中
  - 视觉收益：真实云里光会多次弹射，让厚处不是死黑而是柔和的灰蓝。少了它云会"发脏"
  - 同族拓展：octave approximation（Wrenninge 方法）、ambient term、powder effect、energy-conserving multi-scatter
  - 提示词片段：`加 3 个八度的多次散射近似（每层衰减 extinction×0.5、相函数 g×0.5）`

- **粉末效应（Powder Effect / Beer's Powder）** · L4 · 电影级 · 成本:低
  - 视觉收益：云朝光面的边缘会**变暗**而不是变亮（反直觉但真实），显著提升可信度
  - 同族拓展：dark-edge effect、Beer-Powder approximation（Frostbite/Horizon 方案）
  - 提示词片段：`加 powder 项 (1-exp(-2×density))，让朝光边缘略暗`

- **瑞利与米氏散射（Rayleigh & Mie）** · L4 · 电影级 · 成本:中
  - 视觉收益：Rayleigh（分子，波长依赖→天空蓝、日落红）+ Mie（气溶胶，前向→太阳光晕）
  - 同族拓展：wavelength-dependent scattering、见 R4·B8 大气
  - 提示词片段：`天空用 Rayleigh(λ⁻⁴) + Mie 双项散射，得到蓝天与日落渐变`

- **次表面散射（Subsurface Scattering, SSS）** · L4 · 电影级 · 成本:中
  - 视觉收益：光透入表面再散出——皮肤、玉石、蜡、牛奶、叶片的通透感
  - 强度档位：假 SSS（厚度贴图+Fresnel）/ 真 SSS（体积积分）
  - 同族拓展：translucency、thickness map、wrap lighting、burley diffusion
  - 提示词片段：`半透材质用 thickness-based 假 SSS，背光处透出暖色`

- **体积光柱（Volumetric Light Shafts / God Rays）** · L4 · 进阶 · 成本:中
  - 视觉收益：可见光柱穿过雾气/窗棂，强烈的空间感与氛围
  - 同族拓展：crepuscular rays、light scattering、radial blur 伪造版（见 R6·D2）
  - 提示词片段：`雾中做体积光柱，沿视线积分光源可见性 32 步`

## B5 流体与运动场（Flow & Motion Fields）

体积不动就是雕塑。运动的**层级和方向**决定可信度。

- **流场推进（Flow Field Advection）** · L3 · 进阶 · 成本:中
  - 视觉收益：让噪声沿向量场移动而非整体平移，产生流动感
  - 同族拓展：advection、velocity field、curl noise 驱动（见 R4·B3）
  - 提示词片段：`噪声坐标沿 curl noise 流场 advect，速度 0.15`

- **开普勒差速旋转（Keplerian / Differential Rotation）** · L3 · 电影级 · 成本:低
  - 视觉收益：内圈快、外圈慢（v∝r^-0.5），产生自然的螺旋剪切拉伸——**吸积盘真实感的关键**
  - 同族拓展：shear flow、orbital velocity、winding
  - 提示词片段：`盘面角速度 ∝ r^-1.5，内快外慢产生螺旋剪切；禁止整盘刚体同速旋转`

- **多层时间尺度（Multi-Scale Time / Layered Speed）** · L3 · 进阶 · 成本:低
  - 视觉收益：大结构慢、细节快，避免"整体一起动"的廉价感
  - 同族拓展：per-octave time offset、temporal layering
  - 提示词片段：`FBM 每个八度用不同时间速率（0.1×2^i），大结构慢细节快`

- **涡量与湍流（Vorticity / Turbulence）** · L3 · 进阶 · 成本:中
  - 视觉收益：卷曲、翻滚、撕裂的湍流结构
  - 同族拓展：vortex particles、turbulence FBM（abs 版）、Kolmogorov cascade
  - 提示词片段：`湍流用 turbulence FBM + 局部涡旋扰动，避免规则周期`

- **实时流体模拟（Stable Fluids / Navier-Stokes）** · L3 · 电影级 · 成本:高
  - 视觉收益：真正的交互式流体（鼠标搅动烟雾），需要 ping-pong RT
  - 同族拓展：Jos Stam stable fluids、advection-projection、pressure solve、见 R4·B7
  - 提示词片段：`2D 流体用 stable fluids（advect→diffuse→project），Jacobi 迭代 20 次`

- **随时间演化的相位（Phase Animation）** · L3 · 基础 · 成本:低
  - 视觉收益：把时间加进噪声的第 4 维（或第 3 维），得到"原地翻滚"而非"平移"
  - 同族拓展：4D noise、time as z-axis、morphing
  - 提示词片段：`用 3D 噪声把 z 当时间轴，得到原地翻滚而非画面平移`

## B6 相变与形态细节（Erosion & Silhouette）

体积的**边缘**决定它像不像真的。这一节是"最后一公里"。

- **侵蚀细节（Erosion / Detail Subtraction）** · L3 · 电影级 · 成本:中
  - 视觉收益：用高频 Worley 从边缘"啃掉"密度，得到蓬松破碎的真实边缘（云的标准做法）
  - 强度档位：轻（保持整体形）/ 强（撕裂成絮状）
  - 同族拓展：detail erosion、curl erosion、edge-weighted subtraction
  - 提示词片段：`用 inverted Worley 只在低密度边缘做侵蚀（权重 = 1-density），保留核心形状`

- **轮廓破碎（Silhouette Breakup）** · L3 · 进阶 · 成本:低
  - 视觉收益：避免体积呈现规则的球形/柱形外轮廓，破掉"CG 感"
  - 同族拓展：low-frequency shape warp、asymmetric bias
  - 提示词片段：`用极低频噪声扰动整体轮廓，禁止出现完美球形/柱形边界`

- **密度层级对比（Density Contrast Layering）** · L3 · 进阶 · 成本:低
  - 视觉收益：厚核心 + 稀薄外晕，产生"实心中带雾"的层次
  - 同族拓展：core-halo separation、two-tier density
  - 提示词片段：`密度分两级：核心 pow(n,3) 高密 + 外晕 pow(n,0.5) 低密叠加`

- **相变发光（Emissive Thresholding）** · L3 · 进阶 · 成本:低
  - 视觉收益：只有超过某密度/温度才发光，产生"火焰核心亮、外围暗烟"
  - 同族拓展：temperature threshold、emission ramp、blackbody（见 R5·C3）
  - 提示词片段：`发光强度 = smoothstep(0.6,1.0,density)^2，低密区只吸收不发光`

## B7 粒子与 GPGPU（Particles & GPGPU）

当"体积"由离散个体组成时。也是所有需要**多帧状态**的效果的载体。

- **GPGPU 位置纹理（FBO Particles / Position Texture）** · L3 · 电影级 · 成本:高
  - 视觉收益：把百万粒子的位置存在纹理里，在 shader 里更新，CPU 完全不参与
  - 强度档位：64²=4k / 256²=65k / 512²=262k / 1024²=1M
  - 同族拓展：ping-pong FBO、GPUComputationRenderer（three.js 内置）、transform feedback、WebGPU compute shader
  - 提示词片段：`粒子用 GPGPU 位置纹理（256×256=65k），ping-pong 双 RT 交替读写`

- **乒乓渲染（Ping-Pong Render Targets）** · L2 · 进阶 · 成本:中
  - 视觉收益：所有需要"读上一帧"的效果（流体、反应扩散、轨迹、时间累积）的基础设施
  - 同族拓展：double buffering、swap targets、feedback loop、trail accumulation
  - 提示词片段：`用两个 FloatType RT 交替读写；每帧 swap，注意首帧初始化`

- **粒子生命周期（Particle Lifecycle）** · L3 · 进阶 · 成本:低
  - 视觉收益：出生-成长-消亡的完整曲线，避免"粒子突然出现/消失"
  - 同族拓展：age、spawn、respawn、size-over-life、alpha-over-life curve
  - 提示词片段：`粒子有 age 通道，尺寸与透明度按生命曲线变化，禁止硬出现硬消失`

- **粒子受力（Forces：Gravity / Curl / Attractor）** · L3 · 进阶 · 成本:低
  - 视觉收益：重力、涡旋、吸引子、排斥——决定粒子群的性格
  - 同族拓展：curl noise force、strange attractor（Lorenz/Aizawa）、flocking/boids、SPH
  - 提示词片段：`粒子受 curl noise 力场 + 中心弱吸引，速度加 0.98 阻尼`

- **拖尾累积（Trail Accumulation）** · L3 · 进阶 · 成本:中
  - 视觉收益：粒子留下轨迹，画面从"点"变成"线条编织"
  - 同族拓展：feedback buffer with decay、motion trail、velocity-stretched billboard
  - 提示词片段：`用累积 RT 每帧乘 0.95 衰减叠加，形成拖尾`

- **点精灵与软粒子（Soft Particles）** · L3 · 基础 · 成本:低
  - 视觉收益：粒子与几何相交处软化，不出现硬切边
  - 同族拓展：depth-fade soft particle、billboard、additive blending
  - 提示词片段：`粒子按深度差做 soft fade，加性混合，禁止硬边圆点`

## B8 大气与天空（Atmosphere & Sky）

背景不是"填充"，是**光源和氛围的一半**。

- **大气散射（Atmospheric Scattering）** · L4 · 电影级 · 成本:高
  - 视觉收益：物理正确的天空色、日落渐变、地平线泛红——一次搞定所有时间段
  - 同族拓展：Preetham、Hosek-Wilkie、Bruneton precomputed、Rayleigh+Mie（见 R4·B4）
  - 提示词片段：`天空用简化 Preetham/Hosek 模型，太阳高度角驱动整体色调`

- **程序化星空（Procedural Starfield）** · L3 · 进阶 · 成本:低
  - 视觉收益：无贴图的星空，可无限缩放不失真
  - 强度档位：单层 / 3 层不同亮度与密度 / 带色温分布
  - 同族拓展：hash-based star placement、star temperature color（见 R5·C3）、scintillation（闪烁）、star magnitude distribution
  - 提示词片段：`星空用 hash 网格生成 3 层星点，亮度幂律分布，颜色按恒星色温（蓝白→黄→红），加轻微闪烁`

- **程序化星云与银河（Procedural Nebula / Milky Way）** · L3 · 进阶 · 成本:中
  - 视觉收益：背景不再是纯黑+白点，有色彩层次与结构
  - 同族拓展：domain-warped FBM band、dust lane（暗尘带）、双色梯度
  - 提示词片段：`银河用沿一条带分布的 domain-warped FBM，加暗尘带遮挡，主色青蓝到暖褐`

- **高度雾（Height Fog）** · L3 · 基础 · 成本:低
  - 视觉收益：低处浓、高处淡，建立地面层次与远近
  - 同族拓展：exponential height fog、fog scattering with sun tint
  - 提示词片段：`加指数高度雾，雾色朝太阳方向偏暖`

- **云层（Cloud Layer）** · L3 · 电影级 · 成本:高
  - 视觉收益：天空有内容，且能投影/影响光照
  - 同族拓展：cumulus/stratus/cirrus profile、weather map（覆盖率纹理）、cloud shadow
  - 提示词片段：`云层用 weather-map 控制覆盖率，高度带内做体积步进 32 步`

## B 组 · 组合速查

| 想要的效果 | 组合 |
|---|---|
| 体积吸积盘 | R4·B1 全套 + R4·B2 径向+高度剖面 + R4·B3 FBM/curl + R4·B4 HG散射 + R4·B5 开普勒差速 |
| 真实云海 | R4·B1 + R4·B2 高度重映射 + R4·B3 Perlin-Worley + R4·B4 单次散射+多次近似+powder + R4·B6 侵蚀 |
| 交互烟雾 | R4·B7 ping-pong + R4·B5 stable fluids + R4·B4 单次散射 |
| 极光星云 | R4·B3 domain warping + R4·B1 emission-only + R4·B5 慢速流场 |
| 火焰 | R4·B3 turbulence FBM + R4·B5 向上流场 + R4·B6 相变发光 + R5·C3 黑体色 |
| 粒子星河 | R4·B7 GPGPU + R4·B7 curl 力场 + R4·B7 拖尾 + R4·B8 星空背景 |
| 玉石/皮肤 | R4·B4 次表面散射 + R4·B2 厚度场 |
| 光柱氛围 | R4·B4 体积光柱 + R4·B8 高度雾 |

**常见坑**：
- 体积像一张贴片 → 缺 R4·B1 Beer-Lambert 和 R4·B2 密度梯度
- 云是一团死白 → 缺 R4·B4 单次散射（没有内部明暗）
- 逆光不透亮 → 缺 R4·B4 Henyey-Greenstein
- 厚处发脏发黑 → 缺 R4·B4 多次散射近似
- 边缘像塑料球 → 缺 R4·B6 侵蚀与轮廓破碎
- 运动很廉价 → 缺 R4·B5 多层时间尺度与差速
- 有明显条纹 → 步长太大，补 R3·A2 抖动起点
- 帧率崩了 → R4·B3 八度数降到 3–4，R4·B1 步数降到 24，R4·B4 阴影射线降到 4

> 下一步：介质有了，去 R5 光照与色彩管线（C 组）决定它发什么颜色的光、亮到什么程度。**注意：色彩管线错了，B 组做得再好也是灰的。**
