# E2 · 2025-2026 趋势

> 当下正在发生的设计与技术趋势。用这些词让产出有时代感。

---

## 一、生成式界面（Generative UI）

**定义**：AI 实时组装界面组件，而非预设固定布局。

**特征**：
- 根据用户意图动态生成表单/图表/卡片
- 界面即对话的一部分
- 组件由 AI 选择和填充

**关键词**：generative UI, adaptive interface, AI-composed layout, dynamic component assembly

**代表**：Vercel AI SDK 的 Generative UI, ChatGPT Canvas

**实现要素**：
- 组件白名单（AI 只能用预设组件）
- Streaming 渐进渲染
- 结构化输出（JSON Schema / Tool Calling）

---

## 二、液态玻璃（Liquid Glass）

**定义**：Apple iOS 26 / macOS Tahoe 引入的新材质语言。

**特征**：
- 实时折射（refraction）
- 深度感知的透明度
- 光影响应环境
- 比 Glassmorphism 更物理真实

**关键词**：liquid glass, refraction, dynamic blur, depth-based transparency, specular highlight

**Web 实现**：
- `backdrop-filter: blur() saturate()`
- WebGPU 渲染复杂光照
- SVG filters 模拟折射

**注意**：性能开销大，可访问性需额外处理（scrim 层保文字可读）。

---

## 三、空间界面（Spatial UI）

**定义**：为 3D 空间设计的界面（Vision Pro、AR 眼镜、车载）。

**特征**：
- 元素有真实 Z 轴深度
- 视差随头部移动
- 眼动 + 手势 + 语音多模态输入
- 无边框，浮在空间中

**关键词**：spatial computing, visionOS, depth layers, gaze-based interaction, z-space, immersive

**Web 相关**：
- WebXR API
- CSS `transform-style: preserve-3d`
- Three.js / React Three Fiber

---

## 四、多模态与感知交互

**定义**：告别"只有点击"，语音/手势/眼动/表情成为一级输入。

**特征**：
- 输入方式流动切换（打字 + 语音 + 注视同时）
- 系统融合多路输入理解意图
- 情感计算：从打字速度/语调推断情绪

**关键词**：multimodal input, ambient interaction, emotion-aware, gaze + gesture, perceptual interface

**代表**：Hume AI（情感语音）、Apple 眼动追踪

---

## 五、Bento Grid（持续强势）

**定义**：非对称模块化卡片网格，源自日本便当盒。

**特征**：
- 卡片大小混排（2x2 / 1x1 / 1x2）
- 统一圆角和间隙（12-24px）
- 天然响应式（移动端塌成单列）
- 2026 演化：每格加 subtle 背景色调分类

**关键词**：bento grid, asymmetric modular layout, varied card sizes, compartmentalized

**代表**：Apple 产品页、Arc Browser、大量 SaaS 落地页

**为什么持续流行**：兼顾信息密度与视觉趣味，且实现简单（CSS Grid）。

---

## 六、巨型字体（Massive Typography）

**定义**：首屏用一个超大词/短句承载全部视觉重量。

**特征**：
- 字号 72-200px
- 字重 700-900
- 负字距 (-0.02 到 -0.04em)
- 少文字多冲击

**关键词**：oversized display type, typographic hero, bold statement, hero-as-type

**变体**：Kinetic Typography（文字本身动起来）

---

## 七、滚动叙事（Scrollytelling）

**定义**：滚动驱动动画，页面像电影一样展开。

**特征**：
- Pin（元素固定）+ 内容滚过
- 背景/3D 模型随滚动变化
- 文字逐段淡入
- 有明确"章节"节奏

**关键词**：scroll-driven narrative, cinematic scroll, pin-and-reveal, immersive storytelling

**技术**：
- CSS Scroll-driven Animations（原生，2024+）
- GSAP ScrollTrigger（成熟方案）
- Lenis（平滑滚动）

---

## 八、动效令牌化（Motion Tokens）

**定义**：动效像颜色和间距一样进入设计系统。

**特征**：
- `motion.duration.fast` / `motion.easing.standard` 标准化
- 设计师和工程师共享同一套动效语言
- 支持 reduced-motion 主题

**关键词**：motion tokens, systematized animation, motion design system

**为什么现在**：动效随意导致产品不一致，团队规模化后必须标准化。

---

## 九、AI 智能体体验（AX - Agent Experience）

**定义**：除了 DX（开发者体验）和 UX（用户体验），现在还要考虑"AI 能否理解和操作你的产品"。

**特征**：
- 页面结构对 AI 友好（语义化 HTML、清晰 schema）
- 提供 AI 可读的接口（llms.txt, MCP）
- 内容可被 Agent 检索和操作

**关键词**：agent experience (AX), AI-readable, llms.txt, MCP, machine-consumable UI

**代表**：Astro 6 的 Agent CMS、Markdown for Agents

---

## 十、原生 CSS 能力回归

**新特性已可用**：
- **Container Queries** — 组件级响应式
- **Cascade Layers (`@layer`)** — 级联控制
- **`:has()`** — 父选择器
- **Nesting** — 原生嵌套
- **`@scope`** — 样式作用域
- **Subgrid** — 嵌套网格对齐
- **View Transitions API** — 原生页面过渡
- **Scroll-driven Animations** — 原生滚动动画
- **`text-wrap: balance`** — 标题自动平衡换行
- **`field-sizing: content`** — 输入框自适应
- **Anchor Positioning** — 原生 popover 定位
- **`color-mix()` / OKLCH** — 现代色彩
- **Popover API** — 原生弹层

**趋势**：混合使用——Tailwind 快速搭建 + 原生 CSS 精细控制。

**关键词**：native CSS, container queries, :has(), view transitions, scroll-driven, anchor positioning

---

## 十一、深色模式成为默认

**趋势**：开发者工具、金融、创意工具大量以深色为主界面。

**2026 做法**：
- 不是"支持深色"，而是"深色为主，浅色为选项"
- Surface 分层（base → surface1 → surface2 → overlay）
- 用 luminous border 代替 shadow
- 品牌色饱和度降低适配深色

---

## 十二、尊重注意力（Attention-Respectful Design）

**背景**：用户对数字成瘾警惕性达到顶峰，隐私和心理健康关注上升。

**趋势**：
- 从"争夺注意力"转向"尊重注意力"
- Calm Technology 平静科技
- 减少通知、无无限滚动、明确使用时长
- 反 Dark Patterns 成为竞争优势

**关键词**：calm technology, attention-respectful, digital wellbeing, ethical design, anti-dark-pattern

---

## 十三、性能作为设计约束

**趋势**：Core Web Vitals 直接影响 SEO 和转化，性能进入设计决策。

**要点**：
- LCP < 2.5s / INP < 200ms / CLS < 0.1
- 字体加载策略（`font-display: swap` + preload）
- 图片格式（AVIF / WebP）+ 响应式 srcset
- 减少 JS bundle（RSC / Islands 架构）
- 边缘渲染

---

## 十四、可访问性从合规到默认

**背景**：欧盟 EAA 2025 年 6 月强制生效，法律风险上升。

**趋势**：
- 无障碍进入设计系统底层（组件默认合规）
- 自动化检测进 CI
- Headless UI 库流行（Radix/Headless UI 内置 a11y）

---

## 十五、端侧 AI

**趋势**：浏览器可直接运行精简 LLM。

**含义**：
- 隐私保护（数据不出设备）
- 零延迟响应
- 离线 AI 功能

**技术**：WebGPU + WebAssembly + 量化模型（如 Transformers.js）

---

## 趋势使用建议

### 安全的（推荐大胆用）
- Bento Grid
- 深色模式
- Motion Tokens
- 原生 CSS 新特性
- 巨型字体（品牌页）

### 需要权衡的
- Glassmorphism / Liquid Glass（性能 + 可访问性）
- Scrollytelling（开发成本高）
- Spatial UI（设备受限）
- 3D（性能）

### 前瞻性的（现在布局）
- Generative UI
- Agent Experience (AX)
- 端侧 AI
- 多模态交互

## Prompt 里怎么用

```
【趋势应用】：
- 布局采用 Bento Grid（非对称卡片，统一 16px gap 和 12px radius）
- 深色为主基调，surface 分 3 层，border 用 white/8 代替 shadow
- 背景用 aurora mesh gradient + subtle noise
- Hero 用巨型字体（clamp(48px, 8vw, 120px)，字重 800，负字距 -0.03em）
- 滚动入场用原生 CSS scroll-driven animations
- 页面过渡用 View Transitions API
- 动效全部走 motion tokens
- 容器查询做组件级响应式
- 无障碍：WCAG 2.2 AA，Radix 无头组件保证键盘和 ARIA
```
