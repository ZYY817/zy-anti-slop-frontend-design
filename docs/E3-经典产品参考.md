## 参考的正确方式

### ✅ 好的参考表达
```
"参考 Linear 的克制感和精密排版，但用暖色调而非冷灰"
"参考 Stripe 的渐变和文档并排布局"
"参考 Arc Browser 的 Bento 布局和圆润感"
"参考 Aesop 的极简和衬线字体使用"
"参考 Duolingo 的游戏化元素但更成人化"
```

### ❌ 差的参考表达
```
"做得像 Apple 一样"（Apple 什么？官网？App？）
"参考大厂设计"（哪个大厂？）
"要高级"（太抽象）
```

**要点**：参考"某产品的某个方面"，不是整体照搬。

## 学习方法

1. **拆解**：打开产品，用截图 + 标注拆解间距/字号/色值
2. **提炼关键词**：这个产品给我的感受是哪 3 个词？
3. **找规律**：它的 tokens 是什么？间距系统是 4pt 还是 8pt？
4. **复现**：用它的规则做一个自己的界面
5. **迁移**：把规则用到不同场景

**工具**：
- 浏览器 DevTools 直接看 CSS
- **Fontanello** — 看字体
- **CSS Peeper** — 看色彩/间距
- **WhatFont** — 字体识别
