# B78 · 摄影与影像艺术指导

> B32 讲图片在界面中的**技术处理**（格式、加载、蒙层、裁切）。
> 本文讲图片**内容本身**的视觉导演——怎么定义一套摄影语言，让所有图像"像同一个摄影师同一天拍的"。
> 核心价值：让 AI 生成/选用图片时保持系列一致性，避免"素材库拼贴感"。

**相关文档**：[B32-图片与媒体的视觉处理.md](B32-图片与媒体的视觉处理.md) · [B77-前端视觉艺术指导系统.md](B77-前端视觉艺术指导系统.md) · [B54-品牌视觉识别系统.md](B54-品牌视觉识别系统.md) · [B56-视觉焦点与注意力引导.md](B56-视觉焦点与注意力引导.md) · [B81-数字显示渲染与视觉精度.md](B81-数字显示渲染与视觉精度.md)

> **标记约定**：〈规范要求〉来自 W3C/官方规范或 WCAG；〈技术事实〉可验证的实现行为（附兼容性）；〈经验建议〉作者总结的常用起点；〈创意策略〉可有意打破的设计方法。
> 本文的摄影参数（色温 K 值、焦段、负空间比例等）多属〈经验建议〉与〈创意策略〉，可根据品牌调性调整。

---

## 一、为什么重要

- 一页里的图片色调不统一 → 视觉割裂，像PPT素材堆叠。
- AI 生成多张图片时，每张都好看但放一起像不同世界 → 缺少系列指导。
- 摄影/影像是 Hero 和内容区**面积最大的视觉元素**——它定义了大部分的页面气质。
- 前端开发需要能**描述**想要的摄影风格给设计师/AI，而不只是"找一张好看的图"。

---

## 二、核心概念

### 摄影风格的六大维度

任何一张照片的"风格"可以沿六个轴定义：

| 维度 | 控制什么 | 极端 A | 极端 B |
|---|---|---|---|
| **光线** | 照明方向、硬/软、色温 | 硬光/高对比 | 柔光/低对比 |
| **色彩** | 饱和度、色温、分级 | 高饱和暖色 | 低饱和冷灰 |
| **景别** | 镜头与主体的距离 | 特写/细节 | 远景/环境 |
| **焦段与透视** | 镜头焦距带来的空间感 | 广角夸张 | 长焦压缩 |
| **构图** | 主体位置、留白、裁切 | 满构图 | 大量负空间 |
| **后期** | 颗粒、对比曲线、风格化 | 胶片/颗粒/漏光 | 干净数码 |

一套摄影艺术指导 = 在这六个轴上**各固定一个范围**，所有图像都落在这个范围内。

## 三、中英文术语表

| 中文 | 英文 | 定义 | 使用场景 | 易混淆 |
|---|---|---|---|---|
| 光质 | Light Quality | 硬光（清晰阴影）vs 柔光（渐变阴影） | 定义品牌图片调性 | ≠ 亮度 |
| 色温 | Color Temperature | 光源的暖（低K）冷（高K）倾向 | 统一全系列情绪 | ≠ 白平衡校正 |
| 色彩分级 | Color Grading | 后期对色彩的艺术性调整（暗部/中间调/高光分别偏色） | 统一系列调性 | ≠ 色彩校正（还原真实） |
| 景别 | Shot Size | 远景/全景/中景/近景/特写/大特写 | 控制信息与情绪 | ≠ 焦距 |
| 焦段 | Focal Length | 镜头焦距（24mm/35mm/50mm/85mm/135mm） | 控制透视和空间感 | ≠ 景深 |
| 景深 | Depth of Field (DoF) | 清晰范围的深浅 | 引导视线到主体 | ≠ 模糊（blur 是后期） |
| 自然光 | Natural / Ambient Light | 利用环境光照明 | 生活化、真实感 | ≠ 人造光/布光 |
| 轮廓光 | Rim Light / Back Light | 从主体后方打光，勾勒边缘 | 分离主体与背景 | ≠ 逆光（更极端） |
| 黄金时刻 | Golden Hour | 日出/日落前后的暖色低角度光 | 温暖、电影感 | ≠ Blue Hour |
| 编辑风格摄影 | Editorial Photography | 杂志级有叙事性的摄影 | 品牌故事页 | ≠ 商业产品照 |
| 产品摄影 | Product Photography | 聚焦产品本身的拍摄 | 电商/功能展示 | ≠ 生活场景照 |
| 生活方式摄影 | Lifestyle Photography | 人物在真实场景中使用产品 | 情感连接/代入感 | ≠ Studio Shot |
| 电影定格 | Cinematic Still | 像电影截图一样的构图/光影/调色 | 品牌叙事/高端感 | ≠ 纪录片感 |
| 环境肖像 | Environmental Portrait | 人物置于其工作/生活环境中 | About/团队页 | ≠ 棚拍大头照 |
| 裁切安全区 | Safe Area / Bleed | 图片中保证不被裁切的核心区域 | 响应式不同比例 | ≠ 出血（印刷） |
| 视线方向 | Gaze Direction | 人物眼睛看向的方向 | 引导阅读方向 | ≠ 身体朝向 |
| LUT | Look-Up Table | 调色预设映射表 | 批量统一调色 | ≠ Filter（简化版） |

## 四、光线方向与光质

### 方向（Position）

| 光位 | 效果 | 适合 |
|---|---|---|
| 前平光 (Front) | 平面、少阴影、干净 | 美妆、证件、扁平设计 |
| 45° 侧光 (Rembrandt) | 立体、经典、有深度 | 肖像、产品、大多数场景 |
| 侧光 (Side) | 强烈明暗对比、戏剧 | 高端品牌、艺术感 |
| 轮廓光 (Rim/Back) | 主体边缘发光、分离背景 | 科技产品、黑暗背景 |
| 顶光 (Top) | 神秘、不友好（眼窝阴影） | 慎用（恐怖片既视感） |
| 底光 (Under) | 极不自然、诡异 | 几乎不用于商业 |

### 光质（Quality）

| 光质 | 视觉 | 情绪 | AI Prompt 关键词 |
|---|---|---|---|
| 硬光 Hard | 边缘锐利的阴影 | 力量、戏剧、时尚 | "hard directional light, sharp shadows" |
| 柔光 Soft | 柔和渐变的阴影 | 温暖、亲切、舒适 | "soft diffused light, gentle shadows" |
| 漫射光 Diffused | 几乎无阴影 | 平静、干净、匀称 | "overcast sky, flat even lighting" |

## 五、景别与焦段

### 景别速查

| 景别 | 英文 | 画面内容 | 传达 | UI 用途 |
|---|---|---|---|---|
| 大远景 | Extreme Long Shot | 环境全貌 | 场景设定、渺小感 | 全屏背景 |
| 远景 | Long Shot | 人物全身+环境 | 关系、空间 | Banner |
| 中景 | Medium Shot | 腰部以上 | 对话、交互 | 团队/关于 |
| 近景 | Close-Up | 面部 | 情绪、连接 | 引用/证言 |
| 大特写 | Extreme Close-Up | 局部细节 | 质感、精密 | 产品细节 |

### 焦段与空间感

| 焦段 | 透视 | 感受 | 适合 |
|---|---|---|---|
| 24mm | 广角夸张、近大远小 | 空间开阔、戏剧性 | 建筑、环境全景 |
| 35mm | 轻微广角、接近人眼 | 纪实、街头、真实 | Lifestyle、编辑 |
| 50mm | 无畸变、自然 | 标准视角、平实 | 产品、人物日常 |
| 85mm | 轻微压缩、背景虚化 | 肖像美化、亲密 | 人物特写 |
| 135mm+ | 强烈压缩、前后景贴近 | 电影感、隔离 | 运动、长焦肖像 |

## 六、系列图片的一致性

这是**最容易出问题**的地方——一页里多张图不像同一套。

### 一致性核心检查（六统一）

1. **统一光线方向**：全系列光线从同一侧打（如都是左上45°柔光）
2. **统一色温**：全部偏暖 或 全部中性 或 全部偏冷
3. **统一色彩分级**：阴影偏蓝/中间调中性/高光偏暖——或用同一 LUT
4. **统一景别范围**：同页卡片要么全特写，要么全中景，不混
5. **统一背景处理**：全部纯色底/全部环境实景/全部虚化——不混
6. **统一后期质感**：全部干净数码/全部胶片颗粒/全部哑光——不混

### AI 生成多图的一致性策略

```
给 AI 生成同一页的多张图片时：
- 先生成一张"基准图"确认风格
- 后续图都附带基准图作为风格参考
- Prompt 中明确列出六统一约束
- 生成后用统一 filter/LUT 做二次对齐
```

### CSS 统一后期（兜底手段）

当图片来源不同时，用 CSS filter 强制拉到"同一个色彩世界"：

```css
.photo-series img {
  filter:
    saturate(0.85)        /* 降饱和 → 统一 */
    contrast(1.08)        /* 微加对比 */
    brightness(0.97)      /* 微压亮度 */
    sepia(0.05);          /* 微暖色 → 统一色温 */
}
```
这不是最佳方案（源头统一更好），但是**当图片来源杂时的有效兜底**。

## 七、图片与 UI 叠加时的可读性

图片用作背景/Hero 时，上方文字的可读性是核心挑战。

### 六种处理手法

| 手法 | CSS 实现 | 适合 |
|---|---|---|
| 暗色蒙层 | `linear-gradient(rgba(0,0,0,0.5), rgba(0,0,0,0.5))` | 白字通吃，最安全 |
| 渐变蒙层 | `linear-gradient(to right, rgba(0,0,0,0.7) 40%, transparent)` | 文字在一侧 |
| 模糊底 | 文字区 `backdrop-filter: blur(12px)` | 保留图片信息量 |
| 图片留白 | 选用本身有大面积纯色/浅色区域的图 | 最自然 |
| 投影文字 | `text-shadow: 0 2px 8px rgba(0,0,0,0.5)` | 轻量级 |
| 色块承托 | 文字放在半透明色块卡片内 | 结构感强 |

### 对比度检查
- WCAG 要求正文 4.5:1、大字 3:1
- 图片有明暗变化区域——**最暗处仍满足对比度**才安全
- 工具：Chrome DevTools "Rendering → Show contrast issues"

## 八、响应式图片的艺术指导

同一张图在不同比例裁切时，"焦点/重心"必须保持正确。

### `<picture>` + art direction

```html
<picture>
  <!-- 移动端竖版：裁切到人物面部 -->
  <source media="(max-width: 767px)" srcset="hero-mobile.avif" type="image/avif">
  <!-- 桌面端宽版：保留环境 -->
  <source media="(min-width: 768px)" srcset="hero-desktop.avif" type="image/avif">
  <img src="hero-desktop.jpg" alt="..." width="1440" height="600">
</picture>
```

### `object-position` 指定焦点
```css
.hero-img {
  object-fit: cover;
  object-position: 70% 30%; /* 焦点偏右上 */
}
@media (max-width: 768px) {
  .hero-img {
    aspect-ratio: 3/4;
    object-position: 50% 20%; /* 移动端焦点居中偏上 */
  }
}
```

## 九、摄影风格定义模板（可直接用于 AI 或品牌规范）

```
【摄影风格定义】
光线：{柔光，左上 45° 方向，色温 5500K 中性}
色彩：{低饱和，高光微暖，暗部微冷蓝}
景别：{中景为主（产品使用场景），特写为辅（细节质感）}
焦段感：{50mm 自然，浅景深 f/2.8 柔化背景}
背景：{真实环境，去杂乱，保持一个主色调的背景}
后期：{统一 LUT（如 VSCO Kodak Portra 感），颗粒 0.03，对比 +5}
人物：{自然表情，非摆拍，视线看向画外或产品}
主体朝向：{面向页面内侧（引导阅读），不朝向页面边缘}
构图规则：{主体偏三分之一位置，至少 30% 负空间给文字叠加}
裁切安全区：{主体不在图片边缘 15% 范围内}
```

## 十、Prompt 模板（AI 生成图片）

```
为 {产品/页面} 生成一组系列图片（{4} 张），要求：

摄影风格（全系列统一）：
- 光线：柔光，左上 45° 方向，无硬阴影
- 色温：微暖（5800K），高光偏金
- 色彩分级：暗部偏深蓝，中间调中性，高光偏暖（统一 cinematic teal & orange 趋势）
- 焦段感：85mm 浅景深，背景虚化自然
- 后期质感：微颗粒（胶片 Portra 400 风格），对比适中，不过曝

构图约束：
- 主体位于三分之一处
- 至少 30% 负空间保留给 UI 文字叠加
- 主体面朝画面内侧（不朝边缘）
- 裁切安全区：主体不在边缘 15% 内

系列一致性（关键）：
- 所有图片来自同一"虚拟拍摄日"——光线方向、色温、背景虚化度不变
- 先生成第一张确认风格，后续以第一张为参考保持一致
- 若无法保持一致，输出后建议统一 CSS filter 参数
```

## 十二、检验清单

- [ ] 有明确的摄影风格定义（光线/色彩/景别/焦段/后期 五维度）
- [ ] 同页所有图片通过"六统一"检查（光向/色温/分级/景别/背景/质感）
- [ ] AI 生成多图时先出基准图、后续参考基准图
- [ ] 生成后若不一致，有 CSS filter 统一兜底
- [ ] 主体朝向画面内侧（不朝向边缘）
- [ ] 裁切安全区：主体不在边缘 15% 内
- [ ] 至少 30% 负空间留给 UI 文字
- [ ] 文字叠加区满足 WCAG 对比度（最暗处也够）
- [ ] 响应式不同比例裁切时焦点仍正确（object-position）
- [ ] 全页图片"像同一天同一台相机拍的"
