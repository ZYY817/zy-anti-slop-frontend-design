# B63 · 视觉降噪与极简工程

> "完美不是无可添加,而是无可删减。" —— Antoine de Saint-Exupéry
> 但大部分"极简"设计只是**内容不够**,不是**减法到位**。
> 真正的极简是**减到不能再减,但依然丰富**——像 Apple 官网:看起来什么都没有,实际每一个像素都在工作。
> 这份文档拆的是:如何系统性地减法,以及减法之后如何**不 Boring**。

---

## 一、降噪与极简术语表

| 中文术语 | 英文术语 | 一句话含义 |
|---|---|---|
| 视觉噪音 | Visual Noise | 不承载信息但占据注意力的视觉元素 |
| 信噪比 | Signal-to-Noise Ratio | 有效信息与视觉噪音的比例 |
| 数据墨水比 | Data-ink Ratio | Tufte 概念:传达数据的墨水占总墨水比例 |
| 非数据墨水 | Non-data Ink | 装饰性、不传达信息的视觉元素 |
| 图表垃圾 | Chartjunk | Tufte 术语:图表中多余的装饰 |
| 减法设计 | Subtractive Design | 通过移除而非添加来改进设计 |
| 极简主义 | Minimalism | 用最少元素达成目的的设计哲学 |
| 本质主义 | Essentialism | 只保留本质要素的设计取向 |
| 渐进式披露 | Progressive Disclosure | 按需逐层展示信息 |
| 分层信息 | Layered Information | 信息按重要性分层展示 |
| 认知负载 | Cognitive Load | 处理界面所需的心理资源 |
| 选择过载 | Choice Overload | 选项太多导致决策困难 |
| 希克定律 | Hick's Law | 选项越多决策时间越长 |
| 米勒定律 | Miller's Law | 短期记忆容量 7±2 |
| 奥卡姆剃刀 | Occam's Razor | 简单解释优于复杂解释 |
| 视觉冗余 | Visual Redundancy | 同一信息被多次视觉编码 |
| 装饰性元素 | Decorative Element | 纯装饰无功能的视觉元素 |
| 隐性边界 | Implicit Boundary | 用间距/对齐代替边框划分区域 |
| 显性边界 | Explicit Boundary | 用边框/背景明确划分区域 |
| 单色设计 | Monochromatic Design | 只用一个色相的设计 |
| 无边框设计 | Borderless Design | 去掉所有边框的设计方案 |
| 简约不简单 | Simple but Rich | 视觉简洁但内涵丰富 |
| 空而不空 | Full Emptiness | 留白但有张力,不显空洞 |

## 二、噪音清单:哪些是必须删的

### 2.1 常见视觉噪音 25 项

```
□ 1. 装饰性边框(无功能的框线)
□ 2. 冗余分隔线(间距已经分开了)
□ 3. 无必要的阴影(不表达层级的阴影)
□ 4. 装饰性图标(与文字重复表达同一意思)
□ 5. 渐变背景(无理由的花哨渐变)
□ 6. 图案纹理(不属于品牌语言的纹理)
□ 7. 多余的圆角变化(同一页 5 种圆角)
□ 8. 无意义的动效(纯装饰的动画)
□ 9. 过度的图片滤镜
□ 10. 重复的品牌 Logo(一屏出现三次)
□ 11. 冗余的说明文字(标题已经说清了)
□ 12. 无必要的分类标签
□ 13. 装饰性斜线/波浪线
□ 14. 多余的按钮(应该是文字链接)
□ 15. 过多的颜色(> 3 种主色)
□ 16. 无必要的加粗(到处都是粗体)
□ 17. 多种字体混用(> 2-3 种)
□ 18. 装饰性字体特效(描边/投影/浮雕)
□ 19. 无必要的角标/徽章
□ 20. 重复的导航入口
□ 21. 无必要的卡片包裹(内容不需要"卡片")
□ 22. 冗余的进度指示
□ 23. 装饰性背景大图(遮盖内容)
□ 24. 无必要的头像/图片占位
□ 25. 装饰性 emoji(不承载语义)
```

### 2.2 降噪自检问题

对每个元素问三个问题:

```
1. 移除它,信息会丢失吗?      → 不会 = 删
2. 它承载了什么功能?          → 说不出 = 删
3. 它能被更简单的方式替代吗?  → 能 = 替换
```

## 三、减法的五个层次

### 3.1 L1 移除装饰(Remove Decoration)

```css
/* Before:装饰过多 */
.card-before {
  border: 2px solid var(--brand);
  border-radius: 16px;
  box-shadow: 0 8px 24px rgba(0,0,0,0.15);
  background: linear-gradient(135deg, #f0f0f0, #fff);
  padding: 24px;
}
.card-before::before {
  content: "★";
  color: gold;
}

/* After:只留必要 */
.card-after {
  border: 1px solid oklch(92% 0.005 265);
  border-radius: 8px;
  background: var(--surface);
  padding: 24px;
}
```

### 3.2 L2 合并重复(Merge Redundancy)

```html
<!-- Before:图标 + 文字重复表达 -->
<div>
  <span>📧</span>
  <span>邮件</span>
  <span>Email</span>
</div>

<!-- After:只留一个 -->
<div>
  <svg class="icon-mail"></svg>
  <span>邮件</span>
</div>
```

### 3.3 L3 替换为隐性(Replace with Implicit)

```css
/* Before:显性边框分区 */
.section-before {
  border: 1px solid #ddd;
  border-radius: 8px;
  padding: 16px;
  margin-bottom: 16px;
}

/* After:用间距和对齐分区(无边框) */
.section-after {
  padding-block: 32px;
  /* 间距足够大,不需要边框 */
}
.section-after + .section-after {
  border-top: 1px solid oklch(94% 0.005 265);  /* 极细分隔线代替全框 */
}
```

**核心原则**:**间距 > 分隔线 > 背景色 > 边框**(优先用左边的方式分区)。

### 3.4 L4 渐进式披露(Progressive Disclosure)

```html
<!-- 默认只显示核心信息 -->
<details class="disclosure">
  <summary>
    <h3>项目名称</h3>
    <span class="status">进行中</span>
  </summary>
  <!-- 展开后才显示的详细信息 -->
  <div class="detail">
    <p>创建时间: 2026-08-01</p>
    <p>负责人: 张三</p>
    <p>预算: ¥50,000</p>
  </div>
</details>
```

```css
.disclosure summary {
  cursor: pointer;
  list-style: none;
  display: flex;
  align-items: center;
  gap: 12px;
}
.disclosure summary::-webkit-details-marker { display: none; }

/* chevron 旋转 */
.disclosure summary::after {
  content: "";
  margin-left: auto;
  width: 8px;
  height: 8px;
  border-right: 1.5px solid currentColor;
  border-bottom: 1.5px solid currentColor;
  transform: rotate(45deg);
  transition: transform 200ms;
}
.disclosure[open] summary::after {
  transform: rotate(-135deg);
}
```

### 3.5 L5 重新定义问题(Redefine the Problem)

```
最高级的减法:不是"这个功能怎么简化",而是"这个功能真的需要吗"

例:
❌ 简化设置页面 20 个选项的布局
✅ 用智能默认值,把 20 个选项减到 3 个
```

## 四、无边框设计(Borderless)

### 4.1 边框替代方案矩阵

| 分区需求 | 替代方案 | CSS |
|---|---|---|
| 区分两个区块 | 间距(最优) | `margin-block: 48px` |
| 分隔列表项 | 极细线 | `border-top: 1px solid oklch(0% 0 0 / 0.06)` |
| 标示可交互区 | hover 背景 | `:hover { background: oklch(0% 0 0 / 0.03) }` |
| 输入框边界 | 底部线 或 背景色 | `border-bottom: 1px` 或 `background: gray-50` |
| 卡片边界 | 背景色差 | `background: white` on `gray-50` 底 |
| 层级表达 | 极微阴影 | `box-shadow: 0 1px 2px oklch(0% 0 0 / 0.04)` |

### 4.2 无边框输入框

```css
/* 无边框输入:只有底线 */
.input-underline {
  border: none;
  border-bottom: 1px solid var(--border);
  border-radius: 0;
  padding: 8px 0;
  background: transparent;
  transition: border-color 200ms;
}
.input-underline:focus {
  outline: none;
  border-bottom-color: var(--brand);
  border-bottom-width: 2px;
}

/* 或用背景色代替边框 */
.input-filled {
  border: none;
  background: oklch(96% 0.005 265);
  border-radius: 8px;
  padding: 10px 14px;
}
.input-filled:focus {
  background: oklch(100% 0 0);
  box-shadow: 0 0 0 2px var(--brand);
  outline: none;
}
```

### 4.3 无边框表格

```css
.table-borderless {
  border-collapse: collapse;
}

.table-borderless th {
  border-bottom: 1px solid oklch(88% 0.007 265);  /* 只有表头下线 */
  font-weight: 600;
  font-size: 12px;
  text-transform: uppercase;
  letter-spacing: 0.05em;
  color: var(--text-tertiary);
  padding: 8px 12px;
  text-align: left;
}

.table-borderless td {
  border: none;
  padding: 12px;
}

/* 靠 hover 而非边框指示行 */
.table-borderless tr:hover td {
  background: oklch(0% 0 0 / 0.025);
}
```

## 五、色彩降噪

### 5.1 色彩数量的严格限制

```
极简铁律:
- 主色: 1 个
- 中性色: 1 套(灰阶 9 级)
- 语义色: 3-4 个(仅用于状态)
- 装饰色: 0 个

总视觉色相数: ≤ 2(主色相 + 中性色相)
```

### 5.2 单色设计(Monochromatic)

```css
:root {
  /* 只用一个色相 265,靠明度和饱和度建立全部层次 */
  --c-1:  oklch(98% 0.005 265);
  --c-2:  oklch(94% 0.010 265);
  --c-3:  oklch(85% 0.020 265);
  --c-4:  oklch(70% 0.060 265);
  --c-5:  oklch(55% 0.120 265);
  --c-6:  oklch(45% 0.140 265);
  --c-7:  oklch(35% 0.100 265);
  --c-8:  oklch(22% 0.050 265);
  --c-9:  oklch(14% 0.020 265);
}

.page  { background: var(--c-1); color: var(--c-9); }
.card  { background: white; border: 1px solid var(--c-2); }
.cta   { background: var(--c-5); color: white; }
.muted { color: var(--c-6); }
```

### 5.3 灰度优先原则

```
设计流程:
1. 先用纯灰度做完整个界面
2. 检查:层级是否清晰?(没有颜色也要清晰)
3. 最后才加颜色,且只加在最需要的地方(通常 ≤ 3 处)
```

```css
/* 灰度测试 */
.grayscale-test {
  filter: grayscale(1);
}
/* 如果去掉颜色后层级失效 → 说明过度依赖颜色 */
```

## 六、字体降噪

### 6.1 字体数量限制

```
极简铁律:
- 字体家族: 1-2 个(最多 3:Display + Body + Mono)
- 字重档位: 3-4 个(如 400/500/600/700)
- 字号档位: 5-7 个
```

### 6.2 减少字重变化

```css
/* ❌ 过多字重 */
h1 { font-weight: 900; }
h2 { font-weight: 800; }
h3 { font-weight: 700; }
h4 { font-weight: 600; }
strong { font-weight: 650; }

/* ✅ 只用两档,靠字号建立层次 */
h1, h2, h3, h4 { font-weight: 600; }
strong { font-weight: 600; }
body { font-weight: 400; }
```

### 6.3 去掉文字特效

```css
/* ❌ 文字装饰噪音 */
.title-noisy {
  text-shadow: 2px 2px 4px rgba(0,0,0,0.3);
  -webkit-text-stroke: 1px black;
  background: linear-gradient(...);
  -webkit-background-clip: text;
}

/* ✅ 纯粹的文字 */
.title-clean {
  color: var(--text-primary);
  font-weight: 700;
}
```

## 七、极简但不 Boring 的方法

### 7.1 关键:一个"惊喜点"

**极简 + 一个极致细节 = 高级**;极简 + 什么都没有 = 无聊。

```
Apple:极简 + 极致的产品摄影
Vercel:极简 + 完美的字体和微动效
Stripe:极简 + 一个渐变
Linear:极简 + 微光边框和丝滑动效
```

### 7.2 六种"不 Boring"的手段

**1. 一个极致的排版**
```css
.hero-typographic {
  font-size: clamp(64px, 14vw, 180px);
  font-weight: 900;
  line-height: 0.85;
  letter-spacing: -0.05em;
  /* 纯文字,但尺寸极端 = 视觉冲击 */
}
```

**2. 一个精致的动效**
```css
.link-underline {
  position: relative;
}
.link-underline::after {
  content: "";
  position: absolute;
  bottom: -2px;
  left: 0;
  width: 100%;
  height: 1px;
  background: currentColor;
  transform: scaleX(0);
  transform-origin: right;
  transition: transform 300ms cubic-bezier(0.65, 0, 0.35, 1);
}
.link-underline:hover::after {
  transform: scaleX(1);
  transform-origin: left;
}
/* 极简的下划线,但方向切换的细节让它有灵魂 */
```

**3. 一个大胆的留白**
```css
.editorial-space {
  padding-block: 240px;  /* 极端留白本身就是设计 */
}
```

**4. 一个高质量的图片/视频**
```
极简界面 + 一张顶级摄影 = 高级
极简界面 + 素材库图片 = 廉价
```

**5. 一个不对称的构图**
```css
.asymmetric {
  display: grid;
  grid-template-columns: 1fr 2.618fr;  /* 黄金比不对称 */
  gap: 64px;
}
```

**6. 一个材质细节**
```css
/* 极微的噪点,只有放大才看得到 */
body::after {
  content: "";
  position: fixed;
  inset: 0;
  pointer-events: none;
  opacity: 0.015;
  background-image: url("data:image/svg+xml,...noise...");
  z-index: 1;
}
```

## 八、Tufte 五律的前端应用

```
1. 展示数据(Show the data)
   → 界面的主体应该是内容,不是框架

2. 最大化数据墨水比(Maximize data-ink ratio)
   → 每个像素都应该传达信息

3. 消除图表垃圾(Erase chartjunk)
   → 去掉所有装饰性元素

4. 消除非数据墨水(Erase non-data-ink)
   → 去掉不必要的边框/网格线/背景

5. 修订与编辑(Revise and edit)
   → 反复迭代,每次都试着删掉一些东西
```

```css
/* Tufte 式图表 */
.tufte-chart {
  /* 无边框 */
  border: none;
  /* 无网格线,或极浅 */
  --grid-color: oklch(0% 0 0 / 0.04);
  /* 无背景 */
  background: transparent;
  /* 数据线是唯一的主体 */
}

.tufte-chart .axis {
  stroke: oklch(0% 0 0 / 0.15);
  stroke-width: 0.5;
}

.tufte-chart .gridline {
  display: none;  /* 或极浅 */
}

.tufte-chart .data-line {
  stroke: var(--brand);
  stroke-width: 2;
  fill: none;
}
```

```
一屏选项 ≤ 7 个(Miller 定律)

═══ 极简但不 Boring(必须有 1 个惊喜点) ═══
选一个:
- 极端排版(H1 clamp 到 180px, 字重 900, 行高 0.85)
- 精致动效(下划线方向切换/微妙 hover)
- 大胆留白(padding-block 240px)

- 不对称黄金比构图(1fr 2.618fr)

═══ Tufte 五律 ═══
展示数据 / 最大化数据墨水比 / 消除图表垃圾 /
消除非数据墨水 / 反复迭代删减
```

## 十、踩坑指南

### 坑1:极简 = 空洞
**症状**:什么都没有,但也没有任何吸引力。
**解法**:极简必须有一个"极致的点"(排版/图片/动效/留白)。

### 坑2:把内容不足当极简
**症状**:因为没内容,所以看起来很空,自称"极简"。
**解法**:极简是有内容但精心组织,不是没内容。

### 坑3:删掉了必要的功能提示
**症状**:为了极简去掉了标签/说明,用户不知道怎么用。
**解法**:降噪是删装饰,不是删信息。功能性文字不能删。

### 坑4:无边框导致边界不清
**症状**:去掉所有边框后,不知道哪里是可点击区。
**解法**:hover 高亮 + 明确的间距分组补足。

### 坑5:过度依赖颜色建立层次
**症状**:灰度测试后层级完全消失。
**解法**:先用灰度做完,靠大小/字重/间距建立层次。

### 坑6:极简但可访问性差
**症状**:极浅的分隔线/边框对比度不足 3:1。
**解法**:功能性元素(边框/图标)对比度必须 ≥ 3:1。

### 坑7:渐进式披露藏太深
**症状**:重要信息被折叠了 3 层。
**解法**:折叠层级 ≤ 1 层,重要信息永远可见。

## 十一、谁在用(极简典范)

| 产品/网站 | 极简手法 | 惊喜点 |
|---|---|---|
| **Apple** | 极致留白 + 无装饰 | 顶级产品摄影 |
| **Vercel** | 纯黑白 + 无边框 | 完美字体 Geist + 微动效 |
| **Notion** | 无色彩 + 系统字体 | 极致的编辑体验 |
| **Stripe** | 中性色 + 大留白 | 一个品牌渐变 |
| **Linear** | 深色极简 | 微光边框 + 丝滑动效 |
| **Muji 无印良品** | 无 Logo 无装饰 | 材质本身的质感 |
| **Google 搜索** | 一个输入框 | 极致的功能纯粹性 |
| **Tufte CSS** | 学术极简 | 边注(side notes)排版 |
| **Aesop** | 无彩色 + 衬线 | 极致的图片和排版 |

## 检验清单

- [ ] 色相数量 ≤ 2 个
- [ ] 字体家族 ≤ 2-3 个
- [ ] 字重档位 ≤ 4 个
- [ ] 圆角档位 ≤ 3 个
- [ ] 分区优先用间距,不轻易加边框
- [ ] 无装饰性边框/阴影/渐变/纹理
- [ ] 无与文字重复的图标
- [ ] 无文字特效(描边/投影)
- [ ] 灰度测试后层级仍清晰
- [ ] 一屏选项 ≤ 7 个(Miller 定律)
- [ ] 渐进式披露层级 ≤ 1 层
- [ ] 功能性元素对比度 ≥ 3:1(极简不牺牲可访问性)
- [ ] 有至少一个"惊喜点"(不是无聊的空)
- [ ] 每个元素都能说清它的功能
- [ ] 试着删掉一些东西后界面反而更好
