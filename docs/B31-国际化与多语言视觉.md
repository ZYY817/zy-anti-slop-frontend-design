# B31 · 国际化与多语言视觉

> 做全球化产品,视觉必须为 100+ 语言留余地。
> 这是最容易被忽略但一旦翻车就是灾难的维度。

---

## 一、文案长度膨胀(Text Expansion)★ 最常见翻车点

以英文为基准,翻译后长度变化:

| 语言 | 长度变化 | 备注 |
|---|---|---|
| **德语** | +30~35% | 复合词超长(Rechtsschutzversicherung) |
| **芬兰语** | +30~40% | 最长 |
| **俄语** | +15~20% | |
| **法语** | +15~20% | |
| **西班牙语** | +15~25% | |
| **葡萄牙语** | +20~30% | |
| **意大利语** | +10~15% | |
| **荷兰语** | +20~25% | |
| **波兰语** | +20~30% | |
| **日语** | ±10% | 字符少但字宽 |
| **韩语** | ±10% | |
| **中文** | -20~30% | 最短 |
| **阿拉伯语** | -10~20% | 但需 RTL |

### 设计对策

```css
/* ❌ 固定宽度按钮 */
.button { width: 120px; }

/* ✅ 内容驱动 + 最小宽度 */
.button {
  min-width: 120px;
  padding-inline: 24px;
  white-space: nowrap;   /* 或允许换行 */
}
```

**规则**:
- 按钮/标签**不要固定宽度**
- 导航项预留 30% 伸缩空间
- 表格列宽用 `minmax()`
- 卡片高度用 `min-height` 不是 `height`
- 图标+文字组合要能换行

### 短语无法拼接
```
❌ "You have " + n + " new " + type + " messages"
   (不同语言语序不同)

✅ 完整句子模板
   en: "You have {n} new {type} messages"
   ja: "{n}件の新しい{type}メッセージがあります"
   ar: "لديك {n} رسائل {type} جديدة"
```

## 二、RTL(从右到左)完整适配

### 需要 RTL 的语言
阿拉伯语、希伯来语、波斯语、乌尔都语、迪维希语(约 5 亿人口)

### HTML 声明
```html
<html lang="ar" dir="rtl">
```

### 用逻辑属性(自动镜像)★
```css
/* ❌ 物理属性 - RTL 下错 */
margin-left: 16px;
text-align: left;
border-left: 1px solid;

/* ✅ 逻辑属性 - 自动适配 */
margin-inline-start: 16px;
text-align: start;
border-inline-start: 1px solid;
```

### 需要镜像的元素
- 布局方向(侧栏从右侧)
- 文字对齐
- 图标方向(箭头/返回/前进/播放)
- 进度条方向
- 滑块方向
- 面包屑方向
- 表格列顺序

### 不需要镜像的元素
- 数字(仍从左到右)
- 时钟图标
- Logo
- 播放/暂停(媒体控制约定)
- 代码块
- 电话号码
- 图表(数据方向可能保持)

### 图标镜像
```css
[dir="rtl"] .icon-arrow {
  transform: scaleX(-1);
}
```

### RTL 字体
阿拉伯语需要专门字体:
```css
[lang="ar"] {
  font-family: "IBM Plex Sans Arabic", "Noto Sans Arabic", Tahoma, sans-serif;
  line-height: 1.8;   /* 阿拉伯文需要更大行高 */
}
```

## 三、多语言字体栈

### 按语言指定
```css
:root {
  --font-latin: "Inter", -apple-system, sans-serif;
  --font-cjk-sc: "PingFang SC", "Microsoft YaHei", "Noto Sans SC", sans-serif;
  --font-cjk-tc: "PingFang TC", "Microsoft JhengHei", "Noto Sans TC", sans-serif;
  --font-jp: "Hiragino Sans", "Yu Gothic", "Noto Sans JP", sans-serif;
  --font-kr: "Apple SD Gothic Neo", "Malgun Gothic", "Noto Sans KR", sans-serif;
  --font-arabic: "IBM Plex Sans Arabic", "Noto Sans Arabic", Tahoma, sans-serif;
  --font-thai: "Noto Sans Thai", "Leelawadee UI", sans-serif;
  --font-devanagari: "Noto Sans Devanagari", sans-serif;
}

[lang="zh-CN"] { font-family: var(--font-cjk-sc); }
[lang="ja"]    { font-family: var(--font-jp); }
[lang="ar"]    { font-family: var(--font-arabic); }
```

### 中英混排字体栈
```css
font-family:
  "Inter",              /* 英文优先 */
  "PingFang SC",        /* 中文 macOS */
  "Microsoft YaHei",    /* 中文 Windows */
  "Noto Sans SC",       /* 中文兜底 */
  sans-serif;
```
**顺序很重要**:英文在前,中文渲染中文,英文渲染英文。

### unicode-range 精确控制
```css
@font-face {
  font-family: "MyFont";
  src: url("latin.woff2");
  unicode-range: U+0000-00FF;   /* 只用于拉丁字符 */
}
@font-face {
  font-family: "MyFont";
  src: url("cjk.woff2");
  unicode-range: U+4E00-9FFF;   /* 只用于中日韩 */
}
```

## 四、各语言的排版特殊要求

### 中文
- 行高 ≥1.6(比英文高)
- 字重 400 可能显细,可用 450-500
- 中英之间加空格
- 段首缩进 2em(正式排版)或用段间距
- 标点挤压(`text-spacing-trim`)
- 不需要连字符断词
- 竖排:`writing-mode: vertical-rl`

### 日文
- 行高 1.7-1.9(最高)
- 禁则处理(约物不能在行首/行尾)
- 假名与汉字混排的字重平衡
- 竖排常见(小说/传统)
- Ruby 注音:`<ruby>漢字<rt>かんじ</rt></ruby>`

### 韩文
- 行高 1.6-1.8
- 词间有空格(与中日不同)
- 可以断词换行

### 阿拉伯文
- 行高 1.8-2.0(字符有上下延伸)
- 连写(字形随位置变化)
- 数字用阿拉伯-印度数字或西方数字
- 不支持斜体(用其他方式强调)
- 不支持全大写

### 泰文
- 行高 1.8-2.0(有上下叠加符号)
- 无词间空格,断行规则复杂
- 需要专用字体

### 德文
- 超长复合词需要 `hyphens: auto` + `lang="de"`
- 允许 `overflow-wrap: break-word`

### 西里尔文(俄语等)
- 字宽比拉丁文略宽
- 需要字体支持 Cyrillic 子集

## 五、日期/时间/数字/货币格式

### 日期格式差异
```
美国:   08/03/2026  (MM/DD/YYYY)
英国:   03/08/2026  (DD/MM/YYYY)
中国:   2026-08-03  (YYYY-MM-DD)
日本:   2026年8月3日
德国:   03.08.2026
```
**用 Intl API**:
```js
new Intl.DateTimeFormat('ja-JP', { dateStyle: 'long' }).format(date)
```

### 数字格式
```
美国:   1,234,567.89
德国:   1.234.567,89   (点千分位,逗号小数)
法国:   1 234 567,89   (空格千分位)
印度:   12,34,567.89   (特殊分组!)
瑞士:   1'234'567.89
```
**用 Intl.NumberFormat**。

### 货币
```
美元:   $1,234.56
欧元:   1.234,56 €     (符号在后)
日元:   ¥1,235          (无小数)
人民币: ¥1,234.56 或 ￥
```
符号位置、小数位数、千分位都不同。

### 时区
- 显示相对时间("2 小时前")避免时区问题
- 显示绝对时间时标注时区
- 或用户设置时区偏好

### 周首日
- 美国/日本:周日开始
- 欧洲/中国:周一开始
- 中东:周六开始

## 六、文化色彩差异

| 颜色 | 西方 | 东亚 | 中东 | 拉美 |
|---|---|---|---|---|
| 红 | 危险/警告/爱 | 喜庆/吉祥/股市涨 | 危险 | 热情 |
| 白 | 纯洁/婚礼 | 丧事(部分) | 纯洁 | 和平 |
| 黑 | 丧事/高级 | 高级/正式 | 丧事 | 丧事 |
| 绿 | 环保/成功/金钱 | 健康/股市跌 | **神圣**(伊斯兰) | 自然 |
| 黄 | 警告/懦弱 | 皇家(中国古代) | 幸福 | 丧事(部分) |
| 紫 | 奢侈/皇家 | 财富 | — | 死亡(巴西) |
| 蓝 | 信任/企业 | 信任 | 保护 | 信任 |

**关键陷阱**:
- 中国股市:**红涨绿跌**(与西方相反!)
- 绿色在伊斯兰文化是神圣色,慎用于负面语义
- 白色在部分东亚文化关联丧事

## 七、图标与图像的文化适配

### 手势图标风险
- 👍 大拇指:中东/西非部分地区是侮辱
- ✌️ V 手势:英澳反手是侮辱
- 👌 OK:巴西/土耳其是侮辱
- 🖐 手掌:希腊是侮辱

**建议**:全球产品避免手势图标,用抽象符号。

### 其他文化敏感
- 猪的图像:伊斯兰/犹太文化避免
- 牛的图像:印度教敏感
- 酒精图像:部分地区不宜
- 特定手势/宗教符号
- 邮箱图标:各国邮箱形状不同(用信封更通用)
- 房子图标表"首页":通用性 OK
- 购物车 vs 购物篮:欧洲用篮子更多

### 人物图像
- 服装/发型/肤色的多样性
- 避免刻板印象
- 手势/姿势的文化含义

## 八、i18n 的技术实现

### HTML lang 属性
```html
<html lang="zh-CN">
<!-- 页面内混合语言 -->
<p>这是中文,<span lang="en">this is English</span>。</p>
```
影响:字体选择、断词规则、屏幕阅读器发音、拼写检查。

### hreflang(SEO)
```html
<link rel="alternate" hreflang="en" href="https://example.com/en/">
<link rel="alternate" hreflang="zh-CN" href="https://example.com/zh/">
<link rel="alternate" hreflang="x-default" href="https://example.com/">
```

### 语言切换器设计
- 用**语言自身名称**("日本語" 不是 "Japanese")
- 加国旗要谨慎(语言 ≠ 国家,西班牙语不只西班牙)
- 位置:通常右上角或 footer
- 记住用户选择(localStorage / cookie)

### 库
- **i18next** — 最通用
- **next-intl** — Next.js 首选
- **FormatJS / react-intl** — Intl API 封装
- **Lingui** — 编译时优化

## 九、视觉设计的 i18n 检查清单

**布局**:
- [ ] 按钮无固定宽度
- [ ] 导航预留 30% 伸缩
- [ ] 全部逻辑属性(margin-inline 等)
- [ ] 卡片用 min-height 不是 height
- [ ] 表格列用 minmax()

**RTL**:
- [ ] `dir="rtl"` 下布局正确镜像
- [ ] 方向性图标镜像
- [ ] 非方向性图标不镜像(时钟/Logo/播放)
- [ ] 数字仍 LTR

**字体**:
- [ ] 每种语言有专用字体栈
- [ ] 中英混排字体顺序正确(英前中后)
- [ ] CJK 行高 ≥1.6,阿拉伯 ≥1.8
- [ ] 字体文件按 unicode-range 分片

**格式**:
- [ ] 日期用 Intl.DateTimeFormat
- [ ] 数字用 Intl.NumberFormat
- [ ] 货币符号位置正确
- [ ] 时间显示相对时间或标注时区
- [ ] 周首日按地区

**文化**:
- [ ] 色彩语义检查(尤其红绿)
- [ ] 无手势图标
- [ ] 无宗教/文化敏感图像
- [ ] 人物图像多样性

**技术**:
- [ ] lang 属性正确
- [ ] hreflang 完整
- [ ] 语言切换器用语言自身名称
- [ ] 不拼接句子片段

## 十、Prompt 模板

```
【国际化视觉要求】

文案膨胀:
- 所有按钮/标签不设固定宽度,用 min-width + padding
- 导航项预留 30% 伸缩空间(德语最长 +35%)
- 卡片用 min-height,允许内容撑高
- 不拼接句子片段(用完整模板)

RTL 支持:
- 全部使用逻辑属性:margin-inline / padding-block / inset-inline / text-align: start
- 方向性图标(箭头/返回)在 [dir=rtl] 下 scaleX(-1)
- 非方向性图标(时钟/Logo/播放)不镜像
- 数字保持 LTR

多语言字体:
- 定义 --font-latin / --font-cjk / --font-jp / --font-arabic
- 中英混排:Inter → PingFang SC → Microsoft YaHei
- CJK 行高 1.7,阿拉伯行高 1.9
- 用 unicode-range 分片加载

格式本地化:
- 日期用 Intl.DateTimeFormat
- 数字用 Intl.NumberFormat(注意印度特殊分组)
- 货币符号位置随地区
- 时间显示相对时间

文化适配:
- 避免手势图标(👍✌️👌 在部分地区是侮辱)
- 涨跌色可配置(中国红涨绿跌,西方相反)
- 绿色慎用于负面语义(伊斯兰文化神圣色)
- 人物图像多样性

技术:
- html lang 属性正确
- 混合语言用 <span lang="en">
- hreflang 完整
- 语言切换器用语言自身名称("日本語" 不是 "Japanese")
```
