# B84 · 设计伦理与反操控

> 本库其他文件教"怎么做好"，本文件教"**什么不该做**"——负向维度的完整性。
> B44 是"视觉禁忌"（丑），本文件是"**伦理禁忌**"（坏）：操控、欺骗、强制、隐私侵犯。
> 2026 年监管趋严（FTC 扫荡暗黑模式、欧盟 DSA/DMA），操控设计是法律风险。

## 一、Dark Patterns 识别清单（设计时逐项排除）

### 诱骗类（Trick）
| 模式 | 表现 | 为什么坏 |
|---|---|---|
| 伪装广告（Disguised Ads） | 广告长得像内容/按钮 | 误导点击 |
| 诱饵切换（Bait and Switch） | 点 A 得到 B | 欺骗 |
| 视觉伪装 | 关闭按钮隐藏/过小/同色系 | 诱导误操作 |
| 强迫续订（Forced Continuity） | 试用结束自动扣费 | 剥夺选择 |
| 惊喜搭售（Sneak into Basket） | 结账时偷偷加购 | 欺骗 |

### 强制类（Forces Action）
| 模式 | 表现 | 为什么坏 |
|---|---|---|
| 确认羞辱（Confirmshaming） | "不用就说明你不环保" | 情绪勒索 |
| 强制注册 | 看内容必须先注册 | 过度索取 |
| 隐私窥探（Privacy Zuckering） | 默认全开分享 | 侵犯隐私 |
| 阻挠删除（Hard to Cancel） | 注册容易取消难 | 剥夺自由 |
| 死胡同（Dead End） | 付费墙无返回路径 | 困住用户 |

### 操纵类（Manipulation）
| 模式 | 表现 | 为什么坏 |
|---|---|---|
| 稀缺造假 | 虚假倒计时/假库存 | 捏造紧迫（见 H3 区分真实稀缺） |
| 社交操纵 | 伪造"某某刚买了" | 欺骗社会证明 |
| 认知负荷过载 | 故意复杂化阻止退出/比价 | 剥削认知 |

## 二、负责任的 CRO 边界（与 H3 划清界限）

| H3 合法手段 | 越线变操控 |
|---|---|
| 真实稀缺（库存/截止） | 虚假倒计时、假库存 |
| 真实社会证明 | 伪造/虚构评价 |
| 默认偏好（合理默认值） | 默认捆绑付费/共享隐私 |
| 减少摩擦 | 隐藏取消路径、强制多步 |
| 对比框架（措辞优化） | 误导性事实（"零风险"无风险说明） |

> 判断标准：**用户事后知情后，会不会觉得自己被骗了？** 会 = 操控。

## 三、AI 时代的新伦理维度

| 风险 | 表现 |
|---|---|
| AI 人格欺骗 | AI 伪装成真人客服/评论 |
| 生成内容操控 | AI 批量生成好评/舆论 |
| 个性化操纵 | 利用个人数据精准诱导冲动消费 |
| 模糊边界 | 用户不知道在和 AI 对话 |
| 数据滥用 | 对话内容被用于未经同意的画像 |

### 3.1 AI Dark Patterns：静态 → 动态（2026 核心变化）

- **传统暗黑模式是静态的**：同一个陷阱所有人可见，易于文档化、批评、监管
- **AI 暗黑模式是动态自适应的**：实时分析行为，逐人调整界面以最大化操纵
  - 例：根据你的犹豫时长生成"仅剩 1 件！"（传统站对所有人显示同样内容）
  - "Yes" 永远是最容易的路径，"No" 被缩小或换成让你有损失感的措辞
- **个性化 = 不可见**：每个人看到的都不一样 → 很难证明存在一致欺骗模式
- **操纵层比 UI 更深**：排名逻辑、推荐引擎、默认开关（"智能模式"自动订阅）——问题不在某个按钮，而在优化目标本身。AI 行为就是界面的一部分，不能当黑盒

### 3.2 数据（2026 实测）

| 数据点 | 数值 |
|---|---|
| 用户识别 AI 生成的假评论 | **仅 12%**（真人写的欺骗内容 28%） |
| AI 个性化操纵的转化提升 | +37%（vs 传统欺骗设计） |
| 发现被 AI 欺骗后永久弃用 | **68%**（Finance Watch） |
| 透明 AI 实现的认可率 | 82% |
| 短期代价 | 移除欺骗元素短期转化 -15~22%（长期被 CLV 与留存覆盖） |
| CRO 团队初始阻力 | 68% 反对伦理约束（需用数据+CLV 叙事说服） |

### 3.3 2026 监管升级（不只是伦理，是罚款）

| 法规/标准 | 状态 | 处罚 |
|---|---|---|
| **EU AI Act** | 2026-02-01 生效，禁止欺骗性 AI 界面 | 最高 **€30M 或 6% 全球营业额** |
| **ISO/IEC 24027:2026** | 2026-01 发布，首个全球"防 AI 暗黑模式"标准 | 合规审查基准 |
| India 2025-01 | 12 种暗黑模式禁令 | ₹500,000/违规 |
| FTC | 暗黑模式投诉 2023→2025 **+300%**，AI 变体占 68% 案例 | 执法/和解（如 Amazon $2.5B） |
| 前瞻 | Forrester：2027 检测工具达 95% 准确率——欺骗会被自动曝光 | 声誉+合规双重风险 |

### 3.4 5 步伦理审计（AI 界面交付前）

```
1. 找出产品流程中所有用户决策点
2. 逐个映射：每个决策点可能被利用的认知偏误
3. 验证 AI 透明度：≥92% 的用户能正确识别"这是 AI"
4. 取消路径测试：≤3 步到达取消，成功率 ≥95%（与开通同权）
5. 文档化每个说服元素的存在理由；操纵风险评分 >0.7 → 高管审批
```

## 四、设计伦理自检清单（交付前）

- [ ] 关闭/取消/退订路径与开通一样容易找到？
- [ ] 所有"限时/限量"都是真的？
- [ ] 广告与内容视觉可区分？
- [ ] 无确认羞辱/情绪勒索文案？
- [ ] 默认选项尊重用户而非公司利益？
- [ ] 删除账号/数据路径存在且可达？
- [ ] 付费/订阅自动续费有明确前置提示？
- [ ] AI 对话对象身份透明？
- [ ] 收集的数据都有用途说明 + 可撤回？
