# B25 · 领域术语与品质评价体系

> 用什么词评价一个界面"好"或"不好",决定了你能不能精准指出问题、精准要求 AI 修改。
> 这份把评价术语系统化——好界面的正面词、坏界面的负面词、业界五套评价标准全都在这。

## 四、负面评价词库(说"这里不对")

### 视觉问题
- **通用感 Generic** ★ 2026 最致命
- **模板感 Template-y / Bootstrap-y**
- **AI 味 AI-slop** ★ 新词
- **平均分 Average / Middle-of-the-road**
- **视觉噪音 Visual noise**
- **视觉冗余 Visual redundancy**
- **层级扁平 Flat hierarchy / Weak hierarchy**
- **无焦点 No focal point**
- **动线混乱 Broken flow**
- **对齐松散 Loose alignment**
- **间距不成系统 Inconsistent spacing**
- **字号跳跃 Type scale jump**
- **色彩失控 Color sprawl**
- **色温混杂 Mixed color temperature**
- **圆角不一致 Radius mismatch**
- **阴影堆叠 Shadow soup**
- **灰度不均 Uneven typographic color**

### 情绪问题
- **平庸 Bland / Middling**
- **廉价感 Cheap-looking**
- **塑料感 Plastic**
- **过度设计 Over-designed / Overwrought**
- **拥挤 Cramped**
- **空洞 Sparse to a fault**
- **不协调 Discordant**
- **过时 Dated**
- **山寨感 Knock-off**

### 完成度问题
- **半成品 Rough / Unfinished**
- **未打磨 Unpolished**
- **粗糙 Sloppy**
- **随手值 Arbitrary(间距/字号)**
- **半吊子 Half-baked**

### 交互问题
- **假交互 Fake interactivity**
- **状态缺失 Missing states**
- **反馈缺失 No feedback**
- **意外行为 Unexpected behavior**
- **僵硬 Stiff**
- **粘滞 Sluggish**

## 五、五套业界评价标准

### 1. Awwwards 三柱(获奖标准)
```
Art Direction    艺术方向 — 有明确概念
Directed Motion  有目的的动效 — 不乱动
Performance      性能 — 中端手机 60fps
```
**三者缺一不可。**

### 2. Nielsen 可用性五要素
```
Learnability   可学习性
Efficiency     效率
Memorability   可记忆性
Errors         容错
Satisfaction   满意度
```

### 3. Dieter Rams 好设计 10 条
创新 / 实用 / 美 / 易懂 / 不显眼 / 诚实 / 持久 / 关注细节 / 环保 / 尽可能少

### 4. Google Core Web Vitals(技术品质)
```
LCP < 2.5s   最大内容绘制
INP < 200ms  交互响应
CLS < 0.1    布局稳定
```

### 5. 实操三要素(最简版)
```
Hierarchy 层级清晰
Consistency 一致统一
Restraint 克制精炼
```

## 六、用评价词做设计评审(实操话术)

看到一个界面,不说"感觉不太好",而是精确诊断:

```
❌ "这个不好看"
✅ "层级扁平,一屏 5 个东西同等重量,焦点丢失"

❌ "有点乱"
✅ "视觉噪音过多——每张卡片都有边框+阴影+图标,信噪比过低"

❌ "感觉像 AI 做的"
✅ "有明显模板感——圆角卡片 + 默认 Inter + 蓝色渐变,可以直接看出是 v0 生成的"

❌ "太满了"
✅ "版面率过高,呼吸不足。section 之间没有停顿"

❌ "很廉价"
✅ "阴影堆叠 + 高饱和撞色 + 冷暖灰混用,这三条一起就显得廉价"

❌ "字体不对"
✅ "字号跳跃率不足,H1 和 body 差距太小(2:1),缺乏编辑张力"
```

**这就是"专业"和"外行"的差别——不是知道更多,是能精确指出。**

## 七、给 AI 用的评审 prompt 话术

生成后拿这些话术让 AI 自我批评并修正:

```
"用 Awwwards 评审标准检查这个设计:
1. Art Direction:有没有明确概念?还是通用感?
2. Directed Motion:动效有目的还是纯装饰?
3. Performance:预估会不会掉帧?
逐项打分并给出改进建议。"

"用眯眼测试检查视觉层级:眯眼后应该看到一个主视觉块 + 一个次块 + 清晰留白。你现在的设计通过吗?"

"用负面词库自检:
□ 通用感?□ 模板感?□ 视觉噪音?□ 层级扁平?
□ 廉价感?□ 冗余?□ 色温混杂?□ 阴影堆叠?
逐条检查并修正。"

"这个设计的'设计意图'是什么?每个决定能说出理由吗?哪些是随手值(间距/字号/颜色)?"
```

## 八、把品质词转成 prompt 约束

不只是描述你想要什么,直接说要**避免**什么:

```
【品质约束】
- 避免通用感:不要圆角卡片堆砌 + 默认 Inter + 蓝色渐变的 v0 默认组合
- 避免视觉噪音:去掉所有非功能装饰,信噪比 >0.8
- 避免层级扁平:确保每屏有一个绝对主导焦点
- 避免廉价感:不用重阴影/高饱和撞色/冷暖灰混用
- 避免半成品感:所有状态(hover/focus/loading/empty/error)完备
- 追求工艺水准:间距/字号/圆角全部来自 tokens,无随手值
```

## 九、检验清单(用评价词做自检)

正面自检——**至少中 8 条**:
- [ ] 层级清晰(眯眼能看到主块)
- [ ] 焦点明确(每屏一个视觉最强点)
- [ ] 一致统一(圆角/间距/字号成系统)
- [ ] 信噪比高(去掉了非功能装饰)
- [ ] 呼吸充分(section 间距 ≥96px 桌面)
- [ ] 色温统一(冷灰不混暖灰)
- [ ] 色彩收敛(≤5 色)
- [ ] 排版精密(负字距/text-wrap balance)
- [ ] 对齐严格(4pt 网格)
- [ ] 状态完备(六态齐全)

负面自检——**任一条中招即需修**:
- [ ] 是否通用感/模板感?
- [ ] 是否层级扁平?
- [ ] 是否视觉噪音过多?
- [ ] 是否有随手值(15px/22px这种)?
- [ ] 是否阴影堆叠?
- [ ] 是否色温混杂?
- [ ] 是否装饰盖过内容?
- [ ] 是否半成品(状态不全)?
