# B28 · 暗色设计完全系统

> 暗色不是"反色"。它是一整套设计范式——色彩/层次/发光/材质/图片/无障碍全部要重新思考。
> 2026 年,深色优先的产品越来越多(开发工具/AI/金融/创意工具)。做好暗色 = 顶级前端的必修课。

---

## 一、为什么暗色难做

大多数暗色设计翻车是因为把浅色简单反色:
- 浅色的黑字变白字 → 但对比度不对了
- 浅色的阴影变什么? → 深色下阴影看不见
- 浅色的高饱和主色 → 深色下太刺眼
- 浅色的图片 → 深色下太亮扎眼

**结论**:暗色 = 独立的设计系统,不是浅色的镜像。

---

## 二、暗色的表面分层(Surface Elevation)

浅色模式用阴影表达层级。**暗色模式改用"表面颜色渐亮"**:

```
Base     #0A0A0A    页面背景(最深)
Surface 1 #141414    Card/一级浮层
Surface 2 #1C1C1C    嵌套 Card
Surface 3 #262626    悬浮层
Overlay  #333333    Modal/Popover
```

**规律**:每层比下层**亮 4-6%**(明度)。层级越高越亮,不是越暗。

**为什么**:深色空间中光"照亮"了上方物体,越高越亮符合物理直觉。

### Material Design 3 的做法
使用主色的极浅版本混入表面:
```
Base:      surface + 0% primary tint
Level 1:   surface + 5% primary tint
Level 2:   surface + 8% primary tint
Level 3:   surface + 11% primary tint
Level 4:   surface + 12% primary tint
Level 5:   surface + 14% primary tint
```
好处:表面之间有品牌调性,不只是黑白灰。

## 三、暗色的色彩重校

### 不用纯黑
- ❌ `#000` — 太绝对,长看疲劳,和内容边界"过于锐"
- ✅ `#0A0A0A` 或 `#0F0F0F` — 温和,依然够深
- 高端产品:略带蓝调的深色 `#0F172A`(Slate 950)

### 不用纯白
- ❌ `#FFFFFF` 白字 — 太亮刺眼,在深底上"过曝"
- ✅ `#F5F5F5` 或 `#FAFAFA` — 主要文字
- 次要文字:`#A1A1AA` 灰
- 辅助:`#71717A`(注意仍要 4.5:1 对比度)

### 主色饱和度必须降
```
Light Mode: hsl(217, 91%, 60%)  ← 品牌蓝,正常饱和
Dark Mode:  hsl(217, 75%, 55%)  ← 饱和降 16%,明度降 5%
```
**为什么**:深色环境下高饱和色显得更亮更刺眼,视觉刺激过强。

### 语义色调整
| | Light | Dark |
|---|---|---|
| Success | emerald-600 | emerald-400 (更亮) |
| Warning | amber-500 | amber-400 |
| Danger | red-600 | red-400 |
| Info | blue-600 | blue-400 |

**规律**:深色模式下语义色**明度略提**,饱和度略降。

## 四、暗色的阴影策略

**核心问题**:黑阴影在深色底上看不见。

### 解决方案 1:微光边框(Luminous Border)★ 推荐
```css
.card-dark {
  border: 1px solid rgba(255, 255, 255, 0.08);
}
```
用**极淡白边**代替阴影表达"这里有个卡片"。

### 解决方案 2:表面提亮(Surface Elevation)
不加阴影,用**更亮的背景色**表示层级(见前面表面分层)。

### 解决方案 3:双层阴影
如果一定要阴影,用两层:
```css
box-shadow:
  0 0 0 1px rgba(255,255,255,0.06),      /* 微光轮廓 */
  0 8px 32px rgba(0,0,0,0.5);            /* 极深阴影 */
```

### 解决方案 4:发光(Glow)
浮层用**外发光**替代阴影:
```css
box-shadow: 0 0 24px rgba(59, 130, 246, 0.4);
```
适合:CTA / focus 态 / 主要浮层。

## 五、暗色的对比度重新校准

WCAG 对比度公式在深色下**行为不同**。经验规律:

| 元素 | Light 对比度 | Dark 对比度 |
|---|---|---|
| 正文 | 12-16:1(#111 on #FAFAFA) | 12-14:1(#F5F5F5 on #0A0A0A) |
| 次要 | 5-6:1 | 4.5-6:1(略降) |
| 辅助 | 3-4.5:1(仅限大字) | 3.5-4.5:1 |
| 边框 | 1.5:1 | 1.5:1 |

**必须用工具测**:contrast-ratio.com 或 Chrome DevTools。

**深色特别陷阱**:
- 灰色文字在深底上很容易掉到 3:1 以下
- 主色文字(蓝色链接)对比度要重测

## 六、暗色的图片处理

### 图片可能太亮
浅色环境的高亮图片放进深色 UI,视觉"过曝"。

**处理方案**:
```css
/* 加半透明蒙层降亮 */
img { filter: brightness(0.9) contrast(1.05); }

/* 或加渐变蒙层柔化边缘 */
.image-container::after {
  background: linear-gradient(transparent 60%, rgba(0,0,0,0.4));
}
```

### 白底图片
Logo 或图表用白底 → 深色下变成"白色板块"很扎眼。

**处理方案**:
- 换透明背景版本
- 或加**混合模式**:`mix-blend-mode: screen`(黑变透明)
- 或加圆角容器 + `overflow: hidden` + 稍暗背景色

### 用户上传内容(UGC)
无法预测颜色 → 加统一的**边框/圆角/容器**:
```css
.user-image {
  border: 1px solid rgba(255,255,255,0.1);
  border-radius: 12px;
  overflow: hidden;
}
```

## 七、暗色的组件专属处理

### 输入框
```
Light: 白底 + 灰边框 + 深字
Dark:  深底(#141414)+ 微光边框 white/10 + 白字
       focus: 边框主色 + 微光外发光
```

### 按钮
```
Primary (Light):  实心主色 + 白字
Primary (Dark):   实心主色(饱和低)+ 白字
                  或:半透明主色 white/12 + 主色字(玻璃质感)

Secondary (Light): 白底 + 边框
Secondary (Dark):  透明底 + 白边 + 白字
```

### 卡片
```
Light: 白底 + 极淡阴影
Dark:  深底(比页面稍亮)+ 微光边框
```

### 分隔线
```
Light: 淡灰(#E5E7EB)
Dark:  微光(rgba(255,255,255,0.08))
```

## 八、暗色的品牌氛围手法

### 极光渐变(Aurora Gradient)★ 最流行
深色底 + 大而模糊的彩色光球:
```css
background:
  radial-gradient(at 20% 30%, #4F46E5 0px, transparent 50%),
  radial-gradient(at 80% 20%, #7C3AED 0px, transparent 50%),
  #0A0A0A;
filter: blur(0);
```
参考:Linear / Vercel / Stripe

### 星尘背景
稀疏 white/30 小圆点漂浮,营造深度。

### 网格底纹
极淡的规则网格,营造技术感:
```css
background-image: linear-gradient(rgba(255,255,255,0.04) 1px, transparent 1px);
background-size: 32px 32px;
```

### 噪点叠加
2% grain 消除数字塑料感,增加质感。

## 九、暗色主题切换

### 三种模式
```
:root { color-scheme: light; }
[data-theme="dark"] { color-scheme: dark; }
[data-theme="system"] { /* 跟随系统 */ }
```

### 使用 light-dark() 函数(2025+ 原生)
```css
:root { color-scheme: light dark; }
body {
  background: light-dark(#FFFFFF, #0A0A0A);
  color: light-dark(#0F172A, #F5F5F5);
}
```
**一行代码支持双主题**,无需 data-theme。

### 切换动画
```css
* {
  transition: background 300ms, color 300ms, border-color 300ms;
}
```
**注意**:transition 只加在颜色相关属性,别加 `all`(会闪烁其他动画)。

### 用户偏好持久化
```js
localStorage.setItem('theme', 'dark');
document.documentElement.dataset.theme = 'dark';
```

### 尊重系统偏好
```css
@media (prefers-color-scheme: dark) {
  /* 默认深色样式 */
}
```

## 十一、暗色特有的高级手法

### 1. 玻璃拟态(Glassmorphism)
深色底最适合玻璃拟态:
```css
background: rgba(255,255,255,0.05);
backdrop-filter: blur(16px) saturate(150%);
border: 1px solid rgba(255,255,255,0.1);
```

### 2. 霓虹光效(Neon Glow)
CTA 和 focus 用外发光:
```css
box-shadow:
  0 0 20px rgba(59, 130, 246, 0.5),
  0 0 40px rgba(59, 130, 246, 0.3);
```

### 3. 微光边框动画(Border Beam)
CTA 边框有流光效果——2026 最热的暗色手法。

### 4. 深色渐变文字
在深底上文字用**明亮渐变**:
```css
background: linear-gradient(135deg, #E0E7FF, #C4B5FD);
background-clip: text;
color: transparent;
```

### 5. 逆光边缘(Rim Light)
元素上方 1px 白色内高光,模拟"背光照射":
```css
box-shadow: inset 0 1px 0 rgba(255,255,255,0.1);
```

## 十二、暗色常见错误

- ❌ 用纯黑 #000
- ❌ 用纯白 #FFF 做文字
- ❌ 直接反色浅色的主色(不降饱和)
- ❌ 用黑色阴影(看不见)
- ❌ 图片不做处理直接放(太扎眼)
- ❌ 对比度不重新测(依赖浅色的比例)
- ❌ 忘记灰色文字容易掉到 3:1 以下
- ❌ 用同一套 tokens 硬套(要独立定义)
- ❌ 白底 Logo 不换透明版
- ❌ transition 加在 `all`(切换主题时全乱)

- 极光渐变背景(3 个 blur 光球)

- 纯黑 #000
