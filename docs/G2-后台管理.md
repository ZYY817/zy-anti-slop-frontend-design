# G2 · 后台管理场景 Prompt 库

> Dashboard 是 AI 生成频次最高、也最容易做得"通用平庸"的场景。
> 本文件给出后台管理各页面的完整 prompt 模板 + 避免"AI 味仪表盘"的具体约束。

---

## 一、为什么 AI 生成的后台"一看就通用"

- 千篇一律：左侧栏 + 顶栏 + 一堆等宽卡片 + 蓝色折线图
- 缺信息层级：所有数字一样大，找不到重点
- 数据假：都是 "1,234" "56%" 占位，没有真实感
- 状态缺失：没有加载/空/错误/权限态
- 密度失衡：要么太空要么太挤

**破解**：给具体的信息优先级、真实数据示例、密度档位、状态覆盖。

---

## 二、Dashboard 总览页

```
【页面】数据总览 Dashboard
【风格】{暗色专业 / 浅色清爽}，中高密度
【技术栈】React + Tailwind + shadcn/ui + Recharts

【布局】
- 左侧栏（240px，可折叠到 64px 图标态）+ 顶栏（56px）+ 主内容区
- 主内容：Bento 式非等分网格，不是一排等宽卡片
  · 顶部：4 个 KPI 卡（关键指标，最大最醒目）
  · 中部：1 个大图表（占 2/3）+ 1 个列表/排行（占 1/3）
  · 底部：数据表格（近期活动/订单）

【KPI 卡片】
- 每张含：指标名（小灰字）+ 数值（大，tabular-nums）+ 环比变化（↑12% 绿 / ↓3% 红）+ 迷你趋势线（sparkline）
- 主指标卡比次要卡大或有强调色边框
- 数值用等宽数字对齐，货币/百分比格式化

【图表】
- 主图表：折线/面积图，有网格线（淡）、坐标轴标签、hover tooltip、图例
- 颜色：主品牌色 + 1-2 辅助色，不要 5 色彩虹
- 空数据态：不显示空白图，显示"暂无数据"插画
- 加载态：图表区骨架屏

【数据要真实】
- 用拟真数据：日期用近期真实日期，金额有零有整（¥12,847 而非 ¥12,000）
- 名字用多样化真实姓名，状态有多种（成功/处理中/失败/退款）

【顶栏】
- 左：面包屑 / 页面标题
- 右：搜索（⌘K）、通知铃铛（有未读红点）、用户头像菜单

【左侧栏】
- 分组导航（概览/订单/用户/设置），当前项高亮
- 图标 + 文字，折叠后仅图标 + tooltip
- 底部：用户信息 + 折叠按钮

【状态覆盖】
- 加载：KPI + 图表 + 表格各自骨架屏
- 空：首次无数据引导"导入数据 / 创建第一个"
- 错误：某区块加载失败，error boundary 兜底 + 重试
- 权限：无权限模块显示锁图标 + "申请权限"

【无障碍】
- 图表有 aria-label 描述趋势 + 数据表格替代
- 键盘可导航侧栏和表格
- 颜色不是唯一信息载体（涨跌加箭头图标）

【性能】
- 图表库按需加载，表格虚拟滚动
- KPI 数字用 content-visibility 优化
```

## 三、数据表格页（CRUD 列表）

```
【页面】数据表格（订单/用户/商品列表）
【核心】高信息密度 + 强操作性

【工具栏（表格上方）】
- 左：搜索框 + 筛选器（多条件，下拉/日期范围/标签）
- 右：批量操作（选中后出现）、导出、列设置、新建按钮（主色）

【表格】
- 表头：可排序（点击列头，箭头指示方向）、可固定列
- 行：斑马纹 或 hover 高亮（二选一，不要都有）
- 首列：复选框（批量选择）
- 数值列：右对齐 + tabular-nums
- 状态列：彩色 badge（成功绿/处理中黄/失败红）
- 操作列：固定右侧，图标按钮（查看/编辑/删除）或 ⋯ 菜单
- 行高：紧凑 40px / 舒适 52px / 宽松 64px（提供密度切换）

【分页】
- 底部：总数 + 每页条数选择 + 页码
- 或无限滚动（大数据集）

【交互】
- 行 hover：显示快捷操作
- 点击行：进详情（View Transitions 可选）
- 内联编辑：双击单元格编辑（可选）
- 批量选择：顶部出现操作栏"已选 5 项：[删除][导出][标记]"

【状态】
- 加载：表格骨架屏（行占位）
- 空：无数据插画 + "创建第一个"
- 搜索无结果："没有匹配 '{query}' 的结果" + 清除筛选
- 错误：整表错误 + 重试

【删除确认】
- 危险操作二次确认 Modal
- 批量删除显示数量："确认删除 5 条记录？此操作不可撤销"
- 删除后 Toast + "撤销"（软删除）
```

## 四、详情 / 编辑页

```
【页面】记录详情 / 编辑表单
【布局】
- 顶部：面包屑 + 标题 + 主操作（保存/删除，右上）
- 主体：{单栏表单 / 左表单右预览 / Tab 分区}
- 长表单用分区（Section）或 Tab，不要一泻到底

【表单】（详见 B51）
- 标签在输入框上方（不用占位符当标签）
- 分组：相关字段用 fieldset 分区，区间距 32px
- 必填标 * ，实时校验（blur 时）
- 保存按钮：sticky 底部或右上，未改动时禁用
- 未保存离开：确认提示

【详情展示】
- 只读字段：label + value，label 灰小字 value 正常
- 状态时间线（如订单流转）：竖向 timeline
- 关联数据：Tab 或折叠区

【状态】
- 保存中：按钮 loading（spinner + "保存中"）
- 保存成功：Toast + 按钮短暂勾号
- 保存失败：字段级错误 + 顶部汇总
- 加载详情：字段骨架屏
```

## 五、设置页

```
【页面】设置
【布局】左侧二级导航（账户/通知/安全/团队/计费）+ 右侧内容

【设置项样式】
- 每项：左标题+说明，右控件（开关/下拉/输入）
- 分组卡片，组间距明显
- 危险区（删除账户）：红色边框卡片，放最底部

【常见控件】
- 开关 Toggle：即时保存 + 保存指示（小勾/loading）
- 下拉/单选：即时或"保存更改"按钮
- 头像上传：预览 + 裁剪
- API Key：脱敏显示 + 复制 + 重新生成（危险确认）

【保存模式】
- 即时保存（开关类）：切换后立即保存 + 微反馈
- 批量保存（表单类）：底部"保存更改"，检测到改动才启用
```

## 六、避免通用感的检查

- [ ] 不是一排等宽卡片，用了 Bento 非等分布局
- [ ] KPI 有主次之分（主指标更大/有强调）
- [ ] 数据是拟真的（真实日期、有零有整的金额、多样状态）
- [ ] 图表颜色 ≤3 色，不是彩虹
- [ ] 提供密度切换（紧凑/舒适）
- [ ] 四态齐全（加载骨架/空/错误/权限）
- [ ] 涨跌不只靠颜色（加箭头图标）
- [ ] 表格数值列右对齐 + 等宽数字
- [ ] 危险操作有二次确认 + 撤销
- [ ] 侧栏可折叠，当前项高亮
- [ ] ⌘K 全局搜索
- [ ] 图表有无障碍替代（aria-label + 数据表）

## 七、快速 Prompt（精简版）

```
生成一个 {订单管理} 后台页面，React + Tailwind + shadcn。
- 布局：可折叠侧栏 + 顶栏 + Bento 网格主区（不要一排等宽卡片）
- 顶部 4 个 KPI 卡（主指标最大，含 sparkline + 环比），
  中部大折线图 + 排行榜，底部数据表格
- 用拟真数据（近期真实日期、有零有整金额、多样状态 badge）
- 图表 ≤3 色，有 tooltip/图例/网格线
- 四态齐全：骨架屏加载 / 空态引导 / error boundary / 权限锁
- 表格：可排序、批量选择、状态 badge、操作列固定、密度切换
- 涨跌加箭头图标（不只靠颜色），数值 tabular-nums 右对齐
- ⌘K 搜索，无障碍键盘导航 + 图表 aria-label
```
