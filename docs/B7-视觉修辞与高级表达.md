# B7 · 视觉修辞与高级表达

> 从"排列元素"到"表达意图"。这是设计师与拼装工的分界线。
> 本文档收录视觉修辞、气质词库、感官通感、批评术语——最难量化但最影响品质的维度。

---

## 一、视觉修辞（Visual Rhetoric）

设计不只是排版，是"说话"。视觉也有修辞手法。

| 修辞 | 定义 | 界面应用 |
|---|---|---|
| **隐喻 (Metaphor)** | 用熟悉概念表达陌生功能 | 桌面/文件夹/购物车/收件箱/垃圾桶 |
| **提喻 (Synecdoche)** | 局部代整体 | 用一个齿轮图标代表整个设置系统 |
| **夸张 (Hyperbole)** | 刻意放大 | 巨型字体 hero、超大数字统计 |
| **对比 (Antithesis)** | 并置相反 | Before/After 对比、免费 vs 付费 |
| **重复 (Anaphora)** | 结构重复 | 卡片网格、三列特性 |
| **省略 (Ellipsis)** | 故意留白让人补全 | 负空间 Logo、图标简化 |
| **拟人 (Personification)** | 赋予人格 | 吉祥物、AI 头像、"我在思考…" |
| **反讽 (Irony)** | 反差幽默 | 404 页面的自嘲文案 |
| **递进 (Climax)** | 逐层加强 | Onboarding 逐步揭示价值 |
| **押韵 (Rhyme)** | 视觉呼应 | 首屏与尾屏用同一图形元素 |

**高级用法**：一个页面用 1-2 种主修辞贯穿，形成"视觉论点"。

## 二、气质词库（Aesthetic Vocabulary）

写 prompt 时最缺的就是"形容气质"的词。这里分类穷举。

### 克制系
克制 / 内敛 / 精简 / 洗练 / 疏朗 / 素净 / 冷静 / 中性 / 低调 / 沉稳
`restrained, understated, spare, austere, distilled, quiet, muted, sober`

### 精密系
精密 / 严谨 / 工整 / 锐利 / 考究 / 一丝不苟 / 工程感 / 校准感
`precise, meticulous, crisp, exacting, calibrated, engineered, tight`

### 高级系
高级 / 隽永 / 有质感 / 有分量 / 昂贵感 / 从容 / 稀有感
`refined, timeless, tactile, weighty, premium, effortless, rarefied`

### 温暖系
温暖 / 亲切 / 柔和 / 舒缓 / 治愈 / 人文 / 手作感 / 呼吸感
`warm, approachable, soft, soothing, humane, handcrafted, breathable`

### 活力系
活力 / 大胆 / 张扬 / 明快 / 俏皮 / 有趣 / 年轻 / 顽皮
`vibrant, bold, exuberant, punchy, playful, whimsical, spirited`

### 未来系
未来 / 科技 / 冷峻 / 数字 / 虚拟 / 悬浮 / 全息 / 极速
`futuristic, technical, clinical, digital, ethereal, weightless, holographic`

### 编辑系
编辑感 / 杂志感 / 书卷气 / 叙事感 / 学术 / 档案感
`editorial, magazine-like, literary, narrative, scholarly, archival`

### 粗野系
粗野 / 原始 / 生猛 / 反叛 / 未修饰 / 工业 / 硬核
`brutal, raw, unpolished, defiant, industrial, hardcore, utilitarian`

### 有机系
有机 / 流动 / 自然 / 柔曲 / 生长感 / 液态
`organic, fluid, natural, curvilinear, biomorphic, liquid`

### 怀旧系
怀旧 / 复古 / 复古未来 / 千禧 / 手工 / 胶片感 / 做旧
`nostalgic, retro, retro-futuristic, Y2K, analog, filmic, weathered`

### 神秘系
神秘 / 深邃 / 幽暗 / 沉浸 / 电影感 / 戏剧性
`mysterious, deep, moody, immersive, cinematic, dramatic`

**用法**：选 3 个词（同系或跨系冲突），比"好看"精确一万倍。
> "克制 + 精密 + 有质感" → Linear
> "温暖 + 手作感 + 有趣" → Notion
> "未来 + 悬浮 + 电影感" → Apple Vision Pro

## 三、通感与跨感官（Synesthesia）

高级设计描述会借用其他感官的词。

| 感官 | 借用词 | 视觉对应 |
|---|---|---|
| 触觉 | 柔软 / 坚硬 / 粗糙 / 顺滑 / 温热 / 冰冷 | 圆角 / 直角 / 噪点 / 渐变 / 暖色 / 冷色 |
| 听觉 | 安静 / 喧闹 / 有节奏 / 刺耳 / 低音 | 低对比 / 高饱和 / 韵律排列 / 撞色 / 深色重量 |
| 味觉 | 清淡 / 浓郁 / 甜 / 酸 / 苦 | 低饱和 / 高饱和 / 粉橙 / 黄绿 / 深褐 |
| 重量 | 轻盈 / 沉重 / 悬浮 / 扎实 | 浅色细字 / 深色粗字 / 阴影 / 无阴影贴地 |
| 温度 | 温暖 / 冷峻 / 灼热 / 清凉 | 暖色调 / 冷灰 / 高饱和红橙 / 淡蓝绿 |
| 空间 | 开阔 / 拥挤 / 深邃 / 扁平 | 大留白 / 高密度 / 多层 z / 无层次 |
| 速度 | 迅捷 / 缓慢 / 停顿 | 短动效 / 长动效 / delay |

**Prompt 示例**：
> "整体触感要像磨砂金属——冰凉、顺滑、有重量。不要塑料感。"

## 四、设计批评术语（Design Critique）

review 界面时用这些词，比"感觉不对"专业得多。

### 结构问题
- **层级不清 (Weak hierarchy)** — 不知道先看哪
- **视觉噪音 (Visual noise)** — 干扰元素太多
- **信息过载 (Information overload)** — 一屏塞太多
- **重心不稳 (Unbalanced)** — 视觉重量偏一边
- **无焦点 (No focal point)** — 每个元素都在喊
- **动线混乱 (Broken flow)** — 视线不知往哪走

### 细节问题
- **对齐松散 (Loose alignment)** — "差不多对"
- **间距不成系统 (Inconsistent spacing)** — 随手写的数值
- **字号跳跃 (Type scale jump)** — 不成阶梯
- **色彩失控 (Color sprawl)** — 颜色越用越多
- **圆角不一致 (Radius mismatch)** — 有的 4 有的 6
- **阴影堆叠 (Shadow soup)** — 到处都是阴影
- **灰度不均 (Uneven typographic color)** — 段落有空洞或黑块

### 感受问题
- **平庸 (Generic / Bootstrap-y)** — 没有性格
- **过度设计 (Over-designed)** — 装饰盖过内容
- **廉价感 (Cheap-looking)** — 高饱和撞色 + 强阴影 + 渐变滥用
- **拥挤 (Cramped)** — 没有呼吸
- **空洞 (Sparse to a fault)** — 留白到显得没做完
- **不协调 (Discordant)** — 风格语言混杂
- **过时 (Dated)** — 用了淘汰的视觉语言

### 正面评价词
- **克制得当 (Well-restrained)**
- **层级清晰 (Clear hierarchy)**
- **系统一致 (Systematic)**
- **细节讲究 (Considered details)**
- **有性格 (Has personality)**
- **呼吸充分 (Well-paced)**
- **意图明确 (Intentional)**

## 五、内容密度与节奏（Density & Pacing）

### 密度分级
| 级别 | 特征 | 场景 |
|---|---|---|
| 极稀疏 | 一屏一句话 | 品牌宣言、艺术站 |
| 稀疏 | 大量留白 | 落地页、品牌页 |
| 中等 | 平衡 | 内容页、消费 App |
| 密集 | 紧凑排布 | 后台、Feed |
| 极密集 | 小字紧间距 | 金融终端、监控 |

### 节奏设计（Pacing）
好的长页面有节奏起伏，不是均匀铺开：
```
Hero (极稀疏, 大留白)
  ↓
Social Proof (窄条, 紧凑)
  ↓
Features (中等密度, 三列)
  ↓
Deep Dive (稀疏, 大图 + 少字)
  ↓
Testimonial (中等, 卡片)
  ↓
Pricing (密集, 对比表)
  ↓
CTA (极稀疏, 聚焦)
```

**原则**：密-疏-密-疏交替，让眼睛有休息点。

### 反面：单调节奏
每个 section 都是"标题+三列卡片" → 用户滚到第三屏就腻了。

## 六、品牌视觉资产（Brand Visual Assets）

| 资产 | 说明 |
|---|---|
| **视觉锤 (Visual Hammer)** | 一眼认出的图形符号（Nike 勾、Apple 苹果） |
| **品牌图案 (Brand Pattern)** | 可无限延展的纹理（Louis Vuitton 老花） |
| **签名色 (Signature Color)** | 独占的颜色（Tiffany 蓝、爱马仕橙） |
| **签名形状 (Signature Shape)** | 独特的形状语言（Airbnb 的 Bélo 圆角） |
| **品牌字体 (Brand Typeface)** | 定制字体（Google Sans、Netflix Sans） |
| **品牌插画风格** | 统一的插画语言 |
| **品牌动效签名 (Motion Signature)** | 独特的动效个性（iOS 的 spring） |
| **品牌声音 (Sonic Branding)** | 开机音、通知音（Netflix "ta-dum"） |

**高级做法**：至少拥有 2-3 个可被记住的视觉资产。

---

## 七、视觉一致性的四个层次

1. **视觉一致** — 颜色、字体、间距、圆角相同
2. **功能一致** — 相同组件行为相同
3. **内部一致** — 全产品线统一
4. **外部一致** — 符合平台惯例与用户预期（雅各布定律）

**冲突时优先级**：外部 > 功能 > 内部 > 视觉

## 八、"廉价感"的成因清单

界面显廉价，通常是这些原因（逐条排查）：

- [ ] 颜色饱和度过高（纯红纯蓝）
- [ ] 颜色数量太多（>6 种）
- [ ] 冷暖灰混用
- [ ] 渐变生硬（直接从 A 到 B 经过灰）
- [ ] 阴影过重（模糊小、透明度高）
- [ ] 圆角不统一
- [ ] 字体用了默认 Arial / 宋体
- [ ] 字号不成阶梯
- [ ] 行高太挤（<1.4）
- [ ] 图标风格混杂（线性+填充混用）
- [ ] 留白不足（元素挤在一起）
- [ ] 图片质量低 / 拉伸变形
- [ ] 到处都有边框
- [ ] 装饰元素过多（无意义的图形）
- [ ] 中英混排未加空格
- [ ] 用了 emoji 当主要图标
- [ ] 动效过多过夸张

**反向操作**：以上每条反过来做，界面立刻"贵"起来。

---

## 九、"高级感"的成因清单

- [ ] 颜色 ≤4 种，饱和度克制
- [ ] 色温统一（全冷或全暖）
- [ ] 阴影极弱或改用 1px 边框
- [ ] 圆角全站统一
- [ ] 字体考究（Inter / 思源 / 定制）
- [ ] 字号成模块化阶梯
- [ ] 行高舒适（正文 1.5-1.6）
- [ ] 负字距用在大标题
- [ ] 留白充足，尤其 section 之间
- [ ] 对齐严格（光学对齐）
- [ ] 图标统一风格且尺寸一致
- [ ] 图片高质量、统一调色
- [ ] 有一个明确视觉焦点
- [ ] 动效克制、有节奏
- [ ] 加了微妙质感（噪点/颗粒）
- [ ] 状态完整（不会点了没反应）

## 十、高级 Prompt 组合示例

### 示例 1：用气质词 + 通感 + 修辞
```
【气质】克制 / 精密 / 有质感（三词定调）
【通感】触感像磨砂铝——冰凉、顺滑、有重量。不要塑料感和廉价光泽。
【修辞】用"省略"作为主修辞——大量负空间，让用户自己补全。图标极简到只剩轮廓。
【密度节奏】Hero 极稀疏 → Features 中等 → Deep dive 稀疏 → Pricing 密集 → CTA 极稀疏
【视觉资产】统一使用一个几何图形元素（细线圆环）在首尾呼应
【禁止】高饱和色、重阴影、渐变滥用、装饰性图形、emoji 图标
```

### 示例 2：批评式修正 prompt
```
当前问题（用批评术语指出）：
- 层级不清：Hero 三个元素同等大小，无焦点
- 间距不成系统：出现 15px / 22px / 27px 等随手值
- 色彩失控：用了 9 种颜色
- 阴影堆叠：卡片/按钮/输入框都有阴影

修正要求：
- 建立单一焦点：H1 放大到 clamp(40px, 6vw, 72px)，其余降级
- 间距全部改为 4 的倍数（4/8/12/16/24/32/48/64/96）
- 颜色收敛到 1 主色 + 5 阶中性 + 3 语义色
- 只有可交互的浮层保留阴影，其余用 1px border
```

## 十一、检验：这个界面"有意图"吗

最高标准不是"好看"，而是"每个决定都有理由"：

- [ ] 能说出为什么用这个颜色（不是"看着好看"）
- [ ] 能说出为什么这里留这么多白
- [ ] 能说出为什么这个字号
- [ ] 能说出视觉焦点是哪个、为什么
- [ ] 能说出用户视线走的路径
- [ ] 能说出这个动效解决什么问题
- [ ] 能说出气质是哪三个词
- [ ] 删掉任何一个元素都会变差（无冗余）

如果有任何一条答不出来，那部分就是"随手做的"，也就是拉低品质的地方。
