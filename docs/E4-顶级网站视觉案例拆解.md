## 一、2024-2026 获奖站八大原型（Awwwards/FWA/CSSDA 实证）

| # | 原型 | 视觉特征 | 代表站 | 技术基础 |
|---|---|---|---|---|
| 1 | Minimalist / Type-Driven | 两色系统、排版即设计、大留白、滚动叙事 | Terminal Industries（SOTM 2025-09） | GSAP ScrollTrigger + Lenis |
| 2 | Editorial / Magazine | 衬线大标题(60-120px)+无衬线正文、6-12 列非对称网格、拉出引用、单色/双色调图片 | Siena Film Foundation（SOTM 2025-04） | 12 列 grid + fluid type |
| 3 | Bento | 模块化非对称卡片网格、统一圆角、中性色 | Anime.js v4（SOTM 2025-05） | CSS Grid + 滚动驱动动画 |
| 4 | Experimental / Art-Directed | 无模板、混合媒介、非常规导航（空间探索/物理交互） | Bruno Simon Portfolio（SOTM 2026-01） | Three.js + p5.js + GLSL |
| 5 | Immersive WebGL | 墨黑画布 + 巨型衬线/无衬线标题、雾代替纹理、光代替细节 | Lusion v3（SOTY 2023） | WebGL/自研引擎 |
| 6 | Brutalist / Neo-Brutalist | 2-4px 粗黑边框、硬阴影(4-8px offset 纯黑)、平涂色、零渐变 | FlowFest 2025 / Anime.js（混血） | 平色 + 大号展示字 |
| 7 | Playful / Character-Driven | 游戏设计思维、gooey 交互、AR/3D Gaussian Splatting | Resn 作品集 | 游戏引擎 + 音频设计 |
| 8 | Dark / Cinematic | 深色氛围、电影化光效、三幕式滚动 | messenger.network（Developer SOTY 2025） | Three.js 微缩行星 |

## 二、实测案例 #1：Terminal Industries（SOTM 2025-09 + Developer Award）

> 罕见拿下 SOTM 的 B2B 物流 SaaS——**克制打败装饰**的最强证据。

### 视觉 DNA（从真实 CSS 取证）

| 维度 | 实测值 | 可学点 |
|---|---|---|
| 字体 | SuisseIntl（400/450/500/600 多字重自托管）+ Geist Mono（数字/标注） | 单一字体家族多字重 + mono 做"数据感"点缀 |
| 配色 | 深墨绿 `#052424` 主文、酸橙绿 `#abff02` 强调、橘 `#fb6b3c` 次级强调、脏白 `#f0f0f0` 背景、灰阶 5 级 | **主色+锐利强调**（B82 官方原则的活案例）；灰阶体系完整 |
| 排版系统 | H1 = `10.256vw` 响应式巨字（desktop 上限 146px）；负字距 -0.308vw；footer 大字 7.692vw；小标签 `letter-spacing .18em` 全大写；mono 数字标注 `letter-spacing .14625rem` | **字号跳跃 10 倍级**（146px vs 13px 数字），全站只有一个层级突出 |
| 布局 | 12 列 grid；容器 padding `0 5.128vw`；间距 token `--spacing:5.128vw`（vw 驱动 = 天然响应式） | vw 单位做边距/字号 = 整站按视口缩放 |
| 动效 | reveal-y 上滑入场（`translate3d(0,100%,0)` + 1.2s 缓出）；链接下划线 scaleX 双线动画（`cubic-bezier(.85,0,.15,1)`）；Lenis 平滑滚动；文字 color-transition（浅灰→lime→深绿） | 动效克制：入场 + 下划线 + 滚动，无炫技 |
| 无障碍 | focus-visible `outline 2px solid lime`；`-webkit-font-smoothing`；`user-select:none`（可复制区单独放开） | 强调色同时是焦点色——**一个颜色两个职能** |
| 装饰 DNA | 四角"十字"标记（crosses__wrapper）贯穿全站 | 标志性微元素（B18 公式的"标志元素贯穿全站"） |

### 拆解结论
- **两色系统 + 巨型排版 + 单一强调色** = 低成本、高辨识
- "十字角标"是全站记忆点（去掉它站就普通了）——印证 B18：1-2 个英雄元素
- 性能即设计：无图片重资产，字体自托管 woff2

## 三、实测案例 #2：Opal Electronics（op.al · 2026-06 品牌宣言页）

> Opal Tadpole 站（SOTY 2024 提名）作者 Claudio Guglieri 团队的 2026 新作；纯滚动叙事教科书，实测取证（Next.js + Tailwind v4）。

| 维度 | 实测值 | 可学点 |
|---|---|---|
| 技术栈 | Next.js + Tailwind v4；CSS 变量驱动（`--page-gutter`/`--header-height`/`--color-background`/`--color-foreground`） | **所有间距/颜色走变量**，per-path 主题切换（`data-theme="dark"`） |
| 导航 | 固定头部 `mix-blend-difference`（logo 在任意背景自动反色） | 一个 CSS 属性解决"换背景时 logo 看不清" |
| 英雄 | 全屏视频优先：Mux 视频流 + AVIF 首帧占位（`fetchPriority="high"`） | 视频首帧用 AVIF 静态图，首屏不黑 |
| 字体系统 | vw 驱动：`--heading-fs-desktop:3.39vw`、正文 1.45vw；mobile 巨字 12vw；`tracking-[0.02em]` | 标题+正文都 vw 级联，全屏等比缩放 |
| 滚动叙事 | **逐字显现**：每个 `<span style="opacity:0">` + 滚动触发；桌面左栏/移动双栏 50vw 交错排布；长篇电影感文案（"the table" 宣言） | 字级入场比块级入场更细腻；双栏交叉 = 页面节奏 |
| 质感 | `noise.avif` 胶片噪点（opacity 0.04 + `0.4s steps(1)` 循环动画）+ 底部渐隐蒙版 | 噪点蒙版 4% 透明度给视频"胶片感"；滚动时上下渐隐衔接 |
| 配色 | 黑白极简 + 唯一黄色 accent（"See you soon." 用 `text-yellow`） | **全站只允许一个彩色词**——克制的极致 |
| 彩蛋 | 品牌化 404："This page doesn't exist, yet. Read this one instead."；footer 交互 canvas | 404 也是品牌资产（文案人格化） |

### 拆解结论
- `mix-blend-difference` 头部 + vw 字体 + 噪点蒙版 = 低成本高级感三件套
- "每页只有一个彩色词"是 B82 反 AI 味的极端示范
- 逐字滚动叙事适合**宣言/品牌页**，不适合产品页（信息损耗）

## 四、实测案例 #3：Pangram Pangram（SOTY 2021 · Locomotive 开发）

> 世界级字库电商站（pangrampangram.com），Locomotive 开发，2026-08 实测取证。

| 维度 | 实测值 | 可学点 |
|---|---|---|
| 平台 | Shopify + 完全自研主题（theme `pp.com` v3.0.0），`fonts.css` 自托管 | 电商也能做出定制感：模板只是底座 |
| 内容即设计 | 卖字体的站 = 全站都是字体样张；每种字体一个"角色"（Palma/Monument/Neue Montreal...） | **产品本身就是视觉资产**时，别加戏 |
| CTA 策略 | 首页标题即钩子："Free to try, High-Quality Fonts for Designers" | 免费试用驱动转化，设计感服务于试用 |
| 性能 | 自托管 woff2、预连接 CDN、仅 25% 采样埋点 | 字库站性能=加载即看（LCP 关键） |
| 指纹 | 自家字体的 logo、衬线/展示体混排 | 别学：除非你也是字体公司 |

### 拆解结论
- 类型驱动的电商：**字体就是全部品牌资产**，站内不额外堆装饰
- 与 Opal/Terminal 对比：三站同获大奖，但全靠"品牌内容与视觉语言强绑定"，而非动效炫技

## 七、原型 → 视觉 Prompt（衔接 F7）

每个原型可变成一句话定调 + 维度填充：

```
风格原型：{Minimalist Type-Driven / Editorial / Bento / Brutalist / Dark Cinematic / Immersive WebGL}
定调句：{如"深墨绿+酸橙绿两色系统，巨型排版，四角十字角标"}
字体：{SuisseIntl 式单族多字重 + Geist Mono 数据感}
布局：{12 列 vw 驱动网格，10 倍级字号跳跃}
动效：{上滑入场 + 双线下划线 + Lenis 平滑滚动}
```

> 注意：原型是"逻辑"，**具体字体/配色/角标是那个站的指纹**——学结构，替换皮肤（B85 变异）。

## 八、学习路径（五步，与 F9 闭环）

1. 在 F9 平台锁定目标（Awwwards SOTD/Godly 精选）
2. 打开原站，桌面+移动+性能面板都过一遍（F9 评审标准）
3. 取证：DevTools 里看字体（@font-face）、CSS 变量（:root 色板）、网格、动效（transition/animation）
4. 对照本文件"可复用模式表"登记可学维度
5. 用 B85 变异：换皮肤（你的品牌色/字体）+ 保留结构逻辑 → 进 F7 提示词
