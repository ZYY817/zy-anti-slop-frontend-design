# B60 · 数字排版极致细节

> 排版的高级感,90% 来自那 10% 的"数字级别细节"。
> 普通排版和顶级排版的差异,不在于字体选得多贵——而在于**每一个字符的每一个像素**是否都被处理过。
> 引号是不是弯的?破折号用对了没?数字对齐了吗?连字打开了吗?小数点位数一致吗?
> 这份文档拆的是:排版工艺的**微观世界**——那些没人会明说、但顶级作品都做到了的极致细节。

## 二、OpenType 特性完全清单

### 2.1 必开的默认特性

```css
:root {
  font-feature-settings:
    "kern" 1,     /* 字符对间距微调 */
    "liga" 1,     /* 标准连字 fi fl */
    "calt" 1;     /* 上下文替代 */
}

/* 更现代的写法(优先级更高,可继承) */
body {
  font-kerning: normal;
  font-variant-ligatures: common-ligatures contextual;
}
```

### 2.2 数字场景专用

```css
/* 表格/数据/时间 → 等宽数字 */
.tabular {
  font-variant-numeric: tabular-nums lining-nums;
  /* 或 font-feature-settings: "tnum" 1, "lnum" 1; */
}

/* 正文数字 → 比例数字 + 老式(如果字体支持) */
.body-text {
  font-variant-numeric: proportional-nums oldstyle-nums;
}

/* 分数 1/2 自动排成 ½ */
.fractions {
  font-variant-numeric: diagonal-fractions;
}
```

### 2.3 高级排版特性

```css
/* 小型大写(全大写但更文雅) */
.small-caps {
  font-variant-caps: small-caps;
  letter-spacing: 0.06em;  /* 小型大写需要加宽字距 */
}

/* 全大写 */
.all-caps {
  text-transform: uppercase;
  letter-spacing: 0.05em;
}

/* 风格集(字体特有,如 Inter 的 ss01 打开单层 a) */
.inter-ss01 {
  font-feature-settings: "ss01" 1;
  /* Inter 单层 a、方点句号等 */
}

/* 上下标 */
sup { font-variant-position: super; }
sub { font-variant-position: sub; }
```

### 2.4 可变字体轴

```css
/* 精细控制字重/宽度/斜度 */
.variable {
  font-variation-settings:
    "wght" 550,    /* 字重(通常 100-900) */
    "wdth" 100,    /* 宽度(通常 75-125) */
    "slnt" -5,     /* 倾斜角度 */
    "opsz" 32;     /* 光学尺寸 */
}

/* 光学尺寸自动适配 */
.optical {
  font-optical-sizing: auto;
  /* 字体会根据 font-size 自动选择正确的光学版本 */
}
```

## 三、数字的精细排版

### 3.1 何时用哪种数字

| 场景 | 数字类型 | CSS |
|---|---|---|
| 表格数字 | 等宽 + 衬线 | `tabular-nums lining-nums` |
| 财务金额 | 等宽 | `tabular-nums` |
| 时间/计时器 | 等宽 | `tabular-nums` |
| 电话号码 | 等宽 | `tabular-nums` |
| 版本号 | 等宽 + 衬线 | `tabular-nums lining-nums` |
| 正文中的年份 | 老式 + 比例 | `oldstyle-nums proportional-nums` |
| 大数字 Hero | 衬线 + 比例 | `lining-nums proportional-nums` |
| 章节序号 | 老式 | `oldstyle-nums` |

### 3.2 数字对齐工艺

```css
/* ❌ 数字不对齐,视觉抖动 */
.price-list li {
  /* 默认比例数字,1 和 8 宽度不同 */
}

/* ✅ 表格数字对齐 */
.price-list li {
  font-variant-numeric: tabular-nums;
  text-align: right;
}
```

**规律**:
- 需要**上下对齐比较**的数字 → 等宽
- 需要**嵌入文本流**的数字 → 比例
- **计数器/时钟** → 必须等宽(否则跳动)

### 3.3 大数字的分组

```javascript
// 千位分隔(en-US)
(1234567).toLocaleString('en-US');  // "1,234,567"

// 中文分组(万位)
(12345678).toLocaleString('zh-Hans-CN');  // "1234 万"(需要自己写)

// 财务简写
function abbreviate(n) {
  if (n >= 1e9) return (n / 1e9).toFixed(1) + 'B';
  if (n >= 1e6) return (n / 1e6).toFixed(1) + 'M';
  if (n >= 1e3) return (n / 1e3).toFixed(1) + 'K';
  return n.toString();
}
```

```css
/* 数字分组视觉:细空白代替粗逗号 */
.number-nice {
  /* 用 CSS content 而非文本内容 */
}
/* 或 SI 制:用窄空格 */
.metric::after {
  content: " " attr(data-unit);
  margin-left: 0.15em;
  color: var(--text-secondary);
  font-size: 0.75em;
}
```

### 3.4 小数点对齐

```css
/* 表格金额小数点对齐 */
.amount {
  font-variant-numeric: tabular-nums;
  text-align: right;
}

/* 使用 char="." 对齐(CSS 支持有限,可用 grid 模拟) */
.amount-grid {
  display: grid;
  grid-template-columns: 1fr auto 1fr;
  align-items: baseline;
}
.amount-grid .int { text-align: right; }
.amount-grid .dot { padding: 0 1px; }
.amount-grid .dec { text-align: left; }
```

### 3.5 负数与前导零

```css
/* 用 tabular-nums 保证负号也占等宽 */
.stat[data-trend="down"] { color: var(--error); }
.stat[data-trend="down"]::before { content: "−"; }  /* 减号 U+2212,不是连字符 */

/* 前导零(时间/进度) */
.time-value {
  font-variant-numeric: tabular-nums;
  /* JS: String(n).padStart(2, '0') */
}
```

## 四、标点符号的正确用法

### 4.1 引号

| 语言 | 主引号 | 次引号 | Unicode |
|---|---|---|---|
| 英文 | " " | ' ' | U+201C/201D, U+2018/2019 |
| 中文简体 | " " | ' ' | 同上(横排) |
| 中文简体(书面) | 「」 | 『』 | U+300C/300D |
| 法文 | « » | ‹ › | 带空格 |
| 德文 | „ " | ‚ ' | 下引号开始 |

```css
/* CSS 自动引号 */
q {
  quotes: "\201C" "\201D" "\2018" "\2019";
}
q::before { content: open-quote; }
q::after  { content: close-quote; }

/* 中文文档用直角引号更传统 */
:lang(zh) q {
  quotes: "「" "」" "『" "』";
}
```

**自动替换直引号**:
```javascript
// 输入 "hello" 自动变 "hello"
function smartQuotes(text) {
  return text
    .replace(/(\s|^)"/g, '$1\u201C')
    .replace(/"/g, '\u201D')
    .replace(/(\s|^)'/g, '$1\u2018')
    .replace(/'/g, '\u2019');
}
```

### 4.2 破折号与连字符

```
- 连字符(Hyphen, U+002D):     连接词  "state-of-the-art"
– 短破折号(En Dash, U+2013):  范围    "2020–2026" / "北京–上海"
— 长破折号(Em Dash, U+2014):  插入语  "他说—— 不,是她说"
− 减号(Minus, U+2212):        数学    "−273.15°C"
─ 长横线(U+2500):             表格边框(不同用途)
```

**中文长破折号**:两个 `——` 连用,不是一个:`他说——不,是她说`。

```javascript
// 自动替换
text
  .replace(/(\d+)-(\d+)/g, '$1\u2013$2')   // 范围用 en dash
  .replace(/ - /g, ' \u2014 ')              // 插入语用 em dash
  .replace(/-(\d)/g, '\u2212$1');           // 负数用减号
```

### 4.3 省略号

```
✅ 单字符 …(U+2026):       正确的省略号
❌ 三个点 ...:              不专业
❌ 六个点 ......:           中文错误(应为 …… 两个)
```

**中文规范**:`……`(两个省略号) 表示更长的省略。

### 4.4 CJK 标点挤压

**问题**:中文标点占全角宽,连续标点显得松散。

```
❌ 未挤压: "你好, "他说, "很久不见了。"
              ↑       ↑
           这里显得很空

✅ 挤压后: "你好,"他说,"很久不见了。"
```

```css
/* CSS 中文标点自动挤压 */
:lang(zh),
.cjk-text {
  text-spacing: normal;             /* 2024+ 新特性 */
  text-spacing-trim: space-all;
  hanging-punctuation: allow-end;
}

/* 兼容方案:用 font-feature-settings */
.cjk-compact {
  font-feature-settings: "halt" 1, "palt" 1;
}
```

### 4.5 悬挂标点

**引号伸出文本框**,让左边缘更整齐:

```
❌ 未悬挂:
"这是一段引用的文字,注意
第一行开头的引号让整段文
字向内缩了。"

✅ 悬挂:
"这是一段引用的文字,注意
 第一行开头的引号伸出左边
 缘,文字对齐了。"
```

```css
blockquote {
  hanging-punctuation: first last;
  /* first: 开头标点悬挂 */
  /* last: 结尾标点悬挂 */
}

/* 兼容方案: 手动负 margin */
blockquote::first-letter {
  margin-left: -0.4em;
}
```

### 4.6 中英混排空格

**规范**:中英文之间加**半角空格**。

```
❌ 使用JavaScript编程
✅ 使用 JavaScript 编程

❌ 12岁的AI科学家
✅ 12 岁的 AI 科学家
```

**自动化**(打字麻烦):
```javascript
// Pangu.js 思路:中英之间自动加空格
function pangu(text) {
  return text
    // 中文 + 英文/数字
    .replace(/([\u4e00-\u9fa5])([A-Za-z0-9])/g, '$1 $2')
    // 英文/数字 + 中文
    .replace(/([A-Za-z0-9])([\u4e00-\u9fa5])/g, '$1 $2');
}
```

**注意**:标点前后不加(如 `"你好,World"` 不是 `"你好, World"`)。

## 五、光学对齐(Optical Alignment)

### 5.1 视觉居中 ≠ 几何居中

**播放三角形几何居中,但视觉上偏左**:

```css
.play-icon {
  /* ❌ 几何居中 */
  display: flex;
  justify-content: center;
  align-items: center;
}

.play-icon svg {
  /* ✅ 光学补偿:向右偏 1-2px */
  margin-left: 2px;
}
```

### 5.2 圆形按钮内文字的光学位置

```css
.round-btn {
  width: 40px;
  height: 40px;
  border-radius: 50%;
  display: flex;
  justify-content: center;
  align-items: center;
}

/* 按钮内文字/图标可能需要视觉调整 */
.round-btn .arrow {
  transform: translateX(1px);  /* 箭头视觉居中补偿 */
}
```

### 5.3 括号的光学对齐

```css
/* 括号视觉上偏离基线,需要微调 */
.paren-adjust {
  display: inline-block;
  transform: translateY(-0.05em);
}
```

### 5.4 顶部对齐的视觉修正

```css
/* ❌ align-items: center 让不同高度元素挤到中间 */

/* ✅ 光学基线对齐:标题和图标共享基线 */
.title-with-icon {
  display: inline-flex;
  align-items: baseline;      /* 而不是 center */
  gap: 8px;
}

/* 图标基线补偿 */
.title-with-icon .icon {
  transform: translateY(0.15em);
}
```

## 六、微排版细节

### 6.1 首字下沉(Drop Cap)

```css
article > p:first-of-type::first-letter {
  float: left;
  font-size: 4.5em;
  line-height: 0.9;
  padding-right: 8px;
  padding-top: 4px;
  font-weight: 700;
  color: var(--brand);
  /* 衬线字体首字下沉更有编辑感 */
  font-family: "Playfair Display", serif;
}
```

### 6.2 段落孤字与孤行

```css
p {
  text-wrap: pretty;    /* 2024+ 智能换行避免孤字 */
  orphans: 3;           /* 段末至少留 3 行 */
  widows: 3;            /* 段首至少 3 行 */
}

/* 标题:平衡换行 */
h1, h2, h3 {
  text-wrap: balance;
}
```

### 6.3 中文行首行末禁则

**规则**:
- 行首禁止:标点(,、。!?;:)、闭合括号、后引号
- 行末禁止:开括号、前引号

```css
:lang(zh) {
  line-break: strict;
  word-break: normal;
  overflow-wrap: anywhere;
}
```

### 6.4 竖排文本

```css
/* 日文/中文竖排 */
```

### 6.6 字距的极端应用


## 七、字体加载与渲染

### 7.1 减少 CLS

```css
@font-face {
  font-family: "Inter";
  src: url("/fonts/inter.woff2") format("woff2");
  font-display: swap;

  /* 关键:让后备字体的度量对齐真实字体,消除跳动 */
  size-adjust: 107%;
  ascent-override: 90%;
  descent-override: 22%;
  line-gap-override: 0%;
}
```

### 7.2 文字渲染质量

```css
body {
  -webkit-font-smoothing: antialiased;
  -moz-osx-font-smoothing: grayscale;
  text-rendering: optimizeLegibility;
}

/* 但注意:antialiased 在深色底上让文字变细,可能不是你想要的 */
/* 建议默认 subpixel-antialiased,只在特殊场景用 antialiased */
```

### 7.3 大字号的渲染优化

```css
h1.hero {
  /* 巨字必须打开 kerning 才能好看 */
  font-kerning: normal;
  font-feature-settings: "kern" 1, "liga" 1;

  /* 抗锯齿平滑 */
  -webkit-font-smoothing: antialiased;

  /* 硬件加速渲染 */
  will-change: auto;
  transform: translateZ(0);
}
```

## 九、踩坑指南

### 坑1:输入的直引号未替换
**症状**:界面上显示 `"hello"` 而不是 `"hello"`。
**解法**:输入时自动替换,或 CSS 用 `<q>` 标签,或后端渲染时处理。

### 坑2:混用连字符与破折号
**症状**:`2020-2026` 应该是 `2020–2026`(en dash)。
**解法**:输入辅助或后端规范化。

### 坑3:数字跳动(时钟/计数器)
**症状**:每秒变化时数字左右晃动。
**解法**:`font-variant-numeric: tabular-nums`。

### 坑4:全大写不加字距
**症状**:`ABOUT` 字符挤在一起,不专业。
**解法**:全大写必须 `letter-spacing: 0.05em+`。

### 坑5:中英之间无空格
**症状**:`使用JavaScript编程` 太挤。
**解法**:半角空格或用 Pangu.js 自动化。

### 坑6:CJK 标点太松
**症状**:`"你好, "他说` 显得空。
**解法**:`text-spacing-trim: space-all`。

### 坑7:巨字未压行高
**症状**:大标题两行时行间有空洞。
**解法**:`line-height: 0.92`。

### 坑8:巨字未负字距
**症状**:大字看起来松散、散架。
**解法**:`letter-spacing: -0.035em`。

### 坑9:字体加载 CLS
**症状**:字体加载完后布局跳动。
**解法**:`size-adjust` + `ascent-override` 对齐后备字体。

### 坑10:光学未补偿
**症状**:播放按钮几何居中,但看起来偏左。
**解法**:向右偏移 1-2px。

### 坑11:标题不平衡换行
**症状**:标题最后一行只有 1 个字。
**解法**:`text-wrap: balance`。

### 坑12:三个点当省略号
**症状**:`hello...` 显得不专业。
**解法**:用 `…`(U+2026)。
