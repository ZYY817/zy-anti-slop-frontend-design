# 99 · 缺口图谱与入库方案
（调研期汇总 · 五份报告交叉验证 · 2026-11 · 来源全部见 research/A~E 各报告）

## 一、五份调研的交叉结论

**1. "视觉层级"这个问题世界已经解决了——解法是"角色×档位矩阵+强调配额"，不是"权重规则"**
- A：M3 五角色×三尺寸字阶 / Polaris 三角色（角色数本身是实测折中）/ Spectrum "attention hierarchy=信噪比"
- D：焦点序/权重分配/视线流三个维度可写成验收句（3 秒测试 / 相邻级≤3 变量 / F·Z 型路径）
- **共同前提**：厂商都把"什么最重要"当外部输入，不替产品决定 → 我们缺的不是矩阵，是**让模型先推出重要性排序的入口**

**2. "品味→可执行结构"的现存最近形态有三份，结构收敛**
- Anthropic frontend-design SKILL.md（~120 行）：人格 + 按维度"禁例+好例+判断原则"三元组 + 病名表（校准非禁令）+ 两阶段流程（先设计计划→generic default 检查→才写码）
- Primer DESIGN_TOKENS_GUIDE.md：RFC2119 分级 + 决策树 + golden example + hallucination guard
- lieflat SKILL.md：规则四件套（实测数字+改法+❌/✅对例+不改例外）+ X 级否决清单 + 三层分工（脚本/封闭判据/人审）
- **效果排序**：流程+判断+病名表 ＞ 硬约束+token 化 ＞ 纯形容词（bolt 只有一句 "beautiful unique" 基本无效）

**3. 剂量证据收敛**：~400 token ≈ 120 行 skill ≈ 6K 字符 ≈ 70 行嵌入；按需加载 > 常驻注入；指令数↑遵守率↓（~150 条注意力预算）——我们 Z2 的"5-12 文档"方向正确，但每篇都该是高信号

**4. 验证回路的工业形态**：截图+vision 自审已产品化（v0/Replit/Anthropic）；开源版=多 viewport 截图→独立 critic VLM→"期望 vs 实际"式 issue→修 top3→收敛。**AUV-Bench"判断-行动鸿沟"：会评分≠会修（诊断链成功率 24.7%）——自审必须验证"修完真变了"**

**5. 我们的回路 = OpenAI eval flywheel 同构**，缺口在：失败分类成文、基线量化、grader 化；lieflat RESEARCH.md 给了可操作证据闸门（配对比较/分模型/≥2.0 倍率/可定位触发/不编造）

**6. 写不成词的边界已被三份报告独立划清**：个性选型/craft 密度阈值/何时破格/整体 coherence（squint test 是最接近代理）——词管"不差"，管不了"卓越"。这与"不想限制参数达到某种效果"一致：**词该教判断+给锚点，不该写死风格**

## 三、入库方案（三期，按依赖排序）

### 第 1 期 · 形态改造（先造容器）
- 抽 **SKILL.md 薄主文件**（≤300 行，Anthropic skill 格式）：人格+两阶段流程（设计计划→generic default 检查→写码）+反默认值否决区（B82/B44 精选改写成四件套）+验收 checklist+人审边界+优先级声明（brief>项目体系>库默认）
- 190 文档降级为 references/ 语义层，全部引用压平到一跳；AGENTS.md 缩成 <200 行索引+铁律
- K 词条格式升级：补四件套缺件（判据数字/❌✅对例/不改例外）；B44 增设 **X 级否决区**

### 第 2 期 · 内容补词（装填弹药）
- **K19·视觉层级系统**（合并入库 A#1-6+D#1-3）：决策链=本页重要性排序→角色×档位分配→高注意配额≤2→3 秒/squint 验收
- **B88·界面文案词库**：E#9-14 六对象（行描述信息位/利益 vs 对象/CTA≤2词/空态公式/错误两句式/朗读测试）
- **K20·排版数字层**：D#5-10（模数阶/行长 45-75/行距 120-145%/8pt 阶/光学对齐）
- 病名表加"采样日期+重采样机制"；反收敛条款进生成协议

### 第 3 期 · 回路固化（装发动机）
- **失败分类成文**：case 反哺档案按 open→axial coding 写 5-10 类（现有：过修正/指征堆叠/彩度失控/控件权重/布局经济/交互纵深——已成 6 类）
- **verify.py 升级**：+截图渲染维 + "期望 vs 实际"issue 格式 + 修复后复检（防判断-行动鸿沟）
- **反哺证据闸门**入 AGENTS/M2：配对比较+可定位触发+被推翻进 X 区不删
- **挖词分工**：agent 提取候选（DOM/截图→特征→聚类）→人审闸门入库（DMiner 先例，不承诺端到端）

### 不做清单（边界诚实）
- 不写"必须用什么色/什么字"——写死风格已被 bolt/二阶收敛证伪
- 不追求端到端自动挖词——过滤步是人工闸门（产业共识）
- 不把 coherence/破格判据写成词——squint test 代理+人审位
