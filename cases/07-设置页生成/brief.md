# 任务书：墨迹（Inkwell）应用内设置页

## 产品背景
墨迹是一款本地优先的 Markdown 笔记应用（桌面 Web 端）。本任务交付的是**应用内的设置界面**——不是营销页，是用户实际操作的界面。

## 必须包含的设置区（左侧导航 ≥6 项）
1. **通用**：语言（简中/English）、启动行为、自动保存间隔
2. **编辑器**：正文字号/行宽/字体族选择、打字机模式、拼写检查、Tab 行为
3. **外观**：主题（跟随系统/浅色/深色）、4+ 款主题色板可选、界面密度（紧凑/标准/宽松）
4. **同步**：同步状态显示、已连接设备列表（≥3 台：本机/iPhone/旧 MacBook）、端到端加密开关、立即同步按钮
5. **快捷键**：≥6 条快捷键可查看，其中 ≥3 条可点击重新绑定（真实捕获按键）
6. **存储与数据**：本地用量显示（文稿数/占用空间）、导出全部（Markdown zip）、导入、危险区（清空本地数据需二次确认）

## 硬性要求
- 单个自包含 HTML（内联 CSS/JS，除字体外零依赖）
- **所有控件必须真实可用**：开关真切换并改变状态、主题切换真换肤、密度切换真改间距、快捷键点击后真实捕获按键、搜索设置项实时过滤左侧导航、危险操作有二次确认
- 顶部或显著位置有**搜索设置**输入框，输入时实时过滤左侧导航项
- 375px 移动端可用（导航形态可重组）、1280px 桌面为设计主端
- 中文为主
- 品牌延续（可选）：墨迹=给认真写字的人的笔记应用，克制/书房气质
