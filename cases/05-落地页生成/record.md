- W1：**7/7 全部决策级**——排版（宋体题组/display cut）、色彩（来源色板"宣纸+松烟墨+朱砂印泥"+职责分工+单墨透明度阶）、构图（非对称编辑式+破格锚定）、纵深（前中后景三段）、空间（呼吸峰+密度序列 L3→L1.5→L2.5→L2→L3）、动效（双轨+expressive 仅 hero 一处+统一签名缓动）、人性（被款待+诚实文案+印章母题）

**W0 的 P0**：页脚两个主 CTA `href="#dl"` 自指死链——点了没反应，主转化路径功能缺口（K12·死控件实证+1）。

## W1 的词条决策执行（trace 实证）

- 案名「案上墨 DESK INK」：宣纸+宋体题组+朱砂印章母题 ≥3 处变奏
- K·视觉配额：signature 峰 1、朱砂恰 5 处 <3%、装饰 2 种
- K·密度节奏：呼吸峰=Hero 唯一 L1.5，五档序列落地
- K·职责分工：朱砂=动作岗、墨=信息岗六档阶、三字面分工
- K·动效双轨：productive 150ms / expressive 仅 hero 900ms 编排、签名缓动全站统一
- K·破格：2 处单轴横向有锚定、移动端归零
- Z3 审计 18 条实修（对比度三组、padding 覆盖 P0、序数改中文"其一/其二/其三"）

## 证据价值

- **第二任务类型验证**：方向卡+B86+K 词条在"视觉重表达"任务上同样生效（第一任务是工作台 UI），且视觉/空间/动效三个"美学维"分差比第一任务更大——B86 词库是直接原因
- **反哺零新增**：W0 死链 P0 已被 K12·死控件词条覆盖（实证+1，置信从"单任务"升"双任务"）；人性维度词在 W1 被实际消费（照管/款待词汇进入方向卡可选槽的执行例）
- **诚实标注**：同族模型裁判、单轮盲审、代码审查级；两案合计两次全胜为指示性证据，非统计结论

## 第三轮：用户终审反转 → B87 结构层 → W2 复验

**用户终审（本轮真判决）**：W0 结构与内容展示更好；W1 质感稍好但没用 → 结构层缺失确诊（三案同一盲区第三次出现）

**修复**：B87-结构与内容展示词库（10 维~55 词）+ Z1 结构卡（先于方向卡）+ Z2 闸门前置 + K10 维度2 结构检查

**W2（武装+B86+B87）盲审 vs W0**：79.0 : 64.0
- 信息设计维 **9.5 : 7.5** ——上轮 W0 唯一胜维，本轮被反超
- W2 结构卡执行：论证页+论证链六岗齐全+hero 大实证窗+每主张配 show+tell-only 0 区块+FAQ 排疑前置+收口回扣
- W0 P0 实锤：页尾双 CTA `href="#dl"` 自指死链+3 条 `href="#"` 占位
- 裁判原话："armJ 像专门设计的官网；armI 是气质上乘但骨架通用的'写得很好的模板'"

**证据强度**：同任务三轮迭代；W2 结构决策全部可回溯到 B87/结构卡；仍属指示性（同族裁判/单轮/代码审查级）。用户终审待测——这次测的是"结构卡是否补上了用户判负的维度"
