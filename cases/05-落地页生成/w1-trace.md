## 4. 写码前承诺：方向卡 + 风格案名

### 方向卡（Z1 第 0 层，R21 决策树十问收敛）

- 【页面目标】转化（下载）+ 信任；【核心任务】10 秒确认"这是为我做的安静工具"
- 【核心概念】"一张永远摊开的稿纸"——工具退后，写作在前
- 【气质三词】克制 / 书卷气 / 笃定
- 【视觉隐喻】书桌·编辑室（宣纸、墨、印章）
- 【参考锚点】要像 iA Writer 官网的单一主张与克制排版、原研哉式的"空"；**不要** Notion 式多功能 Bento、SaaS 模板的双按钮居中 hero、大渐变背景
- 【反面清单·AI 默认指纹点名】紫蓝渐变 / 三张等宽圆角特性卡 / emoji 图标 / 01·02·03 装饰编号（改用有信息的中文序数"其一其二其三"）/ 双按钮居中 hero / 滚动指示箭头 / logo 墙 / 玻璃拟态 / "赋能·效率提升 10 倍"文案
- 【R21 十问答案】① 主风格=日式素净×优雅衬线极简 ② 核心锚点=巨型排印（E41）+空白即主角（I85）③ 配色=单色+1 点缀，来源色板「宣纸+松烟墨+朱砂印泥」④ 字体=宋体 display+系统 CJK 正文+mono 数据层（contrast 配对）⑤ 动效=双轨仅关键节点 ⑥ 纯 2D ⑦ 无 shader ⑧ 无粒子 ⑨ 首屏=宣纸上一枚巨型宋体题组+一张像真截图的编辑器窗口+朱砂印章落款 ⑩ 线性五幕压缩

### 风格案名（Z1 第 1 层）

> **「案上墨 DESK INK」**——一张刚铺开的宣纸：巨型宋体题组是唯一的浓墨，一枚朱砂印章是全页唯一的颜色事件；元素像书桌上的物件各就其位，克制到近乎骄傲。

- 风格签名（会重复 ≥3 处的母题）：**墨点/印章**——hero 朱砂小印、特性 meta 前墨点、图谱朱砂热节点、footer 大印章（变奏非复制）
- 编辑题组语法：mono kicker（带 22px 短线）→ 宋体标题 → 灰 deck，全页复用
- 张力对立：空与满（纸白 60%+ vs 104px 巨字）、素与朱（墨灰 vs 印章）

#### K·视觉职责分工（K18）

- 色相→岗：朱砂=动作岗（CTA/链接/印章，不挪用不装饰）；墨=信息岗（单墨透明度阶 100/72/66/42/14/8% 六档，不引第二灰）；纸=底。
- 字阶→岗：宋体=表达层（h1/h2/h3）；sans=界面层（正文/按钮/导航）；mono=数据层（kicker/版本/时间戳/状态栏/图谱 meta）。
- 母题：墨点/印章 ≥3 处变奏（小印→meta 墨点→图谱热节点→footer 大印）。
- 闲员审计：噪点=纸感、hairline=分隔、印章=签名——全部有名有姓。

#### K·动效性格与双轨预算（K18）

| 决策点 | Decision | Spec |
|---|---|---|
| ① 分轨声明 | productive=hover/focus/按压；expressive=仅 hero 入场 1 处 | `@media (hover:hover)` 内 transition 150ms |
| ② 表现轨配额 | 1 处（hero 编排 ~900ms） | `.js .hero` keyframes |
| ③ 性格选型 | 从容笃定（静奢系）：入场 480-900ms `--ease:cubic-bezier(0.19,1,0.22,1)`；交互 150ms 干脆无回弹 | token `--ease` 全站唯一签名缓动 |
| ④ 轨道一致性 | 入场统一从下往上、位移 14-22px；hover 统一 translateY(-2px)+色深 | rise-in/mask-up/float-up |

#### K3·触屏无 hover

① hover 承载物全为装饰性（变色/位移/下划线）→ 触屏可无，无 hover 独占信息；
②④ `@media (hover:hover) and (pointer:fine)` 统一隔离 hover 样式与 transition；
③ 长按语义 N/A（无 hover 预览功能）。

#### 未命中/判定不适用

- K·悬停意图/悬停延迟：无悬停展开菜单/tooltip → N/A
- K·语义色冲突：品牌色朱砂为红系但全页无错误/成功语义场景 → 已标注，若后续加表单需按词条处置
- K·输出视图：适用性弱但低成本顺手做——`@media print` 隐藏顶栏/按钮/噪点、深底转浅
- K6 滚动工程：仅取锚点偏移（`scroll-padding-top:88px`），无 snap/pin/scroll-jacking（克制决策）

#### R 条目（7 条 ≤8，含必备三类）

1. **主视觉决定**：R10·I4 巨型排印——h1 clamp(52px,8.6vw,104px)，两行 mask 下推入场
2. R10·I5 CJK 排版——`palt`+`line-break:strict`+标题字距 +0.03em+hanging-punctuation 渐进增强；`keep-all` 仅用于超短 h1（长句标题会溢出）
3. R10·I7 层级 ≤3 级 + 字阶跳跃 ~9.5:1（104/11）
4. R11·F2 区块入场——IO threshold .22、位移 16px、600ms、stagger 60ms 整数倍、只播一次
5. R11·F8 时间常数——缓动 1 条签名曲线 + 时长 4 档（150/480/600/720/900）；持续动效仅 blink 1 处
6. **性能/降级**：动画只用 transform/opacity；JS 仅 IO 渐进增强，无 JS 全可见；reduced-motion 零自动运动
7. **无障碍/状态**：正文对比 ≥4.5:1、focus-visible 2px、skip link、`role="img"`+aria-label 替代图形占位、文字不进 canvas

## 5. Z1 完整版分层填写摘要

- **第2层 版式**：12 列 max-width 1120；hero 6.2:4.8 左右分栏+截图右悬出；特性 zigzag 5:7 / 7:5 / 上文下满幅图谱（三种布局类型，不三连）；版面率留白 60%+
- **第3层 字体**：宋体栈（STZhongsong→Songti SC→思源宋→SimSun）display；系统 CJK sans 15.5px/1.8 正文；mono 数据层；字阶 104/58/52/30/17/15.5/11 ≈9.5:1
- **第4层 色彩**：来源色板「宣纸+松烟墨+朱砂印泥」；纸 #F4F0E6 / 墨 #221F1A / 朱 #8E3B24（暗底校准 #C05A44/#B04E38）；单墨透明度阶分档；禁 #000/#FFF/渐变
- **第5层 光影**：暖光源 rgba(30,24,16,*) x0 y+；阴影两档 0 2 8 / 0 24 60；哑光纸质
- **第8层 动效**：hero 入场 900ms 编排（kicker→两行 mask→deck→CTA→截图→印章落定）；滚动入场一次；光标 blink 唯一持续动效
- **第10层 内容**：真实中文文案；CTA「下载墨迹」动词开头 ≤6 字；禁词检查通过（无赋能/抓手/极致/神器/感叹号）
- **第12层 状态**：链接/按钮 default/hover/active/focus-visible 全有；disabled/loading/empty/error 标注 N/A（纯静态展示页无异态内容）；触控 ≥44px
- **第13层 底线**：AA 对比度（见 §6 修复 #1-#4）；语义化；键盘可达；动画 transform/opacity only

### 五轮结论

- **R1 视觉/品牌**：眯眼→hero 巨字+截图为唯一强块，特性区为次级块，CTA 深底收束；母题（墨点/印章）≥3 处可辨；装饰手法 2 种在限内。✅
- **R2 UX/内容**：单 section 单一职责；首屏 3 秒可读（kicker→巨字→deck→CTA）；全页真实中文文案零黑话；mock 内容自洽（时间流四条日期递减、图谱标签与特性文案互文——"城市漫游"在 hero 截图与图谱中重复出现形成伏笔-回响）。✅
- **R3 交互/响应式**：hover/focus/active/focus-visible 齐；reduced-motion 零自动运动（`*{animation:none!important}`+scroll-behavior:auto+光标静止显示）；破格 ≤960 归零；375px 全块重排非缩放（顶栏隐藏 ver/单列/图谱横滑）。✅
- **R4 工程/a11y**：语义标签+aria-labelledby 区段命名；role="img"+aria-label 覆盖全部图形占位；`lang="zh-CN"`；动画仅 transform/opacity；无 CLS（截图占位为 DOM 无图加载）；标签配平机检通过；`node --check` JS 通过。✅
- **R5 原创性**：遮 logo 可识别组合——纸墨朱砂色板+宋体巨字编辑题组+mono 数据层+印章母题+悬出破格；"01/02/03 编号"默认脸改"其一其二其三"（信息性序数）；非"紫渐变+三圆角卡"任何已知模板组合。✅
