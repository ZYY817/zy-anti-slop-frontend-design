# 任务书 · 落地页生成（视觉重表达 A/B）

## 产品上下文（范围钉死，两组一致）

- 产品：「墨迹 Inkwell」——一个给写作者用的极简笔记 App（Mac/Win 客户端），卖点是"打开即写、无文件夹、双向链接"
- 任务：做它的**官网落地页首屏 + 向下 3 个完整区块**（单文件 HTML，不引外部库，图片用文字/色块/CSS 图形占位）
- 目标用户：独立开发者、研究员、写作者——对"工具感"和"审美"都挑剔的人群
- 必须包含：Hero（标题+主 CTA+产品截图占位）、3 个特性区块、页脚 CTA
- 内容：用真实中文文案（产品名/标语/特性名自拟但要有产品感，不许 lorem、不许"赋能/抓手"类黑话）
- 兼容：responsive 到 375px；动效需 reduced-motion 降级

## 对比维度（本题重点考视觉表达）

- 排版文字：标题/正文字阶、字体搭配、中文排版细节
- 色彩：配色是否有来源和气质、色用量是否克制
- 布局层级：构图是否有主张、密度是否有节奏、层级是否有纵深
- 动画：入场/滚动/悬停动效是否有性格、是否克制
- 人味/信任：文案是否像人写的、细节是否有温度、还是模板腔

## 实验设计

- **W0 裸跑**：仅本任务书
- **W1 武装**：本任务书 + `AGENTS.md` 入口（走 Z2 检索→方向卡→Z1 生成→Z3 自检）。**本题视觉是主表达，R 板块按协议可用**
- **裁判**：九维盲审 + 加问"第一眼成品感/像真实产品的官网还是作业"
- 产出命名：`w0.html` / `w1.html` + `w1-trace.md` / `judge-report.md`
