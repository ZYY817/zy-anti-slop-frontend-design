## 4. Z1 结构卡（B87 词，先于方向卡作答）

### ① 页面类型

**论证页**。落地页不是展示橱窗而是论证链：要让一个挑剔的写作者 10 秒内相信"这工具懂我"，每个区块必须报岗，不许空转。

### ② 叙事结构：压缩论证链

```
顶栏导航 → Hero[勾住+定向+证明] → 特性1 打开即写[证明] → 特性2 无文件夹[证明→深化]
→ 特性3 双向链接[深化] → 引用[深化·第三方证言] → 问答[排疑] → CTA[收口] → 页脚
```

### ③ 逐块报岗（B87 职责词）

| 区块 | 岗位 | 证据件（show） |
|---|---|---|
| Hero | 勾住（"打开，就是稿纸"）+ 定向（kicker"为写作者做的桌面笔记"）+ **证明** | 大编辑器窗口：真实笔记《长夜将尽·终章草稿》、日期/字数/本地存储状态、闪烁光标 |
| 特性1 · 打开即写 | 证明（用数字证明主张） | 启动时序条 0.0s→0.4s→0.8s，旁注"实测 M3 Air 十次取中位" |
| 特性2 · 无文件夹 | 证明→深化（把抽象卖点演给你看） | 搜索界面：查询"截稿"、3 条命中高亮、18ms、"库内 214 篇"旁注 |
| 特性3 · 双向链接 | 深化（从功能升维到方法） | 双栏：被引面板"←3 篇笔记引用了这篇" + SVG 关系图谱（中心节点互链） |
| 引用 | 深化·第三方证言 | blockquote 署名"沈以宁·城市研究者·墨迹用户第 121 天" |
| 问答 | 排疑（五问：迁移/注册/免费/本地/崩溃） | dl 语义列表，旁注"答于 v2.4.1 未删改" |
| CTA | 收口（回应开场承诺"稿纸亮着"） | 整幅稿纸亮面+双平台下载按钮+版本/体积/格式 chips |

### ④ 首屏四问 + 证据件

- 这是什么？→ kicker 直答"为写作者做的桌面笔记"
- 跟我什么关系？→ h1"打开，就是稿纸"+ deck"把光标放回你上次停下的地方"
- 凭什么信？→ **证据件=大编辑器窗口**（非缩略装饰件）：可见真实中文长文、写作元信息、光标在闪
- 下一步？→ 琥珀 CTA"开始写，免费"+ 次链"看看它怎么工作 ↓"

### ⑤ show/tell 配比

四大主张（快/找得到/连得起/可信）各配 1 件 show 证据件；文案块（tell）永远与证据件同屏并置，**无连续两个 tell-only 区块**。引用段虽是文字但属证言类证据，前后均被 show 区夹住。

### ⑥ 承诺阶梯

`看证据（免费注意力）→ 点 CTA（零成本意图）→ 下载免费版（行为承诺，不注册）→ 用后自升 Pro（页面只做暗示不跪求）`。问答块在承诺前集中排疑，CTA 页脚不再追加新主张。

## 5. 方向卡 + 风格案名（R21 十问收敛，B86 词）

### 方向卡

- 【页面目标】转化+信任；【核心任务】10 秒确认"为我做的、且在真用的安静工具"
- 【核心概念】**深夜书房里被照亮的那一块**——钨丝灯下，稿纸发光，其余退入墨色
- 【气质三词】克制 / 笃定 / 有体温
- 【视觉隐喻】墨夜·钨丝灯·稿纸（来源色板直译场景，不取抽象色名）
- 【参考锚点】要像 iA Writer 的单一主张、文学杂志夜读版的纸墨温度；**不要**暗色 SaaS 的霓虹辉光、紫蓝渐变、玻璃卡片阵列
- 【反面清单点名】紫蓝渐变 / 三圆角特性卡 / 霓虹 glow / 居中大 hero 双按钮 / logo 墙 / 滚动指示箭头 / 01·02·03 装饰编号 / "赋能·神器"文案
- 【十问答案】① 暗夜编辑极简（dark editorial）② 主视觉=被照亮的稿纸窗（hero 大证据件）③ 配色=来源色板「墨夜+钨丝+稿纸」，琥珀仅动作岗 ④ 字体=宋体表达层/系统 sans 界面层/mono 数据层 ⑤ 动效=双轨：表现轨仅 hero 点灯 1 次，生产轨 150ms ⑥ 纯 2D ⑦ 无 shader ⑧ 无粒子 ⑨ 首屏=左题组右亮窗，窗口占视觉主峰 ⑩ 压缩论证链线性
- 【视觉母题】**"被照亮的一块"**——hero 亮窗 → 三个特性各一块稿纸证据面 → CTA 整幅稿纸，同一母题放大收束（B80：收束回应开场）
- 【密度梯度】顶栏 L3 → hero L1.5 呼吸峰 → 特性区 L2.5-3 → 问答 L3 → CTA 放开 → 页脚 L3（B86 密度梯度+呼吸峰）
- 【人性词】照管感：崩溃恢复、不注册、本地存储状态栏明示；优雅失败：迁移问答"删了也不伤原文"

### 风格案名

> **「深夜书房 NIGHT DESK」**——夜是 #16120D 的墨，光是 #D9A24B 的钨丝，稿纸 #F2EDDF 只在被照亮的地方出现。全页只允许一件事发光：稿纸。

### K·密度节奏与呼吸峰（K18）

呼吸峰=hero（L1.5，padding 放量+题组 3 行短文案）；特性区收紧至 L2.5-3（证据面内部 mono 高密度反衬）；问答五连 L3；CTA 放开为收尾印象。

### K·视觉职责分工（K18）

- 色→岗：琥珀=动作/命中岗（CTA、搜索命中、热节点，不挪装饰）；墨夜=底；稿纸=证据面与收口；`--amber-p:#8A5A1B` 为纸面专用深钨（跨底校准 ≈5.3:1，R20#37）。
- 字→岗：宋体=表达（h1/h2/引文）；sans=界面（正文/按钮/导航）；mono=数据（kicker/时序/ms 数/版本/状态栏/图谱 meta）。
- 闲员审计：噪点=纸感、hairline=分隔、lamp=光源叙事、caret=写作心跳——全部有岗。

### K·动效性格与双轨预算（K18）

| 决策点 | Decision | Spec |
|---|---|---|
| ① 分轨 | productive=hover/focus/按压 150ms；expressive=仅 hero 点灯 1 次 | `@media (hover:hover)` 内 transition .15s |
| ② 表现轨配额 | 1 处编排（kicker→题组两行 mask→deck→CTA→lamp→窗→图注 ≈1.8s） | `.js .hero` keyframes 序列 w2.html:345-353 |
| ③ 性格 | 从容笃定：入场 600-1700ms `--ease:cubic-bezier(.19,1,.22,1)`；交互 150ms 无回弹 | 单一签名缓动 token |
| ④ 一致 | 入场统一 rise/fade/lampOn 三式；位移 16-28px；滚动入场只播一次 | IO `.reveal→.in` |

### K3·悬停与触屏

① hover 承载物全为装饰性（位移/变色），无 hover 独占信息；② `@media (hover:hover) and (pointer:fine)` 隔离 hover；③ 触控目标 ≥44px（`.btn--sm` min-height:44px，修复#3）。

### K6·滚动工程

仅取锚点偏移 `scroll-padding-top:88px`（w2.html:50）；无 snap/pin/jacking；横滑容器 `.gmap .scroll{overflow-x:auto}` 用于移动端图谱（:278）。

- K·悬停意图/延迟：无悬停展开 UI → N/A
- K·语义色：琥珀非语义红绿体系，无表单场景 → 已标注

### R 条目（含必备三类，≤8）

1. **主视觉**：被照亮稿纸窗——`.lamp` 钨丝辉光 + `.win` 纸面实体，hero 唯一主峰
2. CJK 编辑排印：宋体题组 + mask-up 入场（`.line>span` 双行统一遮罩）
3. mono 数据层：时序/ms/字数/版本全走 mono，与宋体形成张力
4. 动效签名：1 条缓动曲线 + 入场三式；持续动效仅 blink
5. **降级**：`prefers-reduced-motion` 全灭动画（:366-368 `*{animation:none!important}`）+ `.js` 按 reduced-motion 早挂（:11），无 JS 全可见
6. **无障碍**：AA 对比（纸面强调色用 `--amber-p` 深钨校准）、focus-visible 双底分色（:62,:64）、skip link、`role="img"`+aria-label 图谱（:601）

- **R2 UX/内容**：结构卡逐块报岗落地：勾住(hero)→定向(kicker)→证明(大窗+时序+搜索)→深化(图谱/引文)→排疑(五问)→收口(亮面 CTA)；全页真实中文，数字可互验（0.8s/18ms/214 篇/v2.4.1）；无黑话。✅
- **R3 交互/响应式**：hover 全隔离生产轨 150ms；IO 入场一次；375px 真机宽度下五块证据面全在、无意外横向裁切（仅 top/CTA 有意满幅）；破格 1319 回流。✅
- **R4 工程/a11y**：标签配平机检全过（section7/7 div47/47 等 26 类）；`node --check` 内联 JS 通过；无 lorem/外链资源（唯一 link 为 data-URI favicon）；skip link+地标+aria-labelledby+`role="img"` 图谱+time datetime。✅
- **R5 原创性**：遮 logo 可辨组合=墨夜×钨丝×稿纸三色源 + "亮块"母题 + mono 数据证据件 + 编辑边注破格；非"暗色 SaaS 霓虹/紫渐变/三圆角卡"任何已知组合；与 W1 的纸白"案上墨"形成昼夜双案。✅

## 8. 验证方式与证据

**代码审查**：结构卡逐块对照 DOM（每 show 证据件确在文档流）；对比度按 sRGB 混合估算并校准纸面强调色；K18 配额逐项对选择器计数。

**无头断言（Chrome headless）**：

- DOM 探针实测几何：`.win` y607 h356 bg=rgb(242,237,223) 亮窗在屏；`.cta` y5267 h553 bg=paper——五块"亮稿纸"全部实体渲染
- 像素断言（reduced-motion 稳态截帧 1440×6100）：亮带 = hero窗790-1170 / 特性1面板1410-1660 / 特性2面板1980-2380 / 特性3面板3080-3280 / **CTA整面5210-5880**；琥珀像素集中于 y600(CTA)/y2000(命中高亮)/y3400(热节点)，与设计配额一致
