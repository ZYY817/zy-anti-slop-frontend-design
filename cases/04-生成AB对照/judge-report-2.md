## 维度 5｜动效设计（时间、曲线、节奏）

- 症状：面板出场 scale .97+translateY(-6px) 标准安全牌，无 stagger 编排（D 有）

**armD ＝ 8.5 / 10**

- 证据：面板 .3s ease + 条目共 26ms/i stagger 入场编排（L136-137）——比 C 多一层进场仪式感；新条目 `freshIn` 0.8s 高亮扫过（L198-203）；徽标 pop 回弹（L108-109）、铃铛 ring（L110-115）；toast 进度条用 WAAPI `.animate`（L763-766）——计时与进度天然同源；hover 暂停 `anim.pause()`（L770-771）✅；reduced-motion CSS 降级（L422-424）

**两句对比**：C 强在"语义正确"——每条动效有理由（铃摆=到达、flash=定位反馈）、双端降级、全部参数 token 化。D 强在"编排更花"——stagger 入场、fresh 扫光、WAAPI 进度条同源的实现方式甚至更优雅，但降级只做了 CSS 半边。

## 特别加答：第一眼"成品感"

- **armC：9/10**。像真实产品。依据：①配色有明确"说法"——青瓷台账方向（雾底/纸面/松墨/朱砂专司未读）是艺术指导级别的分工而非"选了个好看色"；②三字体系统（serif 展示/mono 元数据/sans 正文）是出版物级排印纪律；③装饰预算=1（页顶光晕）+发丝线分隔，哑光质感，密度紧凑克制——气质接近 Linear/Workbench 类效率工具的笃定感。
- **armD：8/10**。像高完成度模板/成熟消费级产品。依据：①暖纸+柿子红+玉绿的配色方向同样成立且更亲和；②单条目工艺（类型徽章头像、引用块、chip 行）甚至更精；但③字体纯系统栈无展示层、圆角普遍大一号偏"友好圆润"、左下常驻 demo 脉冲按钮是脚手架痕迹——离"产品"差一口气，遮 logo 后的辨识度弱于 C。
