## 诚实的三层解读

### 1. 知识库确实提升产出，且增益精确落在词条覆盖处

最大分差在**行为细节维（6→9，+3）**——V1 的 K14 打断分级（仅 @提及/指派升 toast，其余静默徽标+1）、5s 合并窗、6s 撤销 toast（K12）、overscroll contain（K6）、Esc 分层+焦点归还（B76）、announcer 播报全部落地。V0 的丢分几乎全是"想不到要决定的事"：toast 无队列无分级、全部已读无撤销、`innerHTML` 全量重建丢滚动位置、布局动画用 max-height、触屏 hover 独占。

**这正是词条层的设计意图**：K 词条不告诉你答案，它告诉你"有哪些点必须给答案"——裸模型丢分丢在根本没想到要问。

### 2. 但两组 P0 都是 0——别夸大增益

裸模型产出不是坏的，是**薄的**。主路径（展开/分组/标已读/全部已读/到达提示）两臂都完整可用。知识库把 62 分的东西提到 73.5 分，是深度和细节增益，不是"能不能用"的差别。对外表述不许说"没有库就做不出能用的"。

### 3. 两个反向信号值得正视

- **V0 唯一赢的维度是信息设计（8→7）**——V0 的文案更丰（引用块全文/截止 chip/"仅保留 30 天"说明）。V1 精力都投在行为决策上，内容策略相对薄——**库对"内容做得更丰富"没有推动作用**（C6 未被命中权重），这是下次检索权重调优的信号。
- **V1 照样有真缺陷**：死链（viewAll）、`.lede` 自违 token 对比度、Esc 一键关两层偏离栈顶、excerpt 截断。知识库防不了执行错误——Z3 自检抓到了 12 处但没抓全。**词条降低"没想到"的错误，不消除"想到了没做对"的错误。**

## 第二轮：用户目测触发的管线修复 + 复验（V1b）

**触发**：用户看 compare.html 指出"V0 比 V1 好看"——与盲审"视觉 8 vs 7 接近"的结论方向一致：V1 赢了行为但没赢眼球。

**根因与修复**（见计划文档第九轮）：
- Z2 §二点五 R 闸门：常规 UI 行改为"**必答 Z1 第0层轻量方向卡**"（气质三词/配色来源/材质档/反面清单）——闸门管效果词不管视觉方向，此前"不用 R"被执行为"不做视觉决策"
- brief.md：加"范围钉死"（产品页内嵌 vs 组件底座不分导致对比失真）
- K10 维度 1：加"品质判定"行（成品 vs 作业，非仅合规）

**复验**：V1b = 同任务书 + 更新后管线重跑 → 新盲审（armC/armD 匿名，judger 独立上下文）。

| | V0（armD） | V1b（armC） |
|---|---|---|
| 总分 | 71.0 | **79.5**（+8.5） |
| 视觉设计 | 8.0 | **9.0** |
| 行为细节 | 7.0 | **9.5** |
| P0 | 0 | 0 |

裁判结论："C（V1b）看着笃定、用着无缝；D（V0）看着惊艳、用着有缝"——V1b 产出青瓷台账配色（朱砂专司未读）+ 三字体纪律，**视觉维从持平变反超**，行为维优势保持。

**结论**：方向卡补丁有效——"正确但冷"缺口在管线层被关闭。诚实标注：两轮裁判不同、绝对分不可跨轮比，只看轮内相对差与维度格局；A/B 证据仍为指示性。
