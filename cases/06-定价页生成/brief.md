# 任务书：墨迹（Inkwell）定价页

## 产品背景
墨迹是一款本地优先的 Markdown 笔记应用（case05 已建落地页，本任务独立交付定价页）。
- 定位：写给"认真写字的人"——作家、研究者、深度工作者
- 卖点：打开即写（<300ms 启动）、全文检索毫秒级、双向链接、本地文件为唯一事实源、无订阅锁定可导出

## 定价结构（真实信息，必须用）
- **Free**：无限笔记、全文检索、单设备 —— 永久免费
- **Pro ¥68/年**：多设备同步、版本历史（30 天）、PDF/Docx 导出、主题商店
- **Studio ¥168/年**：Pro 全部 + 协作工作区（≤10 人）、API 访问、优先支持、白标导出
- 年付即上述价；月付 Pro ¥8、Studio ¥18
- **不买断、不画大饼**——产品哲学是"订阅只为同步与协作付费，本地功能永远免费"

## 要求
- 单个自包含 HTML 文件（内联 CSS/JS，无外部依赖除字体外）
- 定价卡 + 功能对比 + FAQ + 页脚 CTA 的完整页面
- 所有交互必须真实可用（月付/年付切换、FAQ 折叠、CTA 指向真实锚点/链接，禁死控件）
- 移动 375px 与桌面 1280px 均可用
- 中文为主，英文点缀
