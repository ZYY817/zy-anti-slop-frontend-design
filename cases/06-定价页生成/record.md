# case06 · 定价页（货架页）生成记录

**目的**：冷启动验证——清洗后的词库体系，全新 agent 只给 AGENTS.md 入口能否自行完成"检索→结构卡→方向卡→词条决策→审计→实修"全链路；同时用新任务类型（货架页，非落地页）测试 B87 页面类型选型。

## 实验设置

| 方案 | 条件 | 文件 |
|---|---|---|
| armM (=w0) | 只给任务书，无任何指引（但在仓库目录工作） | `w0.html` / `w0-trace.md` |
| armN (=w1) | 给任务书+"必须先读 AGENTS.md 并按协议执行" | `w1.html` / `w1-trace.md` |

任务书：`brief.md`（墨迹 Inkwell 三档定价页，含真实价格与产品哲学）。

## 关键过程发现

1. **W0 自我武装**：未获指引的 agent 在仓库目录主动读取 case05 成果与 B87——"价目单"方案明显受库影响。实验条件被污染，无真裸跑基线；但反向证明**库的可发现性不靠协议也生效**（目录结构+文档命名本身在指路）。
2. **W1 协议执行是目前最强 trace**：读 10 篇（不超载）→ 结构卡先于方向卡 → K18 五组决策点逐项作答 → **正确判断货架页不开 R 闸** → Z3/K10 实修 11 项（5P1+5P2+1P3）→ 自跑 verify.py+无头探针。"在合适的时候用词"的反面也验证了：不该用的词（R 板块）它没用。
3. **两方案同系异构**：都延续了"深夜书房"色系但案名/隐喻不同——M"灯下价目单"（整张稿纸一张价目单）vs N"灯下账本"（三暗卡+Pro 亮卡破格）。库产出的是方向约束而非单一模板。

## verify.py 实测（真实检查，非代码审查）

| | armM | armN |

| reduced-motion | ✓ | ✓ |

**verify.py 独立抓到了与盲审相同的 P0**——W0 trace 自称"零死控件"但下载链接指向的磁盘文件不存在。真实测试能抓到 trace 自述里的谎。

## 盲审结果（评审只看 armM/armN 中性名）

| 维度 | armM | armN |
|---|---|---|
| 信息设计 | 9.5 | 9 |
| 视觉 | 9.5 | 8.5 |
| 工程真实 | 9 | 9 |
| 真实感 | 6.5 | 8.5 |
| **总分** | **34.5** | **35** |

**判决：armN 险胜 0.5 分。** M 赢在 signature 原创性（"一张被照亮的价目单"比"推荐卡发光"少见）+ 无 JS 也能切价的渐进增强；**M 输在真实感 P0**——货架页主转化出口（两个下载按钮）指向不存在文件，把视觉原创挣的分送了回去。N 赢在交互更彻底（切月付连 CTA 文案都联动）、语义更正（fieldset+legend）、"—"过 AA、零外部依赖。

评审实测细节：M 的 `:has()` 纯 CSS 换价无 JS 可切（¥8/¥18 正确显示）；N 切月付后价格/单位/副文案/CTA `cycle=` 参数/按钮文案全联动；两页 375px 均零横向溢出。

## 结论

- **冷启动验证 ✅**：新 agent 仅凭 AGENTS.md 走完全链路且执行质量高——检索克制、结构卡前置、词条逐项作答、R 闸门正确关闭、审计实修而非承诺。
- **货架页选型 ✅**：B87 页面类型词被双方正确取用（比较便利>叙事）。
- **残余盲区 → 反哺点**：两份方案都把"下载/结算"写成了不存在的文件或外链——库的 CTA 词条管"指向真锚点"但**管不到"锚点外的资源是否真实存在"**。这已进 B44 排雷清单候选（见升级日志第十八轮）。
- 分差收窄（0.5 vs case05 的 15）是因对照组也武装了；本轮不说明"武装边际收益小"，说明**库的存在本身就会抬升同目录产出的下限**。
