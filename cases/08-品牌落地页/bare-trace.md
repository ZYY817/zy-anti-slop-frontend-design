# 山雾 Mistveil · bare.html 制作纪要

## 方向
整页 = 一条「下山路」：首屏站在云海之上（2600m），滚动即下降——
冷杉 2400m → 野姜花 1800m → 岩兰草 1200m →「半山」香薰机 900m →
页脚抵达山脚 600m。海拔是贯穿全页的空间叙事，不只是文案。

## 关键决策
- 左侧固定「海拔标尺」：刻度 + 随滚动实时移动的读数；移动端收进顶部
  野外台站遥测条（坐标 / 日出 06:47 / 雾浓度波动 / 实时时钟，JS 驱动）。
- 无图宣言：香型全部 CSS 渲染——描边玻璃瓶 + 渐变「精油」液位
  （滚入时液位缓缓升起）+ 瓶内留一层雾；香薰机 = 渐变圆柱 + 升腾雾羽。
- Signature 时刻：深色「雾间」段落 + 等高线 SVG 暗纹。按住圆钮「息」，
  雾漫上来盖住上半句「看不见山的时候，」，雾满后下半句
  「山离你最近。」在雾上浮现——一句话要靠雾来拼完。松手雾散。
- 竖排描边巨字「山雾」、feTurbulence 纸纹、等宽 tabular-nums 数据字体：
  野外考察日志气质——克制、不仙、不俗。
- 配色近乎单色（暖纸 + 墨黑）；三个香型色只出现在各自「精油」液位里。

## 自查
- 375px：标尺隐藏、遥测精简、竖排转横排缩字、网格全转单列，不破版。
- prefers-reduced-motion：云漂移/视差/液位升起/雾羽全部关停，
  以静态等价呈现；无 JS 时 `.rv` 不隐藏（.js 门控）。
- 无 lorem、无占位图；香型以颜色、排版、器物结构表达。
